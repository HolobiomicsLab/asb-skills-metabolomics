# isotopologue-envelope-extraction

## Summary

Within each khipu empirical compound, connected isotope edges are grouped into per-adduct branches, re-aligned to the khipu grid, and used to extract the isotopologue envelope (e.g. 13C/12C*1, *2, ...) per compound, enabling isotope-index extraction from U-13C-labeled LC-MS data such as the E. coli ecoli_pos.tsv set.

## When to use

Use when khipu has preannotated untargeted metabolomics or stable isotope tracing data (e.g. U-13C E. coli, 548 empCpds from 3,602 asari features) and you need to extract per-compound isotope-index envelopes for downstream labeling analysis.

## When NOT to use

- The input is a raw LC-MS feature table that has not been preannotated by khipu - run khipu first to produce empirical compound trees before extracting isotope envelopes.
- The analysis targets complete metabolite identification requiring authentic standards or tandem MS data; khipu is a preannotation step and complete annotation still needs contaminants, authentic libraries, and tandem MS.
- The study involves chemical derivatization experiments where the origin and derivatized compounds must be linked by a derivatization m/z shift - this requires a separate khipu-tree linking procedure, not this envelope-extraction skill.

## Inputs

- khipu JSON empirical compound (empCpd) trees produced from a feature table (e.g. ecoli_pos.tsv generated by asari v1.9.2)
- Feature table columns: feature ID, m/z, rtime, followed by intensity columns (start/end column configurable)
- Sample-group labels distinguishing unlabeled versus U-13C-labeled (or other tracing) conditions

## Outputs

- Per-compound isotope-index table (e.g. isotope_index_distribution.csv) with one row per empirical compound
- Counts of compounds with multiple isotopes (e.g. 445 of 548 compounds)
- Isotopologue envelope per compound per sample group (M0 vs 13C/12C*n peaks)

## How to apply

Parse the khipu JSON empirical compound trees and separate isotope edges (1.0034 Da 13C/12C spacing) from adduct edges. Isotope edges form groups by shared nodes, each group belonging to one adduct type; each group of connected isotope edges is treated as one 'branch'. Establish the adduct trunk by optimizing the number of nodes explained, then assign each isotopic branch to the adduct trunk and re-align isotopes in all branches against the theoretical khipu grid (M0 through 13C/12C*6 or user-extended patterns) to establish optimal match. The neutral mass of the M0 compound is obtained by linear regression from the matched m/z values. Tabulate the isotope-index distribution per compound across unlabeled versus labeled samples (e.g. three unlabeled and three U-13C-glucose samples) and validate by checking that unlabeled samples peak at M0 while labeled samples peak at the maximum isotope index (e.g. M9 for a 9-carbon compound such as acetylspermidine, C9H21N3O).

## Related tools

- **khipu** (Python package that performs the khipu-tree annotation and provides the empirical compound JSON trees from which isotope branches are extracted and re-aligned to the khipu grid) — https://github.com/shuzhao-li/khipu
- **asari** (Preprocessing tool (v1.9.2) that generated the feature tables (ecoli_pos.tsv, yeast_pos.tsv, yeast_neg.tsv) feeding khipu annotation upstream of envelope extraction) — https://github.com/shuzhao-li/asari
- **mass2chem** (Search-function library used by khipu for matching feature pairs against isotope and adduct patterns during the annotation step) — https://github.com/shuzhao-li-lab/mass2chem
- **Python 3** (Runtime for parsing khipu JSON trees, tabulating isotope-index distributions, and writing the resulting CSV)
- **Jupyter** (Notebook environment for data analysis and visualization of isotopologue envelopes per compound)

## Examples

```
khipu -i testdata/ecoli_pos.tsv -o this_test
```

## Evaluation signals

- The output table contains exactly one row per empirical compound (e.g. 548 rows for the E. coli reverse-phase ESI+ data set).
- The count of compounds with multiple isotopes matches the expected value (445 of 548 for the E. coli data).
- For unlabeled samples the isotopologue envelope peaks at M0, while for U-13C-labeled samples the envelope peaks at the isotope index matching the compound's carbon count (e.g. 13C/12C*9 for a 9-carbon compound like acetylspermidine).
- The inferred neutral mass from linear regression of matched m/z values matches a plausible chemical formula (e.g. 187.1686 matches acetylspermidine C9H21N3O).
- Isotope edges used for extraction correspond to the 1.0034 Da 13C/12C mass difference and each connected group belongs to a single adduct type.

## Limitations

- Annotation of untargeted metabolomics data, including isotopic tracing data, is still not fully solved.
- Search patterns for isotopes are experiment-dependent and must be supplied by the user when the default khipu grid is insufficient.
- Some ions enter the initial network by mistake or as unresolved signals; they are removed from the established khipu and sent off to form a new khipu.
- Complete annotation still requires additional resources (contaminants, authentic libraries, tandem MS data) beyond khipu preannotation.
