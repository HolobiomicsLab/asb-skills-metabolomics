# metabolomic-edge-list-import-processing

## Summary

Import MetaboDirect-generated transformation edge lists (mass-difference links between FT-ICR MS peaks) into Cytoscape, style nodes by molecular class, and compute per-network and per-transformation-type statistics via the pipeline's network_stats.R script, exporting .csv tables and bar plots.

## When to use

Use when you have edge-list files of putative biochemical transformations from FT-ICR MS peak mass differences and need a Cytoscape network plus network statistics tables and plots.

## When NOT to use

- Input is raw FT-ICR MS spectra or a peak abundance table without molecular formula assignments — MetaboDirect expects formulas to be assigned before network generation
- You only need chemodiversity or multivariate statistics; those are separate MetaboDirect pipeline steps (chemodiversity analysis, statistical analysis) and do not involve Cytoscape
- Mass differences were not filtered against reference biochemical transformation keys (1 ppm max error), since unfiltered mass differences would produce spurious edges

## Inputs

- Edge-list files of putative mass-based transformations (mass differences matched to reference biochemical transformation keys at max 1 ppm error)
- Node metadata table of detected FT-ICR MS peaks with assigned molecular formulas and molecular class annotations

## Outputs

- Cytoscape transformation network (.cys) with nodes colored by molecular class via discrete mapping
- Network statistics .csv tables (per-network and per-transformation-type)
- Bar plot image files summarizing network metrics

## How to apply

Load the edge-list files produced by the transformation calculation phase — mass differences retained with a maximum error of 1 ppm against reference biochemical transformation keys — into Cytoscape (3.8+, with the FileTransfer app for py4cytoscape connectivity). Import the node metadata table of detected peaks with assigned molecular formulas and map node fill color to molecular class using a discrete color-mapping visual style, then apply a force-directed layout so that nodes represent detected peaks and edges represent putative chemical transformations. Run the network_stats.R script generated by MetaboDirect (R 4+, tidyverse) on the network files to compute per-network and per-transformation-type statistics. Export the statistics as .csv tables and render bar plots summarizing network metrics as image files.

## Related tools

- **MetaboDirect** (Generates the transformation edge-list files and the network_stats.R script consumed by this skill) — https://github.com/Coayala/MetaboDirect
- **Cytoscape** (Imports the edge lists as a network, applies the molecular-class visual style and force-directed layout (3.8+ with FileTransfer app))
- **py4cytoscape** (Python module MetaboDirect requires for programmatic interaction with Cytoscape during network import and styling)
- **pandas** (Used by MetaboDirect to build/export the edge-list and node metadata tables)
- **R / tidyverse** (Runs the generated network_stats.R script to compute network statistics and render bar plots)

## Examples

```
Rscript network_stats.R
```

## Evaluation signals

- Every edge in the imported network corresponds to a mass difference whose error against a reference biochemical transformation key is ≤ 1 ppm
- Nodes in the exported .cys carry molecular-class fill color from the discrete mapping — unassigned or uncolored nodes indicate the node metadata table was not mapped correctly
- The .csv statistics tables contain both per-network and per-transformation-type summaries; missing per-transformation rows indicate the network files passed to network_stats.R were incomplete
- Bar plot image files are produced alongside the .csv tables and their metric values match the corresponding .csv entries
- The Cytoscape session was applied with a force-directed layout rather than a default grid layout

## Limitations

- Transformation networks are ab initio mass-difference-based; edges are putative chemical transformations, not confirmed reactions
- Cytoscape must be installed (3.8+) with the FileTransfer app, and both R (4+) and Python (3.5+) dependencies must be present for the full workflow
- Peaks with isotopic-carbon formulas and other filtered masses are excluded upstream, so the network only reflects peaks surviving the pipeline's filters (e.g., ~200 isotopic-carbon masses removed in the bacterium-phage data set)
