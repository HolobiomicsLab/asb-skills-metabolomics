# lipid-spectra-library-formatting

## Summary

Export the lipid spectra generated by the Lipid Spectrum Generator as a spectral-library file using the '.MSP' extension, the format consumed by LC-MS/MS lipid identification search engines. Alternatives (.CSV precursor/transition lists) are handled separately.

## When to use

Use when a completed Lipid Spectrum Generator run (lipids enumerated by class and fatty-acid composition, spectra per adduct) must be written out as a '.MSP' spectral library for downstream LC-MS/MS lipid identification.

## When NOT to use

- The goal is an Excalibur-compatible precursor list for Orbitrap DDA analysis or a Skyline-compatible transition list — in that case select '.CSV' instead of '.MSP'.
- Only experimental (non-in-silico) spectra are involved and no on-demand spectral library generation by lipid class, fatty acid composition, or adduct is needed.

## Inputs

- Generated lipid spectra from the Lipid Spectrum Generator (organized by lipid class, fatty acid composition, and adduct)
- Export-format selection within the Lipid Spectrum Generator ('.MSP' for spectral libraries)

## Outputs

- A single '.MSP' spectral-library file containing the generated in silico lipid fragmentation spectra

## How to apply

Assemble the generated lipid spectra, which the Lipid Spectrum Generator produces by enumerating lipids with respect to lipid class and fatty acid composition and then generating spectra for each allowed adduct. Format each entry according to the MSP spectral-library convention recognized by LC-MS/MS search engines. Write all formatted spectrum entries into a single file, choosing the '.MSP' file extension in the export selector — this is the tool's primary spectral-library export path. Do not select '.CSV' unless the goal is an Excalibur-compatible precursor list (for Orbitrap DDA analysis) or a Skyline-compatible transition list instead of a searchable spectral library.

## Related tools

- **Lipid Spectrum Generator** (Generates the in silico lipid fragmentation spectra and performs the '.MSP' export when the .MSP extension is selected) — https://github.com/98104781/LSG
- **Python** (Implementation language used to run the generator script and its export path)

## Evaluation signals

- The exported file carries the '.MSP' file extension and parses as a valid MSP spectral library.
- Every enumerated lipid (per class and fatty acid composition) and its adduct spectra are represented in the exported library.
- Choosing '.CSV' yields an Excalibur precursor list or Skyline transition list instead — if that output appears, the wrong export option was selected for spectral-library generation.
- Fragmentation patterns in the exported spectra match the peer-reviewed fragmentation patterns used by the generator.

## Limitations

- Generated spectra are in silico and derive from peer-reviewed fragmentation-pattern studies, so they may not capture every experimentally observed fragment.
- The '.MSP' route exports spectra only; precursor lists (Orbitrap DDA) and transition lists (Skyline) require the separate '.CSV' export.
