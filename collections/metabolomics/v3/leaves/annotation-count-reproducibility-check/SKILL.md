# Annotation-count reproducibility check

## Summary

Validates that a khipu preannotation run reproduces the published E. coli ESI+ benchmark by comparing empirical compound counts, grouped/singleton feature counts, and isotope-bearing compound counts against the reference numbers from Li & Zheng (2023).

## When to use

Use when a khipu run on a reference feature table (e.g. ecoli_pos.tsv from asari v1.9.2) must be verified before the annotations are used downstream, or when confirming a new khipu install/setup behaves identically to the published 548-empirical-compound result.

## When NOT to use

- When the input feature table is not the E. coli ESI+ reference dataset — different datasets (e.g. yeast ESI+/ESI− with 1,775/908 empirical compounds) have their own expected counts, so the 548/1,745/1,857/445 benchmark does not apply
- When the goal is a downstream annotation quality assessment (e.g. confirming acetylspermidine assignment with tandem MS/authentic standards) rather than reproducing the tool's tree-building counts
- When the input table comes from a preprocessing tool other than asari 1.9.2 — column positions and feature definitions may differ, making count comparisons unreliable

## Inputs

- Feature table testdata/ecoli_pos.tsv (tab-delimited; columns feature ID, m/z, rtime, then intensities; 3,602 features; generated by asari v1.9.2)
- this_test.json (khipu transparent JSON empCpd format output from a khipu run)
- this_test.tsv (tab-delimited khipu output table from the same run)

## Outputs

- Count of empirical compounds in the output JSON (expected 548)
- Count of grouped features summed over empirical compounds (expected 1,745 of 3,602)
- Count of singleton features (expected 1,857)
- Count of empirical compounds with multiple isotopes (expected 445)
- Pass/fail verdict per count against the published benchmark

## How to apply

Run khipu as a command-line tool on the E. coli positive-mode feature table (testdata/ecoli_pos.tsv, 3,602 features generated by asari 1.9.2) with the default positive-mode parameter set that includes 13C isotope tracking (13C/12C mass difference 1.0034) and adduct patterns (e.g. 22.9893 for M+Na+). Export results to this_test.json and this_test.tsv, then parse the JSON empCpd objects and count: total empirical compounds, features included in compounds, singleton features, and compounds with multiple isotopes. Compare each count to the published reference values — exactly 548 empirical compounds, 1,745 of 3,602 features grouped, 1,857 singletons, and 445 empirical compounds with multiple isotopes. Rationale: these counts capture the tree-construction outcome (DAG conversion, isotope-branch alignment to the adduct trunk, neutral-mass regression), so deviation on any count signals a khipu version, parameter, or input-column mismatch rather than a benign numeric difference.

## Related tools

- **khipu** (Command-line preannotation tool whose output JSON/TSV is parsed and counted; the check verifies its tree-grouping pipeline (mass distance network → DAG → khipu grid alignment) against the published counts) — https://github.com/shuzhao-li/khipu
- **asari** (Preprocessing tool that generated the reference feature table ecoli_pos.tsv; version 1.9.2 must match to keep the benchmark comparable) — https://github.com/shuzhao-li/asari

## Examples

```
khipu -i testdata/ecoli_pos.tsv -o this_test && python3 -c "import json; d=json.load(open('this_test.json')); print(len(d))"  # expect 548
```

## Evaluation signals

- Total empirical compound count in this_test.json equals exactly 548 (no rounding, no off-by-one)
- Sum of features assigned across compounds equals 1,745 out of 3,602 input features
- Singleton feature count equals 1,857, and 1,745 + 1,857 = 3,602 (accounts for every input feature)
- Count of empirical compounds with multiple isotopes equals 445
- Output files this_test.json and this_test.tsv both exist and the JSON parses as a list of empCpd objects with neutral mass fields populated

## Limitations

- The published counts were produced with asari 1.9.2 and the E. coli ESI+ table; other feature-table formats or preprocessing versions may shift counts without indicating a khipu bug
- Different applications (isotope tracing, chemical derivatization) may require different parameters, so the default ESI+ benchmark is not universal
- Count agreement alone does not guarantee correct chemical assignment — the article notes complete annotation requires contaminants, authentic libraries, and tandem MS data beyond khipu preannotation

- [methods] Khipu annotated 548 empirical compounds from 1,745 of 3,602 LC-MS features in the E. coli reverse phase ESI+ data: "3,602 LC-MS features were measured, and khipu annotated 548 empirical compounds (trees) from 1,745 features."
- [readme] Reproduce khipu preannotation benchmark counts: "khipu -i testdata/ecoli_pos.tsv -o this_test

This will output pre-annotation to two files of JSON and tab delimited formats, this_test.json and this_test.tsv."
- [methods] Preprocessing version that generated the reference table: "All data sets were processed using asari21 version 1.9.2."
- [methods] Parameter basis for the default isotope/adduct patterns: "Annotation methods in MS metabolomics commonly start by searching mass difference patterns, e.g. 1.0034 for 13C/12C in isotopes and 22.9893 for Na+ in adducts."
