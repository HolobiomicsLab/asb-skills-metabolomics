# mass-spectrometry-feature-annotation-parsing

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Parses deposited LC-HRMS feature/annotation files (m/z and retention-time pairs) from the PharmMet DB workflow and joins them with a drug-class mapping table to aggregate unpredicted metabolite features per therapeutic class.

## When to use

Use when deposited LC-HRMS feature tables need to be parsed, joined with sample metadata or a drug-class mapping, and aggregated into per-feature or per-class counts of unpredicted metabolites.

## When NOT to use

- Input is already a curated metabolite-identification result table (not raw feature m/z/RT pairs)
- Goal is spectral matching or MS2 fragment annotation rather than parsing m/z/RT pairs and aggregating counts
- The parent-drug assignment metadata is missing or ambiguous, so the join would be unreliable

## Inputs

- ST003991 feature/annotation files from the Metabolomics Workbench project (DOI: 10.21228/M8W55K), containing m/z and retention time pairs for unpredicted metabolites detected at 24 hours
- Supplemental Table 1 drug-class mapping from the PharmMet GitHub repository, assigning each of the 1114 therapeutic drugs to its therapeutic class
- Sample/plate metadata in the deposited files linking each feature to its parent drug incubation

## Outputs

- Per-drug-class counts of unpredicted LC-HRMS features (expected total: 486,215, with anti-inflammatory 126,210, antimicrobial 100,617, cardiovascular 88,653, CNS 62,693)
- Joined table of unpredicted features mapped to parent drug and therapeutic class

## How to apply

Download the ST003991 feature/annotation files from the Metabolomics Workbench project, which contain paired m/z and RT entries for unpredicted metabolites detected at 24 hours. Load Supplemental Table 1 from the PharmMet GitHub repository that assigns each of the 1114 therapeutic drugs to its therapeutic class. Join each unpredicted feature to its parent drug incubation using the sample/plate metadata in the deposited files. Use R 4.0.3 to aggregate the joined table, counting unpredicted features per parent drug and then per therapeutic class, verifying the grand total equals 486,215. The aggregation should reproduce the reported distribution in which 89% of tested drugs produced at least one metabolite not predicted by BioTransformer 3.0, with the most unpredicted features from anti-inflammatory/immunomodulatory (126,210), antimicrobial (100,617), cardiovascular (88,653), and CNS (62,693) drugs.

## Related tools

- **R 4.0.3** (Used to perform the statistical aggregation and data visualization when joining the deposited feature table to the drug-class mapping)
- **GraphPad Prism 6.0** (Used alongside R 4.0.3 for statistical analysis and visualization of the aggregated per-class feature counts)
- **PharmMet DB** (Reference resource that provides the experimentally validated drug metabolite data and the Supplemental Table 1 drug-class mapping used for the join) — https://github.com/ClinicalBiomarkersLaborabory/PharmMet
- **BioTransformer 3.0** (Provides the in silico predicted metabolite set against which detected LC-HRMS features are compared to classify them as unpredicted)

## Examples

```
Rscript count_unpredicted_per_class.R --feature-table ST003991_features.tsv --drug-classes SupplementalTable1.tsv --metadata sample_plate_metadata.tsv --output unpredicted_counts_per_class.csv
```

## Evaluation signals

- The aggregated grand total of unpredicted features must equal 486,215
- Per-class counts must match the reported distribution: anti-inflammatory/immunomodulatory 126,210, antimicrobial 100,617, cardiovascular 88,653, CNS 62,693
- The fraction of drugs yielding at least one unpredicted feature must be 89% of the 1114 tested drugs
- Every unpredicted feature must be successfully joined to a parent drug and a therapeutic class before aggregation
- All counted features must be detected at the 24-hour time point and absent at 0-hour (differential comparison)

## Limitations

- Unpredicted features are only detected by differential comparison of 0-hour vs 24-hour samples, so metabolites already present in the starting drug mixture are missed
- Detection depends on ionization and cofactor conditions in the S9 assay; limited cofactor availability or ionization suppression may reduce apparent counts
- Novel metabolites require further isolation and structural elucidation; the counts represent feature-level aggregates, not confirmed molecular identities
