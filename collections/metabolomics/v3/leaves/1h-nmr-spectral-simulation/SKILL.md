# 1h-nmr-spectral-simulation

## Summary

Simulate realistic metabolomic 1H NMR spectra (1D and 2D J-Res/COSY) for urine, blood, and CSF using MetAssimulo 2.0, a Python-based Dash web app that supports single and grouped spectra with discrete (case-control) and continuous (e.g. BMI) outcomes and inter-metabolite correlations.

## When to use

Use when you need synthetic 1D 1H NMR metabolomic spectra (urine, blood plasma, or CSF) with known ground-truth metabolite concentrations and outcome labels for algorithm development, benchmarking, or method validation.

## When NOT to use

- You already have real measured 1H NMR spectra with known outcome labels — simulation is intended for cases where real spectral data are unavailable for algorithm development
- You need spectra for biofluids other than urine, blood, or cerebral spinal fluid, or nuclei other than 1H — these are outside MetAssimulo 2.0's scope
- You need MS or chromatography data simulation — this skill covers only NMR spectral simulation

## Inputs

- Input/parameters.txt simulation configuration (biofluid, spectrum type, metabolite list, concentrations, outcome model)
- Metabolite reference 1H NMR spectra (MetaboLights accession MTBLS12081)
- Simulation input data archive (Input.zip from Google Drive, fetched via gdown)
- Optional real reference spectra (e.g. real blood 1D 1H NMR spectrum) for validation

## Outputs

- Simulated 1D (and optionally 2D J-Res/COSY) 1H NMR spectra of urine, blood, or CSF
- Grouped-spectra matrices (e.g. 100 replicates x spectral buckets/ppm variables) with associated discrete or continuous outcome values
- Validation metrics such as Pearson correlation (~0.82) between simulated and real blood spectra

## How to apply

Clone the MetAssimulo_2 repository and download the Input data archive via gdown, then create the py37_metassimulo_2_env conda environment from environment.yml. Set PYTHONPATH to the repo root and launch the app with 'python3 apps/index.py -p Input/parameters.txt'; the Dash app serves at http://127.0.0.1:8060/. Configure the simulation in Input/parameters.txt: choose biofluid (urine, blood, CSF), 1D or 2D spectrum type, and either a single spectrum or a group of replicates (e.g. 100 blood mixtures) with outcomes generated by a linear regression model against a continuous variable such as BMI. For blood simulations, enable the broad protein (albumin) background, which is what makes simulated blood spectra approximate real ones (Pearson correlation ~0.82). Export the simulated spectra matrix (samples x spectral buckets/ppm variables) with associated outcome values for downstream analysis such as PCA; metabolite spectral data are deposited at MetaboLights MTBLS12081.

## Evaluation signals

- The Dash app reports 'Dash is running on http://127.0.0.1:8060/' after launch, and the URL serves the simulation interface
- Blood simulations with the broad protein (albumin) background enabled yield a Pearson correlation of approximately 0.82 against a real blood spectrum
- For the BMI continuous-outcome simulation, PCA on 100 simulated blood spectra shows PC2 capturing most BMI-related variance, with lactate having the largest absolute PC2 loading
- The Input folder with parameters.txt exists after gdown download and unzip, and the app runs without PYTHONPATH/module errors
- Exported spectra matrices have the expected shape (e.g. 100 samples x spectral bucket variables) with outcome values aligned per replicate

## Limitations

- Realism of blood spectra depends on the broad protein background enhancement; without it, simulated blood spectra are a poorer approximation of real blood spectra
- Simulation scope is limited to urine, blood, and cerebral spinal fluid and 1H NMR (1D plus 2D J-Res and COSY); other biofluids/modalities are not supported
- Requires a Python 3.7 conda environment (py37_metassimulo_2_env) and a Google Drive download step, so setup can fail if the Drive link or network is unavailable
