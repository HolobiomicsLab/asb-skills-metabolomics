# msp-file-export

## Summary

Exports spectra generated by the Lipid Spectrum Generator into a '.MSP' spectral-library file, the tool's primary output format for downstream LC-MS/MS lipid identification.

## When to use

Use when generated in silico lipid spectra (by lipid class, fatty acid composition, and adduct) must be written out as a spectral library consumable by LC-MS/MS search engines, i.e. an '.MSP' file.

## When NOT to use

- When an Excalibur-compatible precursor list for DDA analysis via Orbitrap or a Skyline-compatible transition list is required — select '.CSV' instead of '.MSP'.
- When the input is raw MS data or an existing spectral library rather than spectra generated by the Lipid Spectrum Generator.

## Inputs

- Generated lipid spectra from the Lipid Spectrum Generator (organized by lipid class, fatty acid composition, and adduct)

## Outputs

- A single '.MSP' spectral-library file containing all generated lipid spectra

## How to apply

Collect the lipid spectra the Lipid Spectrum Generator has assembled, where lipids are generated with respect to class and fatty acid composition and spectra are generated with respect to their adducts. In the tool's export step, choose the '.MSP' file extension as the export format; this is the path designated for spectral-library output. Each spectrum entry is written according to the MSP convention into a single output file. Note the decision point: if a precursor list for DDA analysis via Orbitrap (Excalibur-compatible) or a Skyline-compatible transition list is needed instead, select '.CSV' rather than '.MSP'.

## Related tools

- **Lipid Spectrum Generator** (Open-source in silico spectral library generator whose export step writes the '.MSP' file when that extension is selected) — https://github.com/98104781/LSG
- **Python** (Language in which the Lipid Spectrum Generator script is implemented and run to produce the exported library)

## Evaluation signals

- The exported file carries the '.MSP' extension and parses as a valid MSP spectral library.
- Every generated lipid spectrum (per class, fatty acid composition, and adduct) appears as an entry in the exported file — no entries dropped.
- Spectrum entries conform to the MSP convention expected by LC-MS/MS search engines (precursor/adduct metadata plus fragment peaks).
- If the export dialog defaulted to '.CSV', the output would be a precursor/transition list, not a spectral library — verify the correct extension was selected.

## Limitations

- The '.MSP' export is specific to spectral libraries; it cannot deliver precursor lists or Skyline transition lists — those require selecting '.CSV'.
- Spectral content is limited to the fragmentation patterns encoded in the tool, which are based on peer-reviewed studies; species outside the supported lipid classes/adducts will not be represented.
