# spectral-annotation-coverage-filtering

## Summary

Assesses how many MS/MS spectra in a GNPS molecular network receive structure-based class predictions from CANOPUS or MolNetEnhancer, and uses this coverage to decide which candidate BGC–MS/MS links must be discarded when their spectra lack a structure-based ClassyFire class.

## When to use

Use when applying NPClassScore to a paired genomics–metabolomics dataset and you need to determine which spectra lack CANOPUS or MolNetEnhancer ClassyFire superclass predictions, so candidate links based on unannotated spectra can be filtered out.

## When NOT to use

- When every candidate spectrum already has a confirmed structure-based class from a third source, as the coverage filter would then be redundant to the NPClassScore cut-off of 0.25
- When the goal is purely co-occurrence-based (e.g. standardised Metcalf scoring alone), since annotation coverage does not affect Metcalf scores

## Inputs

- GNPS molecular networking mgf file (e.g. for the Streptomyces/Salinispora dataset from Crüsemann et al., MassIVE MSV000078836/MSV000078839/MSV000079284)
- CANOPUS superclass prediction table generated by Sirius v4.9.3 within NPLinker
- MolNetEnhancer superclass annotations run externally on the GNPS platform
- NPLinker candidate BGC–MS/MS link list with standardised Metcalf scores

## Outputs

- Per-spectrum annotation-coverage table recording whether each spectrum received a CANOPUS and/or MolNetEnhancer ClassyFire superclass prediction
- Count of spectra with predictions from both tools (e.g. 6606) and spectra lacking predictions from either tool (e.g. 1988)
- Filtered candidate link graph retaining only links whose spectra carry structure-based classes

## How to apply

Run CANOPUS (via Sirius v4.9.3) directly on the mgf file resulting from GNPS molecular networking and run MolNetEnhancer externally on the GNPS platform, then tabulate how many spectra per dataset received a superclass prediction from either tool. In the Streptomyces/Salinispora dataset, 6606 spectra had predictions from both tools while 1988 spectra across the datasets lacked a CANOPUS or MolNetEnhancer prediction. Set the NPLinker filter_missing_scores toggle to discard candidate BGC–MS/MS links whose spectra have no structure-based class; note that not filtering such links only decreases the average candidate links per GCF by 49%, so coverage directly controls how aggressively NPClassScore (cut-off 0.25, applied after a standardised Metcalf cut-off of 2.5) reduces link lists. Validate the coverage table against Tables S6–S7, including the 2686-vs-1301 lipid superclass discrepancy between MolNetEnhancer and CANOPUS for the same spectra.

## Related tools

- **CANOPUS** (Generates structure-based ClassyFire superclass predictions directly from MS/MS spectra in the mgf file, defining the coverage boundary) — github.com/kaibioinfo/canopus_treemap
- **MolNetEnhancer** (Provides the alternative structure-based superclass annotations whose coverage is compared against CANOPUS to determine which spectra are annotated)
- **NPLinker** (Hosts the filter_missing_scores toggle that discards candidate links whose spectra lack structure-based class predictions) — github.com/NPLinker/nplinker
- **ClassyFire** (The hierarchical ontology (superclass, class, subclass) whose categories define what counts as an annotated spectrum)

## Examples

```
nplinker.load_data(); link_graph = npl.get_links(npl.gcfs[:3], 'metcalf'); npl.filter_links(link_graph, min_metcalf=2.5, min_npclassscore=0.25, filter_missing_scores=True)
```

## Evaluation signals

- The coverage table reproduces the reported counts from Tables S6–S7: 6606 spectra with predictions from both tools and 1988 spectra without a CANOPUS or MolNetEnhancer prediction
- The 'Lipids and lipid-like molecules' superclass shows the reported tool discrepancy (2686 via MolNetEnhancer vs 1301 via CANOPUS)
- No candidate link survives filtering if its spectrum appears in the unannotated subset (filter_missing_scores enabled)
- Not filtering decreases the average candidate links per GCF by ~49%, so the filtered output should reflect that reduction

## Limitations

- 1988 MS/MS spectra across the datasets lacked any CANOPUS or MolNetEnhancer prediction and their links were discarded
- CANOPUS coverage is limited by an 850 Da mass cut-off, so larger metabolites are not well handled by current structure-based prediction tools
- MolNetEnhancer cannot currently be run within NPLinker and must be run externally, e.g. on the GNPS platform
- The two tools disagree substantially on the same spectra, so annotation coverage depends strongly on which ontology-prediction tool is chosen
