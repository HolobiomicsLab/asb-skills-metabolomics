# per-reaction-fraction-computation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Tabulates experimentally detected versus BioTransformer 3.0-predicted metabolite counts for each biotransformation reaction type in the human liver S9 LC-HRMS data, yielding per-reaction detection fractions (e.g., oxidation 52%, reduction 65%) that quantify in silico prediction coverage.

## When to use

Use when metabolite annotations are tagged with BioTransformer reaction types and you need detected-vs-predicted counts and detection fractions per biotransformation (oxidation, glucuronidation, etc.).

## When NOT to use

- Input is raw vendor files or an uncurated MZmine 2.53 feature table — annotations must first pass 0-hour vs 24-hour differential detection and ±5 ppm BioTransformer cross-referencing before per-reaction counting.
- The task is structural identification or isolation/elucidation of novel metabolites rather than summarizing detected-vs-predicted coverage per reaction type.
- The in vitro system is extrahepatic (e.g., intestine or kidney), where the reaction-type distribution is not comparable to the liver-S9 Phase I/II breakdown.

## Inputs

- Metabolite annotation tables for Metabolomics Workbench Study ID ST003991 (DOI 10.21228/M8W55K), one row per detected LC-HRMS feature passing 0-h vs 24-h differential detection
- BioTransformer 3.0 prediction lists with reaction-type tags used for ±5 ppm cross-referencing/curation of detected mass signals
- Controlled reaction-type vocabulary: oxidation, reduction, hydrolysis, methylation, acetylation, glucuronidation, sulfation, glutathione conjugation

## Outputs

- Tab-separated table with columns: reaction type, detected count, predicted count, detection fraction
- Per-reaction detection fractions (e.g., oxidation 30,752/59,296 = 52%; reduction 7114/10,899 = 65%; hydrolysis 3184/5744 = 55%; methylation 3136/6235 = 50%; acetylation 45%; glutathione conjugation 21%)

## How to apply

Download the metabolite annotation tables for Metabolomics Workbench Study ID ST003991 (DOI 10.21228/M8W55K); these LC-HRMS features come from the dual-column, dual-ESI Orbitrap ID-X runs (HILIC with positive ESI, C18 with negative ESI), were flagged by 0-hour vs 24-hour differential detection, and were curated against BioTransformer 3.0 predictions at ±5 ppm. Parse each annotation's reaction-type tag from the BioTransformer 3.0 curation: oxidation, reduction, hydrolysis, methylation, acetylation, glucuronidation, sulfation, glutathione conjugation. In R (paper used version 4.0.3), count detected and predicted metabolites per reaction type and compute the detection fraction (detected/predicted). Cross-check against the reported values: oxidation 30,752 of 59,296 (52%), reduction 7114 of 10,899 (65%), hydrolysis 3184 of 5744 (55%), methylation 3136 of 6235 (50%), acetylation 45%, glutathione conjugation 21%, with glucuronidation (6311) dominating phase II. Emit the result as a tab-separated table with columns reaction type, detected count, predicted count, and detection fraction.

## Related tools

- **R 4.0.3** (Statistical analysis environment used to tally detected and predicted metabolite counts per reaction type and compute detection fractions)
- **BioTransformer 3.0** (Source of the reaction-type tags and predicted metabolite sets that detected signals (±5 ppm) are cross-referenced against before counting)
- **PharmMet DB** (Compiled human liver S9 metabolite resource whose annotation tables supply the per-drug reaction-type annotations being counted) — https://github.com/ClinicalBiomarkersLaborabory/PharmMet
- **NIH Common Fund’s National Metabolomics Data Repository (Metabolomics Workbench)** (Hosts Study ID ST003991 data (DOI 10.21228/M8W55K) that are downloaded as the counting input) — https://www.metabolomicsworkbench.org

## Examples

```
Rscript -e 'a<-read.delim("ST003991_annotations.tsv"); t<-table(a$reaction_type); write.table(data.frame(reaction_type=names(t),detected=as.vector(t)),"reaction_counts.tsv",sep="\t",row.names=FALSE)'
```

## Evaluation signals

- Oxidation row exact-matches the paper's reported 30,752 detected of 59,296 predicted (52%).
- Reduction 7114/10,899 (65%), hydrolysis 3184/5744 (55%), methylation 3136/6235 (50%), acetylation 45%, and glutathione conjugation 21% reproduce within exact-match tolerance.
- Glucuronidation emerges as the dominant phase II reaction with 6311 detected metabolites.
- Output is a tab-separated table with exactly the columns reaction type, detected count, predicted count, and detection fraction.
- Every detected count is ≤ its predicted count (detection fraction within (0, 1]).

## Limitations

- Reliance on human liver S9 means not all drug-metabolizing activities are present, and metabolites formed in extrahepatic compartments (eg, intestine, kidney) are expected to be missing, biasing per-reaction counts.
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression, deflating detection fractions.
- Unpredicted metabolites (89% of tested drugs produced at least 1 not predicted by BioTransformer 3.0) cannot be assigned a predicted reaction-type tag and fall outside the per-reaction tally.
