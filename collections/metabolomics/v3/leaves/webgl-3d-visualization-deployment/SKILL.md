# webgl-3d-visualization-deployment

## Summary

Deploy EMPeror-style interactive 3D ordination plots: an HTML5, WebGL, JavaScript and Python stack converts QIIME principal coordinates plus a metadata mapping file into a standalone, hardware-accelerated, plugin-free web page that scales to thousands of samples (26 MB vs KiNG's 1.85 GB for 5,740 samples).

## When to use

Use when a QIIME principal coordinates file (PCoA of beta diversity distances) and a metadata mapping file must become an interactive, plugin-free WebGL 3D scatter for thousands of samples, shareable as a standalone web page or embedded in email.

## When NOT to use

- No ordination exists yet — the input is raw sequencing data or an OTU/feature table; QIIME must first run PCoA on beta diversity distance matrices before this skill applies.
- Deployment must be automated on Windows or rendered in a browser other than Chrome — the paper restricts the command line interface to OS X (10.6 and higher) and Linux and lists Chrome as the GUI requirement.
- The data to display is not ordination-based (e.g., raw abundance tables or phylogenies); EMPeror's 3D view is defined over principal coordinates space.

## Inputs

- QIIME principal coordinates file (PCoA coordinates of a beta diversity distance matrix)
- Metadata mapping file with sample categories and/or gradients
- Second coordinates file for procrustes analysis coordinate comparisons (optional)
- Taxa/biplot coordinates to overlay as arrows in the ordination space (optional)
- Jackknifed-resampled ordination data for beta diversity confidence display (optional)

## Outputs

- Standalone HTML web page embedding an interactive, hardware-accelerated 3D WebGL scatter (no extra plugins)
- UI controllers for metadata-driven recoloring and point visibility, plus switching of principal coordinates axes
- Auxiliary layers rendered in the same ordination space: biplot taxa arrows, procrustes coordinate comparisons, jackknifed beta diversity displays

## How to apply

Start from principal coordinates analysis (PCoA) of beta diversity distance matrices (as generated by QIIME) and keep the resulting principal coordinates file plus the metadata mapping file. Run EMPeror's command line interface on those two files: it serializes the ordination and metadata into a compact HTML5/WebGL/JavaScript bundle — for 5,740 samples and 120 metadata columns, 26 MB instead of KiNG's 1.85 GB (1.3% of the original size) — that renders with hardware-accelerated graphics in the browser. Use the UI controllers to drive point color and visibility from metadata categories or gradients and to switch which principal coordinates axes are displayed; when auxiliary layers are needed, attach jackknifed-resampled beta diversity data for clustering confidence, biplot taxa coordinates (taxa arrows), or a second coordinates file so procrustes coordinate comparisons can be drawn in the same ordination space. Export the result as a standalone web page and open it in Chrome (the stated GUI requirement) to confirm the sample spheres and any biplot/procrustes layers are visible and interactive. The rationale: small output files and plugin-free WebGL rendering let visualizations load in seconds rather than the many minutes KiNG required, and be shared via emails or web pages without extra plugins.

## Related tools

- **EMPeror** (Primary renderer: its command line interface consumes the QIIME principal coordinates file and metadata mapping file and exports a standalone WebGL/HTML5 3D visualization, with controllers for metadata-based coloring, visibility, and auxiliary layers (biplots, procrustes, jackknifed beta diversity).) — http://emperor.colorado.edu
- **QIIME** (Generates the upstream principal coordinates files from beta diversity distance matrices; its Python libraries are a stated runtime requirement for running EMPeror.)

## Examples

```
emperor.py -i pcoa.txt -m mapping.txt -o emperor_output
```

## Evaluation signals

- The exported HTML opens in Chrome and renders the 3D sample spheres with no extra plugins installed.
- Output file size tracks the paper's baseline: ~26 MB for 5,740 samples with 120 metadata columns (1.3% of KiNG's 1.85 GB for the equivalent discrete and gradient coloring).
- Load time is seconds, not the many minutes reported for KiNG on comparable datasets.
- Metadata controllers correctly change point color/visibility for both categorical categories and gradients, and the viewport can display different principal coordinates axes.
- Where auxiliary data were supplied, biplot taxa arrows and procrustes coordinate comparisons of corresponding samples are visible and remain interactive in the exported page.

## Limitations

- Chrome is the stated GUI requirement, suggesting untested compatibility with other browsers.
- The command line interface is limited to OS X (10.6 and higher) and Linux only; no Windows support is stated.
- Legacy dependency stack: Python 2.7, QIIME (python libraries only), NumPy, BIOM 1.1.0 and PyCogent.
- The paper states no software version number and no code repository URL — only the project home page (http://emperor.colorado.edu) — and supporting example files carry no archival DOI/accession IDs.
