# Authentic-vs-Spurious Identification Separation

## Summary

A method for separating authentic from spurious metabolite/lipid identifications using MAVEN2 spectral matching, standards spiked into water and yeast backgrounds, and library-specific hypergeometric score thresholds (Retention Balance Points: 22.8 for CalicoLipids, 13.9 for MS-DIAL).

## When to use

Decision support for choosing score cutoffs that distinguish true from false MAVEN2 spectral matches when annotating features against the CalicoLipids or MS-DIAL in-silico lipidomics libraries.

## When NOT to use

- Input is already a curated, threshold-filtered feature annotation table — the separation analysis requires raw MAVEN2 hypergeometric scores
- Data were matched against a library other than CalicoLipids or MS-DIAL without re-deriving a library-specific threshold, since RBP cutoffs are library-specific
- Analysis targets non-lipid metabolites where the in-silico lipidomics libraries and their lipid-class fragmentation models do not apply

## Inputs

- Per-feature annotation tables from MAVEN2 spectral matching against the CalicoLipids library (standards spiked into water and yeast backgrounds)
- Per-feature annotation tables from MAVEN2 spectral matching against the MS-DIAL library
- In-silico lipid MSP files generated by CalicoLipidLibrary (e.g., generateDB.py output)

## Outputs

- Agreement and disagreement score histograms per library
- Collapsed authentic-vs-spurious separation metric per library
- Library-specific RBP thresholds (22.8 for CalicoLipids, 13.9 for MS-DIAL) written to rbp_thresholds.csv

## How to apply

Run MAVEN2 spectral matching of features from standards spiked into water and yeast backgrounds against each fragmentation library (CalicoLipids-generated MSP files and MS-DIAL). Bin the hypergeometric match scores into agreement and disagreement histograms per library, then collapse each histogram pair into a single authentic-vs-spurious separation metric per library. Sweep candidate Retention Balance Point (RBP) cutoffs and select the library-specific threshold that maximizes the collapsed separation metric; this yields 22.8 for CalicoLipids and 13.9 for MS-DIAL. The rationale is that different in-silico libraries have different score distributions, so a single global cutoff misclassifies matches; per-library thresholds align lipid annotations across libraries. Use the resulting RBP thresholds to filter annotations when comparing CalicoLipids searches to MS-DIAL searches.

## Evaluation signals

- The swept cutoff maximizing the collapsed separation metric reproduces 22.8 for CalicoLipids and 13.9 for MS-DIAL
- rbp_thresholds.csv contains exactly the two library-specific thresholds and the collapsed separation metrics used to derive them
- Agreement and disagreement histograms are built per library (one histogram pair for CalicoLipids, one for MS-DIAL), not pooled across libraries
- Thresholded annotations from CalicoLipids and MS-DIAL searches show improved agreement in lipid assignments relative to using a single shared cutoff
- Generated MSP library files cover the intended lipid classes and ionization mode (e.g., -m pos or neg) before searching

## Limitations

- Thresholds are library-specific and must be re-derived for any new or updated fragmentation library
- The separation relies on standards spiked into water and yeast backgrounds; other matrix types may shift the score distributions
- MAVEN2 project notes incomplete documentation (e.g., changelog gaps for release 8.0.0), and Linux builds have been retired, with macOS and Windows executables produced by Appveyor as of 2024-11-05
