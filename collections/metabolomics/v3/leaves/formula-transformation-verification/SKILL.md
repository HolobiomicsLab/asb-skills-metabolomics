# Formula transformation verification

## Summary

Verification of proposed transformation logic against feature formula annotations, applied as part of patRoon 2.0's TP component prioritization after parent and TP features have been grouped into components during TP componentization.

## When to use

Use when a patRoon 2.0 TP componentization result links parent and TP features and proposed transformation logic must be checked against feature formula annotations before final TP prioritization.

## When NOT to use

- Input is raw MS data or a feature table that has not yet been through TP componentization — the filter operates on grouped parent/TP components, not raw features
- No feature formula annotations are available — the explained-transformation filter specifically verifies transformations against formula annotations and cannot be applied without them
- The goal is general non-target feature prioritization rather than transformation-product screening — this skill is specific to the TP component prioritization filters of patRoon 2.0

## Inputs

- TP components generated by the patRoon 2.0 componentization step (parent feature linked with corresponding TP features)
- Feature formula annotations from the patRoon workflow (e.g. formula candidates from GenForm or SIRIUS)
- patRoonData example LC-HRMS data (standard-X and solvent-X, positive and negative ionization)

## Outputs

- Prioritized TP component table with per-filter verdicts (e.g. tp_components_prioritized.csv) including the explained-transformation verdict column

## How to apply

In the patRoon 2.0 TP screening workflow, TP componentization (Figure 1F) links each parent feature with its corresponding TP features and groups them into a TP component; prioritization is then applied to these components. Within the prioritization routine, the explained-transformation filter verifies the proposed metabolic-logic transformation against feature formula annotations obtained earlier in the workflow, so a TP is kept only when its annotated formula is consistent with the proposed transformation from the parent. Run the prioritization in R on the patRoonData example data (standard-X vs solvent-X, positive and negative ionization), enabling this filter alongside the complementary filters: RT direction (checks expected relative retention-time direction based on chemical polarities), structure similarity (removes TPs with high MS similarity but low structural similarity), isomer removal (drops isomers difficult or impossible to distinguish with MS), and duplicates (removes duplicate TPs formed from the same parent through different pathways). The formula check is decisive because MS similarity alone cannot distinguish structurally plausible but chemically inconsistent transformations.

## Evaluation signals

- script_runs: the patRoon prioritization routine in R executes without error on the patRoonData example data
- file_exists: the exported tp_components_prioritized.csv file is present after the workflow
- field_present: the output table contains one row per TP component and columns recording each of the five filter verdicts (RT direction, structure similarity, explained transformation, isomers, duplicates)
- The explained-transformation verdict column is consistent with the feature formula annotations — TPs whose proposed transformation contradicts the annotated formula should be flagged/removed
- Filter interplay sanity check: enabling additional filters (structure similarity, isomers, duplicates) should not increase the number of retained TP components relative to the RT-direction-only run

## Limitations

- The explained-transformation check is only as good as the feature formula annotations it verifies against; no annotations means no verification
- Isomers can be difficult or impossible to distinguish with MS, so the isomer-removal filter — which operates alongside this filter — drops candidates that might otherwise be verifiable
- Duplicate TPs formed from the same parent through different pathways are removed, so multi-pathway assignments will not all survive prioritization
