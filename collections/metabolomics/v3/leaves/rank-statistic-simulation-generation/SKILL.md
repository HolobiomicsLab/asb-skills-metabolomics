# rank-statistic-simulation-generation

## Summary

Generate simulated replicate datasets in which the correlation between replicate pairs decreases linearly with rank, then apply the nonparametric MaRR maximal rank statistic to assess FDR control, power (1-NDR), and bias in estimating the proportion of reproducible signals.

## When to use

Use when benchmarking a rank-based reproducibility method under realistic correlation decay — e.g., testing whether MaRR maintains FDR, power, and low bias when correlation between replicate pairs decreases with rank.

## When NOT to use

- The goal is not simulation-based benchmarking but reproducibility assessment on real MS-Metabolomics replicate data (Tech, BioTech, Bio datasets), which uses the Real_Data folder workflows instead
- A comprehensive evaluation of pre-processing steps (imputation: BPCA/kNN; normalization: quantile/median/RUV) is the goal — the paper states the aim was only to benchmark comparisons, not evaluate pipelines

## Inputs

- Simulation setting definition: pi_1 in {0.2, 0.4, 0.75, 0.9} crossed with r_0 in {0.4, 0.6, 0.99} (12 settings)
- Simulation scripts 'SIM_B1.R' ... 'SIM_D4.R' from the 'marr_code_B' folder of Ghoshlab/marr_paper_evaluations
- MaRR functions sourced from 'src/source_MaRR.R'

## Outputs

- Per-setting R objects 'B1_sim_results.Rdata' ... 'D4_sim_results.Rdata' (1000 simulated datasets each)
- Aggregated empirical FDR, power (1-NDR), and bias per setting
- FDR, power, and bias plots generated by 'SIMPLOT_B.R' (reproducing Figs. 3-4 and S6-S7)

## How to apply

In R (>=4.0), source the MaRR functions from 'source_MaRR.R' in the repository folder 'src'. For each of the 12 Simulation II settings — the proportion of reproducible signals pi_1 in {0.2, 0.4, 0.75, 0.9} crossed with the baseline correlation r_0 in {0.4, 0.6, 0.99} — execute the corresponding script from the 'SIM_B1.R' ... 'SIM_D4.R' series (run from folder 'marr_code_B') to generate 1000 simulated datasets with replicate correlation linearly decreasing with rank. Apply the MaRR maximal rank statistic to every simulated dataset to estimate the proportion of reproducible signals and detect reproducible features per sample pair. Aggregate the empirical FDR, power (1-NDR), and bias (estimated minus true reproducible proportion) per setting, and save each setting's results as the corresponding R object ('B1_sim_results.Rdata' ... 'D4_sim_results.Rdata'). Finally run the design-B plotting script 'SIMPLOT_B.R' from the 'Output' folder on the saved R objects to generate the FDR, power, and bias plots.

## Related tools

- **marr** (Nonparametric maximal rank reproducibility procedure applied to each simulated dataset to estimate the proportion of reproducible signals and detect reproducible features per sample pair) — http://bioconductor.org/packages/marr
- **R** (Execution environment (>=4.0) for running the SIM_B1.R-D4.R simulation scripts and MaRR functions)

## Examples

```
Rscript SIM_B1.R  # after: source('src/source_MaRR.R'); runs one of the 12 Simulation II settings, saving B1_sim_results.Rdata
```

## Evaluation signals

- Reproduced figures show empirical FDR at or below the nominal level across all 12 settings, with conservative behavior when pi_1 is high and r_0 is low
- High 1-NDR power across settings except at the smallest pi_1 values (0.2, 0.4)
- Bias (estimated minus true reproducible proportion) close to zero, with the characteristic negative-bias pattern at low pi_1
- Generated figures match Figs. 3-4 and S6-S7 of the paper
- Each of the 12 settings produces a valid R object ('B1_sim_results.Rdata' ... 'D4_sim_results.Rdata') that 'SIMPLOT_B.R' can load

## Limitations

- MaRR can be conservative when pi_1 is high and r_0 is low (FDR well below nominal)
- Power drops at smaller values of the proportion of reproducible metabolites (small pi_1)
- True signals may fall in undetectable regions due to lack of separation between reproducible and irreproducible components
- The simulation goal is benchmarking, not a comprehensive evaluation of pre-processing steps
