# mass-spectrometry-annotation-evaluation

## Summary

Evaluates molecular-network annotation quality by testing whether random-walk propagation (ChemWalker) annotates nodes that lack any direct neighbour with a spectral library match, overcoming NAP's local first-neighbour limitation.

## When to use

Use when benchmarking annotation propagation on a molecular network: you need to quantify whether annotations reach nodes not directly connected to spectral library matches, not just first neighbours.

## When NOT to use

- Input is an unannotated molecular network with no spectral library matches — the seed set would be empty and no propagation benchmark is possible
- Goal is only local first-neighbour annotation (NAP-style) rather than evaluating propagation beyond direct neighbours
- No candidate structures available from in silico fragmentation (MetFrag), since ChemWalker propagates through candidate structures rather than raw spectra

## Inputs

- NIST 555-spectra benchmark molecular network
- per-spectrum candidate annotation tables (MetFrag in silico fragmentation results)
- seed-node list of spectral library matches (10% of network nodes)
- MetFusion-weighted graph combining spectral-network edges and structural similarity among candidate structures

## Outputs

- annotation_propagation_nonneighbor_summary.csv aggregating per-spectrum non-neighbour annotation counts
- per-spectrum counts of annotations on nodes without a direct edge to any spectral-library-match node

## How to apply

Load the NIST 555-spectra benchmark molecular network together with its per-spectrum candidate annotation tables in Python, and designate 10% of network nodes as seed nodes defined by spectral library matches. Build the MetFusion-weighted graph that combines spectral-network edges with structural similarity among candidate structures (candidates generated by MetFrag in silico fragmentation). Run the ChemWalker random walk, backed by the pyrwr solver (RWR via power iteration, restart probability c, epsilon tolerance, max_iters), from the seed nodes over the weighted graph to compute candidate probabilities. For each of the 555 spectra, count annotations assigned to nodes that lack a direct edge to any spectral-library-match node, then aggregate the per-spectrum non-neighbour counts across the benchmark into annotation_propagation_nonneighbor_summary.csv. Success requires a nonzero count of annotations recorded on nodes not directly connected to the spectral library match, reproducing the paper's claim that propagation reaches nodes beyond the first neighbour.

## Related tools

- **ChemWalker** (Python library whose random-walk propagation is evaluated for reaching nodes beyond the first neighbour of a spectral library match) — https://github.com/computational-chemical-biology/ChemWalker
- **pyrwr** (Random walk with restart solver (power iteration) backing the propagation step) — https://github.com/jinhongjung/pyrwr
- **MetFusion** (Scoring function used as the weight function to build the weighted graph from spectral network plus candidate-structure similarity)
- **MetFrag** (Provides combinatorial in silico fragmentation candidate structures searched in biologically relevant databases) — https://github.com/ipb-halle/MetFragRelaunched

## Examples

```
conda activate chemwalker; python -c "from pyrwr.rwr import RWR; rwr = RWR(); rwr.read_graph('metfusion_weighted_graph.tsv', 'undirected'); r = rwr.compute(seed, c=0.15, epsilon=1e-9, max_iters=100)"
```

## Evaluation signals

- Nonzero count of annotations recorded on nodes not directly connected to any spectral library match node
- Per-spectrum non-neighbour annotation counts aggregate to a nonempty annotation_propagation_nonneighbor_summary.csv across all 555 spectra
- Seed set equals 10% of network nodes, defined by spectral library matches
- RWR score vector returned by pyrwr has shape (n, 1) over the n network nodes and positive values on non-seed nodes
- Propagation result demonstrates improvement over NAP's local first-neighbour limitation

## Limitations

- One of the limitations of NAP is that the information for the spectral matches is only propagated locally, to the first neighbor of a spectral match — ChemWalker is the evaluated fix, so results cannot be attributed to NAP
- Requires positively weighted networks for the pyrwr RWR solver; only positive edge weights are allowed
- Evaluation is anchored to the NIST 555-spectra benchmark regime with at most 10% seed nodes; behaviour outside this regime is not established by this benchmark
