# smiles-fragment-tree-comparison

## Summary

A candidate-ranking procedure from the TeFT workflow: predict molecular structures de novo from tandem MS spectra, then rank candidate substances by comparing the SMILES fragment trees of each predicted molecule with the molecular fragment trees generated from the tandem mass spectra, scored with Tanimoto/Dice similarity.

## When to use

Use when ranking candidate molecular structures against low-resolution MS2/MSn spectra (e.g. from a miniaturized mass spectrometer) by comparing SMILES fragment trees of predicted molecules with fragment trees derived from the spectra.

## When NOT to use

- High-resolution, high-accuracy spectra — the article states TeFT 'may not exhibit exceptional performance advantages in predicting high-quality resolution spectra compared to other deep models' such as MassGenie or MSNovelist, which are geared to high resolution
- Spectra recorded in negative ion mode — TeFT was trained only on positive ion mode (H+) spectra, restricting its applicability
- Compounds outside the constrained chemical space (MW ≥500 Da or elements beyond C/H/O/N/P/S/Cl/Br/I/F), where the imposed filters are invalid

## Inputs

- Low-resolution tandem MS (MS2/MSn) spectra in positive ion mode (H+) from a miniaturized mass spectrometer
- Candidate structure lists (SMILES) for each spectrum, e.g. CASMI 2017 challenge candidate sets
- Predicted molecular structures (SMILES fragment strings) generated by a de novo model such as TeFT

## Outputs

- Ranked list of candidate substances per spectrum, ordered by SMILES fragment tree similarity
- Per-spectrum Tanimoto/Dice similarity scores of predicted vs ground-truth structures
- Aggregate performance metrics: % correct structures ranked first, % mostly correct, % with Dice >0.8 and >0.9
- Wilcoxon signed-rank p-values comparing the similarity distribution against SIRIUS4/MetFrag baselines

## How to apply

Generate predicted structures de novo from each MS2 spectrum (e.g. with the TeFT Transformer model, trained on GNPS, HMDB 5.0 and MoNA), enforcing the paper's filters: molecular weight <500 Da, only the ten elements C/H/O/N/P/S/Cl/Br/I/F, peak lists capped at 100 peaks by ion intensity, top 5–6 fragmentation peaks (with their nearby points) as experimental data, and a 1500-node limit on the SMILES tree. Build the molecular fragment tree from the tandem mass spectrum, then compute the similarity between each predicted molecule's SMILES fragment tree and this spectral fragment tree to rank candidate substances. Score each ranked prediction against the ground-truth structure using Tanimoto similarity expressed as a Dice coefficient. Aggregate metrics as percentage of correct structures ranked first, percentage mostly correct, percentage with similarity >0.8, and percentage with similarity >0.9. For benchmarking, compare similarity distributions against baselines such as SIRIUS4 and MetFrag using Wilcoxon signed-rank tests.

## Related tools

- **TeFT** (De novo structure generation model producing the SMILES fragment strings that are compared as fragment trees against spectra-derived fragment trees for candidate ranking) — thumingo/TeFT
- **SIRIUS4** (Baseline structure-prediction tool run on the same spectra for Wilcoxon comparison of similarity distributions)
- **MetFrag** (Baseline database-search/fragment-prediction tool used as a statistical comparator for the ranked similarity scores)

## Evaluation signals

- On the 93 CASMI 2017 MS2 spectra, ~12% of ground-truth structures should be ranked first and ~22% mostly correct
- Dice similarity >0.8 should hold for ~78% of spectra and >0.9 for ~39% against ground truth
- Wilcoxon signed-rank p-values vs baselines should be significant (reported: 4.4×10⁻⁶ vs SIRIUS4, 2.7×10⁻¹¹ vs MetFrag)
- All peak lists respect the maximum of 100 peaks by ion intensity, with top 5–6 fragmentation peaks selected
- No SMILES fragment tree exceeds the 1500-node limit and all predicted structures fall within the <500 Da / ten-element constraints

## Limitations

- TeFT was trained only on positive ion mode (H+) spectra, restricting applicability to other ionization modes
- On CASMI 2017, only 12% of structures were fully predicted correctly; performance on high-quality/high-resolution spectra is not advantaged versus models like MassGenie or MSNovelist
- The method is suited to annotating fragmentation peaks with clear fragmentation rules; compounds with unclear fragmentation may rank poorly
