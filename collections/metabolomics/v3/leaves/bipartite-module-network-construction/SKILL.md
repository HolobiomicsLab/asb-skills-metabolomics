# bipartite-module-network-construction

## Summary

Bicluster the MiMeNet microbe-metabolite attribution-score matrix into 8 microbe modules and 8 metabolite modules via consensus clustering (Euclidean distance, complete linkage, delta-area threshold 0.025), then score module-module edges by mean normalized attribution within each block and export a Cytoscape-compatible bipartite network.

## When to use

Use when you have a cross-validated MiMeNet interaction-score matrix (microbes x metabolites) and want to reveal the underlying structure of the microbe-metabolite interaction network as module-level nodes and edges.

## When NOT to use

- You only have raw metabolite or microbial abundance tables and no trained MiMeNet model — the input must be an interaction/attribution score matrix, not a feature table.
- You want metabolite-level (not module-level) edges — mmvec-style conditional probabilities or NED's latent-space interpretation does not reveal shared interaction-pattern modules, so this biclustering network is inappropriate for that goal.
- The score matrix has fewer features than the number of consensus clusters implied by the delta-area threshold, making the 8x8 module structure degenerate.

## Inputs

- Mean microbe-metabolite interaction-score matrix (features x features) produced by cross-validated MiMeNet models
- Normalized attribution-score matrix (RA or CLR transformed MiMeNet outputs)

## Outputs

- 8 microbe modules and 8 metabolite modules with feature-to-module assignments (k1*, k2* selected by delta-area threshold 0.025)
- 8x8 block-mean normalized attribution matrix
- Cytoscape-compatible weighted bipartite module-module network file (nodes = modules, edges = mean attribution scores)

## How to apply

Load the mean microbe-metabolite interaction-score matrix (microbes x metabolites) generated by the cross-validated MiMeNet MLPNN models. Run consensus clustering on the microbe axis using Euclidean distance and complete linkage, selecting k1* where the delta-area criterion falls below the threshold 0.025; repeat the identical procedure on the metabolite axis to select k2*. Assign microbes and metabolites to the resulting 8 microbe modules and 8 metabolite modules, which the article reports as groups with similar interaction patterns and functions (supporting 'Guilt by Association' for uncharacterized metabolites). Aggregate the normalized attribution-score matrix into the k1* x k2* block structure and set each microbe-module / metabolite-module edge weight to the mean normalized attribution score within that block. Export the resulting weighted bipartite graph (nodes = microbe and metabolite modules, edges = block-mean attributions) as a Cytoscape-compatible network file.

```
python MiMeNet_train.py -micro ibd_micro.csv -metab ibd_metab.csv -micro_norm CLR -metab_norm CLR -num_run_cv 10 -num_cv 10 -output ./out; # then bicluster the interaction-score matrix into 8x8 modules and export the Cytoscape network
```

## Evaluation signals

- The consensus-clustering delta-area criterion falls below 0.025 on both axes, selecting k1* = 8 microbe modules and k2* = 8 metabolite modules.
- The exported Cytoscape file contains exactly 8 microbe module nodes and 8 metabolite module nodes with edges weighted by block-mean normalized attribution.
- Every microbe and metabolite feature in the input score matrix is assigned to exactly one module (bicluster partitions are complete and non-overlapping).
- The block-mean attribution matrix is dimensionally consistent (8x8) with the chosen module counts and its values are non-negative normalized scores.
- Module members show similar interaction patterns, consistent with the article's claim that modules group microbes and metabolites with similar interaction patterns and functions.

## Limitations

- All methods including MiMeNet are still limited in providing biological plausibility and mechanistic insights; the modules reveal interaction patterns, not causal mechanisms.
- Some metabolites may not be associated with microbes and will have lower prediction correlations, weakening their module assignments.
- The delta-area threshold of 0.025 was calibrated on the three paired datasets (IBD PRISM, cystic fibrosis, soil wetting); other data types (e.g., longitudinal soil observations) may require re-tuning.
