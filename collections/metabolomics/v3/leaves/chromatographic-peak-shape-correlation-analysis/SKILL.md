# chromatographic-peak-shape-correlation-analysis

## Summary

Computes chromatographic peak-shape correlation (Pearson correlation of the extracted EIC intensity profiles) between LC/MS features within a compound spectrum and feeds the resulting edge scores into CAMERA's weighted relationship graph, which is subsequently split by highly connected subgraphs (HCS) or label propagation (LPC) to separate features of closely co-eluting compounds that survive the initial groupFWHM retention-time grouping.

## When to use

Decision support for splitting CAMERA pseudospectra that the retention-time window alone left ambiguous — i.e. when features co-elute within one FWHM group but their EIC peak shapes (corval, pval thresholds on calcCaS edges) indicate two overlapping analytes.

## When NOT to use

- When the compound spectrum contains no possibly co-eluting features — a single-analyte spectrum separated cleanly by groupFWHM retention-time grouping needs no additional graph split.
- When only cross-sample intensity correlation is available without peak-shape or isotope information: calcCaS edges require EIC peak profiles, so running the skill on feature tables lacking chromatographic profiles is inappropriate.

## Inputs

- CAMERA xsAnnotate object (previously processed with groupFWHM and findIsotopes) from an LC/MS (e.g. UPLC/ESI-QTOFMS) data set
- Cross-sample EIC peak tables generated by getAllPeakEICs
- Optional isotope-relation annotations from findIsotopes

## Outputs

- Refined pseudospectra (compound spectra) assignments in the xsAnnotate object after graph splitting via calcPC.hcs or calcPC.lpc
- Annotated peak list exported with getPeaklist (e.g. as groupcorr_peaklist.tsv, a tab-separated table)

## How to apply

Load the CAMERA xsAnnotate object that has already been processed with groupFWHM and findIsotopes, then call groupCorr with graphMethod='hcs' (RBGL highly connected subgraphs) or 'lpc' (igraph label propagation). groupCorr first obtains EICs via getAllPeakEICs and then invokes calcCaS to compute peak-shape correlation edges; calcCiS optionally adds cross-sample intensity-correlation edges (thresholds corval for the correlation value and pval for its significance). Pass calcIso=TRUE to include isotope-relation edges and calcCaS=TRUE to include the peak-shape edges in the merged weighted graph; calcPC then splits each pseudospectrum at weak edges between the co-eluting compounds. Rationale: CAMERA does not rely on ad-hoc heuristics such as assuming the most intense feature is the [M+H]+-ion, so peak-shape similarity — the same criterion Scheltema et al. used for a 60% feature-list reduction — provides a data-driven separation signal for overlapping peaks. Verify on a synthetic mixture that the two co-eluting compounds end up in different pseudospectra before trusting the split on real samples.

## Related tools

## Examples

```
Rscript -e 'library(CAMERA); xs <- readRDS("xsAnnotate.rds"); xs2 <- groupCorr(xs, cor_eic_th=0.75, pval=0.05, graphMethod="hcs", calcIso=TRUE, calcCaS=TRUE); write.table(getPeaklist(xs2), "groupcorr_peaklist.tsv", sep="\t")'
```

## Evaluation signals

- On a synthetic example with two co-eluting compounds, the two compounds must fall into different pseudospectra (the graph splits at the weak edge between them).
- Every split pseudospectrum should still contain the isotope relation edges when calcIso=TRUE was set, so isotopic peaks are not separated from their parent.
- Cross-check that corval and pval thresholds were actually applied by inspecting the calcCaS/calcCiS edge scores before graph splitting.
- Export via getPeaklist and confirm the resulting tab-separated table (e.g. groupcorr_peaklist.tsv) contains the refined pseudospectra assignments.
- Compare the number of features per pseudospectrum before and after splitting: features of the overlapping analyte should move to the second pseudospectrum, not be discarded.

## Limitations

- CAMERA does not use ad-hoc heuristics such as assuming that the most intense feature in a spectrum is the [M+H]+-ion, so peak-shape correlation alone may leave ambiguities when two analytes share very similar peak shapes.
- If compound spectra contain only the molecular ion and fragment ions with no further adducts, downstream annotation may fail even after correct splitting; adding the neutral loss to the rule set is needed for direct annotation.
- Saturation of the MS detector causes shifts of m/z and retention time centroids and truncated peak profiles, which can distort the EIC shapes used by calcCaS — sample concentration must avoid detector saturation.
