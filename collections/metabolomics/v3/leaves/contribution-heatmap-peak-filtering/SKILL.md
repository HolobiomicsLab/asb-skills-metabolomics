# contribution-heatmap-peak-filtering

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Ranks LC-MS spectral peaks by their ensemble RISE contribution scores from a DeepMSProfiler run_feature step and retains only high-contribution peaks (score > 0.70) so that downstream network inference (PIUMet) is seeded with disease-relevant m/z signals rather than the full raw spectrum.

## When to use

Use when a trained DeepMSProfiler model has produced ensemble_RISE.npy heatmaps and you must select the disease-contributing m/z peaks for metabolite annotation and metabolite-protein network reconstruction.

## When NOT to use

- Input is already a curated feature table of identified metabolites with no raw-spectrum heatmaps — conventional feature selection or enrichment applies instead
- No trained DeepMSProfiler model or run_feature output exists — RISE contribution scores cannot be computed without the ensemble heatmap
- The goal is sample classification rather than biomarker/network discovery — run_predict with AUC/confusion-matrix outputs suffices without peak filtering

## Inputs

- ensemble_RISE.npy ensemble feature heatmap from DeepMSProfiler run_feature (e.g. ../jobs/jobs007/feature_results/ensemble_RISE.npy)
- Raw LC-MS spectral data in .npy or .mzML format used to train/predict the model
- Metabolite reference annotations (HMDB v3) for m/z and MS2 matching

## Outputs

- Ranked list of spectral peaks with ensemble RISE contribution scores, filtered to score > 0.70
- Annotated high-contribution m/z peaks with putative HMDB metabolite identities
- Prize list of annotated metabolites for PIUMet subnetwork extraction (e.g. LUAD network of 82 proteins and 121 metabolites)

## How to apply

After run_feature completes, load the ensemble RISE heatmap (ensemble_RISE.npy, e.g. shape (6, 341, 341) in the demo) generated by the DenseNet121 ensemble (10 runs, adam, lr 1e-04) and rank spectral peaks by their contribution score, retaining only peaks with contribution score > 0.70. Match the retained m/z values (and MS2 spectra where available) against metabolite reference annotations from HMDB v3 to assign putative metabolite identities, keeping unannotated signals as inputs for hidden-metabolite inference. Feed the annotated, high-contribution metabolites as prizes into PIUMet's prize-collecting Steiner forest algorithm on the iRepIndex v13 interaction network together with HMDB v3 and Recon2, so the extracted disease subnetwork reflects only model-attributed metabolic signals. The rationale is that the interpretability layer converts the deep model's class-discriminative attention into a concrete, filterable peak list linking raw LC-MS signals to disease biology.

## Related tools

- **DeepMSProfiler** (Generates the ensemble RISE feature heatmap (ensemble_RISE.npy) whose per-peak contribution scores are thresholded at 0.70; installed via pip install DeepMSProfiler (Python >= 3.6, TensorFlow 2.2.0, Keras 2.3.1)) — https://github.com/yjdeng9/DeepMSProfiler
- **PIUMet** (Consumes the filtered, HMDB-annotated high-contribution peaks as prizes in the prize-collecting Steiner forest algorithm to extract the disease-specific metabolite-protein subnetwork)

## Examples

```
run_feature(job_dir='DeepMSProfiler/example/out/jobs007'); show_feature(job_dir='DeepMSProfiler/example/out/jobs007',mode='ensemble')
```

## Evaluation signals

- The filtered peak set contains only peaks whose ensemble RISE contribution score exceeds 0.70
- The heatmap array loaded from ensemble_RISE.npy matches the logged shape (e.g. (6, 341, 341) in the demo run)
- Annotated peaks map to valid HMDB v3 entries via m/z (and MS2) matching before PIUMet submission
- The reconstructed LUAD network contains exactly 82 proteins and 121 metabolites
- Metabolites/proteins submitted to MetaboAnalyst joint pathway enrichment all pass FDR < 0.05

## Limitations

- Access to the pre-trained 859-sample serum model (210 healthy, 323 lung nodules, 326 lung cancer) requires contacting the author, so users must train their own ensemble to obtain heatmaps
- Peaks lacking HMDB annotations remain unidentified and must be carried forward as hidden metabolites inferred through the interaction network
- Demo data are distributed as .npy via Baidu Netdisk; .mzML inputs rely on the script's automatic conversion to .npy
