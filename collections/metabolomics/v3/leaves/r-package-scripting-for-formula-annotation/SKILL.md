# r-package-scripting-for-formula-annotation

## Summary

Drive molecular formula annotation of untargeted LC/HRMS peaks through R-based packages (IDSL.IPA → IDSL.UFA) by scripting parameter spreadsheets, IPDB theoretical isotope libraries, and per-sample/aligned peak-list processing in the R environment.

## When to use

Use when you need to assign elemental-composition (molecular formula) candidates to MS1 peaks from untargeted LC/HRMS files (mzXML/mzML/netCDF) at population scale using reproducible R scripts rather than GUI peak-picking tools.

## When NOT to use

- Input is MS2-only data or you need structural identification requiring tandem spectra — IDSL.UFA only requires MS1 for formula annotation but cannot assign structures without additional MS2 workflows (use IDSL.CSA or database search instead).
- Data are peak tables already produced by other tools (e.g. MZmine 2, xcms-CAMERA, MS-DIAL) whose isotopologue grouping and RT correction were not generated via the IDSL.IPA pipeline — the UFA scoring assumes IDSL.IPA-derived per-sample peak properties.
- Study contains fewer than a handful of samples and the aligned-table statistics (detection frequency, median rank) are not meaningful — the ranking thresholds were calibrated for population-scale (n > 500) untargeted studies.

## Inputs

- Raw MS1 HRMS data files (mzXML, mzML, netCDF) from Thermo Q Exactive HF or similar Orbitrap instruments
- Per-sample peak lists (CSV) generated by IDSL.IPA containing m/z, RT, isotopic peak pairs (nIsoPair), and peak areas
- Aligned peak table from IDSL.IPA peak_alignment directory
- Isotopic Profile DataBase (.Rdata) files, e.g. RefMetDB IPDBs for positive or negative ESI mode
- UFA parameter spreadsheet (UFA_parameters.xlsx) with PARAM0001–PARAM0030

## Outputs

- Annotated peak lists per sample with candidate molecular formulas, ranks, scores (equation 6), and IPA-derived properties
- Aligned annotated peak table summarizing formula annotations by detection frequency and median ranks
- Batch untargeted isotopic profile match figures
- Formula classes grouped by a class detection approach (e.g. 7,615 / 18,452 / 32,107 distinct formula classes reported)

## How to apply

First process raw MS1 data (mzXML, mzML, netCDF) with the IDSL.IPA R package to generate per-sample peak lists and an aligned peak table. Then install IDSL.UFA from CRAN (`install.packages("IDSL.UFA")`), download the UFA parameter spreadsheet (UFA_parameters.xlsx) with its 30 parameters across 4 sections, fill PARAM0004 (IPDB .Rdata address), PARAM0009 (HRMS MS1 data location), PARAM0011 (peaklists directory), PARAM0012 (peak_alignment directory), and PARAM0014 (output location), optionally raising processing threads via PARAM0008. Feed the spreadsheet to the `UFA_workflow` function; IDSL.UFA computes theoretical isotopic profiles for each candidate formula, applies the PCS/NEME/NDCS/RCS screening filters, and ranks surviving formulas by the composite score of equation (6). For targeted analysis of many peaks, use `IPA_targeted` instead of `IPA_workflow`; report formulas using median rank ≤ 5 for aligned peaks and top rank ≤ 30 with ≤ 30 hits for unique formulas.

## Related tools

- **IDSL.IPA** (Generates the per-sample peak lists (peaklists directory) and aligned peak table (peak_alignment directory) that are the required inputs for IDSL.UFA formula annotation.) — https://github.com/idslme/IDSL.IPA
- **IDSL.UFA** (Annotates peaklists with molecular formulas by matching theoretical isotopic profiles (IPDB) against observed MS1 peaks, applying PCS/NEME/NDCS/RCS filters and equation (6) ranking; invoked via `UFA_workflow` on a parameter spreadsheet.) — https://cran.r-project.org/package=IDSL.UFA
- **R** (Runtime environment and scripting language; both packages are distributed via CRAN and called from R/RStudio.) — https://cran.r-project.org/package=IDSL.UFA

## Examples

```
library(IDSL.UFA); UFA_workflow("Address of the UFA parameter spreadsheet")
```

## Evaluation signals

- Top-ranked candidate formulas should satisfy the paper's reporting thresholds: median rank ≤ 5 on the aligned table, and top rank ≤ 30 with ≤ 30 hits for unique formula reporting.
- For true positive annotations, expect 54.31–85.51% of formulas as the top hit and 90.58–100% within the top five hits.
- Every output row must contain a rank, score, molecular formula, and IPA-derived peak properties (nIsoPair, RCS, peak area).
- Output CSV per sample should have a rank column and score column for every candidate surviving the PCS/NEME/NDCS/RCS filters.
- Aligned annotated table should group formulas into formula classes whose counts fall in the order reported by the paper (thousands to tens of thousands of distinct classes).

## Limitations

- Formula annotation is database-dependent on the chosen IPDB formula source; 'database dependent' approaches risk missing exposure compounds poorly represented in biochemical databases or lacking transformation products.
- Scoring parameters default to 1 (for PCS, NEME, NDCS, RCS contributions); these defaults were not re-tuned per study in the reported workflows.
- Rank thresholds (median rank ≤ 5; top rank ≤ 30 / ≤ 30 hits) are heuristic cutoffs validated on four studies (ST001154, ST001683, MTBLS1684, MTBLS254); transfer to other instruments or chromatography may need revalidation.
- Version numbers of IDSL.UFA/IDSL.IPA used were not stated in the source text.
