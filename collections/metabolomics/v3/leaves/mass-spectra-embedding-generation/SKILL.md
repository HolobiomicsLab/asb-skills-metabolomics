# mass-spectra-embedding-generation

## Summary

Generate 32-dimensional learned embeddings for MS/MS mass spectra using GLEAMS, a neural network trained on 30 million MassIVE-KB PSMs, so that spectra generated by the same peptide lie close together in embedding space for downstream clustering and annotation.

## When to use

Use when large collections of MS/MS spectra in mzML peak files must be converted to compact feature vectors (embeddings) to enable joint analysis, such as spectrum clustering or label propagation across millions of spectra.

## When NOT to use

- When the goal is direct peptide identification by database search (e.g. MSGF+ at 1% FDR) rather than embedding-based similarity analysis
- When input spectra are not available as mzML peak files and no converter is available to produce them
- When only a small number of spectra are involved and classical pairwise comparison (e.g. cosine similarity clustering) is tractable without an embedding

## Inputs

- MS/MS spectra in mzML peak files (converted from vendor raw files with ProteoWizard msconvert)
- MassIVE-KB metadata TSV with 'filename' and 'scan' columns for locating spectra on the MassIVE FTP server
- Trained GLEAMS model weights (gleams_82c0124b.hdf5, v0.3 release)

## Outputs

- GLEAMS_embed.npy: 2D NumPy array of dimension n x 32, one embedding per embedded spectrum
- GLEAMS_embed.parquet: tabular metadata file for the embedded spectra

## How to apply

Install GLEAMS in a Conda environment (Python 3.8, Linux, CUDA-enabled GPU) via `pip install git+https://github.com/bittremieux/GLEAMS.git`, downloading the model weights gleams_82c0124b.hdf5 from the v0.3 release manually if Git LFS bandwidth is exhausted (GIT_LFS_SKIP_SMUDGE=1 clone, place weights in data/). Convert vendor raw files to mzML with ProteoWizard msconvert, then run `gleams embed` on the mzML peak files to produce a NumPy array of shape n x 32 (GLEAMS_embed.npy) plus a metadata parquet file (GLEAMS_embed.parquet). For unseen datasets (e.g. phosphoproteomics with novel PTMs), embed without retraining and validate pair statistics against expected scales; for repository-scale runs (669M MassIVE-KB spectra), compile spectra from the MassIVE-KB metadata TSV 'filename' and 'scan' columns via the MassIVE FTP server. Advanced neural-network configuration lives in gleams/config.py.

## Examples

```
gleams embed *.mzML --embed_name GLEAMS_embed
```

## Evaluation signals

- Output GLEAMS_embed.npy has shape (n, 32) with n equal to the number of MS/MS spectra read from the mzML files
- GLEAMS_embed.parquet is produced alongside the embeddings with one row per embedded spectrum
- For the independent phosphoproteomics PXD015943 dataset, ~18.6 million spectra embed and pair statistics land near reported scales (~3.7M PSMs at 1% FDR, 1.185B positive pairs, 293M negative pairs within 10 ppm precursor mass tolerance)
- On the full MassIVE-KB run (669M spectra), downstream clustering at distance threshold 0.35 yields ~76% clustered fraction, ~1.16% incorrectly clustered fraction, and 0.837 completeness
- No 'This repository is over its data quota' LFS error during install; if it occurs, weights were fetched manually into data/

## Limitations

- Requires Python 3.8, a Linux operating system, and a CUDA-enabled GPU
- Git LFS bandwidth may be exhausted when downloading model weights, requiring the manual workaround (GIT_LFS_SKIP_SMUDGE=1 clone and manual download of gleams_82c0124b.hdf5)
- MassIVE-KB spectra are not available as a single download; the full training dataset must be assembled from the metadata TSV and MassIVE FTP server
- Neural-network configuration (including training parameters) must be edited in gleams/config.py for non-default setups
