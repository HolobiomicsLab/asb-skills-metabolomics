# r-geneset-pvalue-computation

## Summary

Module 4 of metGWAS 1.0 computes the over-representation P-value for the intersection of a metabolite-interacting gene set and a trait/disease-related GWAS subnetwork using a hypergeometric test in R, with the discoverable gene set (GWAS-network discoverable genes) as the population universe.

## When to use

Use when a metabolite-interacting gene set and a GWAS trait/disease subnetwork have already been generated (metGWAS 1.0 Modules 2 and 3) and you need the over-representation P-value of their overlap.

## When NOT to use

- When paired metabolomics-GWAS individual-level data exist that support direct variant-metabolite association testing rather than unpaired gene-set over-representation
- When either gene set (metabolic or GWAS subnetwork) has not yet been generated by Modules 2/3 of metGWAS 1.0 — the test requires both intersectable gene sets plus the discoverable population universe

## Inputs

- Module 2 output: metabolite-interacting gene set (mapped from disease-associated metabolites to interacting proteins/genes)
- Module 3 output: trait/disease-related GWAS subnetwork gene set
- Discoverable gene set population universe: GWASnetwork_discoverableGenesOnly_2021_10_14.RData
- HMDB all-genes universe: discoverableGenes_akaAllGenesInHMDB_2021_10_14.RData

## Outputs

- hypergeometric_pvalue.csv containing the over-representation P-value together with overlap size k, metabolic gene-set size n, GWAS subnetwork size m, and discoverable population size N

## How to apply

In R, load the Module 2 metabolite-interacting gene set and the Module 3 GWAS trait/disease subnetwork gene set, plus the discoverable gene set (GWAS-network discoverable genes, e.g. GWASnetwork_discoverableGenesOnly_2021_10_14.RData) as the population universe N. Compute the intersection of the two gene sets to get overlap size k, and record the metabolic gene-set size n, the GWAS subnetwork size m, and the discoverable population size N. Run the hypergeometric over-representation test as the upper-tail probability P(X >= k), i.e. the probability of observing at least k overlapping genes when the metabolic gene set is drawn at random from the discoverable population, with GWAS-network genes as successes and the metabolic gene set as the draw. Write the P-value together with k, n, m, and N to hypergeometric_pvalue.csv. The metGWAS 1.0 workflow is run via the metGWAS 1.0_19 April.R script, after setting up the environment with qvalue and bioconductor install.R and RSelenium Driver SetUp.R.

## Evaluation signals

- hypergeometric_pvalue.csv contains the P-value along with all four count parameters k, n, m, N (overlap, metabolic gene-set size, GWAS subnetwork size, discoverable population size)
- Sanity invariants: k <= min(n, m), and n and m must not exceed the discoverable population size N
- The P-value must equal the upper-tail probability P(X >= k) of the hypergeometric draw, not the lower tail or a two-sided probability
- Case-study 1 replication check: nine genes (APOA5, PLA2G5, PLA2G2D, PLA2G2E, PLA2G2F, LRAT, PLA2G2A, PLB1, PLA2G7) with cardiovascular disease association at P < 0.005
- Case-study 2 replication check: marginal significance P = 0.10 (glycine, serine, threonine metabolism) and P = 0.13 (alanine, aspartate, glutamate metabolism) against kidney GWAS data

## Limitations

- Analysis is limited to genes with known metabolite interactions because the metabolomics and GWAS data sets are unpaired/independent
- The required GWASnetwork_discoverableGenesOnly_2021_10_14.RData file (64,516KB) is not included in the supplementary material and must be downloaded externally (Harvard Dataverse)
- Low signal situations can yield only marginal significance (e.g. P = 0.10 and P = 0.13 in case study 2), so absence of significance does not imply absence of association
