# summary-statistics-table-generation

## Summary

Generates proportion statistics over a large predicted-NMR compound set: classify each molecule's predicted 1H signals as shielded or deshielded, tally fractions, and write the headline percentages to a summary CSV. In the source article this validated NMRShiftDB2 HOSE-code predictions over 27,844 Natural Products Atlas microbial natural products (94.9% with ≥10% deshielded signals; 0.4% exclusively shielded).

## When to use

Use when you have batch-predicted 1H chemical shifts for a large compound library and need to report proportions of molecules passing a signal-deshielding threshold (e.g. ≥10% deshielded signals) into a summary statistics table.

## When NOT to use

- When compounds belong to specialist classes with exclusively shielded 1H signals (sterols, low MW isoprenoids, lipids, volatile terpenes) — these are precluded from the platform analysis this statistic motivates
- When the goal is per-sample mixture feature extraction (TOCSY/HSQC spin systems) rather than population-level proportion statistics over a predicted spectral library

## Inputs

- Structure set of 27,844 microbial natural products from the Natural Products Atlas database
- Per-structure predicted 1H chemical shifts generated by the stereo-aware HOSE code model from NMRShiftDB2
- Deshielding threshold (10% deshielded signals) and shielded/deshielded shift classification rule

## Outputs

- Per-molecule fraction-of-deshielded-signals values
- Summary statistics CSV containing the proportion of molecules with ≥10% deshielded 1H signals and the proportion with exclusively shielded 1H signals (expected 94.9% and 0.4%)

## How to apply

Load the full structure set (27,844 microbial natural products from the Natural Products Atlas) and predict 1H chemical shifts for every structure using the stereo-aware HOSE code model available from NMRShiftDB2. For each molecule, classify individual predicted 1H signals as shielded or deshielded and compute the per-molecule fraction of deshielded signals. Set the decision threshold at 10% (molecules with ≥10% deshielded signals) and additionally identify molecules whose predicted signals are exclusively shielded. Tally both counts across the whole set and write the two resulting percentages to a summary statistics CSV file; the counts are population-level descriptors used to justify which compound classes a spin-system dereplication platform can detect.

## Related tools

- **NMRShiftDB2** (Source of the stereo-aware HOSE code model used to predict 1H chemical shifts for every structure before shielded/deshielded classification and tallying)

## Evaluation signals

- Computed percentage of molecules with at least 10% deshielded 1H signals matches the reported 94.9%
- Computed percentage of molecules with exclusively shielded 1H signals matches the reported 0.4%
- All 27,844 Natural Products Atlas microbial natural product structures are represented in the tally (no structures dropped silently)
- Per-molecule deshielded-signal fractions fall within [0, 1] and both summary percentages sum consistently with the two reported categories

## Limitations

- Sterols, low MW isoprenoids, lipids, and volatile terpenes with exclusively shielded 1H signals cannot be captured by this deshielding-based classification
- Current 'lightweight' NMR predictors do not have sufficient accuracy for dereplication-level tasks, so downstream use of the statistics is bounded by predictor accuracy
- Only 0.4% of molecules are exclusively shielded, so the ≥10% deshielded criterion excludes very few compounds — threshold sensitivity is limited
