# drug-class-stratified-rate-computation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Computes the fraction of drugs (of 1114 total) producing at least one metabolite unpredicted by BioTransformer 3.0, and stratifies those rates by therapeutic drug class using Microsource Spectrum Collection / Supplemental Table 1 annotations. This quantifies how often in silico prediction misses experimentally observed human liver S9 metabolites.

## When to use

Use when you have per-drug lists of curated metabolite features (m/z and retention time) and BioTransformer 3.0 predictions, and need to report overall plus per-drug-class rates of unpredicted metabolism.

## When NOT to use

- Input is raw LC-HRMS data requiring metabolite feature detection or curation — this skill starts from already-curated per-drug metabolite feature lists
- The goal is predicting metabolites de novo (e.g., running BioTransformer) rather than quantifying prediction coverage against observed features
- Metabolites were generated in extrahepatic compartments or by enzymes not active in human liver S9 fraction, since PharmMet DB lacks those metabolites

## Inputs

- Per-drug detected-feature lists (m/z and retention time of curated metabolites for each of 1114 drugs) from Metabolomics Workbench Study ID ST003991
- BioTransformer 3.0 predicted-metabolite reference table used as the curation baseline
- Drug class annotations from the Microsource Spectrum Collection metadata
- Supplemental Table 1 (complete breakdown of drug classes of 1114 therapeutic drugs)

## Outputs

- Overall fraction of drugs with at least one unpredicted metabolite (997/1114 = 89%)
- Per-drug-class unpredicted-metabolite rates (e.g., ~77% respiratory, ~91%+ antimicrobial/CNS/other)
- unpredictable_metabolite_summary.csv (per-class and overall summary written with R 4.0.3)

## How to apply

Download per-drug detected-feature lists for the 1114 drugs from Metabolomics Workbench Study ID ST003991 (project DOI 10.21228/M8W55K). Classify each curated metabolite as predicted or unpredicted by matching observed m/z signals against the BioTransformer 3.0 reference set within ±5 ppm, retaining only features that meet the paper's identification criteria (detection exclusively in precursor+cosubstrate samples, ≥10-fold 0-to-24-hour peak-area increase). For each drug, flag whether it has at least one unpredicted metabolite, then compute the overall fraction (expected: 997/1114 ≈ 89%). Join drug class annotations from the Microsource Spectrum Collection metadata and Supplemental Table 1 to compute per-class unpredicted rates (reported range: ~77% for respiratory drugs to >91% for antimicrobial, CNS, and other classes). Perform the computation and summary in R 4.0.3.

## Related tools

- **R 4.0.3** (Performs the per-drug and per-class computation and writes the summary CSV)
- **BioTransformer 3.0** (Provides the predicted-metabolite reference set against which observed features are classified as predicted or unpredicted)
- **PharmMet DB** (Source of the experimentally validated metabolite data and drug class breakdown for the 1114 drugs) — https://github.com/ClinicalBiomarkersLaborabory/PharmMet

## Examples

```
Rscript --vanilla -e 'df <- read.csv("st003991_curated_features.csv"); s <- aggregate(unpredicted ~ drug_class, df, mean); write.csv(s, "unpredictable_metabolite_summary.csv", row.names=FALSE)'
```

## Evaluation signals

- The computed overall unpredicted rate must match 997/1114 (89%) as reported in the article
- Per-class ordering must place CNS, antimicrobial, and other classes among the highest unpredicted rates (>91%) and respiratory among the lowest (~77%), consistent with the article's reported pattern
- Every metabolite classified as predicted or unpredicted must have matched a BioTransformer 3.0 prediction within ±5 ppm mass accuracy
- Only metabolite features detected exclusively in precursor+cosubstrate samples with a ≥10-fold 0-to-24-hour peak-area increase should be counted
- The output CSV should cover all 1114 drugs with non-missing class annotations from Supplemental Table 1

## Limitations

- Reliance on the liver S9 fraction for biotransformation means not all drug-metabolizing activities are present, so rates reflect only hepatic in vitro metabolism
- PharmMet DB is expected to lack metabolites formed by enzymes not abundant or active in the liver S9 fraction, or generated in extrahepatic compartments (eg, intestine, kidney)
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression
- The identification of novel metabolites from nearly 1000 drugs will require considerable research for isolation and structural elucidation
