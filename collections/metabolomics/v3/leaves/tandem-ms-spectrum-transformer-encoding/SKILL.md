# Tandem-MS spectrum transformer encoding

## Summary

Encodes tandem MS/MS spectra (individual spectra and consensus spectra over collision energies) with transformer encoders inside MVP's four-view contrastive framework, mapping spectral peaks and subformula labels into the same joint embedding space as molecular graph and fingerprint encoders for candidate ranking on MassSpecGym.

## When to use

Use when building contrastive spectrum-to-molecule encoders for MS/MS retrieval: spectra are peak lists with subformula labels (formSpec) or binned spectra (binnedSpec), and candidates must be ranked in a shared embedding space.

## When NOT to use

- When the task is de novo molecule generation or spectrum simulation rather than retrieval-based annotation on a fixed candidate set
- When only a single spectrum per molecule is available and no consensus spectrum can be formed — the consensus-view advantage (aggregate-then-rank) cannot be realized, though individual-spectrum ranking is still supported

## Inputs

- MassSpecGym spectra table (data.tsv) with MS/MS peak lists across collision energies
- MassSpecGym candidate molecules file (candidates_mass.json)
- Preprocessed subformula label directory (from assign_subformulae.py --max-formulae 60) for the formSpec path
- params_formSpec.yaml or params_binnedSpec.yaml configuration with dataset and candidates paths

## Outputs

- Trained spectral transformer encoder weights (trained_model.pt) embedding spectra and consensus spectra into the joint space
- Consensus-spectrum training files generated by data_preprocess.py
- Per-epoch training loss curve (training_loss.png) logged by Lightning
- Ranked molecular candidate lists; rank@1 retrieval metrics (35.99% by mass, 13.96% by formula with the consensus view; 26.37% and 11.10% with individual spectra)

## How to apply

Preprocess spectra via MVP's data_preprocess.py with --spec_type formSpec, after running assign_subformulae.py with --max-formulae 60 to compute per-peak subformula labels (or --spec_type binnedSpec to skip subformula assignment), producing fingerprint and consensus-spectrum training files from the MassSpecGym spectra table (data.tsv) and candidates file (candidates_mass.json). Instantiate a PyTorch transformer encoder over the individual spectrum view (Zs) and a second transformer over the consensus spectrum view (Zcs) derived by aggregating the spectra of one molecule across collision energy levels. Train the spectral encoders end-to-end together with the GCN molecular-graph encoder and MLP fingerprint encoder using MVP's CMC-style pairwise contrastive loss that aligns all four views in one joint embedding space, launched with train.py and a params_formSpec.yaml (or params_binnedSpec.yaml) config pointing at the preprocessed data. The rationale is that jointly learning from all views captures complementary and shared information while mitigating view-specific artifacts; at inference, ranking with the consensus spectrum view outperforms rank aggregation over individual spectra. Save encoder weights to trained_model.pt and inspect the per-epoch Lightning-logged training loss.

## Examples

```
python subformula_assign/assign_subformulae.py --spec-files ../data/msgym/data.tsv --output-dir ../data/msgym/subformulae_default --max-formulae 60 --labels-file ../data/msgym/data.tsv ; python data_preprocess.py --spec_type formSpec --dataset_pth ../data/msgym/data.tsv --candidates_pth ../data/msgym/candidates_mass.json --output_dir ../data/msgym/ ; python train.py --param_pth params_formSpec.yaml
```

## Evaluation signals

- training_loss.png shows the four-view contrastive loss decreasing monotonically over epochs
- trained_model.pt loads and embeds all four views (molecular graph, fingerprint, spectrum, consensus spectrum) consistently with the checkpoint
- Consensus-spectrum evaluation on MassSpecGym reproduces the reported retrieval levels: 35.99% rank@1 by mass and 13.96% rank@1 by formula
- Individual-spectrum ranking falls near the reported 26.37% (mass) and 11.10% (formula) rank@1
- Consensus-view ranking outperforms rank-then-aggregate aggregation of the three per-collision-energy spectra on molecules with exactly three spectra (1,531 test cases)

## Limitations

- Losses that directly prioritize ranking molecular candidates are not included in MVP's contrastive objective; the authors note these could improve ranking performance
- Representation quality could benefit from more accurate peak labeling and additional views
- The preprocessed MassSpecGym download URLs in the MVP README are empty, so preprocessing from data.tsv must be run locally
- Peak labels via the formSpec path assume every peak is charged with the adduct, an assumption inherited from MIST's formula annotation algorithm
