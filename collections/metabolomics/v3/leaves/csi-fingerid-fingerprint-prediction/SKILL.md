# csi-fingerid-fingerprint-prediction

## Summary

Predicts a structural fingerprint (xF) from an MS2 tandem mass spectrum using CSI:FingerID, after SIRIUS assigns the molecular formula (xM). The fingerprint acts both as a database-search target and as the structural blueprint that MSNovelist's encoder–decoder consumes for de novo SMILES generation.

## When to use

Use when an MS2 spectrum (mgf, .ms, or preprocessed SIRIUS workspace) needs a predicted structural fingerprint xF — either to rank candidate structures by modified Platt score or to serve as the blueprint input for MSNovelist de novo generation.

## When NOT to use

- Negative-mode MS2 spectra — MSNovelist/CSI:FingerID performance is lower there since MSNovelist is trained only on positive-mode data
- Spectra with fewer than three fragment ions — the pipeline requires a minimum of three fragment ions, and richer spectra are desirable
- Spectra at high m/z with unreliable formula assignment — SIRIUS formula error rates rise to >50% for compounds up to m/z 800, which propagates into fingerprint prediction

## Inputs

- MS2 tandem mass spectra in .mgf or .ms (SIRIUS format) files
- Preprocessed SIRIUS 4.4.29 workspace folder (used directly as MSNovelist input)
- Predicted molecular formula (xM) from SIRIUS, optionally supplied directly if known

## Outputs

- Predicted structural fingerprint xF per spectrum
- Candidate structures ranked by modified Platt score (decode-RUNID.csv / .pkl)
- Fingerprint cache (fingerprint_cache.db) for reuse across runs

## How to apply

First run SIRIUS molecular formula prediction on the MS2 spectrum (default settings in the container: 'formula -p qtof structure -d ALL_BUT_INSILICO'), because CSI:FingerID fingerprint prediction depends on the formula xM. CSI:FingerID then maps the spectrum to a structural fingerprint xF, which directly encodes structural information and acts as a blueprint for a molecule. Downstream, candidates (database hits from PubChem/KEGG or k de novo SMILES generated by MSNovelist under the xM constraint) are re-ranked by computing the match to the query fingerprint xF using the modified Platt score — the article notes this final re-ranking is important for best results. The Docker container handles this end-to-end via predict.sh, maintaining a fingerprint cache at DATAFOLDER/fingerprint_cache.db and writing results to results-RUNID/decode-RUNID.csv ordered by score_mod_platt.

## Related tools

- **CSI:FingerID** (Predicts the structural fingerprint xF from the MS2 spectrum; also performs database search against PubChem/KEGG whose hits are re-ranked by modified Platt score against xF)
- **SIRIUS** (Upstream molecular formula prediction (xM) required before fingerprint prediction; formula may also be bypassed with external knowledge) — https://bio.informatik.uni-jena.de/software/sirius/
- **MSNovelist** (Consumes the predicted fingerprint xF as the encoder input blueprint to generate de novo SMILES constrained by xM) — https://github.com/meowcat/MSNovelist

## Examples

```
docker run --init -v "$(pwd)":/msnovelist-data msnovelist predict.sh 377.mgf
```

## Evaluation signals

- On the 3,863-spectra GNPS evaluation set, database search with CSI:FingerID should rank the correct structure on top for 39% of instances
- Ablation check: MSNovelist with fingerprint input retrieves 45% of correct structures (25% first rank) on GNPS, versus only 31% (17% first rank) for naive generation without fingerprint input — the fingerprint must be contributing signal
- Result file rows should be orderable by score_mod_platt descending, with rank_score_lim_mod_platt == 1 identifying the top candidate per query spectrum
- On CASMI 2016, correct predictions 26% / retrieval 57% serve as an independent benchmark comparison
- Re-running the same spectrum should hit the existing fingerprint_cache.db rather than regenerate fingerprints, and results should be reproducible under the same RUNID settings file (msnovelist-config-RUNID.yaml)

## Limitations

- Certain isomers fragment (almost) indistinguishably, so structural elucidation from MS2 data is not possible in all cases
- Fingerprint-based pipeline is trained only for positive-mode data; negative-mode performance is expected to be lower
- Formula determination errors (up to >50% for individual spectra up to m/z 800) degrade downstream fingerprint prediction
- Requires at least three fragment ions per MS2 spectrum; richer spectra give better performance
- The published MSNovelist backend depended on an old SIRIUS version; MSNovelist is now integrated into SIRIUS 6, and data processed with current SIRIUS is incompatible with the old SIRIUS 4.4.29 workspace path
