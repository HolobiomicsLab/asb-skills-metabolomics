# simulation-replicate-aggregation-power-tabulation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Aggregates repeated PaIRKAT simulation replicates into empirical power estimates tabulated by pathway-graph mismatch level (10%/40%/70% incorrect edges) and pathway size (p = 15, 30, 45), to quantify how incorrect pathway edge information erodes kernel score-test power.

## When to use

Use when estimating empirical power of a kernel machine score test (e.g., PaIRKAT with τ = 1) over repeated simulations in which a design factor—fraction of incorrect pathway edges or number of pathway metabolites—is systematically varied.

## When NOT to use

- The goal is real-data association testing (e.g., COPDGene metabolomics with the 28 KEGG pathways) rather than simulation-based power estimation
- Calibrating or estimating type I error rather than power under alternatives (the repo separates 'TypeI and Power simulation scripts')
- Evaluating performance differences on real data, where the paper instead averages p-values over 100 random subsets of sizes 100–500 rather than simulating replicates

## Inputs

- Simulated pathway-structured outcome and metabolite data generated by the PaIRKAT simulation framework (R code from github.com/CharlieCarpenter/PaIRKAT)
- Barabasi-Albert random pathway graphs (igraph) at pathway sizes p = 15, 30, 45 with 10%/40%/70% of true edges replaced by permuted incorrect edges
- Simulation replicate results (per-replicate test outcomes) from the PaIRKAT score test with τ = 1

## Outputs

- power_mismatch_by_size.csv — one row per (pathway size, mismatch level) combination with columns for pathway size, mismatch level, and estimated empirical power
- Qualitative check against the reported claims: ~10% mismatch comparable to perfect structure in small pathways; monotonic power loss at 40% and 70% mismatch

## How to apply

Reproduce the PaIRKAT simulation framework from the R code at github.com/CharlieCarpenter/PaIRKAT and configure the partial-mismatch scenario where a fraction of true pathway edges is replaced by incorrect edges via permutation of edge connections, keeping the edge count constant so only correctness of connections varies. For each pathway size p = 15, 30, and 45 metabolites, generate Barabasi-Albert random pathway graphs with the igraph package, as in the original simulations, and apply the 10%, 40%, and 70% edge-mismatch levels by permuting the corresponding fraction of edges. Run the PaIRKAT kernel machine score test with the regularization parameter fixed at τ = 1 (the value used throughout the paper) on the simulated pathway-structured outcomes for every mismatch-by-size combination, estimating empirical power over simulation replicates. Aggregate replicate results into empirical power estimates and assemble a table with rows indexed by pathway size and by mismatch level, then write the results to the canonical output file power_mismatch_on_size.csv (one row per pathway size × mismatch level combination). Validate that the table is parseable CSV with the expected row count, all power values numeric in [0, 1], and that the pattern matches the paper's claims: ~10% mismatch performs comparably to perfect structure in small pathways, and power decreases monotonically as incorrect-edge proportion grows from 40% to 70%, with power higher in larger pathways.

## Related tools

- **R** (Language in which the PaIRKAT simulation scripts (TypeI and Power simulation scripts) are implemented and run) — https://github.com/CharlieCarpenter/PaIRKAT
- **igraph** (Generates Barabasi-Albert random pathway graphs for each simulated pathway size before edge-permutation mismatch is applied) — https://github.com/CharlieCarpenter/PaIRKAT

## Examples

```
Rscript SimulationFunctions/PowerSimulation.R  # TypeI and Power simulation scripts under SimulationFunctions in the PaIRKAT repo
```

## Evaluation signals

- power_mismatch_by_size.csv exists, parses as CSV, and contains exactly one row per mismatch-level × pathway-size combination (3 mismatch levels × 3 sizes = 9 rows)
- All estimated power cells are numeric and within [0, 1]
- Empirical power decreases monotonically as the incorrect-edge proportion increases from 10% to 40% to 70% at each pathway size
- At ~10% mismatch, power is comparable to the perfect-structure setting in small pathways, matching the paper's reported robustness claim
- Power is higher in larger pathways (p = 45) than smaller ones (p = 15) at comparable mismatch levels

## Limitations

- The regularization parameter τ is fixed to 1 in all simulations and data analyses, with no sensitivity analysis of τ reported
- Software/tool versions for R and igraph are not reported (only citation numbers), so exact reproducibility of the simulation environment is uncertain
- The mismatch conclusions are qualitative simulation findings about incorrect/incomplete pathway knowledge; they do not transfer to real-data performance differences, which the paper demonstrated only on downsampled subsets of 100–500 subjects, not the full cohort
