# MS2 spectral entropy similarity networking

## Summary

Builds an MS2 spectrum similarity network (SSN) by computing pairwise entropy-based spectral similarities between candidate metabolite MS2 spectra and parent pesticide MS2 spectra, then assigns each candidate its highest-similarity parent as the 'seed molecule' for reaction-guided metabolite annotation in CMDN.

## When to use

Use when LC-HRMS MS2 peak lists exist for enzymatic-assay-derived candidate metabolites and their parent xenobiotics, and candidates must be assigned to parents by spectral similarity rather than reference-library matching.

## When NOT to use

- Candidates have not yet been generated by the upstream RCS layer — the SSN assigns preannotated candidates and cannot propose reaction-derived formulas on its own
- The data are MS1-only features with no MS2 spectra, since entropy spectral similarity requires MS2 peak lists
- Authentic analytical/stable-isotopic-labeled standards are available for direct library verification, which supersedes spectral-similarity-based assignment

## Inputs

- MS2 peak lists of parent pesticide spectra (accurate m/z, RT, MS2) from LC-HRMS runs
- Preannotated candidate metabolite MS2 spectra generated by the CMDN reaction-based pseudo-MS1 candidature space (RCS)
- LC-HRMS feature table (accurate m/z, retention time, MS2 spectra) for incubation samples, e.g., human liver S9 incubations

## Outputs

- MS2 spectrum similarity network (SSN) with pairwise entropy similarity scores (ss) as edge weights
- Seed-molecule annotations mapping each candidate metabolite to its most similar parent pesticide
- Confident annotation table, e.g., ssn_annotations.csv with candidate metabolite, seed parent pesticide, similarity score, and filter status
- Parent-specific subnetworks with node metadata and edge similarity scores, e.g., representative_subnetworks.csv

## How to apply

Load MS2 peak lists of parent pesticides and of preannotated candidate metabolites (accurate m/z, RT, MS2) produced upstream by the reaction-based pseudo-MS1 candidature space (RCS) of CMDN. Compute pairwise entropy-based spectral similarity (ss) between every candidate MS2 spectrum and every parent MS2 spectrum using the entropy-based similarity implemented via the msentropy/CluMSID/MSMSsim R packages in the CMDN pipeline. Assign each candidate the parent with the highest ss as its seed molecule. Filter the network by retaining only candidate-parent links with ss >= 0.4 and removing annotations attributable to adducts and in-source fragments (ISF), which otherwise generate spurious high-similarity links. For downstream pathway interpretation, extract parent-specific subnetworks keeping edges in dataset-specific similarity ranges (e.g., 0.62-0.70 for the malathion subnetwork, 0.46-0.64 for the sulprofos subnetwork) and annotate nodes with RT shifts and biotransformation types.

```
Rscript -e "library(tidyverse); library(msentropy); library(MSMSsim)"  # load entropy-based MS2 similarity stack from CMDN requirements
```

## Evaluation signals

- Every retained annotation has ss >= 0.4 and is assigned exactly one seed molecule
- All surviving annotations have passed the adduct and in-source fragment (ISF) removal filter; spot-check a subset by expert review
- Extracted subnetworks have the expected cardinality: the malathion table contains exactly 12 metabolite rows and the sulprofos table exactly 4
- Malathion subnetwork edge similarities fall within the reported entropy similarity range of 0.62-0.70, and sulprofos edges within 0.46-0.64
- Output files (ssn_annotations.csv, representative_subnetworks.csv) carry the required columns: candidate metabolite, seed parent pesticide, similarity score, and filter status

## Limitations

- Adducts and in-source fragments (ISF) generate spurious high-similarity links and must be explicitly removed or they corrupt the seed assignments
- Similarity thresholds (ss >= 0.4; subnetwork ranges 0.62-0.70 and 0.46-0.64) were calibrated on this pesticide/S9-incubation dataset and may need re-tuning for other chemical spaces
- Assignments are similarity-based annotations, not standard-confirmed identifications; confirmation requires the article's multichannel validation (standards, RT prediction, time-course modeling, murine studies)
