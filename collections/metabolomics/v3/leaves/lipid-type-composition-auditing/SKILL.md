# lipid-type-composition-auditing

## Summary

Audits the species/type composition of LipidMatch's in silico fragmentation libraries by enumerating and tallying the library .csv files shipped in 2017_6_14_LipidMatch_Distribution.zip, to reproduce the paper's reported coverage (over 250,000 lipid species across 56 lipid types, with 39 endogenous and 214 oxidized fatty acids).

## When to use

Use when you need to quantify or verify the composition of an in silico lipid fragmentation library — e.g., counting lipid species, lipid types, fatty acid combinations, or class/adduct coverage from a library distribution.

## When NOT to use

- Input is raw UHPLC-HRMS/MS or .ms2 spectral data that you want identified — use LipidMatch's rule-based identification workflow instead of auditing library composition
- Benchmarking annotation performance or number of identifications on a real sample (e.g., Red Cross plasma vs MS-DIAL/Greazy) — this skill counts library contents, not identifications
- Counting lipid types under a different convention that does not split plasmenyl/plasmanyl ether pairs as two types — counts will not match the paper's 56-type figure

## Inputs

- 2017_6_14_LipidMatch_Distribution.zip (Additional file 1) containing lipid libraries in .csv format
- Fatty acid combination lists generated by the LipidMatch R script (endogenous and oxidized)
- Library class-label and adduct annotation fields within the .csv library files

## Outputs

- library_composition_report.csv with total species count, per-type counts, fatty acid list sizes, and unique-class presence flags
- Per-file tallies of unique lipid species entries
- Boolean presence flags for oxidized lipids, bile acids, sphingosines, and ammoniated cardiolipins

## How to apply

Extract the 2017_6_14_LipidMatch_Distribution.zip (Additional file 1, also at http://secim.ufl.edu/secim-tools/) and enumerate its lipid library files in .csv format with R. Load each .csv and tally unique lipid species entries per file, summing across libraries to obtain a total species count treated as a lower bound (the 2017 paper reports over 250,000; the latest README version exceeds 500,000 across over 60 types). Count distinct lipid types using the paper's convention: each plasmenyl/plasmanyl ether pair counts as two types, and oxidized lipids across classes count as one — the 2017 libraries yield exactly 56 types, versus 34 for MS-DIAL and 24 for Greazy. Verify the fatty acid combination lists generated by the R script: 39 endogenous fatty acids and 214 potential oxidized fatty acids (126 long-chain O/OH/OOH additions plus 88 short-chain CHO/COOH cleavage products from LIPID MAPS fatty acids, with redundant permutations such as 18:0_20:0 vs 20:0_18:0 excluded). Finally, scan library class labels and adduct annotations to flag oxidized lipids, bile acids, sphingosines, and ammoniated cardiolipins, and write all counts and presence flags to a report CSV.

## Examples

```
Rscript -e 'libs <- list.files("2017_6_14_LipidMatch_Distribution", "\\.csv$", full.names=TRUE, recursive=TRUE); cat(sum(sapply(libs, function(f) length(unique(read.csv(f)[,1])))))'
```

## Evaluation signals

- Total summed unique species count exceeds 250,000 for the 2017 distribution (README's latest version: over 500,000)
- Distinct lipid-type count equals exactly 56 under the paper's convention (ether plasmenyl/plasmanyl pairs as two types; oxidized lipids across classes as one)
- Endogenous fatty acid combination list contains exactly 39 entries
- Oxidized fatty acid list contains exactly 214 entries: 126 long-chain (O/OH/OOH) plus 88 short-chain (CHO/COOH) products, with redundant permutations like 18:0_20:0 vs 20:0_18:0 deduplicated
- Presence flags are TRUE for oxidized lipids, bile acids, sphingosines, and ammonium-adduct cardiolipins

## Limitations

- Counts are version-dependent: the 2017 distribution gives >250,000 species / 56 types, while the current README claims over 500,000 species across over 60 lipid types, so expected numbers must match the audited release
- Key artifacts (software zip, .csv libraries) are only provided as journal additional files, not archived in a public repository, hindering reproducibility of the audit
- The software was pinned to R version 3.3.3, so library-generation scripts may not run unmodified in current R environments
