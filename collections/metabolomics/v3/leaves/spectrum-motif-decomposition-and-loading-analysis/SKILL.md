# spectrum-motif-decomposition-and-loading-analysis

## Summary

Unsupervised decomposition of every MS2 spectrum from a complex-mixture metabolomics experiment into learned Mass2Motifs (recurring fragment/neutral-loss substructures) using MS2LDA's latent Dirichlet allocation, producing per-spectrum motif loadings that support substructure-based grouping and de novo putative annotation.

## When to use

Use when you have information-rich MS2 spectra (e.g. ~1,000 MS1 peaks per sample, ramped or stepped collision energy) from a complex mixture and want unsupervised substructure discovery without prior compound identification.

## When NOT to use

- The input consists of simple mixtures with low-information MS2 spectra — the paper states MS2LDA 'works best for complex mixtures where a large number of metabolites are fragmented and information-rich MS2 spectra are available (e.g., generated by ramped or stepped collision energy)'
- The analysis goal requires neutral losses in automated spectral matching — 'losses are not currently supported by spectral matching tools and had to be omitted'
- The input is already a feature table or already-identified compound list rather than raw/fragmentation spectra needing unsupervised substructure discovery

## Inputs

- Preprocessed LC-MS/MS spectra corpus from a complex mixture (e.g. four beer extracts, positive and negative ionization mode), each MS1 peak's MS2 spectrum represented as a bag of fragments and neutral losses
- MS/MS data acquired on e.g. Thermo Scientific Q-Exactive Orbitrap with HESI II interface (Thermo Xcalibur Tune 2.5 for acquisition)
- Optional: a set of previously characterized Mass2Motifs to keep fixed during inference (e.g. beer-characterized motifs)

## Outputs

- motifset.json — discovered Mass2Motifs as fragment/neutral-loss distributions (with motifset_optimized.json variant)
- doc2spec_map.pkl — mapping of LDA documents to original spectra (MS1 peaks / MS2 spectra)
- Per-spectrum Mass2Motif loadings decomposing each MS2 spectrum into motifs
- Motif degrees (number of spectra in which each Mass2Motif occurs)
- Convergence curve (convergence_curve.png) of LDA training
- Spectrally matched automatic annotations of Mass2Motif spectra (where Mass Bank/NIST hits pass thresholds)

## How to apply

Preprocess the LC-MS/MS corpus (e.g. four beer extracts, each yielding around 1,000 MS peaks per ionization mode) so each MS1 peak's MS2 spectrum is represented as a bag of molecular fragments and neutral losses, using the MS2LDA preprocessing utilities (which include noise filtering and neutral-loss extraction). Initialize the LDA model with the number of topics (Mass2Motifs) set to the desired motif budget (300 per data file in the beer study; 500 for the 5,670-spectrum GNPS dataset) and train with variational Bayesian inference (or the collapsed Gibbs engine) until the convergence curve stabilizes. Optionally keep previously characterized Mass2Motifs fixed during inference while learning the remaining topics, as done when re-analyzing Mass Bank and GNPS spectra with beer-derived motifs held constant. Extract each Mass2Motif as a fragment/neutral-loss probability distribution, compute per-document (MS1 peak/MS2 spectrum) motif loadings, and calculate each motif's degree (number of spectra in which it occurs); in the beer study degrees spanned 1 to over 200. Retain motifs with degree ≥ 10 for downstream structural characterization, where 30–40 positive-ionization-mode motifs per beer file proved biochemically interpretable, and optionally subject motif spectra to spectral matching (Mass Bank/NIST, 90% normalized-score threshold; probability threshold 0.1 for validating substructure annotations, omitting neutral losses since matching tools do not support them).

## Examples

```
pip install ms2lda; python -c "from ms2lda import LDA; lda = LDA(n_topics=300); docs = lda.preprocess('beer3_pos.mzml'); lda.run(docs, inference='VB'); lda.save('motifset.json','doc2spec_map.pkl')"
```

## Evaluation signals

- The learned motif set contains the expected number of Mass2Motifs per data file (300 per beer file; 500 for the 5,670-spectrum GNPS dataset)
- Motif degrees span a wide, plausible range (1 to over 200 spectra) rather than being degenerate
- LDA training convergence curve stabilizes before stopping; doc2spec_map.pkl correctly maps every document back to its original MS1 peak/MS2 spectrum
- For independently identified spectra, motif-based substructure annotations validate at a probability threshold of 0.1 (81.5% and 63.3% of substructure annotations correct in the beer/Mass Bank evaluations)
- Spectral matching of motif spectra against Mass Bank/NIST achieves hits for a minority of spectra at the 90% normalized-score threshold (25% and 6%), consistent with the unsupervised, de novo nature of the motifs

## Limitations

- MS2LDA relies on reliable matching of MS1 peaks to MS2 spectra and is computationally more costly than simpler tools, 'but not prohibitively so'
- Works best only for complex mixtures with information-rich MS2 spectra (ramped or stepped collision energy); single-collision-energy or sparse fragmentation data underperform
- Neutral losses are not supported by spectral matching tools and must be omitted during automated annotation
- Structural characterization was validated mainly on positive-ionization-mode beer motifs (30–40 motifs); 19 of the characterized positive-mode beer Mass2Motifs were correctly annotated in independent data, but other matrices/modes were not exhaustively characterized
- Spectral matching hits only a fraction of spectra (25% and 6% at 90% normalized score), so most motifs remain manually characterized
