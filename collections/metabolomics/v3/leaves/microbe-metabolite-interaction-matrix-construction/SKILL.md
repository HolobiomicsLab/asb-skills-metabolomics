# microbe-metabolite-interaction-matrix-construction

## Summary

Constructs a microbe-by-metabolite interaction score matrix from the weights of trained MiMeNet cross-validated MLPNN models, then thresholds it against a shuffled-data background to retain only statistically significant interactions and well-predicted metabolites.

## When to use

Use when paired microbiome–metabolome feature tables (samples in rows) have been modeled with a multi-layer neural network and you need a weighted microbe–metabolite interaction matrix for module construction or feature attribution.

## When NOT to use

- The input is a raw unnormalized abundance table — MiMeNet requires prior compositional transformation to RA or CLR and filtering of low-abundant features before training.
- You only need per-metabolite predictions without interaction attribution — the cross-validated evaluation step alone (Spearman correlations per metabolite) suffices; the interaction matrix requires the trained network weights.
- The model is a linear method like MelonnPan's Elastic Net, which produces coefficient weights per compound rather than multiplicative hidden-layer attribution scores.

## Inputs

- Samples-by-microbe feature matrix (comma-delimited, MiMeNet '-micro MICRO')
- Samples-by-metabolite feature matrix (comma-delimited, MiMeNet '-metab METAB')
- Trained MLPNN weight matrices from cross-validated models
- Background interaction score distribution from shuffled-data cross-validation iterations
- JSON network hyperparameter file (MiMeNet '-net_params NET_PARAMS')

## Outputs

- Microbe-by-metabolite mean interaction score matrix (e.g. interaction_scores.csv with 163 significant microbes × 6857 well-predicted metabolite columns)
- Set of significant microbe–metabolite interactions passing the 97.5th-percentile background cutoff
- List of well-predicted metabolites with SCC above the 95th percentile threshold

## How to apply

Load the weight matrices from all cross-validated MLPNN models (e.g. 10 iterations of 10-fold CV yielding 100 models on the IBD/PRISM dataset). For each model, multiply consecutive hidden-layer weight matrices to produce a per-model microbe-by-metabolite attribution matrix, then element-wise average these matrices into a mean interaction-score matrix. Compute a significance cutoff from an empirical background distribution generated by running the same cross-validated procedure on shuffled data (e.g. the 97.5th percentile of background interactions). Retain only microbe–metabolite pairs passing the background cutoff, and optionally subset columns to well-predicted metabolites — those with a Spearman correlation coefficient (SCC) above the 95th percentile of the evaluation distribution (MiMeNet's '-threshold' significance threshold). The resulting filtered matrix (e.g. 163 significant microbes × 6857 well-predicted metabolites on IBD/PRISM) is then biclustered into microbe and metabolite modules. Normalize inputs as relative abundance (RA) or centered log-ratio (CLR) via MiMeNet's -micro_norm and -metab_norm flags before training, since the attribution matrix depends on the trained network's learned weights.

## Examples

```
python MiMeNet_train.py -micro micro.csv -metab metab.csv -output out/ -micro_norm RA -metab_norm RA -threshold 0.95 -num_run_cv 10 -num_cv 10
```

## Evaluation signals

- Output matrix row count equals the number of significant microbes identified against the background cutoff (e.g. 163 for IBD/PRISM).
- Output matrix column count equals the number of well-predicted metabolites whose SCC exceeds the 95th percentile of the evaluation distribution (e.g. 6857 for IBD/PRISM).
- Interaction scores in the final matrix equal the element-wise average of per-model attribution matrices across all cross-validated iterations (100 models for 10×10-fold CV).
- Significance cutoff is derived from the background distribution of shuffled-data cross-validated iterations (e.g. 97.5th percentile), not from the observed-data scores themselves.
- Downstream biclustering of the interaction matrix yields microbe and metabolite modules with coherent interaction patterns (verifiable via consensus clustering).

## Limitations

- All methods including MiMeNet are limited in providing biological plausibility and mechanistic insights; the interaction matrix is an association summary, not causal evidence.
- Metabolites not associated with microbes will have low prediction correlations, lowering overall mean correlation and reducing the pool of well-predicted columns.
- Procedures to discern statistical association of microbe–metabolite interactions to host diseases do not yet exist in the current MiMeNet release.
- Interpretation of interactions depends on the background threshold; a higher threshold (observed for the soil data, possibly due to longitudinal observations) yields fewer significant interactions.
