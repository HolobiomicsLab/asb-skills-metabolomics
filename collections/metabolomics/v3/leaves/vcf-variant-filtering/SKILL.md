# vcf-variant-filtering

## Summary

Normalize and filter a ClinVar VCF (left-align with bcftools, remove duplicates, degenerate bases, large indels ≥50 bp, VUS, MT variants, and missing/multi-MC records) to yield a well-defined benchmark set of 164,549 high-review-status variants for cross-tool annotation concordance testing.

## When to use

Use when preparing a ClinVar or other VCF as a benchmark for comparing variant annotation tools and you must define a reproducible, high-review-status variant set with known clinical-significance composition.

## When NOT to use

- Input is already a fully normalized, filtered variant set (e.g., an in-house benchmark or ClinVar high-confidence set already restricted to the desired classes).
- The goal is small-variant-only discovery without needing a fixed-size benchmark — filtering to 164,549 is specific to reproducing this paper's ClinVar comparison, not a general-purpose filtering rule.

## Inputs

- ClinVar VCF release dated January 7, 2024 (raw, unnormalized)
- Reference genome and transcript annotations shared across annotation tools

## Outputs

- Filtered VCF containing exactly 164,549 variants with clinical-significance composition 38,278 P / 6,073 LP / 57,081 B / 63,117 LB
- Left-aligned, deduplicated, degenerate-base-free variant list ready for ANNOVAR, SnpEff, and VEP annotation

## How to apply

Download the ClinVar VCF release (January 7, 2024) as the raw input and left-align (normalize) all variants with bcftools so repeat-region indels are represented consistently regardless of the original variant caller. Remove duplicate records and records containing degenerate (ambiguous) bases, then drop variants matching the exclusion criteria: indels of 50 bp or larger, VUS entries, mitochondrial (MT) variants, and variants with missing or multiple Molecular Consequence (MC) annotations. Verify the filtered output contains exactly 164,549 variants with the reported clinical-significance composition (38,278 Pathogenic, 6,073 Likely Pathogenic, 57,081 Benign, 63,117 Likely Benign) before feeding the set to annotation tools. This filtering ensures the VCF generated by different callers does not produce inconsistent HGVS notation, especially for nucleotide repeats shifted left or right, so downstream HGVSc/HGVSp concordance measurements (58.52% HGVSc, 84.04% HGVSp) are not confounded by normalization artifacts.

## Related tools

- **bcftools** (Used to left-align (normalize) all variants in the ClinVar VCF so repeat-region indels are represented consistently regardless of the original variant caller.)
- **ANNOVAR** (Downstream annotation tool applied to the filtered 164,549-variant set to extract HGVSc, HGVSp, and coding impact strings per variant.)
- **SnpEff** (Downstream annotation tool applied to the filtered 164,549-variant set; achieved the highest HGVSc match fraction (0.988) in the concordance analysis.)
- **Variant Effect Predictor (VEP)** (Downstream annotation tool run with --per_gene and --coding_only on the filtered set; showed the highest HGVSp match (0.991).)
- **ClinVar** (Source database providing the 164,549 two-star (high review status) variants and the deposited HGVS strings used for string-matching during concordance validation.)

## Examples

```
bcftools norm -f reference.fa clinvar_20240107.vcf.gz | bcftools filter -e 'TYPE="indel" && (ABS(LEN)>50 || /MC="?" || /MC=",")' -o filtered.vcf
```

## Evaluation signals

- The filtered file must contain exactly 164,549 variants.
- Per-class counts must match the reported composition: 38,278 Pathogenic, 6,073 Likely Pathogenic, 57,081 Benign, 63,117 Likely Benign.
- No records with degenerate (ambiguous) bases remain in the output.
- No indels of 50 bp or larger, no VUS entries, no MT variants, and no records with missing or multiple MC annotations remain.
- Downstream concordance rates should reach the reported values (58.52% HGVSc, 84.04% HGVSp, 85.58% coding impact) when the filtered set is annotated with identical reference genomes and transcript annotations across all tools.

## Limitations

- Some HGVS syntax in ClinVar does not adhere to HGVS recommendations (see Table S3 and Table S4), which can affect string-matching during downstream concordance checks.
- Inconsistencies exist between ClinVar web pages and its VCF.
- Different MANE selections still impact the final annotation, so restricting transcripts to ClinVar-selected ones improves consistency but discrepancies with ClinVar persisted.
