# spectra-to-molecule-finetuning-evaluation

## Summary

Finetune the pretrained DiffMS diffusion decoder with a MIST spectrum encoder for end-to-end spectra-to-molecule generation on NPLIB1 (CANOPUS), then evaluate de novo generation by sampling 100 molecules per spectrum, filtering invalid/disconnected structures, ranking by frequency, and computing top-1/top-10 accuracy, MCES distance, and Tanimoto similarity.

## When to use

Use when evaluating de novo molecular structure generation from tandem mass spectra on NPLIB1/MassSpecGym, especially after pretraining the fingerprint-to-molecule diffusion decoder, to quantify downstream accuracy and structural similarity.

## When NOT to use

- When only the decoder pretraining scaling behavior is of interest and no spectra-to-molecule finetuning or benchmark evaluation is needed.
- When the target dataset is not one of the supported benchmarks (MassSpecGym or NPLIB1/canopus) and a new spectra-molecule dataset must first be built in configs/dataset.
- When chemical formula inference is not available or trusted for the spectra, since DiffMS generation is formula-restricted and cannot handle unconstrained heavy-atom composition.

## Inputs

- NPLIB1 (CANOPUS-derived GNPS subset) tandem mass spectra, processed via data_processing/01_download_canopus_data.sh
- Pretrained DiffMS diffusion decoder checkpoint (e.g. trained on the 2.8M-pair 'combined' fp2mol dataset from DSSTox, HMDB, COCONUT, MOSES)
- MIST spectrum encoder checkpoint (Zenodo record 23303289)
- configs/config.yaml with dataset set to 'canopus'

## Outputs

- 100 sampled molecules per test spectrum (formula-constrained, connectivity-filtered)
- Top-k molecule ranking per spectrum by sampling frequency
- Evaluation metrics: top-1 and top-10 accuracy, minimum MCES distance, maximum Tanimoto similarity

## How to apply

Initialize the end-to-end model with the MIST formula-transformer encoder weights (e.g. canopus-noaug from Zenodo 23303289) and the pretrained diffusion decoder checkpoint (from fp2mol pretraining, Zenodo 23542112), setting `general.load_weights` in configs/general/general_default.yaml. Finetune on NPLIB1 spectra-to-molecule generation by running spec2mol_main.py with the dataset in configs/config.yaml set to 'canopus'. At evaluation, sample 100 molecules for each spectrum, remove invalid or disconnected molecules using RDKit, and identify the top-k molecules based on sampling frequency; generation is formula-restricted, so sampled molecules must satisfy the heavy-atom composition inferred for the spectrum. Compute top-1 and top-10 accuracy, minimum MCES distance, and maximum Tanimoto similarity against ground truth to assemble the evaluation table.

## Related tools

- **DiffMS** (End-to-end encoder-decoder diffusion model finetuned on spectra-molecule generation and sampled for evaluation) — github.com/coleygroup/DiffMS
- **MIST** (Formula transformer spectrum encoder whose pretrained checkpoint initializes the end-to-end model) — coleygroup/MIST
- **RDKit** (Validates and filters sampled molecules (removing invalid or disconnected structures) and supports Tanimoto similarity computation)
- **torch_geometric** (Graph representation backend for the molecular structures generated by the diffusion decoder)

## Examples

```
conda activate diffms; sed -i "s/dataset: fp2mol/dataset: canopus/" configs/config.yaml; python src/spec2mol_main.py
```

## Evaluation signals

- The 2.8M-pair-pretrained variant should reach approximately 8.34% top-1 accuracy and 15.44% top-10 accuracy on NPLIB1, matching the reported DiffMS values.
- All molecules counted for ranking must be valid and connected (RDKit-parseable, single component) and consistent with the restricted heavy-atom formula.
- Exactly 100 molecules are sampled per spectrum before filtering; top-k selection is by sampling frequency.
- Metrics computed per spectrum: top-1/top-10 accuracy, minimum MCES distance, and maximum Tanimoto similarity against the ground-truth structure.
- Finetuned performance should improve monotonically (or near-monotonically) with increasing fingerprint-molecule pretraining dataset size (0, 0.2M, 0.8M, 1.2M, 2.8M pairs).

## Limitations

- De novo generation of the exact molecular structure remains challenging; structurally close matches (small MCES distance) are the realistic best case.
- The fp2mol pretraining pool ('combined') must have all NPLIB1 test and validation molecules removed to avoid leakage before finetuning and evaluation.
- Sampling-based evaluation depends on the 100-sample budget and frequency ranking, so rare-but-correct structures may be under-ranked.
- The codebase was tested with PyTorch 2.3.1, cuda 11.8, torch_geometric 2.3.1, and RDKit 2024.09.4; other versions are unverified.
