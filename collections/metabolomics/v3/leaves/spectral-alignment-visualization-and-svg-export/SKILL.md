# spectral-alignment-visualization-and-svg-export

## Summary

Interactive visualization of MMSA multi-spectrum peak alignments in a Python Dash web app, with peak-click highlighting of matching peaks across spectra, set-level statistics (size, top-10 intensity percentages), m/z-range and spectrum-selection filtering, and SVG export for publication figures.

## When to use

Use when an MMSA alignment JSON (from a GNPS2 task ID/USI/FBMN input) must be inspected interactively — verifying consensus peak sets shared across a molecular family's MS/MS spectra — or exported as a high-resolution SVG figure for reporting.

## When NOT to use

- Input is raw LC-MS/MS data or molecular networking output that has not yet been processed with 'Process and Save JSON' — the visualization interface expects precomputed alignment JSON.
- The goal is pairwise spectrum comparison or spectral library matching rather than aligning and visually exploring all spectra of an entire molecular-network component.
- The question requires capturing shifted peaks for specific chemical modifications (e.g., C12 HAA variants) that MMSA's greedy alignment is documented not to fully capture.

## Inputs

- MMSA alignment JSON produced via 'Process and Save JSON' (stored under ./temp/sets)
- Spectra sourced from a GNPS2 task ID + component number, FBMN task ID + component numbers, or multiple USIs (mzspec:GNPS2:TASK-<task-id>-nf_output/clustering/specs_ms.mgf:scan:<scan-number>)
- User filter settings: spectrum selection checkboxes, custom spectrum ordering, X-axis m/z limits

## Outputs

- Interactive peak-alignment figure with click-to-highlight matching peaks across spectra
- Peak set information (m/z values, intensities, set size, top-10 intensity percentages)
- High-resolution SVG export of the alignment figure

## How to apply

Load the alignment JSON generated by 'Process and Save JSON' into the Dash-based visualization interface ('/spectraalignment/'). Use checkboxes under Spectrum Selection to choose which MS/MS spectra to display, and set X-axis Limits (minimum/maximum m/z) for focused analysis of a target region — e.g., narrowing to fragment regions such as the rhamnose m/z 135.017 or HAA fragments at m/z 211.130/357.189. Click any peak to highlight all matching peaks across spectra and inspect the set information panel for m/z values, set size, and the percentage of peaks in each consensus set that rank in the top 10 intensities. Optionally reorder spectra by precursor m/z (ascending/descending) or a custom scan-number order to make adduct/fragment relationships visually comparable. Export the final figure via SVG export for high-resolution, publication-ready output.

## Related tools

- **MMSA** (The web-based tool whose Dash visualization interface presents the multiple spectral alignment interactively and exports SVG figures) — github.com/Wang-Bioinformatics-Lab/NetworkFamily_MultipleAlignment_Website

## Examples

```
git clone <repository-url> && cd NetworkFamily_MultipleAlignment_Website && make server-compose-interactive  # then open http://localhost:5000, load GNPS2 Task ID + component, click 'Process and Save JSON', inspect '/spectraalignment/', export SVG
```

## Evaluation signals

- The interactive peak-alignment figure displays shared fragment peak sets across all spectra in the component (e.g., all five phenylalanine-cholic acid adduct spectra), as judged by expert review of the alignment figure and set statistics.
- Clicking a peak highlights the matching peak in every selected spectrum, and the set panel reports the consensus set's m/z values and intensity percentages.
- The top-10 intensity analysis shows the percentage of peaks in each consensus set that rank in the top 10 intensities, and these percentages are consistent with the expected diagnostic fragments (e.g., m/z 135.017 rhamnose fragment appearing in all RL spectra).
- The exported SVG opens as a valid high-resolution figure reflecting the current filtered view (selected spectra and m/z limits).
- The application is reachable at http://localhost:5000 after deployment and routes '/' to '/setscreation' and '/spectraalignment/' for visualization.

## Limitations

- MMSA did not capture shifted peaks corresponding to the C12 HAA (m/z 239.162, [M+Na]+ of C12H24O3) or rhamnose bound to C12 (m/z 385.219, [M+Na]+ of C18H34O7), so the visualization will not show those alignments.
- Smaller peak alignments, such as y2 peaks in the albicidin family, are not fully captured in the greedy multiple alignment and therefore may be absent from the displayed consensus sets.
- The repository provides no DOI or Zenodo archive for the software, and only a local directory name (NetworkFamily_MultipleAlignment_Website) is shown rather than a full repository hosting URL.
