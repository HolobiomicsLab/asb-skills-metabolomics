# novel-metabolite-classification

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Classifies experimentally detected drug metabolite features from human liver S9 incubations as 'predicted' or 'unpredicted' (novel) by matching observed m/z values against BioTransformer 3.0 predicted metabolites within a ±5 ppm mass tolerance.

## When to use

Use when a detected feature table (paired m/z and RT values from LC-HRMS) must be split into metabolites that were predicted by an in silico tool versus those detected only postincubation with no predicted m/z match.

## When NOT to use

- The input is already a curated list where each feature already carries a predicted/unpredicted label — re-classification would be redundant.
- The experiment uses an in vitro system other than human liver S9 fraction, or metabolites formed by extrahepatic compartments (e.g. intestine, kidney) are expected, since the liver S9 fraction does not capture all drug-metabolizing activities.
- The goal is to predict metabolites de novo rather than to classify already-detected features against a prediction list — use BioTransformer 3.0 directly for prediction instead of this classification step.

## Inputs

- Detected metabolite feature table (paired m/z and RT values per drug) from 24-hour human liver S9 incubation LC-HRMS runs (dual-column HILIC+ESI+ / C18+ESI−, Orbitrap ID-X, processed with MZmine 2.53)
- BioTransformer 3.0 predicted-metabolite list for the same parent drug

## Outputs

- Per-drug feature table with columns for m/z, retention time (RT), predicted/unpredicted label, and matched BioTransformer entry (if any)
- Per-drug counts of predicted and unpredicted (novel) metabolite features

## How to apply

Load the detected metabolite feature table (paired m/z and RT values per drug from the 24-hour human liver S9 incubation LC-HRMS runs, generated by dual-column/dual ESI on a Thermo Orbitrap ID-X) alongside the corresponding BioTransformer 3.0 predicted-metabolite list for the same parent drug. For each detected feature, compute the mass difference between the observed m/z and each predicted metabolite m/z and retain matches within ±5 ppm. If an m/z match exists, label the feature 'predicted'; if no predicted metabolite matches within ±5 ppm, label it 'unpredicted' (novel, reported by paired m/z and RT). Assemble a per-drug feature table with columns for m/z, RT, predicted/unpredicted label, and the matched BioTransformer entry, then summarize per-drug counts (e.g. with R 4.0.3) to support downstream statistics such as the fraction of drugs with at least one novel metabolite. The rationale is to separate experimentally observed signals that BioTransformer's machine learning and rule-based algorithms anticipated from those it did not, revealing gaps in in silico prediction for nearly 1000 drugs.

## Related tools

- **BioTransformer 3.0** (Supplies the in silico predicted-metabolite list against which detected mass signals are cross-referenced within ±5 ppm to label each feature as predicted or unpredicted.)
- **MZmine 2.53** (Processes the raw LC-HRMS files (ADAP chromatogram builder) to produce the detected feature table (paired m/z and RT) that this skill classifies.)
- **R 4.0.3** (Used for statistical analysis and data visualization of the per-drug counts of predicted and unpredicted metabolites.)

## Evaluation signals

- Every detected feature row in the output table carries a non-empty 'predicted' or 'unpredicted' label.
- All features labelled 'predicted' satisfy the ±5 ppm mass-accuracy criterion against a BioTransformer prediction.
- Features labelled 'unpredicted' are detected only postincubation (24-hour sample) with no predicted m/z match within ±5 ppm.
- Per-drug counts of predicted and unpredicted features can be computed and aggregated, e.g. to verify that 89% of tested drugs produced at least 1 metabolite not predicted on BioTransformer 3.0.
- Novel metabolites are reported by paired m/z and RT values, enabling downstream matching against the PharmMet DB resource.

## Limitations

- The reliance on human liver S9 fraction for biotransformation means not all drug-metabolizing activities are present; metabolites formed by enzymes not abundant or active in the S9 fraction, or generated in extrahepatic compartments, may be absent from the DB.
- Novel metabolites (unpredicted features) are reported by paired m/z and RT only; identification of the actual structures from nearly 1000 drugs will require considerable research for isolation and structural elucidation.
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression, so an 'unpredicted' label does not guarantee the metabolite was truly unanticipated by BioTransformer.
