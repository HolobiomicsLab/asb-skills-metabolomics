# morgan-fingerprint-encoder-training

## Summary

Trains an MLP encoder over RDKit Morgan fingerprints as the fingerprint view (Zfp) of MVP's four-view contrastive framework, aligning it with the molecular graph, spectrum, and consensus-spectrum embeddings on MassSpecGym data.

## When to use

Use when preprocessing MassSpecGym spectra/candidate files into fingerprint training inputs and training a fingerprint-view encoder inside a multiview contrastive (CMC-style) model for molecule–spectrum retrieval.

## When NOT to use

- You only need to rank candidates with an already-trained model — use MVP's pretrained weights via test.py --param_pth params_formSpec.yaml instead of training from scratch
- The input is raw LC–MS/MS feature data (mzML) requiring MZmine3 feature extraction and SIRIUS formula/adduct assignment — that upstream pipeline is separate from MVP training on MassSpecGym

## Inputs

- MassSpecGym spectra table (data.tsv) and candidate molecules file (candidates_mass.json) from github.com/pluskal-lab/MassSpecGym
- Preprocessed fingerprint and consensus-spectrum training files generated by data_preprocess.py (--spec_type formSpec or binnedSpec)
- params_formSpec.yaml or params_binnedSpec.yaml configuration with dataset and candidates paths
- RDKit Morgan fingerprints of candidate molecules

## Outputs

- Trained MLP fingerprint-view encoder (Zfp) weights saved as trained_model.pt
- Per-epoch training loss logged by Lightning (plotted as training_loss.png)
- Fingerprint-view embeddings in the joint four-view space for candidate ranking

## How to apply

Download the MassSpecGym spectra table (data.tsv) and candidates file (candidates_mass.json) from github.com/pluskal-lab/MassSpecGym, then run MVP's preprocessing: for formSpec, first assign subformulae with assign_subformulae.py --max-formulae 60, then run data_preprocess.py --spec_type formSpec to generate the fingerprint and consensus-spectrum training files (binnedSpec skips subformula assignment). Edit params_formSpec.yaml (or params_binnedSpec.yaml) so the dataset and candidates paths point at the preprocessed files. Instantiate an MLP over RDKit Morgan fingerprints alongside the GCN (graph view), and transformer encoders over individual and consensus spectra, and train end-to-end with the CMC-style pairwise contrastive loss that aligns all four views (Zmol, Zfp, Zs, Zcs) in one joint embedding space. Launch training with python train.py --param_pth params_formSpec.yaml and save encoder weights to trained_model.pt.

## Examples

```
python data_preprocess.py --spec_type formSpec --dataset_pth data/msgym/data.tsv --candidates_pth data/msgym/candidates_mass.json --subformula_dir_pth data/msgym/subformulae_default/ --output_dir data/msgym/ ; python train.py --param_pth params_formSpec.yaml
```

## Evaluation signals

- training_loss.png shows the four-view contrastive loss decreasing monotonically over epochs
- trained_model.pt loads and embeds all four views (Zmol, Zfp, Zs, Zcs) without key errors
- Consensus-view retrieval on MassSpecGym reproduces reported rank@1 levels: 35.99% by mass and 13.96% by formula
- Individual-spectrum ranking reaches ~26.37% rank@1 by mass and 11.10% by formula
- params_formSpec.yaml paths resolve to the preprocessed fingerprint and consensus-spectrum files in data/msgym/

## Limitations

- Losses that prioritize ranking molecular candidates are not currently included in MVP
- Preprocessed MassSpecGym download URLs in the README are empty, so preprocessing must be run locally via the data prep commands
- Representation quality could benefit from more accurate peak labeling and additional views
