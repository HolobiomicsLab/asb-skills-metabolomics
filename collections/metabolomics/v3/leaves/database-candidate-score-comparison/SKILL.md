# database-candidate-score-comparison

## Summary

Compares the top de novo structure score generated by MSNovelist against the best structural-database (PubChem/KEGG) candidate for the same MS2 spectrum, both scored with the modified Platt fingerprint-match score, to decide whether the de novo prediction is the better explanation of the spectrum.

## When to use

Use when both a de novo MSNovelist prediction and a database search result exist for the same MS2 query spectrum and you must decide which candidate structure better explains the measured spectrum by modified Platt score.

## When NOT to use

- The query spectrum already matches a spectral library entry — dereplication, not de novo vs database comparison, is the right decision path
- The spectrum's molecular formula is not high-confidence (below the ≥80% explained peaks, ≥90% explained intensity, ≥0.9 ZODIAC thresholds), so de novo and database candidates are not comparable under equal constraints
- The database search and the de novo generation were run with different fingerprints or scoring — comparing scores across different scoring schemes is invalid

## Inputs

- Per-spectrum MSNovelist results table (decode-RUNID.csv) with candidate SMILES and score_mod_platt / rank_score_lim_mod_platt columns
- Database (PubChem/KEGG) search results for the same spectra, scored by modified Platt score
- MS2 spectra filtered to high-confidence formulas (≥80% explained peaks, ≥90% explained intensity, ≥0.9 ZODIAC score)

## Outputs

- Per-spectrum table of top de novo score and best database candidate score
- Count of spectra where the de novo structure outscores the database hit (e.g. 169/224, 75%)
- Ranked list of spectra with the largest de novo-vs-database score gaps

## How to apply

For each query spectrum, run the full pipeline (SIRIUS molecular formula prediction, CSI:FingerID fingerprint prediction, encoder-decoder de novo SMILES generation with validation and dereplication) and a database search (PubChem/KEGG) within the same run so both top candidates are scored on the identical query fingerprint. Retrieve the top de novo candidate's score and the best database candidate's score; both must be the modified Platt score of the match to the query fingerprint xF, since final re-ranking with the modified Platt score is important for best results. Record both scores in a per-spectrum table (keyed by the 'query' column) and count spectra where the de novo score exceeds the database score. In the bryophyte MTBLS709 analysis this was done on the 224 of 576 consolidated spectra (m/z < 500) with high-confidence formulas (≥80% explained peaks, ≥90% explained intensity, ≥0.9 ZODIAC score), yielding 169 of 224 (75%) where the de novo structure outscored the database.

## Related tools

- **MSNovelist** (Generates the de novo candidate structures and their modified Platt scores that are compared against database candidates) — https://github.com/meowcat/MSNovelist
- **SIRIUS** (Predicts the molecular formula xM from the MS2 spectrum, constraining both de novo generation and database search)
- **CSI:FingerID** (Predicts the structural fingerprint xF used both to generate de novo candidates and to score database candidates, ensuring scores are comparable)
- **SIRIUS 6** (Integrated runtime providing MSNovelist de novo suggestions and the database search backend) — https://bio.informatik.uni-jena.de/software/sirius/

- On the bryophyte MTBLS709 benchmark, the comparison must yield 169 of 224 spectra (75%) where the de novo structure outscores the best database candidate
- Feature 377 (m/z 381.1020, C21H16O7) must appear among the spectra with the largest score gaps, with its flavonoid-core de novo prediction outscoring the database hit
- Both compared scores must be modified Platt scores computed against the same query fingerprint from the same database search
- In decode-RUNID.csv, the top candidate per query must satisfy rank_score_lim_mod_platt == 1 when rows are ordered by score_mod_platt descending

## Limitations

- MSNovelist is trained only for positive-mode data, so de novo scores on negative-mode spectra will be systematically weaker relative to database hits
- SIRIUS formula error rates rise to >50% for individual spectra up to m/z 800, undermining fair de novo vs database comparison at higher masses
- Spectra with fewer than three fragment ions cannot be processed, and indistinguishably fragmenting isomers make the winning structure uncertain even when the score comparison is decisive
