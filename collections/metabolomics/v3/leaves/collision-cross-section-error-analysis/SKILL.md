# collision-cross-section-error-analysis

## Summary

Validates Snakemake-workflow-computed CCS values by computing percent errors against TWIMS measurements, literature database values, and their consensus average using the paper's ±3% agreement criterion, and separately compares Boltzmann-averaged CCS against the global-minimum-conformer CCS.

## When to use

Use when workflow-calculated CCS values need validation against TWIMS/literature/consensus references for benchmark metabolites, or when deciding whether Boltzmann averaging outperforms the single global-minimum conformer.

## When NOT to use

- No experimental CCS reference values (TWIMS or literature) are available for the metabolites, so no percent error or ±3% agreement can be computed
- The input structures contain elements beyond the CHNO scope of the ANI-1x/ANI-1ccx potentials used upstream for conformation filtering
- The goal is to acquire new experimental IM-MS data rather than to compare already-computed CCS values against existing references

## Inputs

- ccs.txt file from the ensemble (or ensemble_fast) folder containing Boltzmann average CCS values per metabolite
- HPCCS trajectory outputs with individual conformer CCS values and relative energies
- TWIMS experimental CCS values and instrumental parameters (Supporting Information Tables S1 and S2)
- Literature CCS database values for the benchmark metabolites in protonated/deprotonated/neutral states
- Benchmark set of 20 metabolites with atom counts ranging from 10 to 40

## Outputs

- Per-metabolite error table (ccs_averaging_comparison.csv) listing metabolite, molecular state, calculated CCS, TWIMS/literature/consensus reference CCS, and percent errors
- Comparison of percent-error distributions for Boltzmann-averaged versus global-minimum-conformer CCS
- Summary statistics against the ±3% agreement criterion

## How to apply

Parse the ccs.txt file generated by the Snakemake workflow in the ensemble (or ensemble_fast) folder to obtain Boltzmann-averaged CCS per metabolite, and extract individual conformer CCS values plus relative energies from the HPCCS trajectory outputs to identify each metabolite's global-minimum conformer. Load the experimental TWIMS CCS reference values and instrumental parameters from Supporting Information Tables S1 and S2, and compile literature CCS database values for the same metabolites in their protonated ([M + H]+), deprotonated ([M − H]−), and neutral states. Compute the percent error of each calculated CCS against (a) the TWIMS values measured in this work, (b) the literature values, and (c) the consensus average of the two reference sets, judging agreement against the ±3% criterion. Separately compute percent errors for the global-minimum-conformer CCS and compare the two error distributions to judge whether Boltzmann weighting systematically lowers error (e.g. for model 3 of L-tryptophan, the Boltzmann average of 159.69 Å² outperformed the global-minimum 166.44 Å² against the experimental 154.22 Å²). Write the per-metabolite error table and summary statistics to ccs_averaging_comparison.csv.

## Related tools

- **HPCCS** (Produces per-conformer CCS values and trajectory outputs used to identify the global-minimum conformer and reconstruct the Boltzmann average) — https://github.com/cepid-cces/hpccs
- **Snakemake CCS workflow (snakemake_ccs)** (Generates the ccs.txt file of Boltzmann average CCS values that serves as the primary calculated-CCS input to the error analysis)
- **Traveling Wave IM-MS (TWIMS)** (Source of the in-house experimental CCS reference values (Supporting Information Tables S1 and S2) against which percent errors are computed)

## Evaluation signals

- Every benchmark metabolite's calculated CCS agrees within ±3% with the TWIMS values, the literature values, and the consensus average of the two
- ccs_averaging_comparison.csv contains rows for all 20 benchmark metabolites across their protonated/deprotonated/neutral states with percent errors against all three reference sets
- Boltzmann averages recomputed from HPCCS per-conformer CCS values and relative energies reproduce the values in ccs.txt
- Protonation states assigned per metabolite match the molecular states reported in the paper (e.g. carnosine: one neutral, three monoprotonated, one doubly protonated state)
- Percent errors are computed consistently against the consensus average formed as the average of TWIMS and literature reference values

## Limitations

- The upstream ASE-ANI conformation-filtering potential covers only CHNO elements, and ASE-ANI itself is deprecated in favor of TorchANI
- There are no standardized procedures for ion mobility data collection, collation, standardization, and sharing, and most metabolites lack authentic chemical standards, so literature CCS references may be sparse or inconsistent
- Detailed workflow step descriptions are deferred to the Supporting Information, limiting reproducibility from the main text alone
