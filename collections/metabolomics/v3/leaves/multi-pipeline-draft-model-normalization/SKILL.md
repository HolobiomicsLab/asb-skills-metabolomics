# multi-pipeline-draft-model-normalization

## Summary

Normalizes draft genome-scale metabolic reconstructions generated by four automated pipelines (KBase, CarveMe, RAVEN 2.0, AuReMe/Pathway Tools) into a common identifier namespace so they can be structurally compared with distance measures. Necessary because these pipelines' draft reconstructions differ substantially in format and naming.

## When to use

Use when draft GEMs from multiple reconstruction tools must be structurally compared or merged into a consensus, and reaction/metabolite/gene identifiers are in incompatible, self-defined namespaces (SBML from different pipelines).

## When NOT to use

- The models are already in a shared namespace (e.g. all built on the MetaNetX database where identifiers are 'already structurally matched between various databases')
- The goal is gap-filling or community simulation (COMMIT/SMETANA) rather than cross-pipeline structural comparison — normalization is only a prerequisite step
- Only a single reconstruction pipeline is used and no cross-pipeline comparison or consensus is intended

## Inputs

- SBML draft metabolic reconstructions from KBase, CarveMe, RAVEN 2.0, and AuReMe/Pathway Tools (432 At-SPHERE isolate genomes)
- MNXref reference files: reac_prop.tsv, reac_xref.tsv, chem_prop.tsv, chem_xref.tsv
- BLAST all-vs-all results for one-to-one gene identifier mapping

## Outputs

- Normalized draft reconstructions saved as Matlab .mat workspaces under data/models/<habitat>/<method>
- Models with unified MNXref metabolite/reaction IDs and mapped gene IDs, suitable for the eight pairwise distance measures and STATIS compromise matrices

## How to apply

Run each pipeline on the same genome set, then read every pipeline's SBML output with the COBRA toolbox function readCbModel, collecting models into cell arrays and saving them as Matlab workspaces (.mat) under data/models/<habitat>/<method>. Translate metabolite and reaction identifiers using the MNXref reference files (reac_prop.tsv, reac_xref.tsv, chem_prop.tsv, chem_xref.tsv via createMnxrefTranslationTables); replace MNXM01 with MNXM1 since both encode H+, and ignore generic compartments. Where pipelines used different gene IDs, perform one-to-one BLAST mapping (translateGeneIDs). Only after this normalization can the eight pairwise distance measures and the STATIS compromise matrices be computed meaningfully; without it, distance measures conflate naming differences with true structural differences.

## Examples

```
m = readCbModel('data/models/Bulgarelli/KBase/draft.xml'); save('data/models/Bulgarelli/KBase/draft.mat', 'm');
```

## Evaluation signals

- After translation, the same reaction/metabolite is keyed identically across all four pipelines (e.g. MNXM01 replaced by MNXM1 for H+)
- Downstream structural comparison reproduces the reported statistics: average compromise distance 0.64 (range 0.54-0.72)
- Jaccard distance from normalized models correlates with 16S rRNA sequence distance at 0.63-0.75 (mean 0.70, p < 0.001) across the 432 isolates
- SVD/cofactor and dead-end distance correlation rho values reproduced (~0.25 and ~0.04 respectively)
- Consensus reconstruction is smaller than the sum of underlying drafts (not simply the union of reactions/metabolites/genes)

## Limitations

- Comparison to reference models is hampered because some pipelines emit self-defined identifiers without cross-references to other namespaces; translations only work 'whenever possible'
- Gene identifier mapping by one-to-one BLAST fails where orthology is ambiguous or genes are missing from the mapping set
- Normalization is a prerequisite: without it, the eight distance measures conflate identifier naming differences with genuine structural differences
