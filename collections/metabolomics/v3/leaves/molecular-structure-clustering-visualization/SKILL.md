# molecular-structure-clustering-visualization

## Summary

Extracts pooled GNN node representations from a trained model (e.g., SigmaCCS 16-dimensional molecular vectors after ECC layers and global sum pooling) and projects them to 2D with UMAP to test whether the learned embeddings are chemically meaningful, i.e., cluster by ring content, structural similarity, and molecular class.

## When to use

Use when you need to demonstrate that graph-neural-network-learned molecular representations (e.g., 16-dim pooled node attributes) reflect chemical structure, by visualizing their 2D UMAP embedding colored by ring number or molecular class.

## When NOT to use

- The model output you want to inspect is the predicted CCS value or attention/interpretation map rather than the pooled intermediate representation — use the model-agnostic interpretation method instead.
- Your molecules contain elements outside C, H, O, N, P, S, F, Cl, Br, I, Co, As, Se, since SigmaCCS cannot encode them and the ECC-layer forward pass will not be meaningful.

## Inputs

- Trained SigmaCCS model file (model.h5)
- TrainData.csv and TestData.csv molecular datasets
- 1% PubChem sample from Zenodo record 5501674
- Graph dataset matrices per molecule: node feature matrix, adjacency matrix, edge feature matrix (generated by UMAPDataset.py / convertToGraph)
- Morgan fingerprints / structural annotations (ring number, molecular class) for coloring the embedding

## Outputs

- data_molvec.npy: array of pooled molecular vectors with shape (n_molecules x 16)
- data-UMAP-EUC-60.npy: 2D UMAP embedding with shape (n_molecules x 2)
- Rendered UMAP figure showing clustering by ring number and molecular class (Fig. 4b-i style)

## How to apply

Load the trained model (model.h5) and the molecular datasets (TrainData.csv, TestData.csv, and a 1% PubChem sample from Zenodo record 5501674). Convert SMILES to graph inputs (node feature, adjacency, and edge feature matrices) using UMAPDataset.py with the convertToGraph(smiles, Coordinate, All_Atoms) routine. Forward the graphs through the ECC layers of the trained model and collect the 16-dimensional pooled node attributes (molecular vectors), saving them as data_molvec.npy. Compute Euclidean distances between the molecular vectors and fit a UMAP projection (umap 0.5.1, n_neighbors=60 per the EUC-60 naming) to obtain a 2D embedding saved as data-UMAP-EUC-60.npy. Render the embedding colored by ring count or molecular class; structurally similar molecules (by Morgan-fingerprint Tanimoto similarity) should lie closer together if the representations are chemically meaningful (cf. Fig. 4b-i).

## Related tools

- **SigmaCCS** (Trained GNN model whose ECC layers and global sum pooling produce the 16-dimensional pooled node attributes (molecular vectors) that are visualized) — https://github.com/zmzhang/SigmaCCS
- **UMAP (umap-learn)** (Projects Euclidean distances between 16-dimensional molecular vectors into a 2D embedding for clustering visualization (umap 0.5.1)) — https://github.com/lmcinnes/umap
- **UMAPDataset.py / convertToGraph** (Converts SMILES plus 3D coordinates into node feature, adjacency, and edge feature matrices that feed the ECC layers) — https://github.com/YoujiaZhang/SigmaCCS

## Examples

```
embedding = umap.UMAP(n_neighbors=60, metric='euclidean').fit_transform(np.load('data_molvec.npy')); np.save('data-UMAP-EUC-60.npy', embedding)
```

## Evaluation signals

- data_molvec.npy exists and has shape (n_molecules x 16)
- data-UMAP-EUC-60.npy exists and has shape (n_molecules x 2)
- UMAP plot exhibits visually separated clusters consistent with the reported learned-representation visualization (Fig. 4b-i)
- Points colored by ring number form coherent groups, matching the reported clustering by ring number and molecular class
- Molecules with higher Morgan-fingerprint Tanimoto similarity are placed closer together in the 2D embedding

## Limitations

- Interpretation is qualitative: cluster separation is assessed visually against Fig. 4b-i rather than by a quantitative clustering metric
- Applies to representations from the SigmaCCS ECC layers (16-dim); other model architectures will not expose the same pooled node attributes
- SigmaCCS cannot predict molecules containing elements other than C, H, O, N, P, S, F, Cl, Br, I, Co, As, and Se, so such molecules are out of scope for this visualization
