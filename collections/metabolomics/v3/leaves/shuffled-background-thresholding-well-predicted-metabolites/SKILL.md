# shuffled-background-thresholding-well-predicted-metabolites

## Summary

Identifies which metabolites a microbiome-metabolome prediction model genuinely captures by comparing each metabolite's cross-validated Spearman correlation coefficient (SCC) against a null distribution generated by randomly shuffling samples, flagging metabolites whose SCC exceeds the 95th percentile of the background as well-predicted.

## When to use

Use when evaluating per-metabolite prediction accuracy from cross-validated MiMeNet (or MelonnPan) runs and you need a null-calibrated, per-dataset count of well-predicted metabolites rather than raw mean SCC alone.

## When NOT to use

- When no cross-validated per-metabolite prediction correlations exist yet — the thresholding step presupposes held-out fold SCCs from a trained model
- When an absolute SCC cutoff is explicitly required by the analysis design instead of a dataset-specific null-calibrated threshold
- When evaluating conditional probability associations (e.g., mmvec-style) rather than profile-level prediction correlations

## Inputs

- Per-metabolite Spearman correlation coefficients (SCC) from 10-iteration 10-fold cross-validated MiMeNet predictions
- Paired microbiome/metabolome count CSVs (IBD PRISM, cystic fibrosis, soil) for shuffled background generation
- MiMeNet_train.py parameters: -num_background (number of background CV iterations), -threshold (significant correlation threshold), -background (directory with previously generated background)

## Outputs

- Per-dataset well-predicted metabolite counts (metabolites with SCC above the 95th percentile of the shuffled background)
- Shuffled-sample background SCC distribution per cross-validated iteration
- Combined summary table (e.g., mimenet_scc_summary.csv) with mean SCC and well-predicted metabolite counts per dataset

## How to apply

After running MiMeNet_train.py with num_run_cv set to 10 iterations of 10-fold cross-validation and collecting per-metabolite Spearman correlation coefficients on held-out folds, generate a background SCC distribution by randomly shuffling samples within each cross-validated iteration and rerunning the same evaluation (num_background iterations, optionally reusing a previously generated background directory). For each metabolite, compare its real SCC to the 95th percentile of the shuffled background distribution; the -threshold parameter defines this significant correlation cutoff. Metabolites whose SCC exceeds the threshold are counted as well-predicted per dataset (e.g., 366 IBD annotated, 143 cystic fibrosis, 29 soil for MiMeNet). The rationale is that shuffle-based nulls calibrate for dataset size and metabolite abundance structure, avoiding arbitrary absolute SCC cutoffs.

## Related tools

- **MiMeNet** (Generates cross-validated per-metabolite SCCs and the shuffled-sample background distribution; its -threshold and -num_background parameters implement the 95th-percentile well-predicted metabolite identification) — https://github.com/YDaiLab/MiMeNet
- **MelonnPan** (Baseline per-metabolite Elastic Net model evaluated with the same shuffled-background well-predicted metabolite protocol for comparison (198 vs 366, 104 vs 143, 4 vs 29 counts)) — https://github.com/biobakery/melonnpan

## Examples

```
python MiMeNet_train.py -micro micro.csv -metab metab.csv -output out/ -micro_norm RA -metab_norm RA -num_run_cv 10 -num_cv 10 -num_background 10 -threshold 0.95
```

## Evaluation signals

- Well-predicted metabolite counts fall within reproducibility tolerance of reported values: 366 (IBD PRISM annotated), 143 (cystic fibrosis), 29 (soil) for MiMeNet; 198, 104, 4 for MelonnPan
- Each flagged metabolite's SCC exceeds the 95th percentile of the shuffled-sample background SCC distribution
- The background distribution is generated with the same number of cross-validation iterations as the real evaluation (10 iterations of 10-fold CV)
- Summary file (e.g., mimenet_scc_summary.csv) exists and pairs well-predicted counts with mean SCCs (0.309 IBD annotated, 0.457 CF, 0.264 soil, 0.275 IBD External)

## Limitations

- Since not all metabolites may be associated with microbes, some metabolites will have lower prediction correlations, resulting in a lower overall mean correlation across all metabolites
- A higher threshold value was observed for the soil dataset, possibly due to longitudinal observations (unresolved in the paper)
- The number of background CV iterations (-num_background) affects null stability and runtime; reusing a previously generated background directory is supported but assumes the dataset and CV scheme are unchanged
