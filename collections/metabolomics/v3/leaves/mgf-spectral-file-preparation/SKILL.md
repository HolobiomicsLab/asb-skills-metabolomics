# mgf-spectral-file-preparation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Prepare pseudo MS/MS spectra (generated by ms1-id from MS1-only full-scan data) for GNPS2 classical molecular networking by cleaning each feature's spectrum to peaks at or below its precursor m/z and writing all spectra into a single MGF file.

## When to use

Use when you have ms1-id-derived pseudo MS/MS spectra from full-scan LC-MS (e.g. HILIC-positive mzML from Metabolomics Workbench PR000639) that must be reformatted into a cleaned MGF for GNPS2 molecular networking.

## When NOT to use

- Input is already MS/MS data (real tandem spectra collected by the instrument) — no precursor-m/z cleaning of pseudo spectra is needed.
- The downstream tool expects raw mzML/mzXML/imzML for ms1-id annotation (ms1_id lcms/msi modes) rather than an MGF for networking.
- The pseudo spectra will not be used for modified-cosine networking — e.g. when only doing reverse spectral matching, where fragment peaks above the precursor are handled by the precursor-tolerant search.

## Inputs

- pseudo MS/MS spectra generated by ms1-id from MS1-only full-scan LC-MS data (HILIC positive mode, Metabolomics Workbench PR000639)
- metabolic feature m/z values (precursor m/z per pseudo spectrum)

## Outputs

- cleaned pseudo MS/MS MGF file (e.g. ibd_hilicpos_cleaned_pseudo_msms.mgf)
- GNPS2 molecular network edges table (molecular_network_edges.tsv)

## How to apply

Take the pseudo MS/MS spectra generated by ms1-id's correlation-based feature clustering of in-source fragments and clean each metabolic feature's spectrum by removing all ions with m/z larger than the feature's m/z — this is required because GNPS2's modified cosine calculation cannot handle peaks above the precursor. Write the cleaned pseudo MS/MS spectra into a single MGF file (e.g. ibd_hilicpos_cleaned_pseudo_msms.mgf), one spectrum per metabolic feature with its precursor m/z retained. Submit the MGF to the GNPS2 classical molecular networking workflow (version 2024.09.20), setting edge requirements of minimum modified cosine 0.8 and minimum 6 matched peaks. Save the resulting network edges table (e.g. molecular_network_edges.tsv) for downstream subnetwork inspection.

## Related tools

- **ms1-id** (Generates the pseudo MS/MS spectra from in-source fragments via correlation analysis of XICs; its MGF output is the input cleaned and written into the networking-ready MGF) — https://github.com/Philipbear/ms1_id
- **GNPS2** (Consumes the cleaned MGF in the classical molecular networking workflow (version 2024.09.20) with modified cosine >= 0.8 and >= 6 matched peaks per edge)

## Examples

```
ms1_id annotate --input_file pseudo_msms.mgf --libs db/gnps.pkl db/gnps_k10.pkl --min_score 0.7 --min_matched_peak 3
```

## Evaluation signals

- The cleaned MGF contains only peaks at or below each feature's precursor m/z (no ions larger than the feature m/z remain).
- All cleaned pseudo spectra are consolidated into a single MGF file with one spectrum entry per metabolic feature.
- The GNPS2 job completes and produces network edges built under modified cosine >= 0.8 and matched peaks >= 6 criteria (reference job: https://gnps2.org/status?task=670aa34a07544a5cbbd1f1d40605f50f).
- Annotation propagation within subnetworks (e.g. a tyrosine-related subnetwork of N-acyl amides) is driven by modified cosine-based MS/MS similarity edges.
- Isotope peaks excluded by MassCube during pseudo MS/MS generation are absent from the written MGF spectra.

## Limitations

- Pseudo MS/MS from low-energy in-source fragments mismatches public reference MS/MS spectra collected at medium to high collision energies; ms1-id compensates via mass-dependent peak intensity scaling, but networking edges themselves are not library-matched annotations.
- Cleaning removes all ions larger than the feature m/z, discarding any higher-m/z fragment/adduct information from the pseudo spectrum before networking.
- The ms1-id package version itself is not stated in the article (only MassCube ver 1.0.11 and GNPS2 workflow version 2024.09.20 are given), so reproducibility of the pseudo spectrum generation step depends on Zenodo record 10.5281/zenodo.14873172.
