# procrustes-coordinate-comparison-visualization

## Summary

Overlay a second ordination onto a 3D principal coordinates scatter so corresponding samples from two PCoA coordinate files are compared/connected as a procrustes analysis plot, using EMPeror's auxiliary-data display alongside biplot and jackknifed beta diversity layers.

## When to use

Use when two principal coordinates ordinations of the same samples (e.g., QIIME PCoA files from a procrustes comparison) must be visualized together, or when biplot taxa arrows/jackknifed beta diversity layers should be overlaid on a 3D PCoA plot.

## When NOT to use

- The input ordination is not a principal coordinates plot derived from a beta diversity distance matrix — EMPeror is tailored to PCoA of distance matrices as generated by QIIME
- Running on Windows or without Chrome — the command line interface supports OS X (10.6 and higher) and Linux only, and the graphical user interface requires Chrome
- Working outside the Python 2.7 environment with QIIME (python libraries only), NumPy, BIOM 1.1.0 and PyCogent installed — these are stated requirements

## Inputs

- QIIME principal coordinates file for the base ordination (PCoA of a beta diversity distance matrix)
- Second principal coordinates file for the procrustes comparison (matched samples across two ordinations)
- Metadata mapping file (sample metadata used for coloring/visibility controllers)
- Optional taxon biplot coordinate data (taxa arrows in the ordination space)

## Outputs

- Standalone interactive HTML web page rendering sample spheres in 3D principal coordinates with the procrustes coordinate-comparison layer
- Overlay of auxiliary layers (biplot taxa arrows, procrustes connections, optionally jackknifed beta diversity plots) in the same ordination space

## How to apply

First build the base interactive 3D scatter by running the EMPeror command line interface on a QIIME principal coordinates file together with a metadata mapping file; the CLI is limited to OS X (10.6 and higher) and Linux. Then supply the second coordinate file so corresponding samples from the two ordinations are compared/connected in the plot — this is the procrustes analysis layer. Optionally overlay taxon biplot data as auxiliary elements (taxa arrows) in the same ordination space, and/or display jackknifed-resampled data to assess statistical confidence in clustering. The rationale is that EMPeror renders points in the 3D principal coordinates plot while interactively manipulating the datasets to add auxiliary data and visualization techniques. Export the result as a standalone web page and open it in Chrome, the required GUI browser, to verify rendering.

## Related tools

- **EMPeror** (Command line interface builds the base 3D principal coordinates scatter and overlays the procrustes coordinate-comparison layer (plus biplots) as auxiliary data; exports a standalone web page) — http://emperor.colorado.edu
- **QIIME** (Upstream framework that generates the principal coordinates files and metadata mapping files consumed by EMPeror for the procrustes comparison)
- **PyCogent** (Stated Python dependency of EMPeror for its implementation alongside HTML5, WebGL, Javascript and Python)

## Evaluation signals

- The exported HTML opens in Chrome and renders the sample spheres of the base 3D principal coordinates scatter
- Both auxiliary layers are visible and interactive: biplot taxa arrows and the procrustes coordinate comparisons connecting corresponding samples from the two ordinations
- Output file size stays in the tens-of-MB range (e.g., 26 MB vs 1.85 GB in KiNG for 5,740 samples and 120 metadata columns), not GB-scale
- The visualization loads in seconds rather than many minutes when scaled to thousands of points
- Metadata controllers recolor/change visibility of points as a function of the metadata mapping file

## Limitations

- Command line interface limited to OS X (10.6 and higher) and Linux only; no Windows support stated
- Requires Python 2.7, Chrome, QIIME (python libraries only), NumPy, BIOM 1.1.0 and PyCogent; GUI requires the specific Chrome browser
