# calibration-curve-based-quantification

## Summary

Performs targeted-metabolomics absolute quantification by fitting calibration curves from intensity and nominal-concentration tables with internal-standard normalization, as implemented in the GetFeatistics R-package's get_targeted_elaboration function.

## When to use

Use when raw peak intensities of targeted metabolites must be converted into calibrated absolute concentrations, with per-point accuracy, internal-standard CVs, and fitted regression-model summaries needed as deliverables.

## When NOT to use

- The study is untargeted and the input is a feature table from tools like patRoon or MS-DIAL — GetFeatistics routes those through pooled QC filtering and annotation-confidence workflows, not calibration-curve quantification
- No calibration standards with nominal concentrations and internal standards are available in the intensity data, so no calibration curve can be fitted
- The data are already absolute concentrations and the goal is downstream statistics (e.g. mixed-effects or Tobit regression), not conversion from raw intensities

## Inputs

- df_example_targeted: a set of three example tables generated by GetFeatistics::create_df_examples (peak intensity table, nominal-concentration table, and internal-standard table)
- Calibration-curve weighting option selection (the package supports different data weighting options for targeted calibration curves)

## Outputs

- results_concentrations: calculated absolute concentrations per sample and molecule
- results_accuracy: accuracy (%) for calibration-curve points and quality controls
- cv_internal_standards: coefficient-of-variation table for internal standards
- summary_regression_models: summaries of the fitted calibration regression models
- Per-molecule calibration curve ggplot objects from plot_calibration_curves

## How to apply

Generate or supply the mock targeted-analysis example data via GetFeatistics::create_df_examples, which returns the df_example_targeted tables. Run get_targeted_elaboration on the three example tables; the function fits calibration curves from the intensity and nominal-concentration tables with internal-standard normalization and supports different data weighting options for the calibration curves. Collect the four returned result objects: results_concentrations (calculated absolute concentrations), results_accuracy (accuracy in % for curve points and quality controls), cv_internal_standards, and summary_regression_models. Then call plot_calibration_curves to render per-molecule calibration curve ggplots from the elaboration results, and save the result tables and plots to files for verification.

## Related tools

- **GetFeatistics** (R-package providing create_df_examples (mock targeted data), get_targeted_elaboration (calibration-curve quantification with internal-standard normalization), and plot_calibration_curves (per-molecule ggplot calibration curves)) — github.com/FrigerioGianfranco/GetFeatistics
- **R** (Runtime environment for the GetFeatistics package (requires R >= 4.3.1 per README); results and plots are saved/verified in R)
- **ggplot** (Rendering layer for the per-molecule calibration curve visualisations returned by plot_calibration_curves; output visualisations are fully customisable via the ggplot grammar)

## Examples

```
df <- create_df_examples(); res <- get_targeted_elaboration(df$df_example_targeted); plot_calibration_curves(res)
```

## Evaluation signals

- All four result objects (results_concentrations, results_accuracy, cv_internal_standards, summary_regression_models) are returned by get_targeted_elaboration without errors
- results_accuracy contains accuracy (%) values for both calibration-curve points and quality controls, not only samples
- Fitted regression summaries in summary_regression_models correspond to the chosen calibration weighting option and cover every molecule in the intensity table
- cv_internal_standards yields a CV per internal standard; missing or infinite CVs indicate input-table misalignment
- plot_calibration_curves renders one ggplot per molecule whose curve points match the concentrations in results_concentrations

## Limitations

- Quantification is limited to targeted analyses; untargeted feature-table import (patRoon, MS-DIAL) and pooled QC filtering are handled by separate GetFeatistics functions
- Accuracy estimates depend on the nominal-concentration table being correctly specified; mislabelled curve points propagate into results_accuracy
- Calibration weighting options must be chosen by the user; the package supports different data weighting options but does not prescribe one
