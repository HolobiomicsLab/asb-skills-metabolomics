# retention-time-coelution-overlap-analysis

## Summary

Quantifies co-fragmentation (chimeric MS2 spectra) in a simulated LC-MS/MS run by annotating each MS2 scan's peaks with theoretical fragments from co-eluting precursor peptides, yielding the number of distinct peptides contributing to every spectrum.

## When to use

Use when a large set of peptides with overlapping simulated/measured retention times is planned or simulated and you must predict chimeric-spectrum burden (2+ peptides selected for fragmentation simultaneously) before a real MS experiment.

## When NOT to use

- The spectra come from a real acquired LC-MS/MS run where precursor ground truth is unknown — this skill depends on SMITER's simulated, ground-truth co-fragmentation signal
- The biomolecules of interest lack chemical formulas or a matching SMITER fragmentation model (e.g. not peptides/nucleosides/lipids within the default model set)
- You only need an already-computed feature/quantification table rather than per-spectrum chimericity counts

## Inputs

- Simulated complex-mixture mzML dataset (74,067 peptides with overlapping simulated and measured retention times)
- CSV of peptide chemical formulas and retention-time/peak properties (example_data-style input for csv_to_peak_properties)
- Theoretical fragment ions generated by the SMITER PeptideFragmentor for candidate precursor peptides

## Outputs

- chimeric_spectra_statistics.csv with tallies of chimeric spectra, spectra with ≥3 contributing peptides, and maximum peptides-per-spectrum multiplicity
- Per-spectrum annotation mapping each MS2 scan to the set of co-eluting peptides whose fragments it contains

## How to apply

Build the simulated complex mixture by converting a peptide/formula CSV into a peak properties dict via smiter.lib.csv_to_peak_properties, choosing fragmentation_functions.PeptideFragmentor and a noise injector (e.g. smiter.noise_functions.UniformNoiseInjector), then writing the run with smiter.synthetic_mzml.write_mzml — as SMITER generates synthetic mzML from chemical formulas, isotopic patterns come from pyQms. Next, parse the mzML's MS2 spectra and annotate each scan's peaks against theoretical fragment ions produced by the SMITER PeptideFragmentor for candidate precursor peptides. For each scan, determine which peptides co-elute at the scan retention time and contribute fragments, giving the number of distinct peptides per spectrum. Tally chimeric spectra (exactly two molecules selected simultaneously), spectra with fragments of three or more peptides, and the maximum peptides-per-spectrum multiplicity, then write chimeric_spectra_statistics.csv. The rationale: a simulation with known ground truth reveals co-elution/co-fragmentation difficulties that hinder detection or quantification of co-eluents before performing actual MS experiments.

## Related tools

- **SMITER** (Simulates the LC-MS/MS run (synthetic mzML from chemical formulas via pyQms isotopic patterns) and provides the PeptideFragmentor used to generate the theoretical fragment ions that spectra peaks are annotated against) — https://github.com/LeidelLab/SMITER
- **Python** (Parses the simulated mzML MS2 spectra, matches peaks to theoretical fragments, and tallies chimeric-spectrum statistics)

## Examples

```
from smiter.lib import csv_to_peak_properties; from smiter.fragmentation_functions import PeptideFragmentor; peak_properties = csv_to_peak_properties('peptides.csv'); from smiter.synthetic_mzml import write_mzml
```

## Evaluation signals

- Tally of chimeric spectra (exactly two molecules selected for fragmentation simultaneously) reproduces the reported 13,830 on the 74,067-peptide dataset
- Count of spectra containing fragments of three or more peptides reproduces the reported 2,032
- Maximum peptides-per-spectrum multiplicity equals nine, occurring exactly twice
- chimeric_spectra_statistics.csv is produced with the three tally categories present
- Every MS2 scan receives a defined set of contributing co-eluting peptides (no unannotated or unresolvable scans in the simulation ground truth)

## Limitations

- Default fragmentation models cover peptides plus two nucleoside and one lipid model; other molecule classes require implementing a custom fragmentation model in SMITER's modular framework
- SMITER requires Python 3.7 or higher (README for LeidelLab/SMITER)
- Noise is limited to uniform noise or a combined general + intensity-specific noise model, which bounds how realistic chimeric-spectrum detection is compared to real acquisition
