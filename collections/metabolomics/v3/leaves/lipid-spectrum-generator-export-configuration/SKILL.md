# lipid-spectrum-generator-export-configuration

## Summary

Configures the Lipid Spectrum Generator (LSG) to export its in silico lipid spectral libraries in the right file format: '.MSP' for spectral-library output, or '.CSV' for a Skyline-compatible transition list or Excalibur-compatible precursor list for DDA analysis on an Orbitrap.

## When to use

Use when a downstream acquisition or analysis workflow (e.g. Skyline transition lists for targeted MS, or Excalibur precursor lists for Orbitrap DDA) needs lipid species generated by class, fatty-acid composition, and adduct in an importable file format.

## When NOT to use

- The downstream tool expects a spectral-library file rather than a transition/precursor list — export with the default '.MSP' extension instead of '.CSV'.
- The lipid class, fatty-acid composition, or adduct combination has not yet been generated in LSG — export configuration cannot proceed without generated spectra.
- The consuming software requires a format other than Skyline transitions, Excalibur precursor lists, or '.MSP' libraries, since LSG only documents these export options.

## Inputs

- Lipid class and fatty-acid composition selections in the Lipid Spectrum Generator
- Adduct selection(s) for which spectra are generated
- Target software choice (Skyline for transitions, Excalibur/Orbitrap DDA for precursor lists)

## Outputs

- Skyline-compatible transition list exported as a '.CSV' file
- Excalibur-compatible precursor list exported as a '.CSV' file (for DDA analysis via Orbitrap)
- In silico lipid spectral library exported as a '.MSP' file (default option)

## How to apply

First run the LSG Python tool to generate lipids for a chosen lipid class and fatty-acid composition, then generate spectra for the desired adducts, since LSG builds lipids by class and fatty-acid composition and spectra by adduct. At export time, decide the output format based on the consuming software: keep the default '.MSP' file extension for a spectral-library file, or select the '.CSV' option when the target is a Skyline-compatible transition list or an Excalibur-compatible precursor list for DDA analysis via Orbitrap. Write the exported file to disk and confirm the extension matches the intended format ('.CSV' for transition/precursor lists, '.MSP' for the library). The how-to guide for the features is on the v1.3.0 release page of the 98104781/LSG repository.

## Evaluation signals

- The exported file exists on disk with the correct extension ('.CSV' for transition/precursor lists, '.MSP' for the spectral library).
- A '.CSV' export opens in Skyline as a valid transition list (or in Excalibur as a precursor list for Orbitrap DDA).
- The number of transitions/entries in the export matches the lipids generated for the selected class, fatty-acid composition, and adducts.
- The export corresponds to the v1.3.0 release workflow documented on the LSG release page.
- The '.MSP' default export is not confused with the '.CSV' option — the two file types serve different downstream consumers.

## Limitations

- LSG documents only two export families: '.MSP' spectral libraries and '.CSV' lists (Skyline transitions or Excalibur precursors for Orbitrap DDA); other formats are not supported.
- The transition list is Skyline-compatible as produced by LSG; no post-export conversion or validation steps are described in the README.
- Fragmentation patterns used to generate the spectra are based on peer-reviewed studies, so exported transitions depend on the accuracy of those in silico fragmentation rules rather than experimentally acquired spectra.
