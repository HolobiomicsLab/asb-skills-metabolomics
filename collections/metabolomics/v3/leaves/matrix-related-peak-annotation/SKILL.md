# matrix-related-peak-annotation

## Summary

Annotates matrix-related m/z signals in mass spectrometry imaging peak matrices by combining the chemical formula of the LDI-promoting material (e.g. 'Ag1') with the spatial distribution of its ions, and prevents misclassification of overlapped or isobaric ions via a bisecting k-means overlapping-peak detection routine.

## When to use

Use when an MSI peak matrix contains matrix-related signals (e.g. Agn+ cluster peaks in Ag-sputtered AgLDI data) that must be annotated and removed, and simple blank subtraction is insufficient because of ion suppression, adducts, or isobaric peaks.

## When NOT to use

- Input is raw profile-mode imzML that has not been processed into a centroided peak matrix with rMSIproc — the algorithm requires the rMSIproc peak-matrix format
- The chemical formula of the LDI-promoting material is unknown, so theoretical isotope patterns cannot be computed with enviPat and matched to experimental peaks
- The analysis is on non-imaging bulk MS data, since classification depends on ion images and spatial-distribution correlations

## Inputs

- Centroided peak matrix (.zip) generated by rMSIproc from profile-mode imzML
- Processed MSI dataset in rMSI format (.tar) loaded with rMSI::LoadMsiData
- Matrix chemical formula string (e.g. 'Ag1') for the LDI-promoting material
- User-specified threshold on S1 and S2 scores gating overlapping-peak detection

## Outputs

- Per-peak annotation results with matrix-related / matrix-related-overlapping / not-matrix-related labels (rMSIcleanup_annotations.csv, overlapping_peak_flags.csv)
- Per-cluster similarity scores S1 (spectral) and S2 (intra-cluster morphological)
- PDF visual report justifying each annotation
- Cleaned peak matrix with matrix-related peaks removed (stored via rMSIproc::StorePeakMatrix)

## How to apply

Load the centroided peak matrix with rMSIproc::LoadPeakMatrix (.zip) and the processed spectra with rMSI::LoadMsiData (.tar), then run rMSIcleanup::annotate_matrix with the matrix chemical formula (e.g. 'Ag1'); theoretical isotope patterns are computed with enviPat and matched to experimental peaks using a mass tolerance of 4 data-points/scans, yielding per-cluster spectral similarity score S1 and intra-cluster morphological similarity score S2. For clusters whose S1 and S2 fall below a user-specified threshold, run the overlapping peak detection: compute Pearson correlations between the ion images of the cluster's peaks, bisect the ions with k-means on their spatial-distribution correlations, rescore each subgroup, and recursively split until a subgroup qualifies as matrix-related or the largest subgroup holds fewer than half of the original cluster's peaks (then all ions are tagged not-matrix-related). Tag ions in qualifying subgroups as matrix-related and the remaining ions as matrix-related with overlapping. Justify each annotation with rMSIcleanup::generate_pdf_report and optionally produce a cleaned peak matrix with rMSIcleanup::remove_matrix.

## Examples

```
pks <- rMSIproc::LoadPeakMatrix("Ag_Pancreas_TOF_2015_Dataset2.zip"); full <- rMSI::LoadMsiData("Ag_Pancreas_TOF_2015_Dataset2_proc.tar"); results <- rMSIcleanup::annotate_matrix(pks, "Ag1", full)
```

## Evaluation signals

- Against a possible/not-possible validation list, S1 should reach AUC ≈ 0.97 and S2 AUC ≈ 0.91 as classifiers
- The overlapping_peak_flags.csv output must contain all three classification labels (matrix-related, matrix-related with overlapping, not-matrix-related) for every peak
- Recursive bisection must terminate for every low-scoring cluster without adding positives for above-threshold clusters (negative-class scores unchanged)
- A classification gap between S of 0.5 and 0.7 should separate matrix-related from non-matrix-related peaks
- The PDF report must be generated for every annotation, and PCA after remove_matrix should show enhanced morphological contrast in the first principal components

## Limitations

- Overlapping peak detection is only executed on clusters whose S1 and S2 scores fall below the user-specified threshold, so threshold choice directly controls whether overlapped/isobaric ions are re-tagged
- Bisection stops when the largest subgroup contains fewer than half of the original cluster's peaks, in which case all ions are tagged not-matrix-related
- The method requires rMSIproc-processed data (TAR/zip formats); no data normalization was performed in the published workflow, and results depend on prior peak binning (6 data-point window) and 5% pixel-frequency filtering
