# chemical-candidate-dereplication-and-platt-reranking

## Summary

Post-generation step of MSNovelist in which the k SMILES structures produced by the encoder-decoder RNN are validated, deduplicated, and then re-ranked against the query fingerprint using the modified Platt score.

## When to use

Use when you have generated k candidate SMILES from MSNovelist's RNN decoder for a tandem mass spectrum and need to deduplicate, validate, and rank them to pick the top de novo structure.

## When NOT to use

- Input is already a validated, deduplicated, ranked structure list from a database search (e.g. CSI:FingerID output) — no de novo dereplication is needed.
- The MS2 spectrum has fewer than three fragment ions, so SIRIUS/CSI:FingerID cannot produce a reliable fingerprint and formula to rank against.
- Working with negative-mode spectra: MSNovelist is currently trained only for positive-mode data, so candidate quality and re-ranking reliability will be degraded.

## Inputs

- k SMILES candidate structures generated by the MSNovelist encoder-decoder RNN from the query fingerprint xF and formula xM
- Query structural fingerprint xF predicted by CSI:FingerID from the MS2 spectrum
- Molecular formula xM predicted by SIRIUS from the MS2 spectrum

## Outputs

- Dereplicated, validated candidate structure list ranked by modified Platt score (top candidate per spectrum)
- Per-spectrum results table `decode-RUNID.csv` and `.pkl` with score_mod_platt and rank_score_lim_mod_platt columns
- Dereplication statistics (how many of the k generated structures were redundant)

## How to apply

After the encoder-decoder RNN emits k SMILES strings constrained by the SIRIUS molecular formula xM, first validate each candidate structure (e.g. consistency with the formula) and dereplicate duplicates so identical candidates are counted once. Then re-rank the remaining candidates by computing the match between each candidate's fingerprint and the query fingerprint xF predicted by CSI:FingerID, using the modified Platt score. The article notes that final re-ranking with the modified Platt score is important for best results, and the README confirms that ordering results by `score_mod_platt` descendingly (or filtering `rank_score_lim_mod_platt == 1`) yields the top candidate. Results are written to `results-RUNID/decode-RUNID.csv` and `.pkl`.

## Related tools

- **MSNovelist** (Generates the k candidate SMILES structures and produces the score_mod_platt ranking after fingerprint prediction and formula prediction steps.) — https://github.com/meowcat/MSNovelist
- **SIRIUS** (Provides the molecular formula xM that constrains the generated candidates, ensuring that deduplication and ranking happen only among formula-consistent structures.) — https://bio.informatik.uni-jena.de/software/sirius/
- **CSI:FingerID** (Predicts the structural fingerprint xF that serves as the reference for computing modified Platt scores used to re-rank dereplicated candidates.) — https://github.com/meowcat/MSNovelist

## Examples

```
docker run -v $DATAFOLDER:/msnovelist-data msnovelist predict.sh SPECTRA.mgf && sort -t, -k8 -gr results-*/decode-*.csv | head -n 10
```

## Evaluation signals

- The result table must contain the column `score_mod_platt`; the top candidate should be identifiable via `rank_score_lim_mod_platt == 1`.
- The number of distinct candidates after dereplication should be ≤ k (the number of SMILES generated by the RNN).
- Every retained candidate must be consistent with the SIRIUS-predicted formula xM.
- For the GNPS evaluation set (3,863 spectra), aggregate top-1 accuracy should approach 25% and overall retrieval 45% as reported.
- The output file `results-RUNID/decode-RUNID.csv` should exist and its first column `query` must correctly associate each row with its source spectrum.

## Limitations

- Dereplication and re-ranking depend on the quality of the CSI:FingerID fingerprint; poor fingerprint predictions yield unreliable rankings.
- Molecular formula error rates from SIRIUS rise to >50% for compounds with m/z up to 800 when considering individual spectra, so formula-constrained deduplication can be fragile at high mass.
- The pipeline processes MS2 spectra with a minimum of three fragment ions; poorer spectra are undesirable for best performance.
- The model is trained only for positive-mode data, so candidate quality on negative-mode spectra is expected to be lower.
