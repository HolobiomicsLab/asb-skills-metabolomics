# metabolomics-preannotation-json-export

## Summary

Run khipu as a standalone command-line tool to group LC-MS features into empirical compounds (khipus) by isotope/adduct tree matching, exporting pre-annotations in the transparent empCpd JSON format plus a tab-delimited table for downstream data science workflows.

## When to use

Use when you have a preprocessed feature table (feature ID, m/z, rtime, intensities) from LC-MS untargeted metabolomics or isotope tracing and need low-level annotation into empirical compounds with inferred neutral masses before database search.

## When NOT to use

- Input is raw MS vendor files (RAW/mzML) rather than a preprocessed feature table — run a peak-detection tool like asari 1.9.2 first to produce the feature table
- You need complete annotation including authentic library matches or tandem MS confirmation — khipu is a preannotation step; full annotation additionally requires contaminants, authentic libraries, and MS/MS data
- Ionization mode is not set or the feature table lacks an m/z column — the tree alignment depends on mass differences between ions

## Inputs

- Tab-delimited feature table (columns: feature ID, m/z, rtime, followed by intensity columns) generated by any preprocessing tool such as asari 1.9.2
- Ionization mode setting (pos or neg) via -m flag
- Optional custom isotope/adduct search patterns for isotope tracing or chemical labeling experiments
- Optional ppm mass tolerance (--ppm) and retention time tolerance (--rtol)
- Start and end column indices for intensity data (-s, -e)

## Outputs

- <prefix>.json — empirical compound annotations in khipu transparent empCpd JSON format
- <prefix>.tsv — tab-delimited empirical compound table
- Plain-text tree/grid visualizations of each khipu (empirical compound)

## How to apply

Install khipu via pip (pip install khipu-metabolomics) and run the CLI: 'khipu -i <feature_table.tsv> -o <prefix>' with mode set via -m (pos or neg), ppm tolerance via --ppm, and intensity column bounds via -s/-e. Khipu searches the feature list for isotope patterns (e.g. 1.0034 Da for 13C/12C) and adduct patterns (e.g. 22.989276 Da for M+Na[+], 1.007276 Da for M+H[+]), builds a mass distance network, converts it to a directed acyclic graph, and aligns it with the khipu grid via two-step optimization to form empirical compound trees. The neutral M0 mass is then inferred by linear regression from matched m/z values. The Weavor class separates isotope edges and adduct edges, establishes the adduct trunk, assigns isotopic branches, and re-aligns isotopes against the grid. For stable isotope tracing, supply custom search patterns (isotope/adduct patterns are separable from search functions) rather than the default grid.

## Evaluation signals

- On the bundled ecoli_pos.tsv test data (3,602 features), khipu should annotate exactly 548 empirical compounds (trees) from 1,745 features, leaving 1,857 singletons, with 445 empirical compounds having multiple isotopes
- On the two yeast datasets, annotation should yield 1,775 and 908 empirical compounds in ESI+ and ESI- modes respectively; including additional adducts should raise explained ESI+ features from 6,310 to 8,049 and ESI- from 2,601 to 2,912
- Output must parse as the khipu transparent JSON empCpd format (validate schema against metDataModel EmpiricalCompound)
- Inferred neutral M0 masses must match known standards — e.g. the U-13C-labeled E. coli compound with neutral mass 187.1686 should match acetylspermidine (C9H21N3O) with 9 carbons
- Run python3 -m khipu.test to verify the tool downloads ecoli_pos.tsv and reproduces expected results

## Limitations

- Annotation of untargeted metabolomics data, including isotopic tracing data, is still not fully solved
- Benchmarking was deferred to future work in the initial version
- Some ions enter the initial network by mistakes or unresolved signals and are removed from the established khipu to form a new one — ambiguous adducts are trimmed to reduce ambiguity
- Different applications (regular metabolomics, isotope tracing, chemical derivatization) require different parameter sets; the default grid may need overwriting
- Chemical derivatization experiments require linking separate khipu trees by the derivatization m/z shift — not automated in this version
