# match-proportion-pie-chart-annotation

## Summary

Renders an interactive D3 taxonomic tree in which each microbeMASST taxon node is annotated with a pie chart showing the proportion of matched spectra attributable to that taxon, propagating match counts up the NCBI lineage (kingdom→strain) and writing the result as a downloadable HTML file mirroring the _microbe.html output.

## When to use

Use when you have microbeMASST batch search outputs (_matches.tsv and _count_domain.tsv files) plus NCBI lineage data and need to visualize which microbial taxa (8 kingdoms, 20 phyla, 48 classes, 124 orders, 278 families, 561 genera, 1379 species, 542 strains) may produce the queried metabolite as an interactive HTML tree with per-taxon match-proportion pie charts.

## When NOT to use

- Input is a single MS/MS spectrum without batch search outputs — use the standalone microbeMASST web app instead
- Only GNPS library matches are needed (_library.tsv Level 2 MSI annotation) and no taxonomic visualization is required
- The query domain is plant, tissue, microbiome, or food MASST — this skill is specific to the microbeMASST lineage tree (plantMASST has no strain-level coverage: 'NA')

## Inputs

- per-scan match results (_matches.tsv) from microbeMASST batch search
- per-domain match counts (_count_microbe.tsv) from microbeMASST batch search
- NCBI taxonomy lineage table for microbeMASST taxa (kingdom through strain)
- full lineage JSON/Newick tree for microbeMASST taxa

## Outputs

- interactive HTML taxonomic tree (microbe_tree.html / _microbe.html) with per-taxon match-proportion pie charts
- D3-consumable JSON hierarchy (_microbe.json) with per-node match counts and proportions

## How to apply

Load the per-scan match results (_matches.tsv) and per-domain match counts (_count_microbe.tsv) produced by the microbeMASST batch search, together with the NCBI taxonomy lineage table covering the microbeMASST taxa (8 kingdoms, 20 phyla, 48 classes, 124 orders, 278 families, 561 genera, 1379 species, 542 strains). Aggregate matches per taxon at every lineage rank to compute the number and proportion of matched spectra/samples attributable to each taxon, then filter the full lineage JSON tree to retain taxa with at least one match and propagate counts up through kingdom, phylum, class, order, family, genus, species, and strain levels. Convert the filtered hierarchy into a D3-consumable JSON, attaching per-node match counts and proportion values, and render it in HTML with collapsible nodes, per-taxon match-proportion pie charts, and lineage-propagated match information (taxon name, NCBI ID, file counts). Write the rendered visualization as microbe_tree.html (the _microbe.html file generated by the microbeMASST workflow). Python 3.10 is required by the batch search upstream of this rendering step.

## Related tools

- **microbeMASST** (Source of the batch search outputs (_matches.tsv, _count_microbe.tsv) that feed the taxonomic tree; defines the lineage scope rendered in the tree) — https://masst.gnps2.org/microbemasst/
- **Python 3.10** (Runtime environment required by the microbeMASST batch pipeline that generates the inputs and renders the HTML tree) — https://github.com/robinschmid/microbe_masst
- **D3** (JavaScript library used to render the interactive collapsible taxonomic tree with per-taxon match-proportion pie charts in the output HTML)

## Examples

```
python code/jobs.py  # generates _matches.tsv, _count_microbe.tsv, and _microbe.html; run with skip_existing=True until no new output
```

## Evaluation signals

- Per-taxon counts in the rendered HTML reconcile with the input _count_microbe.tsv totals
- The output HTML contains a complete lineage-consistent tree where counts propagate correctly through kingdom → phylum → class → order → family → genus → species → strain
- File existence plus non-empty renderable HTML content is verified
- Each taxon node displays taxon name, NCBI ID, file counts, and a pie chart visualizing match proportion
- The tree can be downloaded as HTML and node counts match the lineage table (542 strains, 1379 species, 561 genera, 278 families, 124 orders, 48 classes, 20 phyla, 8 kingdoms)

## Limitations

- The Fast Search API upstream of the batch search can cause entry failures; jobs.py must be re-run a couple of times with skip_existing=True until no new output is generated
- Python 3.10 is mandatory for the upstream pipeline; other versions are not supported
- The interactive tree covers only the microbeMASST domain (8 kingdoms through 542 strains); plantMASST has no strain-level coverage, so strain-level pie annotations are not applicable there
- Input must be a single .mgf file generated via MZmine, or a list of USIs in .csv/.tsv format — other formats are not accepted
