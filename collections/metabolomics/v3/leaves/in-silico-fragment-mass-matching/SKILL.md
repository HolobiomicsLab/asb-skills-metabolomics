# in-silico-fragment-mass-matching

## Summary

Match experimentally observed MS/MS fragment m/z values against in silico lipid fragment libraries to identify lipids from untargeted UHPLC-HRMS/MS feature tables, as implemented in LipidMatch's rule-based identification pipeline.

## When to use

Use when you have untargeted LC-HRMS/MS feature tables (m/z + retention time) plus .ms2 MS/MS spectra and need to annotate lipid identifications by exact-mass matching experimental fragments to in silico library fragments.

## When NOT to use

- The input MS/MS data comes from Waters instruments, which LipidMatch does not currently support
- No curated in silico fragmentation library exists for the lipid class of interest and the user has not built one in Excel — the match step requires library fragment m/z values
- Feature tables and .ms2 files have not yet been generated from raw vendor files; run peak picking and MSConvert conversion first

## Inputs

- Feature tables (feature m/z and retention time) generated by MZmine, XCMS, or MS-DIAL peak picking
- MS/MS peak-picked spectra converted to .ms2 file format with MSConvert
- In silico lipid fragmentation libraries in .csv format (per lipid class, compiled from LIPID MAPS, LipidBlast, MS-DIAL, literature, and experimentally derived fragments)
- User parameters: MS1 m/z tolerance (Da), RT and m/z tolerances for scan matching, fragment ppm tolerance, minimum fragment intensity, and minimum scan-count threshold

## Outputs

- Per-lipid-class CSV fragment statistics tables listing experimental fragments matched to in silico fragment m/z values and scan counts across each feature
- Binary (0/1) fragment-pass/fail assignments per fragment per feature-lipid pair
- Feature tables appended with lipid identifications, lipid class and adduct of top-ranked lipid, summed fragment intensity, and identification level 1–4

## How to apply

First run exact mass matching at the MS1 level between in silico precursor ions and each feature's m/z using a user-defined m/z tolerance (Da), then find MS/MS scans from .ms2 files within user-defined retention time and m/z tolerances of each feature. Match experimental fragments against in silico lipid fragment m/z values within a ppm tolerance window, counting the total number of scans across the feature peak containing each fragment. Assign each fragment 1 if it passes the user-defined minimum intensity and scan-count thresholds, and 0 otherwise; lipids are identified only if the user-selected required fragments for their lipid type are all observed. The per-lipid-class CSV fragment statistics tables produced here feed downstream steps: confirmatory identification, ranking by summed fragment intensity, and assignment of identification levels 1–4 (class + fatty acyl constituents, DIA, class-only, or precursor m/z only).

## Related tools

- **LipidMatch** (R-based tool that performs the MS1 exact mass matching, MS/MS scan matching, fragment ppm matching, and thresholded 0/1 fragment assignment) — http://secim.ufl.edu/secim-tools/
- **R** (Language in which LipidMatch is written; interface built with gWidgets and tcltk dialogue boxes)
- **MSConvert** (Peak picking of MS/MS data and conversion to .ms2 file format prior to fragment matching)
- **MZmine** (One of the peak-picking tools that generates the feature tables fed into the matching step)
- **LipidBlast** (MS/MS database used to compile structurally indicative in silico fragments for the libraries)

## Evaluation signals

- Each matched experimental fragment falls within the user-defined ppm tolerance window of an in silico fragment m/z value
- Fragments are strictly binary (1/0): 1 only when both minimum intensity and scan-count thresholds are met, 0 otherwise or when unmatched
- Identifications require all user-selected required fragments for the lipid type to be observed (rule-based confirmation)
- Ranking output (top lipid per feature, class/adduct, summed fragment intensity) reproduces the example output data in Additional file 1 of the LipidMatch distribution
- Identification levels are consistent with the evidence: level 1 = class + fatty acyl constituents, 2 = DIA, 3 = class-only, 4 = precursor m/z only

## Limitations

- Tested only on Windows 7 through 10 and pinned to R version 3.3.3; no cross-platform support stated
- Waters vendor files are not currently supported
- Depends on external software: peak picking (MZmine, XCMS, MS-DIAL, or other) and file conversion to .ms2 (MSConvert or equivalent)
- Users must develop their own fragmentation libraries in Excel for full customization of required fragments
- Key artifacts (software zip, lipid libraries in .csv format, manual) are distributed only as Additional file 1, not archived in a public repository
