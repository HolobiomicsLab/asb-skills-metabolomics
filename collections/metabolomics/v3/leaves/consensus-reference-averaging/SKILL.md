# consensus-reference-averaging

## Summary

Validates in silico CCS predictions by computing percent errors against two independent experimental reference sets (TWIMS measurements and literature database values) and a consensus average of the two, applying a ±3% agreement criterion for 20 benchmark metabolites.

## When to use

Use when a calculated property (e.g. Boltzmann-average CCS from ccs.txt) must be validated against two independent experimental reference sets and a consensus of both, with a percent-error tolerance.

## When NOT to use

- Only one experimental reference set is available, so no consensus average of two reference sets can be formed
- The comparison target is raw instrument calibration or CCS correction of the TWIMS instrument itself rather than validating computationally predicted CCS values

## Inputs

- Boltzmann-average CCS values from workflow output file ccs.txt (ensemble or ensemble_fast folder)
- TWIMS experimental CCS values from Supporting Information Table S1
- TWIMS instrumental parameters from Supporting Information Table S2
- Literature CCS database values for the same 20 metabolites in protonated/deprotonated/neutral states

## Outputs

- Agreement table listing metabolite, molecular state, calculated CCS, TWIMS reference CCS, literature reference CCS, consensus average, and percent errors for each comparison
- Pass/fail verdict per metabolite against the ±3% agreement criterion

## How to apply

Load the Boltzmann-average CCS values from the workflow output file ccs.txt generated by the Snakemake CCS workflow, then load TWIMS experimental CCS values and instrumental parameters from Supporting Information Tables S1 and S2 for the 20 benchmark metabolites. Compile available literature CCS database values for the same metabolites in their protonated/deprotonated/neutral molecular states. Compute the percent error of each calculated CCS value against (a) the TWIMS values measured in this work and (b) the literature values, then form the consensus average of the two reference sets and compute error against it as well. Assemble an agreement table listing metabolite, molecular state, calculated CCS, reference CCS values, consensus value, and percent errors. Accept the validation if all three error columns fall within ±3%; note the molecular state must be tracked per metabolite (e.g. carnosine has five states: one neutral, three monoprotonated ions, and one doubly protonated ion).

## Related tools

- **Traveling Wave IM-MS (TWIMS)** (Provides one of the two independent experimental CCS reference sets used for percent-error and consensus comparison)
- **Snakemake** (Workflow manager whose ccs.txt output supplies the calculated Boltzmann-average CCS values being validated) — https://github.com/example-lab/meta-viral-workflow
- **hpccs** (CCS calculation engine producing the computed values compared against TWIMS and literature references) — https://github.com/cepid-cces/hpccs

## Examples

```
python compare_ccs.py --calc ensemble/ccs.txt --twims SI_table_S1.csv --literature literature_ccs.csv --tolerance 3.0 --consensus
```

## Evaluation signals

- Every percent error column (vs TWIMS, vs literature, vs consensus) is within ±3% for each metabolite state
- The consensus value equals the arithmetic average of the TWIMS and literature CCS values for each metabolite/molecular-state pair
- Molecular state (protonated/deprotonated/neutral) is correctly matched between calculated and reference values; e.g. carnosine contributes five states
- The agreement table contains all 20 metabolites with atom counts ranging from 10 to 40 and their reference CCS values
- Reference CCS values trace to Supporting Information Tables S1 and S2 for TWIMS and to cited literature database entries

## Limitations

- Agreement is only demonstrated for 20 benchmark metabolites with atom counts ranging from 10 to 40; extrapolation to larger or more flexible molecules is not validated here
- Molecular state assignment matters: multiple protonation states exist per metabolite (e.g. five states for carnosine), so mismatched states inflate apparent error
- Literature CCS database values are not available for all metabolites/states, limiting where a consensus average can be formed
