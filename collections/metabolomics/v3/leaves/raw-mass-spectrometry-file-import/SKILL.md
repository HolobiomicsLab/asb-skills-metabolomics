# raw-mass-spectrometry-file-import

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Import raw LC-HRMS files (e.g., Thermo Orbitrap ID-X acquisitions from HILIC/positive-ESI and C18/negative-ESI runs) into MZmine 2.53 and build chromatograms per sample with the ADAP chromatogram builder, producing m/z and retention-time feature lists for downstream metabolite detection.

## When to use

Use when raw vendor LC-HRMS files must be converted into m/z and retention-time feature lists in MZmine (ADAP chromatogram builder) before 0-hour vs 24-hour differential metabolite detection.

## When NOT to use

- Input is already a processed feature/peak table (m/z + RT + intensities) — skip to candidate metabolite feature detection instead.
- The goal is MS2-based structural elucidation of metabolites; this skill only builds MS1 chromatograms and features, not annotated MS2 spectra.
- Data were not acquired on instruments whose raw formats MZmine 2.53 can import, or a workflow other than ADAP chromatogram building (e.g., XCMS) is mandated.

## Inputs

- Raw LC-HRMS data files from Thermo Scientific Orbitrap ID-X Tribrid MS (Thermo Vanquish UHPLC), HILIC/positive-ESI and C18/negative-ESI acquisitions (Study ST003991)
- Sample metadata mapping each file to drug incubation, column/ESI platform, and timepoint (0-hour preincubation vs 24-hour postincubation)

## Outputs

- MZmine feature list of m/z and retention-time values per sample
- Tab-separated peak table with m/z, RT, and peak intensities per sample for both 0-hour and 24-hour samples

## How to apply

Download the raw LC-HRMS files for the study (Metabolomics Workbench Study ID ST003991, Project DOI 10.21228/M8W55K), covering both the HILIC/positive-ESI and C18/negative-ESI platforms. Import each raw file into MZmine 2.53 and build chromatograms with the ADAP chromatogram builder module, processing each sample independently rather than pooling. Using the MS1 spectral data (acquired at 60,000 resolution over m/z 100–1000), detect m/z features with retention times for each 0-hour (preincubation) and 24-hour (postincubation) sample. Export the resulting feature list — m/z, retention time, and per-sample peak intensities — as a tab-separated peak table. Per-sample processing preserves the pre/post-incubation pairing needed for the downstream differential comparison of MS1 and RT values.

## Related tools

- **MZmine 2.53** (Imports the raw LC-HRMS files and builds chromatograms per sample with the ADAP chromatogram builder module; exports the tab-separated peak table.)
- **Thermo Scientific Orbitrap ID-X Tribrid mass spectrometer** (Instrument that generated the raw MS1/MS2 files being imported (MS1 at 60,000 resolution, m/z 100–1000; MS2 at 15,000, HCD 35%).)

## Evaluation signals

- The exported peak table exists and contains m/z and retention-time columns.
- The peak table includes entries for both the 0-hour and 24-hour samples of each drug incubation.
- Each sample was processed independently through the ADAP chromatogram builder (per-sample chromatograms, not pooled).
- Feature m/z values are consistent with the MS1 acquisition range of 100–1000 at 60,000 resolution.
- The table carries per-sample peak intensities suitable for the downstream 0-hour vs 24-hour differential comparison.

## Limitations

- Reliance on the liver S9 fraction for biotransformation means not all drug-metabolizing activities are represented; metabolites from enzymes not abundant/active in liver S9 or formed extrahepatically (e.g., intestine, kidney) are expected to be absent.
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression.
- Candidate feature detection downstream depends on comparing MS1 and RT between 0-hour and 24-hour samples, so per-sample feature detection quality directly limits metabolite calls.
