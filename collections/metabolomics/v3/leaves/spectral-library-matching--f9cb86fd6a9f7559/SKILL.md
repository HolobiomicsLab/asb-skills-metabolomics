# spectral-library-matching

## Summary

Spectral library matching for LC-MS/MS lipidomics using LipiDex 2 Spectrum Searcher, which scores experimental MS2 and MS3+ spectra against in silico lipid libraries using dot-product/reverse dot-product scores and spectral purity to assign high-confidence lipid identifications to chromatographic features.

## When to use

Use when MS2 or MS3+ spectra from LC-MS lipidomics runs (e.g. Thermo .raw files) must be matched against an in silico lipid spectral library to identify lipids and annotate chromatographic features.

## When NOT to use

- Input is already an annotated lipid feature table without raw MS2/MS3+ spectra — use Peak Finder (from .cdResult peak tables) or Degreaser QC instead
- Spectra are not lipidomics MSn data or no in silico library exists for the lipid classes of interest — generate a library with the Library Generator first
- Legacy workflows requiring LipiDex 1 Java-based matching on .mgf/.mzXML without Thermo .raw support — LipiDex 1 is no longer supported

## Inputs

- Thermo .raw LC-MS/MS data files (or .mgf/.mzXML for legacy LipiDex 1)
- In silico lipid spectral library generated by LipiDex 2 Library Generator
- MS2 and MS3+ spectra to be matched

## Outputs

- .csv spectral match table with per-match dot product, reverse dot product, and spectral purity scores
- Annotated spectral match table (e.g. annotated_spectral_matches_scored.csv) with pass/fail calls per threshold
- Fragment peak annotations for passing MS2 and MS3+ matches (via Lipid Spectral Annotator)

## How to apply

First generate the in silico spectral library with the LipiDex 2 Library Generator, building lipid classes from a base template of headgroup, backbone and up to four variable groups, with support for MSn tree-based fragmentation so identifications carry the appropriate structural resolution. Run Spectrum Searcher on Thermo .raw files (LipiDex 1 accepted .mgf or .mzXML) to match MS2 and MS3+ spectra against the library, configuring RT filtering, MSn intensity threshold, and PPM or Thomson mass error tolerances. Apply the match-quality thresholds validated in the MSV000091033 Nile rat plasma reprocessing: minimum spectral purity of 75% from co-eluting isobaric lipids, dot product ≥500, and reverse dot product ≥700. Spectral purity is computed as the fraction of fragment ion intensity attributable to the matched lipid versus co-eluting isobaric species, and it is used downstream to estimate the purity of the associated chromatographic feature. Pass the .csv results files to the next module (Lipid Spectral Annotator uses the MS2/MS3+ matches to annotate fragment peaks; Peak Finder consumes the match table along with Compound Discoverer 3.3 .cdResult peak tables). Downstream, the 7-filter criteria and Degreaser QC (e.g. features with >30% RSD in QC samples flagged for removal, ECN vs. RT modeling, required-fragment logic) further boost confidence in identifications.

import pandas as pd; df = pd.read_csv('annotated_spectral_matches.csv'); keep = df[(df['spectral_purity']>=0.75)&(df['dot_product']>=500)&(df['reverse_dot_product']>=700)]

## Evaluation signals

- Only matches meeting spectral purity ≥75%, dot product ≥500, and reverse dot product ≥700 are retained; failing matches are flagged
- Per-match purity and dot-product/reverse dot-product values agree with the deposited reference annotations (output_matches_reference plus expert_review)
- Reprocessing MSV000091033 reproduces 14826 unidentified / 779 identified features before Peak Finder filtering and 13898 / 719 after
- Output .csv passes through the pipeline (all LipiDex 2 modules pass .csv results files) and fragment peaks are annotated for passing matches

## Limitations

- Identification is downgraded to sum composition if a required fragment is absent from the spectrum, and to plasmanyl if plasmenyl ether evidence is insufficient
- Spectral purity depends on detecting co-eluting isobaric lipid species; high co-isolation interference can suppress otherwise correct matches
- Matching is limited to MS2 and MS3+ spectra; the LipiDex 2 Wiki instructions are a work in progress (WiP)
