# feature-table-curation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Classifies each detected drug metabolite feature (m/z–RT pair) from human liver S9 LC-HRMS incubations as 'predicted' or 'unpredicted' by cross-referencing observed masses against BioTransformer 3.0 in silico predictions within a ±5 ppm tolerance, enabling quantification of novel metabolites per drug.

## When to use

Use when you have a table of detected drug metabolite features (paired m/z and RT from LC-HRMS) for one or more parent drugs incubated with human liver S9 fraction, plus a corresponding BioTransformer 3.0 predicted-metabolite list, and need to label each feature as predicted or unpredicted (novel).

## When NOT to use

- Input is already a feature table with predicted/unpredicted labels — re-applying would duplicate the curation step
- The metabolite feature list comes from a matrix other than human liver S9 incubation (e.g. microsomes, hepatocytes, extrahepatic compartments) where BioTransformer predictions may not align with the enzymatic context of the PharmMet DB design
- You need structural elucidation of unpredicted metabolites — this skill only assigns predicted/unpredicted labels and paired m/z–RT identifiers; isolation and structural determination require additional research

## Inputs

- Detected metabolite feature table (paired m/z and RT values per parent drug) from 24-hour human liver S9 incubation LC-HRMS runs, derived from 0-hour vs 24-hour comparison
- BioTransformer 3.0 predicted-metabolite list for the same parent drug(s)

## Outputs

- Per-drug feature table with columns: m/z, retention time (RT), predicted/unpredicted label, and matched BioTransformer entry (if any)
- Per-drug counts of predicted and unpredicted features (e.g. summarized in R 4.0.3)

## How to apply

Load the detected metabolite feature table (paired m/z and RT values per drug, generated by comparing MS1 mass spectra and retention times between 0-hour preincubation and 24-hour postincubation samples) and the corresponding BioTransformer 3.0 predicted-metabolite list for the same parent drug. For each detected feature, compute the mass difference between the observed m/z and each predicted metabolite m/z and retain matches within ±5 ppm. If an m/z match exists, mark the feature as 'predicted'; if no predicted metabolite matches within ±5 ppm, mark it 'unpredicted' and report it by paired m/z and RT. Assemble a per-drug feature table with columns for m/z, RT, predicted/unpredicted label, and the matched BioTransformer entry (if any), then summarize per-drug counts of predicted and unpredicted features (e.g. with R 4.0.3).

## Related tools

- **BioTransformer 3.0** (Provides the in silico predicted-metabolite list that detected mass signals are cross-referenced against at ±5 ppm tolerance to assign 'predicted' vs 'unpredicted' labels)
- **R 4.0.3** (Used for statistical analysis and data visualization when summarizing per-drug counts of predicted and unpredicted features)
- **MZmine 2.53** (Upstream tool used to process raw LC-HRMS files and produce the feature table (m/z–RT pairs) that this curation skill operates on)

## Examples

```
Rscript -e 'feats <- read.csv("detected_features.csv"); preds <- read.csv("biotransformer_preds.csv"); feats$label <- ifelse(sapply(feats$mz, function(m) any(abs((preds$mz - m)/m*1e6) <= 5)), "predicted", "unpredicted"); write.csv(feats, "curated_features.csv", row.names = FALSE)'
```

## Evaluation signals

- Every detected feature row must carry a non-empty 'predicted' or 'unpredicted' label
- All features labelled 'predicted' must satisfy the ±5 ppm mass-accuracy criterion between observed and BioTransformer-predicted m/z
- Per-drug counts of predicted and unpredicted features should sum to the total number of detected features for that drug
- Unpredicted (novel) metabolites should be reported with paired m/z and RT values, not bare masses
- Drugs where the feature table contains only predicted metabolites should be excluded when computing the fraction of drugs with at least one novel metabolite

## Limitations

- Reliance on human liver S9 fraction means metabolites formed by enzymes not abundant or active in this fraction, or generated in extrahepatic compartments (e.g. intestine, kidney), will be absent from the feature table and thus cannot be labelled
- Limited detection of some metabolites may occur due to limited cofactor availability or ionization suppression, leading to false 'unpredicted' labels for real metabolites that were simply not detected
- Unpredicted metabolites are reported only as paired m/z–RT features; structural elucidation requires considerable additional research
- The ±5 ppm cross-reference does not distinguish isomers or metabolites with identical formulae — multiple BioTransformer predictions may match the same detected mass
