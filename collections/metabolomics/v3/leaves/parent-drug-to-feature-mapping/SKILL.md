# parent-drug-to-feature-mapping

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Maps each unpredicted LC-HRMS feature (paired m/z and retention time) detected in 24-hour human liver S9 incubations back to its parent therapeutic drug and drug class, enabling per-class aggregation of novel metabolites not predicted by BioTransformer 3.0.

## When to use

Use when analyzing deposited ST003991 feature tables from PharmMet DB where individual LC-HRMS features must be attributed to a specific incubated drug and then aggregated by therapeutic class to quantify unpredicted metabolites.

## When NOT to use

- Input is already a fully aggregated per-class feature count table rather than raw paired m/z–RT feature annotations needing drug attribution
- The features of interest were already predicted by BioTransformer 3.0 and curated within PharmMet DB, so the parent-drug mapping of 'unpredicted' novel features is not applicable
- Analysis targets metabolites from extrahepatic compartments (intestine, kidney) or enzymes not active in liver S9 fraction, which PharmMet DB is expected to lack

## Inputs

- ST003991 feature/annotation files from Metabolomics Workbench (paired m/z and RT entries for unpredicted metabolites at 24 hours)
- Sample/plate metadata linking LC-HRMS features to specific drug incubations
- Supplemental Table 1 drug-class mapping from the PharmMet GitHub repository (1114 therapeutic drugs assigned to therapeutic classes)

## Outputs

- Per-drug count of unpredicted LC-HRMS features
- Per-therapeutic-class count of unpredicted features with grand total 486,215
- Class-level ranking identifying drugs whose metabolites were most frequently not predicted by BioTransformer 3.0 (anti-inflammatory, CNS, antimicrobial)

## How to apply

Download the ST003991 feature/annotation files from the Metabolomics Workbench (https://doi.org/10.21228/M8W55K), which contain paired m/z and RT entries for metabolites detected at 24 hours but not predicted by BioTransformer 3.0. Load Supplemental Table 1 from the PharmMet GitHub repository (https://github.com/ClinicalBiomarkersLaborabory/PharmMet), which assigns each of the 1114 therapeutic drugs to its therapeutic class. Join each unpredicted feature to its parent drug incubation using the sample/plate metadata in the deposited files, then use R 4.0.3 to aggregate unpredicted feature counts per parent drug and per therapeutic class. Validation: the grand total must equal 486,215 features and the per-class distribution must match the reported ranking (anti-inflammatory/immunomodulatory 126,210; antimicrobial 100,617; cardiovascular 88,653; CNS 62,693). The mapping relies on the study's candidate-feature detection step, which compared MS1 mass and retention time between preincubation (0 h) and postincubation (24 h) samples, and on curation that cross-referenced detected signals (±5 ppm) against BioTransformer predictions.

## Related tools

- **R 4.0.3** (Used for statistical analysis, data visualization, and aggregation of joined feature-to-drug-class counts in the mapping workflow)
- **PharmMet DB / Supplemental Table 1** (Provides the authoritative drug-to-therapeutic-class mapping for 1114 therapeutic drugs that feature counts are aggregated against) — https://github.com/ClinicalBiomarkersLaborabory/PharmMet
- **BioTransformer 3.0** (Defines the 'unpredicted' set: features curated by cross-referencing detected signals (±5 ppm) against BioTransformer predictions; any feature absent from these predictions is retained for mapping)
- **Metabolomics Workbench ST003991** (Deposited source of paired m/z–RT feature entries and sample metadata used as the join input) — https://doi.org/10.21228/M8W55K

## Examples

```
Rscript aggregate_unpredicted_features.R --features ST003991_features.csv --classes SupplementalTable1.csv --output per_class_counts.csv
```

## Evaluation signals

- Grand total of aggregated unpredicted features equals 486,215
- Per-class counts reproduce the reported distribution: anti-inflammatory/immunomodulatory 126,210; antimicrobial 100,617; cardiovascular 88,653; CNS 62,693
- Approximately 89% of the 1114 tested drugs yield at least one unpredicted feature mapped to a parent drug
- Every mapped feature carries both a paired m/z and retention time from the ST003991 deposit and a valid therapeutic-class label from Supplemental Table 1
- No feature attributed to a drug outside the 1114-drug incubation list appears in the output

## Limitations

- Reliance on liver S9 fraction for biotransformation means metabolites formed by enzymes not abundant or active in the liver S9, or generated in extrahepatic compartments (e.g., intestine, kidney), are expected to be absent from PharmMet DB
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression
- Identification of novel metabolites from nearly 1000 drugs will require considerable research for isolation and structural elucidation
