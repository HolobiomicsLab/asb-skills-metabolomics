# fdr-adjusted-statistical-testing

## Summary

Compute per-species log2 fold changes and FDR-adjusted p-values from peak-aligned, TIC-normalized single-cell mass spectrometry (SCMS) metabolomics feature tables, then apply dual thresholds (fold change ≥ 2.0, FDR ≤ 0.05) to nominate lipid biomarker candidates (TG, Cer, SM, PG, PE) between primary and metastatic melanoma cells.

## When to use

Use when a peak-aligned SCMS feature table (e.g., Geena2-aligned at 10 ppm mass tolerance) must be converted into a ranked list of differentially abundant species between two cell phenotypes, with multiple-testing control.

## When NOT to use

- The goal is cell phenotype classification rather than differential abundance testing — use the MetaPhenotype meta-learning model instead, since PCA alone cannot discriminate phenotypically similar cells such as IGR39/IGR37
- The input is raw, unaligned single-cell peak lists — peak alignment (Geena2, 10 ppm mass tolerance), noise/background subtraction, TIC normalization, and missing-value removal must precede group-wise statistical testing
- Sample sizes per group are too small for stable p-value estimation and FDR correction to be meaningful

## Inputs

- Peak-aligned, TIC-normalized SCMS metabolomics feature table (dataset.csv style) for primary/metastatic melanoma cell pairs, control and vemurafenib-treated
- Group labels assigning each single cell to primary vs. metastatic phenotype per cell pair and treatment condition

## Outputs

- Per-species table of log2 fold change and FDR-adjusted p-value per cell-pair/condition
- Volcano plots (log2 FC vs. -log10 FDR p), one per pair/condition
- List of significant lipid species (FC ≥ 2.0, FDR ≤ 0.05) with tentative METLIN/HMDB class annotations (Tables S4/S5-style biomarker candidates)

## How to apply

Start from the TIC-normalized, Geena2 peak-aligned feature table (10 ppm mass tolerance) generated by the established SCMS pretreatment protocol. For each lipid species, compute log2 fold change of abundance between the primary and metastatic groups separately for each cell pair and each condition (control and vemurafenib-treated), and derive p-values from the statistical tests before applying FDR correction for multiple comparisons. Filter species to fold change ≥ 2.0 and FDR-adjusted p ≤ 0.05 — both thresholds must be met to nominate a candidate. Render volcano plots (log2 fold change vs. -log10 FDR-adjusted p-value), one plot per cell-pair/condition, and tentatively annotate significant species against METLIN and HMDB, which the paper used to label detected lipid classes such as TG, Cer, SM, PG, and PE. Confirm the resulting differential species sets reproduce the reported Tables S4/S5 biomarker candidates.

## Related tools

- **MetaboAnalyst 6.0** (Used to compute statistical comparisons and render volcano plots (log2 FC vs. -log10 FDR-adjusted p) for the SCMS feature table)
- **Geena2** (Upstream peak alignment (10 ppm mass tolerance) that produces the aligned feature table the fold-change/FDR statistics are computed on)
- **METLIN** (Online database for tentative annotation of significant differential species (lipid classes TG, Cer, SM, PG, PE))
- **HMDB** (Online database for tentative annotation of significant differential species)

## Evaluation signals

- Every reported biomarker candidate meets both thresholds: fold change ≥ 2.0 AND FDR-adjusted p ≤ 0.05
- Volcano plots visually reproduce the differential species sets tabulated in Tables S4/S5 (TG, Cer, SM, PG, PE members) for each cell pair and condition
- One volcano plot is produced per pair/condition combination (control and vemurafenib-treated), each with annotated lipid classes
- Significant species have consistent tentative annotations when searched against METLIN and HMDB
- Input feature table reflects the established pretreatment chain (noise/background subtraction, TIC normalization, Geena2 10 ppm alignment, missing-value removal) before testing

## Limitations

- PCA cannot effectively discriminate phenotypically similar cells (e.g., IGR39/IGR37), so group-wise univariate testing alone may not capture phenotype-discriminating features; complementary classifiers like MetaPhenotype select 'small numbers of essential species critical for classification'
- Lipid annotations are only tentative — they rely on online database lookup (METLIN/HMDB) rather than confirmed structural identification
- Ambient SCMS methods yield relatively small numbers of cells, limiting statistical power for per-group tests
