# twims-ccs-benchmark-comparison

## Summary

Benchmarks CCS values computed by the snakemake_ccs workflow (Boltzmann-averaged and single global-minimum conformer) against experimental TWIMS CCS reference values from the Supporting Information Tables S1 and S2, using percent error and the paper's ±3% agreement criterion.

## When to use

Use when computed CCS values from the snakemake_ccs workflow (ccs.txt Boltzmann averages or HPCCS per-conformer outputs) must be validated against experimental TWIMS CCS values using percent error and the ±3% agreement criterion.

## When NOT to use

- The metabolite or adduct state of interest has no experimental TWIMS CCS reference value in the Supporting Information tables, so no benchmark comparison is possible.
- The goal is to generate new CCS predictions from SMILES rather than to validate or benchmark already-computed values.
- Evaluating CCS prediction methods outside the conformational-averaging context (e.g., cross-validating a machine learning model on training data), where the Boltzmann-average versus global-minimum comparison is not the relevant question.

## Inputs

- ccs.txt (Boltzmann average CCS per metabolite, generated by the Snakemake workflow in the ensemble or ensemble_fast folder)
- HPCCS trajectory outputs (per-conformer CCS values and relative energies)
- Experimental TWIMS CCS reference values from Supporting Information Tables S1 and S2
- Benchmark set of 20 metabolites with their protonated/deprotonated/neutral adduct states

## Outputs

- ccs_averaging_comparison.csv (per-metabolite percent-error table with summary statistics)
- Comparison of percent-error distributions for Boltzmann-averaged versus global-minimum-conformer CCS

## How to apply

Parse the ccs.txt file generated in the ensemble (or ensemble_fast) folder, which contains the Boltzmann average CCS value per metabolite and adduct/model. From the HPCCS trajectory outputs, extract individual per-conformer CCS values and relative energies to identify the global-minimum conformer for each metabolite. Load the experimental TWIMS CCS reference values from Supporting Information Tables S1 and S2 for the 20 benchmark metabolites (atom counts 10–40) across their protonated/deprotonated/neutral states. Compute the percent error of both the Boltzmann-averaged CCS and the global-minimum-conformer CCS against the experimental TWIMS value (e.g., for L-tryptophan model 3, the Boltzmann average of 159.69 Å² versus the global-minimum conformer's 166.44 Å² against an experimental CCS of 154.22 Å²). Judge each prediction against the paper's ±3% agreement criterion and compare the two error distributions to determine whether Boltzmann weighting systematically outperforms the single-conformer prediction. Write the per-metabolite error table and summary statistics to ccs_averaging_comparison.csv.

## Evaluation signals

- Computed workflow CCS values fall within ±3% of the experimental TWIMS values and available literature values for the benchmark metabolites.
- The per-metabolite error table reports percent errors for both the Boltzmann average and the global-minimum conformer, enabling direct distribution comparison.
- For L-tryptophan model 3, the Boltzmann average CCS (159.69 Å²) should show lower percent error against the experimental value (154.22 Å²) than the global-minimum conformer CCS (166.44 Å²).
- The ccs.txt file contains one Boltzmann average CCS entry per metabolite per adduct/model, matching the number of benchmark species evaluated.
- Coverage spans all 20 benchmark metabolites (atom counts 10–40) across their explored protonated/deprotonated/neutral molecular states.

## Limitations

- The ±3% figure is the paper's reported agreement criterion rather than a hard statistical pass/fail threshold; agreement is judged against literature values, values measured in the study, and consensus averages.
- The comparison depends on TWIMS experimental values, which carry instrumental uncertainty assessed in the study's TWIMS validation experiments.
- A single global-minimum conformer can be a markedly worse predictor than the Boltzmann average (e.g., 166.44 Å² versus 159.69 Å² for L-tryptophan model 3), so single-conformer conclusions should not be generalized.
- The workflow is designed for conformationally flexible metabolites with complex molecular structures; very rigid or very large species may not be well covered by the 10–40 atom benchmark range.
