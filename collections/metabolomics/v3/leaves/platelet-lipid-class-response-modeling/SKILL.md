# platelet-lipid-class-response-modeling

## Summary

Fits fragment-specific linear/nonlinear MS response curves for PUFA-PL species (18:0–20:4 across PA, PC, PE, PG, PI, PS) generated by LipidCreator and analyzed by LC/ESI SRM in human platelet matrix, using flipR nonlinear regression with minpack.lm and nls.multstart, to verify linear MS response with an average Pearson correlation coefficient of 0.99.

## When to use

Use when validating LipidCreator-computed transition lists against Skyline peak-area responses in a platelet or similar lipid matrix, specifically to confirm linear response for a defined fatty acyl combination (e.g., 18:0–20:4) across multiple headgroup classes.

## When NOT to use

- Input data is not from a targeted SRM/PRM assay using LipidCreator-computed transitions — e.g., untargeted DDA lipidomics where no pre-defined transition list exists
- The lipid species under study are outside the six glycerophospholipid classes (PA, PC, PE, PG, PI, PS) or use a fatty acyl combination other than 18:0–20:4
- The analytical goal is false discovery rate estimation or coeluting/isobaric lipid deconvolution — LipidCreator does not provide a dedicated scoring algorithm for these tasks

## Inputs

- LipidCreator-generated transition list for a defined fatty acyl combination (e.g., 18:0–20:4) across lipid classes (PA, PC, PE, PG, PI, PS)
- Skyline peak-area response data from LC/ESI SRM analysis of human platelet matrix

## Outputs

- Per-lipid-class Pearson correlation coefficients for linear response region (platelet_response_correlations.csv)
- Average Pearson correlation coefficient across all six lipid classes (expected ~0.99)

## How to apply

Load the LipidCreator-generated transition list for the target fatty acyl combination (18:0–20:4 across PA, PC, PE, PG, PI, PS) together with Skyline peak-area response data from the platelet lipid matrix. Import Skyline transition results into R and organize fragment-specific response values by lipid class. Fit linear regression models of peak-area response versus amount for each headgroup using flipR's nonlinear regression framework with the minpack.lm Levenberg-Marquardt solver and nls.multstart bounded grid-search optimization. Compute the Pearson correlation coefficient for the linear response region of each lipid class and average the six coefficients. Compare the computed average against the expected value of 0.99 and record per-class coefficients in platelet_response_correlations.csv. The rationale is that flipR uses nonlinear regression with an extended log-normal kernel to fit fragment-specific dissociation profiles, allowing accurate characterization of the linear response region for each class.

## Related tools

- **LipidCreator** (Generates the transition list (fragment masses, collision energies) for the target fatty acyl combination across lipid classes, which is imported into Skyline for targeted SRM assay) — https://github.com/lifs-tools/lipidcreator
- **Skyline** (Processes the raw SRM data and produces peak-area response values for each transition, which are exported for R-based regression fitting) — https://skyline.ms/project/home/software/Skyline/begin.view
- **flipR** (Performs nonlinear regression with an extended log-normal kernel to fit fragment-specific dissociation profiles and determine the linear response region)
- **minpack.lm** (Provides the Levenberg-Marquardt nonlinear least squares algorithm used within the flipR regression fitting) — https://rdrr.io/cran/minpack.lm/
- **nls.multstart** (Performs bounded grid search optimization to initialize the nonlinear regression parameters) — https://rdrr.io/cran/nls.multstart/

## Examples

```
Rscript -e 'library(flipR); library(minpack.lm); library(nls.multstart); data <- read.csv("skyline_peak_areas.csv"); model <- flipR(response ~ amount, data = data, class = "lipid_class"); coefs <- summary(model)$coefficients'
```

## Evaluation signals

- Average Pearson correlation coefficient across all six lipid classes should be ≈0.99, consistent with the published value
- Each individual lipid class (PA, PC, PE, PG, PI, PS) should show a high correlation coefficient (>0.98) in the linear response region
- The fitted regression residuals should show no systematic bias across the tested amount range, confirming a linear rather than saturating response
- The output file platelet_response_correlations.csv must contain one row per lipid class with a numeric correlation coefficient and no missing values

## Limitations

- LipidCreator CE models are currently exclusive to lipid mediators; expansion to other lipid classes requires more structurally diverse lipid standards and CE-dependent measurements
- Due to lack of isotope-coded standards, there are currently no large-scale methods available to cope with occurring stereoisomers
- No dedicated scoring algorithm to determine false discovery rates; does not address coeluting/isobaric lipids and peak area integration
