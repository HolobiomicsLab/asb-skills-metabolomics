# candidate-ranking-evaluation-mass-spectrometry

## Summary

Evaluates mass-spectra metabolite-annotation models by ranking PubChem-derived candidate molecules per test spectrum and reporting average rank (mean ± standard deviation) and Rank@k for k=1–20, as done for the ESP ensemble versus MLP and GNN baselines on NIST-20.

## When to use

Use when you have spectra paired with candidate molecule sets (e.g. torch_tecand_*.pkl from PubChem) and must quantify annotation performance via average rank and Rank@k metrics.

## When NOT to use

- You only have the training/validation/test spectra without candidate sets — training (train.py without --te_cand_dataset_suffix) is the wrong path, not candidate ranking.
- The task requires training new models rather than evaluating pretrained ones on ranked candidates (do not set --te_cand_dataset_suffix and do not reuse *_pd checkpoints).

## Inputs

- Test candidate set file torch_tecand_1000bin_te_cand100 (_torchgeometric.pkl) generated by data_tecand.py
- Pretrained MLP checkpoint best_model_mlp_pd.pt
- Pretrained GNN checkpoint best_model_gnn_pd.pt
- Pretrained ESP ensemble checkpoint (e.g. ESP_can.pt)

## Outputs

- Per-model ranked candidate predictions over the NIST-20 test split
- Average rank with standard deviation (e.g. ESP: 213.597 ± ...)
- Rank@k values for k = 1..20 (e.g. ESP Rank@1 0.187, Rank@10 0.490)

## How to apply

Generate test-candidate files with data_tecand.py (e.g. torch_tecand_1000bin_te_cand100 from PubChem candidate sets of average size 100), then restore pretrained MLP-PD and GNN-PD checkpoints by running train.py with --model mlp or gnn, --model_file_suffix mlp_pd or gnn_pd, disabling two-step prediction, fingerprint, multi-task fingerprint and multi-task ontology heads, and setting --correlation_mat_rank 100 and --te_cand_dataset_suffix to the candidate file. Run ens_train_canopus.py in 'canopus' mode with the mlp/gnn model suffixes to produce the ESP ensemble ranked predictions. For each model, compute average rank with standard deviation and Rank@k for k=1 through 20 on the test split. Correct application is judged by reproducing the reported ordering: ESP average rank 213.597 with Rank@1 ≈ 0.187 and Rank@10 ≈ 0.490, beating MLP by 23.7% and GNN by 37.2% in average rank; note MLP models remain strong contenders within the top five ranks.

## Related tools

- **Ensemble Spectral Prediction (ESP)** (Ensemble model trained on ranking tasks whose weighted-average MLP/GNN predictions are evaluated by candidate ranking) — https://github.com/HassounLab/ESP
- **dgl** (Deep graph library dependency (v0.6.1) for the GNN-based spectral prediction model used in ranking)
- **PyTorch** (Deep learning framework (v1.7.1) backing train.py and ens_train_canopus.py model restoration and inference)
- **PyTorch Geometric** (Defines the torchgeometric test-candidate file format produced by data_tecand.py for ranking evaluation)

## Examples

```
python train.py --cuda 1 --model gnn --model_file_suffix gnn_pd --disable_two_step_pred --disable_fingerprint --disable_mt_fingerprint --disable_mt_ontology --correlation_mat_rank 100 --te_cand_dataset_suffix torch_tecand_1000bin_te_cand100
```

## Evaluation signals

- ESP average rank (213.597) is lower than both MLP-PD and GNN-PD baselines, reflecting the reported 23.7% (MLP) and 37.2% (GNN) improvements.
- ESP Rank@1 ≈ 0.187 and Rank@10 ≈ 0.490 fall within the ranges of the expected output logs.
- Metrics are reported as average rank with standard deviation plus Rank@k for k=1..20, matching the 20-line 'Rank at k' output format.
- The MLP and GNN runs complete only when --disable_two_step_pred, --disable_fingerprint, --disable_mt_fingerprint and --disable_mt_ontology are all set with --correlation_mat_rank 100.
- Rank@k curves are monotone non-decreasing in k (e.g. ESP: 0.187 at k=1 rising to 0.592 at k=20).

## Limitations

- NIST-20 data cannot be redistributed with models trained on it due to NIST license regulations, so evaluation depends on users obtaining NIST-20 themselves.
- Annotation performance is dependent on the training dataset, the number of molecules in the candidate set, and candidate similarity to the target molecule.
- ESP wins on average rank, but MLP approaches remain strong contenders when considering top five ranks, so Rank@1–5 should be inspected before declaring a winner.
