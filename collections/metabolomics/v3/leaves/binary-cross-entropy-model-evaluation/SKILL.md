# binary-cross-entropy-model-evaluation

## Summary

Evaluate the pseudo-Siamese CNN (pSCNN) compound-identification model, which is compiled with binary cross-entropy loss and the Adam optimizer, by measuring ACC, TPR and FPR on an augmented test set and two experimental NMR mixture datasets.

## When to use

Use when a trained pSCNN model on NMR spectra of mixtures must be scored, or when benchmarking binary compound-identification performance with ACC/TPR/FPR metrics.

## When NOT to use

- The task is multi-class compound identification rather than binary per-compound presence/absence scored with Sigmoid outputs and binary cross-entropy
- Input spectra are not NMR spectra of mixtures (e.g. pure-compound library screening or non-spectral tabular data)
- No labeled ground truth is available for the test or experimental spectra, so ACC/TPR/FPR cannot be computed

## Inputs

- Trained pSCNN model (pscnn_model.h5) or pre-trained model from Zenodo DOI 10.5281/zenodo.6504814
- Augmented test set of NMR spectra of mixtures (generated by superposition of database spectra with random noises)
- Experimental NMR mixture datasets: flavor mixtures dataset and additional flavor mixture dataset
- Validation split of the augmented dataset for training-time monitoring

## Outputs

- ACC, TPR and FPR metrics on the augmented test set (expected: 99.80% / 99.70% / 0.10%)
- ACC, TPR and FPR on the flavor mixtures dataset (97.62% / 96.44% / 2.29%) and additional flavor mixture dataset (91.67% / 100.00% / 10.53%)
- Binary compound-identification predictions (Sigmoid outputs) for mixture NMR spectra

## How to apply

Compile the pSCNN model with binary cross-entropy loss and the Adam optimizer in TensorFlow 2.5.0-GPU, train on the augmented training split, and monitor the validation split. After training, run predictions on the held-out augmented test split and compute accuracy (ACC), true positive rate (TPR) and false positive rate (FPR) as the headline metrics; the reported benchmark is ACC = 99.80%, TPR = 99.70% and FPR = 0.10%. Then benchmark on two experimental NMR datasets — flavor mixtures (ACC = 97.62%, TPR = 96.44%, FPR = 2.29%) and additional flavor mixture (ACC = 91.67%, TPR = 100.00%, FPR = 10.53%) — to assess real-world generalization under chemical shift variation and peak overlap. Alternatively, download the pre-trained model from Zenodo (DOI 10.5281/zenodo.6504814), reload pSCNN and predict directly on example mixture spectra. Compare any reproduced metrics against these published values before accepting the evaluation.


## Evaluation signals

- Augmented test-set metrics fall at or near ACC = 99.80%, TPR = 99.70%, FPR = 0.10%
- Flavor mixtures dataset metrics fall at or near ACC = 97.62%, TPR = 96.44%, FPR = 2.29%
- Additional flavor mixture dataset metrics fall at or near ACC = 91.67%, TPR = 100.00%, FPR = 10.53%
- Model compiles with binary cross-entropy loss and Adam optimizer under TensorFlow 2.5.0-GPU and Python 3.8.13 without error
- Reloading the Zenodo-deposited model and predicting the example data reproduces the published predictions

## Limitations

- Performance degrades on real experimental data relative to the augmented test set (e.g. FPR rises to 10.53% on the additional flavor mixture dataset)
- The pre-trained model exceeded repository size limits and must be downloaded from Zenodo rather than cloned from GitHub
- No discussion-section content was available to document limitations and reproducibility gaps
