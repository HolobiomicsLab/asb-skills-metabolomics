# tanimoto-similarity-computation

## Summary

Quantifies structural agreement between predicted and reference molecular structures using Tanimoto (Dice coefficient) similarity over molecular fingerprints/SMILES fragment trees, enabling benchmarking of de novo MS2 structure prediction (e.g., TeFT on CASMI 2017) against baselines like SIRIUS4 and MetFrag.

## When to use

Use when you have predicted molecule structures (SMILES) from de novo MS2 spectra interpretation and need to score them against ground-truth structures, rank candidates, or produce statistically tested benchmark metrics.

## When NOT to use

- Spectra were recorded in negative ion mode or other adducts — TeFT was only trained on positive ion mode (H+) spectra, so similarity scoring of its predictions is not applicable
- The task is high-resolution, high-accuracy spectra prediction, where the article notes the model 'may not exhibit exceptional performance advantages' versus SIRIUS4/MSNovelist/MassGenie
- Input is already a ranked candidate list or similarity score table — no need to recompute fingerprint similarity

## Inputs

- Predicted molecular structures (SMILES) generated by TeFT from low-resolution MS2 spectra
- Ground-truth reference structures (SMILES) for each spectrum (e.g., CASMI 2017 contest answers)
- Positive-mode MS2 peak lists (max 100 peaks by ion intensity; top 5–6 fragmentation peaks with nearby points)
- Baseline prediction outputs from SIRIUS4 and MetFrag on the same spectra (for statistical comparison)

## Outputs

- Per-spectrum Tanimoto similarity (Dice coefficient) scores between predicted and true structures
- Ranked candidate substance lists based on SMILES fragment tree similarity
- Aggregate metrics: % correct structures ranked first, % mostly correct, % similarity >0.8, % similarity >0.9
- Wilcoxon signed-rank p-values comparing TeFT vs SIRIUS4 and TeFT vs MetFrag similarity distributions

## How to apply

For each spectrum (e.g., the 93 positive-mode CASMI 2017 MS2 spectra), take the TeFT-predicted structure and the ground-truth structure and compute Tanimoto similarity (Dice coefficient) between their molecular fingerprints/SMILES fragment trees; ranking of candidate substances is done by comparing similarity between SMILES fragment trees of each predicted molecule and the molecular fragment trees generated from the tandem mass spectra. Apply the TeFT constraints when generating structures first (molecular weight <500 Da, only the ten elements C/H/O/N/P/S/Cl/Br/I/F, peak lists limited to a maximum of 100 peaks by ion intensity, top five to six fragmentation peaks as experimental data). Aggregate the similarity distributions into headline metrics: percentage of correct structures ranked first, percentage mostly correct, percentage with similarity >0.8, and percentage with similarity >0.9. To establish statistical significance, run the same scoring on SIRIUS4 and MetFrag outputs and apply Wilcoxon signed-rank tests on the similarity distributions (reference results: p = 4.4×10⁻⁶ vs SIRIUS4, p = 2.7×10⁻¹¹ vs MetFrag).

## Related tools

## Evaluation signals

- All computed similarity values fall in [0, 1] and higher similarity corresponds to better structural agreement with the ground truth
- On the 93 CASMI 2017 MS2 spectra, expected reference metrics are 12% fully correct, 22% mostly correct, 78% with Dice similarity >0.8, and 39% with >0.9
- Statistical comparison reproduces significant Wilcoxon signed-rank results (p = 4.4×10⁻⁶ vs SIRIUS4; p = 2.7×10⁻¹¹ vs MetFrag)
- SMILES used for scoring are standardized and deduplicated (as done for the training set), so identical molecules yield similarity 1.0
- Every scored spectrum has both a prediction and a ground truth; spectra violating the <500 Da / ten-element constraints are excluded before scoring

## Limitations

- TeFT was trained only on positive ion mode (H+) spectra, restricting applicability of downstream similarity benchmarking to that mode
- Similarity thresholds (>0.8, >0.9) are proxies — high fingerprint similarity does not guarantee the exact correct structure; full-structure prediction was achieved for only a minority (12% fully correct, 8 of 16 flavonoid alcohols on the miniaturized instrument)
- The model targets low-resolution spectra from miniaturized mass spectrometers and may underperform on high-resolution data compared to SIRIUS4, MSNovelist, or MassGenie
