# modified-cosine-similarity-networking

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Builds molecular networks from pseudo MS/MS (composite) spectra generated by ms1-id by submitting cleaned MGF files to GNPS2 classical molecular networking, where edges are formed under modified cosine similarity so that structurally related metabolites (e.g. N-acyl amides) cluster into biologically coherent subnetworks with propagated annotations.

## When to use

Use when you have pseudo MS/MS spectra (MGF) derived from MS1-only full-scan LC-MS data and need a molecular network whose edges link features by modified cosine similarity, enabling annotation propagation across related metabolites.

## When NOT to use

- Input is real acquired MS/MS data rather than pseudo MS/MS spectra from MS1-only full-scan files — standard GNPS networking without the ion-cleaning step is the appropriate path.
- The goal is single-feature library annotation rather than network construction — use ms1-id's reverse spectral matching directly (min_score 0.7, min_matched_peak 3) instead of networking.
- Peaks above the precursor m/z cannot be removed (e.g. multimer/adduct ions must be retained), since modified cosine calculations will not be possible on the uncleaned spectra.

## Inputs

- pseudo MS/MS (composite) spectra in MGF format generated by ms1-id from MS1-only LC-MS data (e.g. IBD HILIC-positive mode, Metabolomics Workbench PR000639)
- per-feature precursor m/z values for cleaning ions above each feature's m/z

## Outputs

- cleaned MGF file (e.g. ibd_hilicpos_cleaned_pseudo_msms.mgf) containing only peaks at or below each feature's precursor m/z
- GNPS2 molecular network edges table (molecular_network_edges.tsv) with edges built under modified cosine >= 0.8 and matched peaks >= 6
- biologically coherent subnetworks with propagated MS/MS-similarity-based annotations

## How to apply

Start from the pseudo MS/MS spectra generated by ms1-id (e.g. from the IBD HILIC-positive mode of Metabolomics Workbench PR000639) and clean each feature's pseudo MS/MS by removing all ions with m/z larger than the feature's precursor m/z, because modified cosine requires peaks at or below the precursor. Write the cleaned spectra into a single MGF file (e.g. ibd_hilicpos_cleaned_pseudo_msms.mgf) and submit it to the GNPS2 classical molecular networking workflow (version 2024.09.20). Run networking with edge requirements of minimum modified cosine 0.8 and minimum 6 matched peaks, which the paper specifies as the thresholds required to build an edge. Retrieve the job output and save the network edges table (molecular_network_edges.tsv); annotations propagate across edges via the modified-cosine-based MS/MS similarity, as demonstrated by the tyrosine-related subnetwork of N-acyl amides in the IBD cohort.

## Related tools

- **ms1-id** (Generates the pseudo MS/MS spectra from in-source fragments of MS1-only LC-MS data and annotates them prior to network construction; its source code is at https://github.com/Philipbear/ms1_id.) — https://github.com/Philipbear/ms1_id
- **GNPS2** (Hosts the classical molecular networking workflow (version 2024.09.20) that computes modified cosine edges (>= 0.8, >= 6 matched peaks) from the cleaned pseudo MS/MS MGF; paper job: https://gnps2.org/status?task=670aa34a07544a5cbbd1f1d40605f50f.)

## Examples

```
ms1_id annotate --input_file ibd_hilicpos_cleaned_pseudo_msms.mgf --libs db/gnps.pkl db/gnps_k10.pkl --min_score 0.7 --min_matched_peak 3
```

## Evaluation signals

- The cleaned MGF contains only peaks at or below each feature's precursor m/z — no ion with m/z larger than the feature m/z remains.
- The GNPS2 job completes successfully and reports edges built under the stated criteria (modified cosine >= 0.8, matched peaks >= 6).
- The saved edges table (molecular_network_edges.tsv) matches the published job output at https://gnps2.org/status?task=670aa34a07544a5cbbd1f1d40605f50f for the IBD HILIC-positive mode.
- Resulting subnetworks are biologically coherent, e.g. a tyrosine-related subnetwork containing N-acyl amides with altered levels in non-IBD vs CD/UC comparisons.
- Edge annotations are propagated via modified cosine-based MS/MS similarity rather than appearing only on isolated singletons.

## Limitations

- Modified cosine calculations are only possible after removing all ions larger than the feature m/z; uncleaned pseudo MS/MS spectra cannot be networked this way.
- The approach depends on pseudo MS/MS spectra generated from in-source fragments of MS1-only data, whose fragment energies are lower than the medium-to-high collision energies of most public reference MS/MS spectra.
- Edge formation requires a minimum of 6 matched peaks, so features with sparse pseudo MS/MS may remain unconnected singletons.
