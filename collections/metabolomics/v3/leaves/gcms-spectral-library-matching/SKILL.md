# gcms-spectral-library-matching

## Summary

Annotates deconvoluted GC-MS spectra by searching them against the GNPS GC-MS reference library (19,808 spectra / 19,708 standards) plus public and user libraries using cosine similarity on fragment ions, with Kovats retention-index filtering. This turns unassigned deconvolution products from MSHub/GNPS into compound-level annotations.

## When to use

Use when deconvoluted GC-MS spectra are available in a .mgf file (e.g. from GNPS-MSHub auto-deconvolution) and compound identifications are needed via reference-library spectral matching.

## When NOT to use

- Input is raw, non-deconvoluted GC-MS data — run the MSHub auto-deconvolution (non-negative matrix factorization) step first to produce deconvoluted spectra.
- The goal is LC-MS/MS molecular networking rather than GC-MS library search; this skill is specific to GC-MS deconvoluted spectra.
- No suitable reference spectra exist for the target analytes and no public/user library covers them — spectral matching cannot annotate compounds absent from the library.

## Inputs

- .mgf file of deconvoluted GC-MS spectra (from GNPS-MSHub auto-deconvolution or another tool)
- GNPS GC-MS reference library (released with the manuscript; 19,808 spectra for 19,708 standards)
- Optional Kovats retention-index values for query compounds

## Outputs

- library_search_annotations.tsv with the best matching library standard and match score per deconvoluted spectrum

## How to apply

Download the GC-MS reference library released with the manuscript and parse its spectra, verifying it contains exactly 19,808 spectra covering 19,708 unique standards. Load the deconvoluted spectra from the input .mgf generated by the upstream MSHub/GNPS auto-deconvolution (unsupervised non-negative matrix factorization) step. Match each deconvoluted spectrum against the library with the GNPS GC-MS library search, which scores candidates by cosine similarity on fragment ions. Where retention information is available, restrict candidate matches to those consistent with the compound's Kovats retention index. Write the best matching library standard per query spectrum, together with its match score, to library_search_annotations.tsv.

## Related tools

- **GNPS** (Hosts and executes the GC-MS library search workflow (cosine similarity scoring on fragment ions) against public, user, and the released reference libraries) — https://github.com/CCMS-UCSD/GNPS_Workflows
- **MSHub** (Upstream: generates the deconvoluted .mgf spectra that serve as query input to the library search) — https://github.com/bittremieux/GNPS_GC

## Evaluation signals

- Library parse check: the downloaded reference library yields exactly 19,808 spectra for 19,708 unique standards.
- Every deconvoluted spectrum in the .mgf receives a search result (match or explicit no-match) in library_search_annotations.tsv.
- Reported best matches are the highest cosine-similarity hits among candidates, and matches are consistent with Kovats retention index where RI data is available.
- Output table schema contains one best matching library standard plus its match score per query spectrum.
- Spot-check known standards: their deconvoluted spectra should match the corresponding library entries with high scores.

## Limitations

- Annotation is limited to compounds represented in the reference, public, or user libraries; unknowns remain unannotated.
- Retention-index restriction is only possible where Kovats RI values are available for the compound.
- Match quality depends on the reproducibility of fragmentation patterns produced by the upstream deconvolution (quantified by the 'balance score').
