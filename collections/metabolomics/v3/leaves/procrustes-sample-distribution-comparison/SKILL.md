# procrustes-sample-distribution-comparison

## Summary

A supervised multivariate evaluation step from the GSimp imputation pipeline: fit PLS-DA (ropls, nPCs=2) to original and imputed matrices using binary group labels, then quantify divergence of sample distributions via vegan's Procrustes sum of squared errors to test whether an imputation method preserved group-separation structure.

## When to use

Use when comparing imputed vs. original metabolomics data matrices to verify that supervised group-separation structure (e.g., case/control labels like rep(c(0,1), each=80)) was preserved after missing-value imputation.

## When NOT to use

- The task concerns unsupervised data structure (PCA-type ordination); the pipeline supports DR='PCA' but group-label fidelity assessment requires supervised PLS with the outcome supplied
- The imputed dataset lacks matched group labels or a complete original reference matrix, since Procrustes SSE is computed between paired original and imputed ordinations of the same samples
- Data are non-targeted GC/MS profiles assumed MCAR/MAR after missing retrieval, where default GSimp truncation settings rather than group-difference evaluation drive the choice

## Inputs

- Scaled complete metabolomics data matrix (e.g., real_data.csv with FFAs and BAs)
- Binary group label factor, e.g., factor(rep(c(0,1), each=80))
- List of imputed data matrices indexed by method, mis_var_prop, and var_mis_prop
- Upstream PLS scores for original data (ropls, nPCs=2)

## Outputs

- PLS-Procrustes SSE per method and number of missing variables (Miss_Num)
- Tidy metrics table, e.g., labeled_evaluation_metrics.csv with method, Miss_Num, p_value_cor, PLS_Procrustes_SSE columns
- Procrustes comparison plot for original vs. imputed PLS ordinations

## How to apply

Load the complete scaled data matrix plus a group label factor (e.g., rep(c(0,1), each=80)) alongside the imputed dataset list generated by mis_var_prop=seq(.1,.8,.1) and var_mis_prop=seq(.3,.6,.1). For each imputation method and missingness level, run supervised PLS ordination with nPCs=2 using ropls with the group labels as the outcome (Procrustes_cal_plot(DR='PLS', outcome=group)). Then call vegan::procrustes to align the original-data PLS sample scores to the imputed-data PLS sample scores and extract the sum of squared errors (SSE) as the dissimilarity metric. Assemble method × Miss_Num rows of PLS-Procrustes SSE into a tidy table (labeled_evaluation_metrics.csv) alongside t-test p-value correlations; the method with the lowest SSE (in this study GSimp) best preserved group-difference information under MNAR degradation.

## Related tools

- **ropls** (Performs the supervised PLS ordination (nPCs=2) using group labels as outcome for both original and imputed matrices)
- **vegan** (Computes the Procrustes alignment and sum of squared errors between original and imputed PLS sample scores)
- **GSimp_evaluation.R** (Provides Procrustes_cal_plot and the labeled evaluation pipeline functions (source from the GSimp repo)) — https://github.com/WandeRum/GSimp
- **GSimp** (The imputation method under test whose imputed matrices are compared against originals via PLS-Procrustes) — https://github.com/WandeRum/GSimp

## Examples

```
Procrustes_cal_plot(DR='PLS', outcome=group) # then: vegan::procrustes(PLS_scores_orig, PLS_scores_imp) -> sse $result$ss
```

## Evaluation signals

- One row per imputation method × mis_var_prop × var_mis_prop combination with a populated PLS-Procrustes SSE value
- SSE should reproduce the reported trend: GSimp attains the lowest PLS-Procrustes SSE among HM, QRILC, kNN-TN, and GSimp as the number of missing variables increases
- SSE is computed on nPCs=2 PLS scores fitted with the same group outcome on both original and imputed data (Procrustes_cal_plot(DR='PLS', outcome=group))
- SSE is paired with the log-transformed two-sample t-test p-value Pearson correlation (cor='P') as the complementary univariate fidelity metric
- The comparison ordination must use identical sample ordering in original and imputed matrices; vegan::procrustes requires paired rows

## Limitations

- PLS-Procrustes SSE is a supervised metric — it measures fidelity to group separation, so it is only meaningful when genuine group labels exist and are used as the PLS outcome
- SSE comparisons are valid only across methods evaluated at the same MNAR generation settings (mis_var_prop=seq(.1,.8,.1), var_mis_prop=seq(.3,.6,.1)); changing degradation parameters breaks cross-method comparability
- Like all PLS-DA-based diagnostics, results can be sensitive to the number of components; the pipeline fixes nPCs=2
- The evaluation was validated on targeted metabolomics (FFA and BA datasets, N=160 with rep(c(0,1), each=80)) and a simulation dataset; transfer to other -omics is noted as future work
