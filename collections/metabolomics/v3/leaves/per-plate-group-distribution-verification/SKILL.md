# Per-plate group distribution verification

## Summary

A validation step for InjectionDesign's inter-batch balancing output that checks whether each single plate's sample group distribution is close to the overall cohort ratio, as demonstrated in the 1300-sample, three-dimension case study on 96-well plates.

## When to use

Use when a stratified inter-batch balancing run (e.g., across gender, treatment/placebo, and age-group dimensions) has produced a plate-assignment table and you must confirm each plate's group proportions match the overall cohort ratio before exporting worksheets.

## When NOT to use

- You are evaluating intra-batch ordering quality (e.g., no three consecutive same-group samples from block size 2) rather than between-plate balance — use the intra-batch randomization check instead
- Sample counts per dimension are extremely skewed and the user needs the natural numerical distribution preserved — the article notes block randomization completely averages out the distribution of sample features, so averaging-based balance verification is not the goal there
- The design has not yet been generated (no plate-assignment table exists); configure plate specifications and run inter-batch balancing first

## Inputs

- Cohort sample list with classification dimensions (e.g., gender, treatment, age group) imported into InjectionDesign via Excel template
- Plate-assignment table (plate_assignments.csv) with one row per sample carrying plate and stratification labels
- Per-plate group-distribution summary table generated by the inter-batch balancing step
- Plate configuration: 96-well template (x-axis=12, y-axis=8) with maximum experimental sample capacity 96 per plate (QC samples excluded)

## Outputs

- Verified plate-assignment table (1300 data rows for the case study) confirming per-plate stratification coverage
- Per-plate group-distribution comparison showing each plate's proportions are close to the overall cohort ratio (Figure 4c-style check)
- Pass/fail validation verdict for the balancing run

## How to apply

After running InjectionDesign's inter-batch balancing on the imported cohort (e.g., 1300 samples stratified across two-, three-, and four-category dimensions such as gender 615 Male/434 Female/251 Unknown, treatment 650/650, and age groups 169/351/481/299), export the plate-assignment table (one row per sample with its plate and stratification labels) plus the per-plate group-distribution summary table. First verify the assignment table contains exactly one data row per sample (1300 in the case study) with the plate capacity respected (max 96 experimental samples per 96-well plate, x=12, y=8, QC samples excluded from capacity). Then, for each classification dimension, compare each single plate's group counts/proportions against the overall cohort ratio; the run is successful when every plate's distribution is extremely close to the overall ratio, as reported for Figure 4c. Note that trailing samples left over after even batching are randomized and interspersed across batches, so treat the final plate as balanced rather than empty.

## Evaluation signals

- plate_assignments.csv contains exactly 1300 data rows (one per input sample) with no samples dropped or duplicated
- No plate exceeds the maximum experimental sample capacity of 96 samples per 96-well plate (QC samples excluded from the count)
- For each classification dimension (gender, treatment, age group), every single plate's group distribution is extremely close to the overall cohort ratio, matching the Figure 4c verification
- Per-plate summary counts across all plates sum to the cohort totals (e.g., 615 Male / 434 Female / 251 Unknown; 650 treatment / 650 placebo)
- Trailing samples appear interspersed across batches (randomized), not lumped into a single final batch

## Limitations

- Block randomization completely averages out the distribution of sample features, losing some numerical characteristics naturally present in the sample; complete randomization is an imperfect alternative for such scenarios
- When there are too many groups in one dimension, the averaging step calculation can lead to local aggregation under some special numerical distributions, weakening per-plate balance
- The service's predefined QC types (Blank, Solvent, Pooled, Long-Term Reference QC, plus one custom) and injection rules may not cover newly emerging QC requirements
