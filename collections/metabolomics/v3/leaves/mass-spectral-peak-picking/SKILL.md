# mass-spectral-peak-picking

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Detect chromatographic features (m/z and retention time) from raw LC-HRMS files by importing each sample into MZmine 2.53 and building chromatograms with the ADAP chromatogram builder, producing the per-sample MS1 feature lists needed for downstream differential metabolite detection (e.g., 0-hour vs 24-hour S9 incubation comparisons).

## When to use

Use when raw LC-HRMS files (e.g., Thermo Orbitrap ID-X, MS1 scan range m/z 100–1000 at 60,000 resolution) must be converted into m/z and retention-time feature lists for differential comparison of preincubation and postincubation samples.

## When NOT to use

- Input is already a processed feature/peak table (m/z, RT, intensities) — skip raw-file import and proceed directly to differential feature detection
- Targeted quantification of known metabolites with validated transitions, rather than untargeted MS1 feature detection for 0-hour vs 24-hour comparison
- MS2 spectra need to be interpreted or matched at this stage — peak picking here operates on MS1 spectral data; MS2 (HCD 35%) is used later for annotation/confirmation

## Inputs

- Raw LC-HRMS data files acquired on a Thermo Scientific Orbitrap ID-X Tribrid mass spectrometer (MS1 spectra at 60,000 resolution, m/z 100–1000; MS2 at 15,000 resolution, HCD 35%)
- Sample set including matched preincubation (0-hour) and postincubation (24-hour) files for each drug incubation
- Raw files from both chromatography/ESI platforms: HILIC coupled to positive ESI and C18 chromatography coupled to negative ESI

## Outputs

- Per-sample MS1 feature list of m/z values with retention times
- Exported tab-separated peak table containing m/z, retention time, and peak intensities per sample, with entries for both 0-hour and 24-hour samples of each drug incubation

## How to apply

Import each raw file independently into MZmine 2.53 and build chromatograms with the ADAP chromatogram builder module, keeping samples separate (HILIC/positive-ESI and C18/negative-ESI platform files are handled as separate acquisitions). Detect MS1 m/z features with retention times for each time-point sample — in the PharmMet DB study, 0-hour (preincubation) and 24-hour (postincubation) samples of each drug incubation. Export the resulting feature list (m/z, retention time, and peak intensities per sample) as a tab-separated peak table. The exported table then feeds candidate drug-metabolite feature detection by comparing MS1 m/z and RT between 0-hour and 24-hour samples, with curation of detected mass signals cross-referenced against BioTransformer 3.0 predictions within a ±5 ppm tolerance.

## Related tools

- **MZmine 2.53** (Import raw LC-HRMS files and build chromatograms with the ADAP chromatogram builder, processing each sample independently, to detect m/z features with retention times)
- **Thermo Scientific Orbitrap ID-X Tribrid mass spectrometer** (Source instrument whose raw files (MS1 60,000 resolution, m/z 100–1000) are the input to peak picking)

## Evaluation signals

- Exported peak table exists and contains both m/z and retention-time columns
- Peak table includes entries for both the 0-hour (preincubation) and 24-hour (postincubation) samples of each drug incubation
- Each sample was processed independently through the ADAP chromatogram builder (no co-processing across samples at this stage)
- Detected features fall within the acquired MS1 scan range (m/z 100–1000) and carry plausible retention times on the respective HILIC/positive-ESI or C18/negative-ESI platform
- Downstream curation of detected mass signals against BioTransformer predictions succeeds within the ±5 ppm mass tolerance, indicating m/z accuracy is adequate

## Limitations

- Peak picking operates on MS1 spectral data only; MS2 (15,000 resolution, HCD 35%) acquired on the Orbitrap ID-X is used later for annotation, so structural information is not available at this stage
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression, so the feature list may miss low-abundance or suppressed signals
- Feature lists are generated per drug incubation across only two time points (0 hour vs 24 hour), which constrains the kinds of kinetic or temporal analyses possible downstream
