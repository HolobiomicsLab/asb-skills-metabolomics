# classification-evaluation-measure-computation

## Summary

Computes Pass/Fail classification evaluation measures (Accuracy, Pass and Fail F-measures, sensitivity, specificity, PPV, NPV) for peak-quality classifiers built on untargeted LC–MS feature tables, as implemented in MetaClean's getEvaluationMeasures(). This quantifies how well a peak-integration-quality classifier distinguishes high-quality from low-quality peaks.

## When to use

Reference for quantitatively comparing peak-quality classifiers — or a classifier against RSD < 30% pooled-QC filtering — on labeled Pass/Fail peaks from untargeted LC–MS datasets.

## When NOT to use

- When peaks are unlabeled — evaluation measures require expert Pass/Fail ground truth, which the paper generated via manual visual inspection by an expert (Petrick)
- When the goal is peak detection or integration itself rather than assessing a classifier's discriminative performance on already-predicted labels

## Inputs

- Pass/Fail predicted labels per peak (from a trained MetaClean classifier or from RSD < 30% pooled-QC filtering)
- Expert-assigned Pass/Fail labels for the same peaks
- Cross-validation performance statistics collected per fold/repetition during model selection

## Outputs

- Per-dataset table of Accuracy, Pass F-measure, Fail F-measure, sensitivity, specificity, PPV, and NPV
- Aggregated comparison table across the development and test datasets
- Critical difference (CD) plots ranking classifiers (e.g., reproducing Fig. 4)

## How to apply

Take predicted labels from a trained classifier (e.g., MetaClean's AdaBoost M11 model) or from an RSD < 30% pooled-QC filter, and compare them to the expert Pass/Fail labels on the labeled peak subsets. Apply getEvaluationMeasures() from the MetaClean R package to each dataset (e.g., the 500 labeled peaks in ST000726, ST000695, MTBLS354, and the two MTBLS306 ionization modes) to compute Accuracy, Pass F-measure, Fail F-measure, sensitivity, specificity, PPV, and NPV. Because Pass and Fail are both biologically important — Fail flags mis-integrated peaks, Pass protects true chemicals — report F-measures for each class separately rather than a single average. Repeat evaluation over the 5-fold cross-validation folds (k=5, repNum=10 via runCrossValidation()) during model selection, and again on independent test sets during validation. Aggregate measures across datasets into a comparison table, then rank competing approaches with critical difference (CD) plots generated by getCDPlots() to assess statistical significance of the ranking.

## Related tools

- **MetaClean** (Provides getEvaluationMeasures() to compute Accuracy, Pass/Fail F-measures, sensitivity, specificity, PPV, and NPV for candidate classifiers; also supplies runCrossValidation() and getCDPlots() for the CV statistics and critical-difference ranking underlying the evaluation) — https://CRAN.R-project.org/package=MetaClean
- **XCMS** (Supplies the upstream feature table whose Pass/Fail peak labels the evaluation measures score)

## Examples

```
library(MetaClean); eval <- getEvaluationMeasures(pred_labels = pred_labels, true_labels = true_labels); cd <- getCDPlots(eval_stats = eval)
```

## Evaluation signals

- Every labeled peak in the development and test sets receives exactly one evaluation row — no peaks are silently dropped
- The global classifier's Pass and Fail F-measures exceed those of RSD < 30% filtering across the test sets, as in the paper's Fig. 4
- Cross-validation evaluation uses k=5 folds and repNum=10 repetitions per candidate classifier, matching the paper's protocol
- Comparisons across classifiers/datasets are validated by Friedman followed by Nemenyi tests on the collected performance statistics, and visualized as CD plots
- A permutation control (100 randomized labelings) should yield near-chance performance, confirming the measures reflect real signal

## Limitations

- Measures are only as trustworthy as the expert labels; manual quality assessment is time-consuming and subjective
- Interpretation is dataset-dependent: ionization mode, analytical platform, and biological matrix affect peak quality, so measures from one dataset may not transfer
- The MetaClean classifier was conservative and performed worse on the Fail class than the Pass class for some test sets, so Fail F-measure should be inspected separately, not averaged away
