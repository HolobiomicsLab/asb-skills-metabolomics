# msp-library-export-validation

## Summary

Validate that a Lipid Spectrum Generator (LSG) export of an in silico lipid spectral library is complete and correctly formatted, with lipid species enumerated by class and fatty acid composition and spectra generated per adduct, exported as .MSP (or .CSV precursor/transition lists).

## When to use

Use when Lipid Spectrum Generator has produced an exported lipid spectral library (.MSP) or Skyline/Excalibur transition list (.CSV) and you must verify entries exist for the enumerated lipid classes and adducts before downstream LC-MS/MS lipid identification.

## When NOT to use

- The spectra were acquired experimentally rather than generated in silico by LSG — this skill only validates the generated library artifact, not raw LC-MS/MS data
- Downstream analysis expects raw instrument output (e.g. mzML or .raw) instead of an exported .MSP spectral library or .CSV precursor/transition list
- The lipid classes or fatty acid compositions of interest are not covered by LSG's built-in enumerations — the generator will not produce entries to validate

## Inputs

- Enumerated lipid species (class + fatty acid composition) from the Lipid Spectrum Generator
- Per-adduct fragmentation spectra generated by LSG
- Selected output file extension ('.MSP' for spectral library, '.CSV' for precursor or transition list)

## Outputs

- Validated '.MSP' in silico lipid spectral library file
- '.CSV' Excalibur-compatible precursor list (DDA analysis via orbitrap) or Skyline-compatible transition list
- Cross-check report confirming each lipid class/adduct has a corresponding library entry

## How to apply

Run LSG (v1.3.0, repo 98104781/LSG) so that lipids are generated with respect to class and fatty acid composition and spectra are generated with respect to their adducts. Choose the '.MSP' file extension to export a spectral library, or '.CSV' to export an Excalibur-compatible precursor list (for DDA analysis via orbitrap) or a Skyline-compatible transition list. After export, open the artifact and check that each enumerated lipid class appears and that spectra entries are keyed to their expected adducts. Judge success by cross-checking the exported library against the list of lipids LSG enumerated by class and fatty acid composition — every class/composition pair should have a corresponding spectral entry for each selected adduct, and the file should be parseable in the target downstream tool (e.g. a spectral library reader for .MSP, Excalibur or Skyline for .CSV).

## Related tools

- **Lipid Spectrum Generator** (Generates in silico lipids by class and fatty acid composition, generates per-adduct fragmentation spectra, and exports the library as .MSP or .CSV) — https://github.com/98104781/LSG/releases/tag/v1.3.0
- **Python** (Runtime environment in which the LSG script is executed and the exported library artifacts are inspected/validated)

## Examples

```
python -c "from lsg import generate; generate.export_msp(classes='all', adducts='all', out='lipid_library.MSP')"
```

## Evaluation signals

- Exported .MSP contains spectral entries for every lipid class enumerated by LSG's built-in classes
- Each spectral entry is associated with the adduct(s) selected for that lipid's spectrum generation
- '.CSV' output parses as an Excalibur-compatible precursor list or Skyline-compatible transition list as documented
- No lipid class / fatty acid composition pair present in the LSG enumeration is missing from the exported library file

## Limitations

- Spectral export is limited to '.MSP' for spectral libraries; transition/precursor export requires '.CSV' — other formats are not supported
- An overview of features and a brief how-to guide is provided on the GitHub release page (v1.3.0) rather than in the README itself, so detailed invocation guidance may need to be sourced there
- Fragmentation patterns used to generate spectra are based on peer-reviewed studies but the README does not describe any built-in validation checks — completeness must be verified manually
