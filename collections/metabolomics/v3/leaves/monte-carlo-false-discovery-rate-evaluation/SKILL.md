# monte-carlo-false-discovery-rate-evaluation

## Summary

Monte Carlo simulation framework to empirically assess whether the MaRR maximal rank procedure controls FDR at a nominal 0.05 level, achieves near-100% discriminative power, and estimates the reproducible signal proportion (pi_1) without substantial bias in bivariate Normal settings mimicking MS-Metabolomics data.

## When to use

Use when validating that a reproducibility-detection procedure (e.g., MaRR) controls the False Discovery Rate at a nominal level (e.g., 0.05), and when quantifying discriminative power and bias of an estimated signal proportion over many simulated replicates.

## When NOT to use

- When the goal is to apply MaRR to real MS-Metabolomics replicate data (Tech, BioTech, Bio) rather than to benchmark its statistical operating characteristics via simulation
- When a comprehensive evaluation of pre-processing steps (imputation/normalization) is the objective — the paper's stated goal was only to benchmark comparisons, not exhaustive pre-processing evaluation
- When the data contain no known ground-truth reproducible component, since FDR, power, and pi_1 bias cannot be computed without true pi_1

## Inputs

- Simulated bivariate Normal metabolomics datasets: M=2860 metabolites split into reproducible and irreproducible components per pi_1
- Simulation grid parameters: mu_R in {3.89, 4.01, 4.13}, rho_R in {0.45, 0.99}, pi_1 in {0.2, 0.4, 0.75, 0.9}, with mu_IR=3.2, sigma_R=0.17, sigma_IR=0.05
- Nominal significance level (0.05) and number of Monte Carlo replicates (1000)
- Sourced MaRR functions from 'src/source_MaRR.R'

## Outputs

- Per-setting aggregated simulation results saved as .Rdata objects (e.g., B1_sim_results.Rdata, C1_sim_results.Rdata, D4_sim_results.Rdata) generated by the SIM_*.R scripts
- Empirical FDR, discriminative power (1-NDR), and pi_1 bias for each of the 24 settings
- Simulation summary plots generated by the SIMPLOT_A45.R, SIMPLOT_A99.R, and SIMPLOT_B.R scripts

## How to apply

In R (>=4.0), first source the MaRR functions from 'src/source_MaRR.R'. For each of the 24 Simulation I settings — mu_R in {3.89, 4.01, 4.13} crossed with rho_R in {0.45, 0.99} and pi_1 in {0.2, 0.4, 0.75, 0.9}, with mu_IR=3.2, sigma_R=0.17, sigma_IR=0.05 fixed — simulate 1000 datasets of M=2860 metabolites split into reproducible and irreproducible components according to pi_1, under bivariate Normal settings mimicking the COPDGene MS-Metabolomics data. Apply the nonparametric MaRR maximal rank statistic to each simulated dataset to estimate the reproducibility signal proportion. At the nominal 0.05 significance level, aggregate over the 1000 replicates the empirical FDR, the discriminative power (proportion of true reproducible features detected, i.e., 1-NDR), and the bias (estimated minus true reproducible proportion) for each setting. Rationale: the bivariate Normal grid with gradual reduction in correlation between replicate pairs for less highly ranked signals mirrors realistic MS-Metabolomics structure, so empirical FDR/power/bias directly probe whether the nonparametric procedure maintains type-I error control and accurate pi_1 estimation without parametric assumptions.

## Related tools

- **marr** (Nonparametric Maximum Rank Reproducibility procedure whose maximal rank statistic is applied to each simulated dataset to estimate the reproducibility signal proportion and whose FDR control is being evaluated) — http://bioconductor.org/packages/marr
- **R** (Implementation environment (>=4.0) for running the SIM_*.R simulation scripts and saving .Rdata result objects) — github.com/Ghoshlab/marr_paper_evaluations
- **xtable** (R package used by the repository's table scripts to generate LaTeX code for simulation/evaluation tables)

## Examples

```
Rscript SIM_B1.R  # generates B1_sim_results.Rdata after sourcing src/source_MaRR.R
```

## Evaluation signals

- Across all 24 Simulation I settings, the empirical FDR is at or below the nominal 0.05 level
- Discriminative power (1-NDR) is near 100% for most settings, except at the smallest pi_1 values (e.g., 0.2)
- Bias of the estimated reproducible signal proportion lies within the narrow range (-0.05, 0.05) for every setting
- Running each SIM_B1.R, SIM_C1.R, ..., SIM_D4.R script reproduces the corresponding B1_sim_results.Rdata, C1_sim_results.Rdata, ..., D4_sim_results.Rdata objects
- Each setting aggregates results over exactly 1000 Monte Carlo replicates of M=2860 metabolites

## Limitations

- MaRR power drops for smaller values of the proportion of reproducible metabolites (pi_1), so FDR control does not imply high power at low signal proportions
- True signals may fall in undetectable regions due to overlap between the reproducible and irreproducible components (lack of separation), which the paper attributes to component overlap
- Simulation results are specific to the BioTech-like bivariate Normal settings; performance under other dependence structures is not established by this skill

## Evidence

- [abstract] MaRR effectively controls the False Discovery Rate under realistic MS-Metabolomics settings with gradual reduction in correlation between replicate pairs for less highly ranked signals: "the MaRR procedure effectively controls the False Discovery Rate (FDR) when there was a gradual reduction in correlation between replicate pairs for less highly ranked signals"
- [methods] Simulation scripts generate the .Rdata result objects used for the Monte Carlo FDR evaluation: "The scripts 'SIM_B1.R',.. , 'SIM_C1.R',..., 'SIM_D4.R' can generate the corresponding R objects 'B1_sim_results.Rdata',..,'C1_sim_results.Rdata',...,'D4_sim_results.Rdata'"
- [readme] MaRR functions must be sourced before running the simulations: "The MaRR functions ('source_MaRR.R') can be sourced from the folder 'src'"
- [abstract] MaRR tends to have high power for detecting reproducible metabolites in most situations except for smaller values of the proportion of reproducible metabolites: "the MaRR procedure tends to have high power for detecting reproducible metabolites in most situations except for smaller values of proportion of reproducible metabolites"
