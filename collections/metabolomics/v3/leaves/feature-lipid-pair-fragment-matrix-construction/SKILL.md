# Feature-lipid pair fragment matrix construction

## Summary

Builds a binary presence/absence fragment matrix for every feature-lipid candidate pair by matching experimental MS/MS fragment m/z values from .ms2 files against the candidate's in silico fragment m/z values, filtering by user-defined ppm, intensity, and scan-count thresholds.

## When to use

Use when you have feature-lipid candidate pairs from MS1 exact-mass matching and corresponding .ms2 spectra (converted from ddMS2-topN or AIF raw files), and need to decide which in silico fragments were observed for each pair so downstream rule-based lipid identification can proceed.

## When NOT to use

- When the input is raw vendor mass-spectrometry files that have not yet been peak-picked and converted to .ms2 format by MSConvert
- When only precursor-level MS1 information is available with no tandem MS scans, since fragment matching is impossible
- When working with Waters vendor files, which LipidMatch does not currently support

## Inputs

- Feature-lipid candidate pairs from MS1 exact-mass matching
- .ms2 files generated by MSConvert from ddMS2-topN or AIF UHPLC-HRMS/MS data
- In silico fragmentation libraries (.csv) for the candidate lipid species

## Outputs

- Per-lipid-class .csv tables containing fragment scan count, average m/z, maximum intensity, RT at maximum intensity, and a binary 0/1 presence flag for each feature-lipid pair
- Feature tables annotated with candidate lipid identifications

## How to apply

Take the feature-lipid candidate pairs produced by the MS1 exact-mass matching stage together with the .ms2 files and select MS/MS scans falling within the user-defined retention-time and m/z tolerance of each feature, where the m/z tolerance equals the isolation window used for ion selection. Match each experimental fragment m/z against the candidate's in silico fragment m/z within a ppm tolerance window. For every matched fragment compute the total number of scans containing it, its average m/z, its maximum intensity, and the retention time at maximum intensity across all scans. Assign each fragment a 1 if it exceeds the user-defined minimum intensity AND the minimum scan-count threshold (default 1 scan for orbitrap data) and a 0 otherwise; fragments absent or outside the ppm window get 0. Finally, write the resulting statistics (scan count, average m/z, max intensity, RT at max intensity, binary flag) as a .csv table, one per lipid class, so that later steps can require necessary fragments for identification and rank lipids by summed fragment intensity.

## Related tools

- **LipidMatch** (Executes the fragment matching, thresholding, and matrix construction for each feature-lipid pair using its in silico libraries) — https://github.com/GarrettLab-UF/LipidMatch
- **R** (Implementation language; LipidMatch is an R-based tool whose scripts perform the .ms2 parsing, ppm matching, and CSV writing) — http://secim.ufl.edu/secim-tools/
- **MSConvert** (Converts vendor peak-picked MS/MS data to the .ms2 format that LipidMatch reads for fragment extraction)

## Evaluation signals

- Every fragment binary flag equals 1 only when the fragment was found within the ppm tolerance AND met both the intensity and scan-count thresholds, and 0 when it was absent or failed either criterion
- A separate .csv table is written for each lipid class, confirming the output structure matches the per-class organization
- The reported m/z tolerance for MS/MS scan selection equals the isolation window used for ion selection
- Fragment counts align with LipidMatch's coverage of over 250,000 lipid species across 56 lipid types, so the number of in silico fragments per class is consistent with the library size
- Lipids are only flagged as identified when they contain the necessary observed fragments, showing the matrix feeds the downstream rule-based confirmation step

## Limitations

- Depends on external peak-picking software (MZmine, XCMS, MS-DIAL, or other) and MSConvert to generate .ms2 files; it cannot work directly on raw vendor files
- Only validated and tested on Q-Exactive orbitrap UHPLC-HRMS/MS data and Agilent, Bruker, and SCIEX Q-TOF instruments; Waters files are not supported
- Users must develop their own fragmentation libraries in Excel for full customization; the default libraries are not exhaustive for all lipid classes
- Only tested on Windows 7 through 10 and pinned to R version 3.3.3, which may pose compatibility issues on newer platforms
- Key artifacts (software zip, supplemental figures/tables, annotation workbook) are only provided as additional files, not archived in a public repository
