# rdkit-substructure-matching

## Summary

Use RDKit's GetSubstructMatch to confirm that a candidate analog pair shares a substructure relationship, enabling identification of the single structural modification linking a known compound to an unknown analog.

## When to use

Use when assembling structurally related compound pairs (e.g., from MS/MS libraries) where the heavier compound must contain the lighter compound as a substructure and exactly one bond links the matched and unmatched atoms.

## When NOT to use

- The two compounds differ by more than one structural modification (edge count > 1), so the pair is not a valid single-modification analog.
- No substructure match exists between the compounds, meaning they are not analogs sharing a common substructure.
- The pair fails upstream eligibility filters (e.g., precursor mass ≥ 2000 Da or mass difference ≥ 50%), making substructure verification moot.

## Inputs

- SMILES strings for the known (lighter) compound and the candidate analog (heavier) compound
- Precursor mass and adduct annotation for each compound from the reference MS/MS library entries

## Outputs

- RDKit Mol objects for both compounds
- Substructure match atom-index mapping from GetSubstructMatch
- Count of edges between matched and unmatched atoms (modification-site count)
- Boolean/label indicating whether the pair qualifies as a single-modification analog

## How to apply

Convert both SMILES strings of a candidate analog pair into RDKit Mol objects, then call GetSubstructMatch with the smaller compound as the query against the heavier compound. Count the edges (bonds) between atoms inside the matched substructure set and atoms outside it; this count equals the number of modification sites. Discard any pair whose edge count is not exactly one, since a valid analog pair must differ by a single structural modification. Applying this after precursor-mass and adduct eligibility filters (precursor mass < 2000 Da, mass difference < 50%, same M+H adduct) yields the 12,909-pair benchmark used to evaluate ModiFinder.

## Examples

```
from rdkit import Chem; known = Chem.MolFromSmiles(smiles_known); analog = Chem.MolFromSmiles(smiles_analog); match = analog.GetSubstructMatch(known); edges = sum(1 for b in analog.GetBonds() if (b.GetBeginAtomIdx() in match) != (b.GetEndAtomIdx() in match))
```

## Evaluation signals

- The number of edges between the matched substructure and the remainder of the heavier compound must equal exactly 1 for a pair to be retained.
- The substructure match must succeed (GetSubstructMatch returns a non-empty atom mapping) for the pair to be considered a valid analog.
- When applied across the four reference MS/MS libraries with the mass/adduct filters, the retained pair count should reproduce the reported benchmark of 12,909 analog pairs.

## Limitations

- The method assumes the smaller compound is a strict substructure of the heavier compound; cases where the modification rearranges the shared substructure rather than replacing it will not be detected.
- Only single-modification pairs are retained; pairs with zero or multiple bonds connecting matched and unmatched atoms are discarded, which may exclude real analogs with more complex relationships.
- The approach is applied after precursor-mass and adduct filters, so its correctness depends on those upstream constraints being applied correctly.
