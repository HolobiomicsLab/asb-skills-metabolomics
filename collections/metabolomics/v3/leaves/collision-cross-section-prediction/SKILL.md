# collision-cross-section-prediction

## Summary

Predict collision cross section (CCS) values for small molecules and their adducts ([M+H]+, [M+Na]+, [M-H]-) using the SigmaCCS graph neural network, which consumes RDKit-generated 3D conformers converted into node/adjacency/edge feature matrices, and benchmark the predictions against experimental (CCSbase, TestData.csv) or in-silico (ISiCLE/PNNL) references.

## When to use

Use when you need per-adduct CCS values for molecules given as SMILES (e.g. to annotate LC-MS/MS ion-mobility features), or to verify/benchmark CCS predictions against experimental CCSbase data or the ISiCLE/PNNL calculated database.

## When NOT to use

- Molecules containing elements outside C, H, O, N, P, S, F, Cl, Br, I, Co, As, Se — SigmaCCS cannot predict them
- Adducts other than [M+H]+, [M+Na]+, [M-H]- — SigmaCCS encodes only these three ion types
- Molecules whose 3D conformer cannot be generated by ETKDG or minimized by MMFF94 (e.g. 33/94,161,896 PubChem entries, 5/5,645 CCSbase entries, and 662 molecules with unminimizable conformers)

## Inputs

- SMILES strings with adduct type labels ([M+H]+, [M+Na]+, [M-H]-), e.g. TestData.csv (559 molecules with experimental CCS values)
- TrainData.csv (SigmaCCS training set from CCSbase experimental values)
- PNNL CCS database (ISiCLE v0.1.0), 825,702 entries keyed by compound identifier and adduct type
- Pretrained SigmaCCS model files: model.h5 and parameter.pkl

## Outputs

- Per-molecule, per-adduct predicted CCS values (e.g. TestData-pred.csv)
- evaluation_metrics.csv with R2 and median relative error comparisons (SigmaCCS vs DeepCCS)
- correlation_summary.csv with per-adduct Pearson correlation coefficients against ISiCLE reference values
- Graph dataset: node feature matrix, adjacency matrix, edge feature matrix per molecule

## How to apply

Convert each SMILES to a 3D conformer with RDKit ETKDGv3 (numConfs=1, randomSeed=-1, maxAttempts=1, useRandomCoords=True) and optimize it with AllChem.MMFFOptimizeMoleculeConfs(numThreads=0), since CCS depends on 3D structure that one-hot SMILES encodings (as used by DeepCCS) lack. Build molecular graphs with SigmaCCS convertToGraph to obtain the node feature matrix, adjacency matrix, and edge feature matrix via MyDataset, saving relevant parameters (adduct set, atoms set, coordinate min/max) via parameter.py. Run SigmaCCS Model_prediction with the pretrained model.h5 and parameter.pkl (Isevaluate flag as needed) to obtain predicted CCS values for each of the three encoded adduct types. For benchmarking, join predictions to experimental CCS values in TestData.csv (559 molecules) or to the 825,702-entry PNNL/ISiCLE v0.1.0 reference per adduct, then compute R2, median relative error, and per-adduct Pearson correlations. Accept the reproduction when metrics match reported values within tolerance, e.g. Pearson r of 0.9572 ([M+H]+), 0.9586 ([M+Na]+), 0.9546 ([M-H]-) within ±0.005, and R2=0.9945 / median RE=1.1751% on the test set.

## Related tools

- **SigmaCCS** (GNN-based CCS prediction model: convertToGraph builds molecular graphs, Model_prediction runs inference with model.h5/parameter.pkl) — https://github.com/zmzhang/SigmaCCS

## Evaluation signals

- SigmaCCS test-set metrics reproduce R2 = 0.9945 and median relative error = 1.1751% against experimental CCS in TestData.csv
- Per-adduct Pearson correlations against 825,702 ISiCLE/PNNL values match 0.9572 ([M+H]+), 0.9586 ([M+Na]+), 0.9546 ([M-H]-) within ±0.005 in correlation_summary.csv
- DeepCCS baseline on its 514 predictable molecules reproduces R2 = 0.9794 and median RE = 2.403% (Supplementary Table 6)
- TestData-pred.csv contains 559 SigmaCCS predictions, one per test molecule, with valid adduct labels
- Each molecule yields exactly one 3D conformer from RDKit ETKDGv3 and passes MMFF optimization; failed conformers are logged and excluded

## Limitations

- SigmaCCS cannot predict molecules containing elements other than C, H, O, N, P, S, F, Cl, Br, I, Co, As, and Se
- Only three adduct ion types are encoded; encoding more adduct types is noted as a future improvement
- ETKDG conformer generation failed for 33/94,161,896 PubChem molecules and 5/5,645 CCSbase entries; 662 conformers could not be minimized by MMFF94
- ISiCLE-based verification requires complex computational steps with high demand on computational resources
- DeepCCS baseline fails on SMILES strings longer than 250 characters or containing unknown chemical symbols
