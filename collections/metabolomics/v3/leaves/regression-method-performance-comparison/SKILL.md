# regression-method-performance-comparison

## Summary

Benchmark linear versus nonlinear machine learning-based regression methods by using pseudoQC-simulated QC sample data to correct and normalize real metabolomics and proteomics feature intensity tables, then compare correction/normalization performance metrics per method and dataset.

## When to use

Use when simulated or pooled QC samples must be applied for signal correction and normalization of a metabolomics or proteomics dataset, and the goal is to decide whether a nonlinear regressor outperforms linear ones.

## When NOT to use

- Input is already normalized or already QC-corrected intensity data — pseudoQC's simulated QC samples are meant for correction and normalization of raw/un-normalized feature tables
- The task requires generating actual measured QC samples rather than simulated ones — pseudoQC simulates QC sample data by regression rather than replacing laboratory QC injections
- The dataset is neither metabolomics nor proteomics feature intensity data, the scope validated in the paper's two published benchmark datasets

## Inputs

- Published metabolomics feature intensity table (matrix of features x samples)
- Published proteomics feature intensity table (matrix of features x samples)
- Simulated QC sample data generated by pseudoQC via four machine learning-based regression methods
- pseudoQC.Supplementary.pdf operating procedure from https://github.com/qade544/pseudoQC/blob/master/pseudoQC.Supplementary.pdf

## Outputs

- correction_normalization_comparison.csv with per-method, per-dataset correction/normalization performance metrics (e.g. residual signal drift, relative standard deviation of QC/internal-standard features)
- Comparison table showing whether nonlinear regression methods outperform linear ones for each dataset

## How to apply

Load the published metabolomics and proteomics feature intensity tables into the R-based pseudoQC environment following the operating procedure in pseudoQC.Supplementary.pdf. Simulate QC sample data for each dataset with the four machine learning-based regression methods implemented in pseudoQC (two linear and two nonlinear regressors). Use each set of simulated QC samples to perform signal correction and normalization of the corresponding real dataset, then compute performance metrics such as residual signal drift and relative standard deviation of QC/internal-standard features for each method-dataset pair. Compare metrics across methods; the expected result, per the paper, is that nonlinear regression methods perform better than linear ones, and per-method, per-dataset metrics are written to correction_normalization_comparison.csv.

## Related tools

- **pseudoQC** (Interactive web-based software used to simulate QC sample data with four machine learning-based regression methods and to apply them for correction and normalization of the metabolomics and proteomics datasets) — https://github.com/qade544/pseudoQC
- **R** (Language in which pseudoQC is developed and run for the regression, correction, and normalization analysis) — https://www.r-project.org/

## Evaluation signals

- correction_normalization_comparison.csv contains one performance metric row per regression method (4 methods) per dataset (metabolomics and proteomics)
- Nonlinear regression methods show better correction/normalization metrics (lower residual signal drift, lower relative standard deviation of QC/internal-standard features) than linear methods, reproducing the paper's reported result
- Each simulated QC set originates from one of pseudoQC's four machine learning-based regression methods (two linear, two nonlinear)
- Correction and normalization is performed with the same simulated QC data that was simulated from the corresponding real dataset, not cross-applied between datasets
- Metrics are computed on both published datasets so the linear-vs-nonlinear conclusion is checked for consistency across omics types

## Limitations

- The four machine learning-based regression methods are not individually named in the extracted article text, only as two linear and two nonlinear regressors
- Validated only on two published datasets (one metabolomics, one proteomics); performance on other data types or highly different acquisition protocols is untested in the paper
- The software is web-based (https://www.omicsolution.org/wukong/pseudoQC/); no CLI invocation is documented, so programmatic batch benchmarking requires reproducing the R workflow manually
- QC data are simulated by regression rather than acquired experimentally, so the correction quality depends on how well the regression models represent true QC behavior
