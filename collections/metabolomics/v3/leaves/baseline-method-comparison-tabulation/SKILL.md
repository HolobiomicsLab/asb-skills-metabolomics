# baseline-method-comparison-tabulation

## Summary

Tabulate the performance of a learned reconstruction (e.g. MEISTER deep-learning decoding) against established spectral baselines (raw Fourier transform, zero-padded FT, linear subspace) on a simulated MSI ground truth, using matched peak-centroid extraction and Pearson peak/spatial correlation scores.

## When to use

Use when a new signal-reconstruction or dimensionality-reduction method for mass spectrometry imaging must be benchmarked against standard FT, zero-padded FT, or linear-subspace baselines on data with known ground truth.

## When NOT to use

- If the data lack a known ground truth or a noise-free reference, peak and spatial correlations against ground truth cannot be computed — use a real-data evaluation with other metrics instead.
- If the goal is annotating or identifying metabolites rather than comparing reconstruction quality across spectral methods.
- If the comparison targets spatial registration or classification performance rather than spectral reconstruction fidelity.

## Inputs

- Simulated MSI dataset with known spectral ground truth (30 chemical formulas, H+/Na+/K+ adducts, isotopic distributions via Python BRAIN algorithm; 26,497 pixels × 262,144 temporal points)
- Noisy full-length transients from the ground truth
- Noisy reduced-length transients (e.g. 10,000 temporal points, ~5% of the original) serving as input to each reconstruction method
- Peak centroid list derived from ground-truth spectra

## Outputs

- Per-method peak-correlation and spatial-correlation score table (e.g. simulated_reconstruction_comparison.csv) mirroring Extended Data Fig. 2c,d
- Transformed mass spectra for each compared method (ground truth, noisy reference, standard FT, zero-padded FT, linear subspace, learned reconstruction)
- SNR metrics quantifying gain of the learned reconstruction over the noisy reference

## How to apply

Build a simulated MSI dataset with known spectral ground truth (in the paper: 30 chemical formulas with H+/Na+/K+ adducts and isotopic distributions generated by the Python BRAIN algorithm, 26,497 pixels × 262,144 temporal points), then generate a noisy reduced-length transient set (e.g. 10,000-point transients, ~5% of the original). Produce spectra from every candidate method — clean ground-truth transients, noisy full transients, noisy reduced transients by standard FT with zero-padding, linear-subspace reconstruction, and the learned reconstruction (MEISTER) — using the MEISTER_simulation.ipynb notebook from the multiscale_analysis repository. Extract peak intensity lists at peak centroids identified from the ground-truth spectra so every method is scored on the same features, then compute Pearson correlation of each method's peak list and ion images against the ground-truth pairs. Assemble per-method peak-correlation and spatial-correlation scores into a single comparison table (e.g. simulated_reconstruction_comparison.csv) mirroring Extended Data Fig. 2c,d. The paper's acceptance bar: the learned reconstruction should approach ground-truth-level fidelity — it reported >10 dB SNR gain over the noisy reference while consuming only 5% of the transient data — which is the signal the comparison must reproduce to count as applied correctly.

## Evaluation signals

- The comparison table contains one row per evaluated method (ground truth, noisy reference, standard FT, linear subspace, MEISTER) with both peak-correlation and spatial-correlation columns.
- MEISTER's peak/spatial Pearson correlations should approach the ground-truth values, matching Extended Data Fig. 2c,d qualitatively.
- Reconstruction should show >10 dB SNR gain over the noisy reference when using only ~5% of the transient data.
- Peak lists are extracted at the same centroid m/z positions derived from the ground-truth spectra for all methods, ensuring a matched-feature comparison.
- The output table is saved as a single CSV (e.g. simulated_reconstruction_comparison.csv) with scores computed as Pearson correlation coefficients.

## Limitations

- The comparison is only as valid as the simulated ground truth: simulated adducts and isotopic patterns may not capture all real-instrument noise and matrix effects.
- Evaluation metrics (peak and spatial Pearson correlation) require a known ground-truth reference, so the method cannot be directly applied to experimental data without synthetic truth.
- The paper notes reconstruction evaluation on experimental data used n = 69,847 pixels and n = 574 ion images, so the exact figure counts differ from the simulated setting.
