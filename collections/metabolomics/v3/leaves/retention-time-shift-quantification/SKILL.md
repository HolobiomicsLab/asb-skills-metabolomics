# retention time shift quantification

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

A Rapid QC-MS metric that tracks in-run retention time (RT) drift of internal standards, reference specimens, and external standards across a chromatographic run to spot gradual RT drifts over hours to years and acute deviations in individual acquisitions.

## When to use

Use when a sequence of LC-MS/MS acquisitions must be monitored for RT drift, e.g. to confirm each specimen's RT against IS/RS/ES m/z-RT windows written live by the Python Watchdog watcher.

## When NOT to use

- The input is already a processed feature table or MS-DIAL export without raw files - Rapid QC-MS is intended to monitor raw vendor data (converted to mzML) during acquisition
- Data are not LC-MS/MS vendor files (e.g. MS-only, non-chromatographic spectra)
- Analysis is on MacOS only - Rapid QC-MS was designed to run on Windows because of MSConvert and MS-DIAL dependencies; MacOS users can only monitor/view run data

## Inputs

- Vendor .raw acquisition files (Thermo RAW tested) from an LC-MS/MS sequence
- Sequence definition .csv
- Biological-standard library .msp (IS/RS/ES analytes with expected m/z and RT)
- mzML files generated by MSConvert from .raw

## Outputs

- Interactive Plotly Dash dashboard panels showing internal standard retention time, _m/z_, and intensity across samples
- Real-time Slack or email alerts on QC fails (RT/intensity deviation)
- QC metrics computed within minutes after each new data file is written

## How to apply

Start Rapid QC-MS (Python 3.8–3.11, `rapidqcms`) and define the analysis sequence in the .csv file plus an .msp library of IS, RS, and ES analytes. Vendor .raw files are converted by MSConvert 3.0.23332-7faa7f422 into mzML, then processed by MS-DIAL ver.4.9.22121823 so that internal standard retention time, _m/z_, and intensity are extracted per file. The RT of each annotated IS/RS/ES feature is plotted and compared to expected RT windows; minutes after a new file is written the browser-viewable dashboard updates, so users can distinguish acute deviations in a single specimen from gradual drifts across hours, days, months, or years. When a newly acquired file's RT or intensity fails the specified QC requirements, a Slack or email notification is emitted; IS, RS, and ES metrics are evaluated together rather than as separate channels.

## Related tools

- **Rapid QC-MS** (main application that watches the data folder and reports internal standard RT, m/z, and intensity drift) — https://github.com/czbiohub-sf/Rapid-QC-MS
- **MSConvert** (converts raw vendor .raw files into open mzML format before routing to the data processing pipeline) — https://proteowizard.sourceforge.io/tools/msconvert.html
- **MS-DIAL** (data processing and identification of IS/RS/ES peaks so RT and m/z can be extracted per file) — http://prime.psc.riken.jp/compms/msdial/main.html
- **MSConvert 3.0.23332-7faa7f422** (exact version used in the article for raw→mzML conversion)

## Examples

```
py -m pip install rapid-qc-ms && rapidqcms
```

## Evaluation signals

- rs_vs_msp_comparison.csv exists and contains one row per aligned RS-to-library feature match including RT shift fields (from the RS-vs-.msp benchmarking card)
- Minutes after a new data file is written, the browser-viewable dashboard updates with retention-time results
- Slack/email notification is fired whenever a newly acquired raw file does not meet specified RT requirements
- IS, RS, and ES RT metrics are all evaluated together in the dashboard rather than only IS
- Interactive visualizations show RT drift over hours, days, months, or years rather than a single-point metric

## Limitations

- Tested extensively only on Thermo Fisher mass spectrometers, Thermo acquisition sequences, and Thermo RAW files - other vendors may have bugs in RT computation
- Requires Python 3.8–3.11; installation on MS instrument computers is discouraged without a virtual environment for security
- MSConvert and MS-DIAL must be installed manually; no automatic RT threshold tuning is described - users must specify requirements themselves
