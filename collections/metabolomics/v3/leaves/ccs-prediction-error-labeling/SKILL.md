# ccs-prediction-error-labeling

## Summary

Labels each Mol2CCS/GraphCCS CCS prediction with a binary error class (relative error within or beyond 5%) so that a downstream random-forest confidence model can score prediction reliability and filter out outlier predictions in structurally novel chemical space.

## When to use

Use when you have per-molecule CCS predictions paired with true experimental CCS values (METLIN-CCS, CCSBase) and need binary error labels to train a confidence model or to evaluate filtered vs unfiltered MAE/MRE.

## When NOT to use

- When you only have predicted CCS values with no paired true experimental CCS values (e.g. pure in-silico screening sets like the 282-million SigmaCCS database) — no ground truth exists to compute the relative error and assign labels.
- When the analysis goal is ranking molecules by absolute CCS error magnitude for regression, not a binary reliability label — a direct regression error metric is more appropriate than thresholding at 5%.
- When CCS predictions are already accompanied by calibrated confidence scores or Monte Carlo dropout outputs that directly indicate reliability, making the error-derived label redundant.

## Inputs

- CSV/Excel/parquet table of Mol2CCS (or SigmaCCS/GraphCCS) CCS predictions with columns: smiles, adduct, predicted CCS, true experimental CCS
- METLIN-CCS and CCSBase (v1.3) experimental CCS reference values for the same molecules
- Model prediction output files generated by scripts/train-test.py (e.g. train-metlin-test-ccsbase.out)

## Outputs

- Per-molecule binary error-label column (1 = relative error within 5%, 0 = otherwise) appended to the prediction table
- Per-regime (train-METLIN-test-METLIN, train-CCSBase-test-CCSBase, cross-dataset) labeled prediction sets ready for random-forest confidence-model training
- Filtered vs unfiltered MAE and MRE comparison tables per regime

## How to apply

For each prediction, load the Mol2CCS output table containing SMILES, adduct, predicted CCS, and true CCS columns, then compute the absolute relative error between predicted and true CCS for every molecule. Label each prediction as positive when the absolute relative error is within 5% of the true CCS value and negative otherwise, per the paper's confidence-model design. These binary labels, together with the model's prediction features, become the training input for a random forest classifier (scikit-learn) whose probability threshold is later swept for precision-recall trade-offs. Once the confidence model filters out low-confidence predictions, recompute MAE and MRE on the retained subset for each training regime (train-METLIN-test-METLIN, train-CCSBase-test-CCSBase, cross-dataset) and compare filtered vs unfiltered errors to reproduce the improvement pattern in Fig. 5 and Supplementary Figs. 9-13. Rationale: the paper found that filtering Mol2CCS predictions by a confidence model decreased MAE and MRE as in-domain sample size increased, showing the labeling scheme successfully separates outlier predictions from reliable ones.

## Related tools

- **Mol2CCS** (Source of the CCS predictions whose absolute relative error against true values is thresholded at 5% to generate the binary reliability label) — https://github.com/enveda/ccs-prediction

## Examples

```
python -c "import pandas as pd; df = pd.read_csv('train-metlin-test-ccsbase.out'); df['error_label'] = ((df['pred_ccs'] - df['true_ccs']).abs() / df['true_ccs'] <= 0.05).astype(int)"
```

## Evaluation signals

- Each labeled row must have a non-negative absolute relative error value and a binary label derived strictly from the 5% threshold — spot-check a handful of predictions manually.
- Across all three training regimes, the fraction of positively labeled (within-5%) predictions should roughly match the accuracy of the unfiltered model reported in the paper's Supplementary Figs. 9-13.
- After filtering with the confidence model at a chosen threshold, MAE and MRE on the retained subset must be lower than the corresponding unfiltered values for each regime.
- The improvement in MAE/MRE after filtering should increase as the in-domain sample size grows, matching the trend reported in Fig. 5.
- The labeled dataset must be split consistently with the paper's data_splits (notebooks/data_processing/2_data_splits.ipynb) so that no test-set molecules leak into the confidence-model training.

## Limitations

- Evaluation is restricted in scope mainly to small molecules and specific regions of chemical space (e.g. METLIN-CCS is based on synthetic structures), so the 5% labeling threshold may not transfer to other compound classes.
- Variations in experimental conditions such as instrument types likely introduced inaccuracies in the CCS values used to train models, adding noise to the error labels themselves.
- The number of high-quality experimental CCS references is only in the low thousands, limiting the size and diversity of the labeled training set for the confidence model.
- The 5% error cutoff is a single operating choice; performance sensitivity to other thresholds is not characterized in the provided context.
