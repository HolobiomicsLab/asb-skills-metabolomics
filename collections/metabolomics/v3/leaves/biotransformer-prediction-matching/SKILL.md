# biotransformer-prediction-matching

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Matches LC-HRMS-detected drug-metabolite features against BioTransformer 3.0 in silico predictions within a ±5 ppm mass tolerance, labeling each detected postincubation feature as 'predicted' or 'unpredicted' (novel). This curation step underpins PharmMet DB's quantification of novel metabolites across 1114 therapeutic drugs.

## When to use

Use when curating LC-HRMS-detected postincubation (24-hour) drug metabolite features from human liver S9 incubations against BioTransformer 3.0 predicted metabolites to label each as predicted or unpredicted (novel).

## When NOT to use

- Features have already been labeled predicted/unpredicted (e.g. loaded from the deposited PharmMet DB curation output) — rerunning matching would duplicate work
- Input is raw vendor LC-HRMS data rather than an MZmine 2.53-derived feature table; feature detection (0-hour vs 24-hour MS1/RT comparison) must happen first
- The analysis targets metabolites from enzymes not abundant in liver S9 or from extrahepatic compartments — the article notes PharmMet DB is expected to lack these

## Inputs

- Detected metabolite feature table: paired m/z and RT values per drug from 24-hour (postincubation) human liver S9 LC-HRMS runs, from MZmine 2.53 feature detection comparing 0-hour vs 24-hour MS1 data
- BioTransformer 3.0 predicted metabolite list (predicted m/z values) for the same parent drugs

## Outputs

- Per-drug annotated feature table with columns m/z, RT, predicted/unpredicted label, and matched BioTransformer entry (if any)
- Per-drug counts of predicted vs unpredicted features; aggregate statistics such as the fraction of drugs with ≥1 novel (unpredicted) metabolite and the overall detection rate (59,869 of 130,464 predicted metabolites = 45.89%)

## How to apply

Load the detected feature table (paired m/z and RT values per parent drug, from 24-hour S9 incubation LC-HRMS runs on the Thermo Scientific Orbitrap ID-X) and the corresponding BioTransformer 3.0 predicted-metabolite list for the same parent drug. For each detected feature, compute the mass difference between the observed m/z and each predicted metabolite's m/z, retaining matches within ±5 ppm — the mass-accuracy criterion applied by the authors. If a match exists, label the feature 'predicted' and record the matched BioTransformer entry; otherwise label it 'unpredicted', since novel metabolites are reported by paired m/z and RT. Apply this per drug across the 1114 therapeutic drugs (drug lists drawn from DrugBank 5.0 and the Microsource Spectrum Collection). Assemble per-drug tables with m/z, RT, predicted/unpredicted label, and matched prediction, then summarize counts (e.g. in R 4.0.3) to compute the fraction of drugs producing at least one unpredicted metabolite — reported as 89% in the article.

## Related tools

- **BioTransformer 3.0** (Source of in silico predicted metabolites that detected signals are cross-referenced against within ±5 ppm; also the baseline for computing novel-metabolite rates (89% of drugs had ≥1 unpredicted metabolite))
- **MZmine 2.53** (Produces the detected feature table (m/z/RT pairs) that serves as the input to the matching step, via ADAP chromatogram builder processing of the Orbitrap ID-X raw files)
- **R 4.0.3** (Used for summarizing per-drug predicted/unpredicted counts and downstream statistics and visualization)

## Examples

```
Rscript match_features.R --features s9_24h_features.csv --predictions biotransformer_predictions.csv --tolerance-ppm 5 --output predicted_labels.csv
```

## Evaluation signals

- Every detected feature row carries a non-empty 'predicted' or 'unpredicted' label
- All matched features satisfy the stated ±5 ppm mass-accuracy criterion between observed m/z and predicted metabolite m/z
- Matching is done only against the BioTransformer prediction set for the same parent drug (not across drugs)
- Aggregate detection rate over all 1114 drugs should be consistent with the article's totals: 130,464 predicted metabolites, 59,869 detected (45.89%)
- Novel-metabolite rate (fraction of drugs with ≥1 unpredicted metabolite) should be ~89% when the full 1114-drug set is processed

## Limitations

- The ±5 ppm matching relies on m/z only (plus RT recording) — matched signals may require structural confirmation; the article notes novel metabolites from ~1000 drugs would require considerable isolation and structural elucidation research
- Some detected metabolites may be missed due to limited cofactor availability or ionization suppression in the S9 incubation system
- The liver S9 fraction does not contain all drug-metabolizing activities, so some experimentally formed metabolites lack BioTransformer-predicted analogues, and predictions may include metabolites not formed in this system
- Only signals detected postincubation (24-hour) relative to 0-hour are candidates; features present in both timepoints are not metabolite candidates
