# lipid-precursor-list-export

## Summary

Exports lipid spectral library entries from the Lipid Spectrum Generator as a .CSV file, yielding either an Excalibur-compatible precursor list for DDA analysis on the Orbitrap or a Skyline-compatible transition list.

## When to use

Use when a generated lipid/precursor library from Lipid Spectrum Generator must be handed to data-dependent acquisition instrumentation (Excalibur/Orbitrap) or to Skyline as a .CSV precursor or transition list.

## When NOT to use

- The goal is to export an in silico spectral library itself for lipid identification — in that case export with the '.MSP' file extension selected instead.
- The instrument acquisition workflow is not DDA on an Orbitrap and no Skyline transition list is needed — the Excalibur-compatible precursor list convention does not apply.

## Inputs

- Generated lipid/precursor library output from a Lipid Spectrum Generator run (lipids generated by class and fatty acid composition, spectra by adduct)
- User selection of entries intended for DDA precursor targeting or Skyline transitions

## Outputs

- precursor_list.csv — a comma-separated (.CSV) Excalibur-compatible precursor list for DDA analysis via Orbitrap
- Alternatively, a Skyline-compatible transition list exported with the same '.CSV' selection

## How to apply

After running the Lipid Spectrum Generator — which generates lipids by class and fatty acid composition and spectra by adduct — select the entries intended for data-dependent acquisition (DDA) precursor targeting. Invoke the tool's export mechanism and choose the '.CSV' file extension rather than '.MSP': selecting '.CSV' produces an Excalibur-compatible precursor list (for DDA analysis via Orbitrap) or a Skyline-compatible transition list, whereas '.MSP' is used only for exporting spectral libraries themselves. Write the exported table to precursor_list.csv with the comma-separated precursor entry layout implied by the Excalibur precursor-list convention. The fragmentation patterns underlying the source library are based on peer-reviewed studies, so exported precursor masses trace back to those curated patterns.
