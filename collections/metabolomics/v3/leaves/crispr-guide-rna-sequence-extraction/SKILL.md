# crispr-guide-rna-sequence-extraction

## Summary

Extracts the crRNA/sgRNA sequences, edit definitions, repair-template homology overlaps, and genotyping restriction-site changes used to engineer the seven top-3 and rmh-2 alleles (top-3-ZnF, top-3::ha, top-3-ZnF::ha, top-3-ZnF4CtoA(jf219), rmh-2(jf168), rmh-2::flag, rmh-2::mCherry) via CRISPR/Cas9.

## When to use

Use when parsing the 'Gene Editing Using The CRISPR/Cas9 System' section of a Nucleic Acids Research paper to recover exact guide-RNA 5'-…-3' sequences, codon-level edit definitions, and repair-template overlap lengths for reconstructing allele designs.

## When NOT to use

- The article describes allele engineering but not via CRISPR/Cas9 (e.g. classical mutagenesis, transposon insertion) — use a different extraction workflow
- The target section only lists guide sequences without accompanying edit definitions or overlap lengths; this skill requires all four record fields (guide, edit, overlap, genotyping site) to be non-empty

## Inputs

- Article text of the Materials And Methods > Gene Editing Using The CRISPR/Cas9 System section
- Source task card specifying which of the seven alleles (top-3, rmh-2 family) to reconstruct

## Outputs

- allele_engineering_records.json — one entry per allele with guide-RNA sequence, edit definition, overlap length, and genotyping restriction site
- Per-allele crRNA/sgRNA 5'-…-3' sequences (e.g. 5'-AAAAGAACAGGAAGAGGAAGAGG-3')
- Repair-template homology overlap lengths (35 bp, 90 bp, ~30 bp)

## How to apply

Locate the allele-construction paragraphs in the Materials And Methods > Gene Editing Using The CRISPR/Cas9 System section and transcribe each guide exactly as written (e.g. top-3-ZnF sgRNA 5'-AAAAGAACAGGAAGAGGAAGAGG-3'; rmh-2(jf168) uses separate 5' and 3' crRNAs; rmh-2::mCherry uses sgRNA I and sgRNA II). For each allele record the edit definition: a premature stop codon at amino acid 715 (5'-TTC-3' to 5'-TAA-3') for top-3-ZnF, deletion of the rmh-2 locus for jf168, an internal HA tag inserted between codons Gly 635 and Gly 636 for top-3::ha, four cysteine-to-alanine substitutions C716A/C718A/C743A/C753A for jf219, a 3xFLAG-plus-linker insertion before the stop codon for rmh-2::flag, and mCherry insertion at the rmh-2 locus. Capture each repair-template homology overlap length (35 bp for top-3 alleles, 90 bp for rmh-2 jf168, ~30 bp for jf219, defined left/right homology regions for rmh-2::mCherry) and the silent restriction-site change used for genotyping (HpaII CCGG->CCAG for top-3-ZnF; a KasI site generated by the C718A mutation for jf219). The rationale is that these design parameters — guide sequence, overlap length, and silent marker — together define a reproducible allele record that supports genotype verification (PCR-digestion) and rescue experiments described later in the paper.


## Evaluation signals

- The JSON contains exactly seven allele entries, one for each engineered top-3/rmh-2 allele
- Each allele entry has non-empty guide-RNA, edit-definition, overlap-length, and genotyping-restriction-site fields
- HpaII (CCGG->CCAG) is assigned to top-3-ZnF and KasI (generated by C718A) is assigned to top-3-ZnF4CtoA(jf219)
- The top-3-ZnF edit records the codon change 5'-TTC-3' to 5'-TAA-3' at amino acid 715
- Overlap lengths match the article: 35 bp (top-3 alleles), 90 bp (rmh-2 jf168), ~30 bp (jf219)

## Limitations

- Guide sequences, overlap lengths, and restriction-site changes are transcribed verbatim from the article; any OCR or transcription error propagates into the JSON records
- For rmh-2(jf168) and rmh-2::mCherry the article lists two separate guide RNAs (5'/3' crRNAs, sgRNA I/II) — a single-guide record would be incomplete
- The skill does not validate guide specificity or off-target risk; it only records the published design parameters
- rmh-2(mCherry) left/right homology regions are 'defined' in the article but the exact base-pair coordinates may require the repair-template map referenced in supplementary material
