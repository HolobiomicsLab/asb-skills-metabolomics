# modified-platt-score-re-ranking

## Summary

Re-ranks candidate molecular structures generated de novo (or retrieved from a database) by scoring the match between each candidate's structural fingerprint and the query fingerprint predicted from the MS2 spectrum, using the modified Platt score as used by CSI:FingerID.

## When to use

Use when a set of validated, dereplicated candidate SMILES structures exists for an MS2 query spectrum and the raw generator ranking (e.g. RNN sequence probability) must be replaced or refined by a fingerprint-match score to obtain a top-1 identification.

## When NOT to use

- When candidates are already ranked by a full database-search pipeline (e.g. CSI:FingerID database search) that already applies this score — re-ranking adds no information
- When no query fingerprint xF is available (e.g. spectra with fewer than three fragment ions that SIRIUS/CSI:FingerID cannot process) — the score is undefined
- When the goal is to evaluate the raw generator without fingerprint guidance (the naïve/RNN-only ablation), where this step is deliberately skipped

## Inputs

- k validated and dereplicated candidate SMILES structures per query MS2 spectrum
- Query structural fingerprint xF predicted by CSI:FingerID from the MS2 spectrum
- Molecular formula constraint from SIRIUS (defines the candidate space)

## Outputs

- Ranked candidate list per query with modified Platt score (score_mod_platt) and top-1 candidate (rank_score_lim_mod_platt == 1)
- Decoded result table (e.g. decode-RUNID.csv / .pkl) with per-candidate scores

## How to apply

For each query MS2 spectrum, take the k validated and dereplicated candidate SMILES structures (e.g. generated by the MSNovelist encoder–decoder RNN under the SIRIUS-predicted molecular formula constraint). Predict the query structural fingerprint xF from the spectrum with CSI:FingerID, compute each candidate's structural fingerprint, and calculate the modified Platt score — the fingerprint-match statistic used by CSI:FingerID — between xF and the candidate fingerprint. Sort candidates by modified Platt score in descending order (in the MSNovelist result table, `score_mod_platt`) so the top candidate corresponds to `rank_score_lim_mod_platt == 1`; the README explicitly instructs ordering by this column to obtain the top hit. The re-ranking is important for best results: the ablation without it dropped GNPS top-1 from 25% to 19%, and the naïve generator with only modified Platt re-ranking reached 17% top-1, showing the score is necessary but not sufficient without fingerprint-guided generation.

## Related tools

- **MSNovelist** (Provides the generated candidate structures and computes `score_mod_platt` / `rank_score_lim_mod_platt` columns for ranking; exposed via Docker/Singularity container and `predict.sh`) — https://github.com/meowcat/MSNovelist
- **CSI:FingerID** (Predicts the query structural fingerprint xF from the MS2 spectrum; the modified Platt score is the CSI:FingerID fingerprint-match statistic applied to candidates)
- **SIRIUS** (Predicts the molecular formula xM that constrains which candidate structures are generated and dereplicated before re-ranking)

## Examples

```
docker run -v $(pwd):/msnovelist-data msnovelist predict.sh 377.mgf;  # then sort results: sort -t, -k<score_mod_platt_col> -nr decode-RUNID.csv
```

## Evaluation signals

- Top-1 rate should improve over raw RNN probability ranking: 25% on GNPS (45% overall retrieval) versus 19% without re-ranking; on GNPS-OK the re-ranked model recovers 35% top-1 versus 39% raw
- In the MSNovelist result table, the top candidate must be the row with `rank_score_lim_mod_platt == 1` when sorted by `score_mod_platt` descending
- Best incorrect candidates after re-ranking should show median modified Platt score around −5,886 (de novo) versus −5,910 for RNN-only ranking
- Re-ranked best incorrect structures should have median Tanimoto similarity ~0.80 to the true structure on GNPS, versus ~0.74 for RNN-only ranking

## Limitations

- Re-ranking alone is insufficient: without fingerprint-guided generation the modified Platt score only recovers 31% of correct structures (17% top-1) on GNPS
- The score depends on fingerprint prediction quality, which degrades for compounds with high m/z where formula determination error rates exceed 50% for individual spectra up to m/z 800
- Requires at least three fragment ions per MS2 spectrum; poorer spectra yield weaker fingerprints and less reliable re-ranking
