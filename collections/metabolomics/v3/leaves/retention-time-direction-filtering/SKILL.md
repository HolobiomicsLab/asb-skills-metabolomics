# retention-time-direction-filtering

## Summary

A patRoon 2.0 prioritization filter for transformation product (TP) components that verifies the expected relative retention time direction of each parent/TP pair based on chemical polarities, so that chemically implausible parent–TP orderings are flagged or removed after componentization.

## When to use

Use when TP components have been generated by patRoon componentization (parents linked to TP features) from LC-HRMS data in mixed positive/negative ionization, and you must prioritize which parent/TP pairs are chemically plausible by chromatographic retention-time direction.

## When NOT to use

- TP components have not yet been formed — the filter operates after parent and TP features are grouped into components, not on raw feature lists
- The chromatographic setup or polarity relationships are such that no retention-time direction expectation exists for a parent/TP pair (filter cannot verify direction)
- The goal is TP structure prediction or suspect screening rather than prioritization of already-formed TP components

## Inputs

- TP components generated by the patRoon 2.0 componentization step (parent features linked with TP features)
- LC-HRMS data with retention-time information, processed in mixed positive/negative ionization modes (e.g. patRoonData standard-X and solvent-X)
- Chemical polarity information for parents and candidate TPs (from formula/compound annotations or in-silico TP structures)

## Outputs

- Prioritized TP component table with a per-component RT direction filter verdict
- Exported CSV (e.g. tp_components_prioritized.csv) with one row per TP component and columns recording each of the five filter verdicts

## How to apply

Load the TP components produced by the patRoon 2.0 componentization step (where each parent feature is linked with corresponding TP features and grouped in a TP component) on data such as the patRoonData example set (standard-X vs solvent-X, positive and negative ionization). Run the prioritization routine in R with the RT direction filter enabled; the filter checks, per parent/TP pair, whether the observed relative retention-time direction matches the expectation derived from the chemical polarities of the parent and TP (e.g. a more polar TP should elute earlier on reverse-phase LC). The filter verdict is recorded per component so it can be combined with the other Table 2 filters — structure similarity, explained transformation, remove isomers, and duplicates — to yield a prioritized TP component table. Export the resulting table with per-filter verdicts (e.g. to tp_components_prioritized.csv) for downstream curation.

## Evaluation signals

- Output file exists and contains a row per TP component (file_exists check)
- Columns recording each of the five filter verdicts (including RT direction) are present in the exported table (field_present check)
- The prioritization script runs without error on the patRoonData example data (script_runs check)
- Parent/TP pairs whose observed retention-time direction contradicts the polarity-based expectation are flagged or removed by the filter
- Components surviving the RT direction filter are consistent with the polarity rules applied (e.g. more polar TP elutes earlier under reverse-phase LC)

## Limitations

- The filter relies on a polarity-based expectation of relative retention time; parents/TPs where no direction is expected cannot be verified
- Isomeric TPs can be difficult or impossible to distinguish with MS, so additional filters (remove isomers, duplicates, structure similarity, explained transformation) are needed alongside RT direction
- Filter operates on components from the patRoon 2.0 workflow; results depend on upstream feature grouping and TP suspect screening quality
