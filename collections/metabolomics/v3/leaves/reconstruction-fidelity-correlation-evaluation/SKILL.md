# reconstruction-fidelity-correlation-evaluation

## Summary

Benchmark protocol for validating MEISTER (or any deep-learning) MSI transient reconstruction fidelity by transforming clean ground-truth, noisy reference, and reconstructed transients into mass spectra and scoring peak and spatial fidelity via Pearson correlations against ground-truth ion images.

## When to use

Use when a deep-learning or subspace reconstruction of FT-ICR MSI transients must be quantitatively compared to standard FT or linear-subspace baselines on simulated data with known ground truth, via peak and spatial correlation scores.

## When NOT to use

- If the dataset lacks a known clean ground-truth transient set — Pearson correlations against ground-truth ion images cannot be computed, as in purely experimental MSI data (use MEISTER_eval.ipynb-style evaluation instead)
- If the input is already processed spectra or a peak table rather than raw/reconstructed transients — the transient-to-spectrum transformation step is not applicable
- For evaluating single-cell MS (SCMS) reconstructions, where the separate MEISTER_singlecell.ipynb workflow with test data of n = 69,847 pixels and n = 574 ion images applies

## Inputs

- Simulated MSI dataset: 30 chemical formulas with H+/Na+/K+ adducts and isotopic distributions via the Python BRAIN algorithm, 26,497 pixels × 262,144 temporal points
- Clean ground-truth transients and noisy reference transients
- Noisy reduced 10,000-point transients (5% of data) as reconstruction input
- MEISTER-reconstructed transients (from MEISTER_simulation.ipynb)
- Standard FT / zero-padding reconstructed spectra and linear-subspace reconstructed spectra (baselines)
- Peak centroids identified from ground-truth spectra

## Outputs

- Mass spectra from each transient set (ground truth, noisy reference, standard FT, linear subspace, MEISTER)
- Peak intensity lists at ground-truth peak centroids per method
- Peak correlation and spatial correlation scores (Pearson correlation coefficients) per method
- Comparison table mirroring Extended Data Fig. 2c,d, saved as simulated_reconstruction_comparison.csv

## How to apply

Load the simulated MSI dataset (30 chemical formulas with H+/Na+/K+ adducts, isotopic distributions generated by the Python BRAIN algorithm, 26,497 pixels × 262,144 temporal points) and reconstruct transients with MEISTER, using the MEISTER_simulation.ipynb notebook from the multiscale_analysis repository. Transform every transient set—clean ground truth, noisy reference, noisy reduced 10,000-point transients processed by standard FT/zero-padding, linear-subspace reconstruction, and MEISTER reconstruction—into mass spectra. Extract peak intensity lists at peak centroids identified from the ground-truth spectra, then compute peak correlation and spatial correlation scores as Pearson correlation coefficients between each method's peak list and ground-truth ion image pairs. Assemble per-method peak and spatial correlation scores into a comparison table mirroring Extended Data Fig. 2c,d and save it as simulated_reconstruction_comparison.csv. Validation: the MEISTER reconstruction should show near-ground-truth-level fidelity, consistent with the reported >10 dB SNR gain over the noisy reference using only 5% of the transient data.

## Related tools

- **MEISTER** (Deep-learning model whose reconstructed transients are the method-under-test being scored for fidelity against ground truth) — https://github.com/richardxie1119/MEISTER
- **BRAIN algorithm (Python version)** (Generates isotopic distributions for the 30 simulated chemical formulas used to build the ground-truth simulated MSI dataset)
- **MEISTER_simulation.ipynb** (Notebook from the multiscale_analysis repository that executes the simulated-data reconstruction, spectrum transformation, peak extraction, and correlation-scoring pipeline) — https://github.com/richardxie1119/multiscale_analysis

## Evaluation signals

- MEISTER-reconstructed spectra show near-ground-truth-level fidelity — SNR gain of more than 10 dB over the noisy reference using only 5% of the transient data
- MEISTER outperforms both standard FT reconstruction and linear-subspace baselines on simulated data: higher SNR over standard FT due to denoising from the learned low-dimensional representation
- Peak correlation and spatial correlation (Pearson) scores for MEISTER match or exceed baseline scores in the comparison table, mirroring Extended Data Fig. 2c,d
- simulated_reconstruction_comparison.csv contains per-method peak and spatial correlation scores for all five transient sets
- Reconstruction achieved with only 10,000-point transients (5% of the full 262,144-point collection time), i.e. <10% collection time per transient

## Limitations

- Requires a simulated dataset with known ground-truth spectra and ion images; experimental data cannot be scored this way directly
- Only ~5% of the transient data is used (10,000 of 262,144 points), so results depend on the fidelity of the simulated isotope/adduct model (BRAIN-generated H+/Na+/K+ adducts) matching real instrument behavior
- The multiscale_analysis README notes documentation is still being expanded ('We are expanding our code documentations to make it friendly'), so notebook-level parameters may need checking against the supplementary protocol
