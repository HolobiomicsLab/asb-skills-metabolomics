# Top-k accuracy evaluation of structure prediction

## Summary

Evaluation skill for the MultiModalSpectralTransformer (MMST) structure-prediction pipeline: candidates generated by multinomial sampling are ranked (e.g. by SGNN-simulated HSQC spectral matching) and scored as top-1 and top-3 accuracy against ground-truth structures.

## When to use

Use when a spectral-to-structure model outputs multiple candidate molecules per compound and you must quantify ranking quality as top-1/top-3 accuracy against known test-set structures.

## When NOT to use

- The pipeline returns a single deterministic prediction with no candidate set, so no ranking exists to evaluate as top-k
- You need experimental performance metrics other than top-k ranking accuracy (e.g. spectral reconstruction error or optimization objectives)
- Ground-truth structures are unavailable for the compounds being predicted, making accuracy computation impossible

## Inputs

- Test-set compounds with ground-truth structures (SMILES) from the data directory (e.g. test_data folder)
- Input HSQC spectra for each test compound
- Pre-trained MMST model checkpoints extracted from Zenodo (models/mmst, models/sgnn, models/mol2mol)
- Candidate SMILES sets generated by multinomial sampling from the MMST output distribution

## Outputs

- Per-compound ranked candidate lists (best candidate first by spectral match score)
- Top-1 and top-3 accuracy summary for the test set
- hsqc_ranking_results.csv with supporting results in the HSQC_results directory

## How to apply

Activate the NMR_Structure_Elucidator conda environment (Python 3.7.12) and load the pre-trained MMST model files extracted from the Zenodo models archive (models.zip / models.tar.xz.part*). For each test-set compound, run the MMST model and draw candidate SMILES via multinomial sampling of the output distribution. For HSQC-based ranking, simulate each candidate's HSQC spectrum with the SGNN network as in the 2.0 NMR data generation notebook, score simulated peaks against the input HSQC, and rank candidates per compound. Compute top-1 and top-3 accuracy over the test set and compare to the reported baselines: 72% top-1 / 80% top-3 for MMST overall, and 83.9% top-1 for the Alberts-trained model with HSQC-spectral ranking. Write per-compound ranked candidate lists and the accuracy summary to hsqc_ranking_results.csv, storing supporting results in the HSQC_results directory.

## Evaluation signals

- Overall MMST top-1 accuracy lands near the reported 72% and top-3 near 80% on the test set
- HSQC-spectral ranking of the Alberts-trained model reproduces the reported 83.9% top-1 accuracy when the correct molecule is present among candidates
- Every test compound has a non-empty, score-sorted candidate list; correct structure's rank is recorded per compound
- hsqc_ranking_results.csv is produced with per-compound rankings and an accuracy summary; supporting files appear in HSQC_results/
- Environment check passes: the notebook runs without ModuleNotFoundError or torch ModuleAttributeError, confirming correct model/data placement

## Limitations

- MMST was trained solely on simulated data, so experimental-spectra performance depends on the simulated-to-experimental transfer; active learning cycles are needed for out-of-distribution chemical spaces
- Requires an NVIDIA GPU with CUDA 11.1 support (e.g. V100 or K80), at least 16GB RAM and 50GB storage; CUDA mismatches cause 'no kernel image is available' errors
- Detailed usage instructions (full improvement cycle workflow and HTML GUI) are deferred to Section 3 of the Electronic Supplementary Information, not the README
- Model loading errors ('torch.nn.modules.module.ModuleAttributeError') occur if model files do not match the expected Zenodo format
