# retention-time-reference-library-construction

## Summary

Constructs a retention-time reference library of chemical standards for HILIC LC-MS metabolomics by evaluating each standard mixture in triplicate with MetaMOPE and recording retention times only for peaks passing Std/Blk intensity ratio, retention-time RSD, and peak-intensity thresholds.

## When to use

Use when building a metabolite reference library from chemical standard injections in LC-MS: replicate mzXML/mzML files of standard mixtures are available and validated retention times per analyte must be extracted and tabulated.

## When NOT to use

- The goal is mobile phase optimization rather than retention-time library building — instead select the mobile phase with the highest peak quality score (sum of detected-peaks score Sp and asymmetry factor score Saf).
- Retention times already exist in a validated reference table and no new standard injections need evaluating.
- Data are not replicate LC/MS runs of chemical standards with matching blank injections, so the Std/Blk ratio and triplicate retention-time RSD cannot be computed.

## Inputs

- mzXML/mzML files of chemical standard mixtures injected in triplicate
- Blank injection intensity data for computing the Std/Blk ratio
- Per-peak metrics generated by MetaMOPE (MCQ, maximum intensity, retention-time RSD, Std/Blk ratio, jaggedness, asymmetry factor, FWHM, modality)
- User-specified thresholds r (Std/Blk ratio), c (retention-time RSD), and I (peak intensity)

## Outputs

- Retention-time reference library table with a validation column and validated retention time per metabolite (e.g., the 571-metabolite HILIC LC-MS reference library)
- Validation flags per metabolite based on the user-specified thresholds

## How to apply

Evaluate each standard mixture three times on the LC/MS method and generate each analyte's extracted ion chromatogram (EIC) from the mzXML/mzML inputs, after IRLS baseline correction and Savitzky-Golay smoothing. For every peak, MetaMOPE computes eight metrics — MCQ, maximum intensity, retention-time RSD, Std/Blk intensity ratio, jaggedness, asymmetry factor, FWHM, and modality. Record a peak only if the Std/Blk intensity ratio exceeds user-specified threshold r, the retention-time RSD across the three replicates is below threshold c, and the peak intensity exceeds threshold I; the validation column marks each metabolite as validated or not against these thresholds. For validated metabolites, take the retention time determined from the EICs of the three replicates and write the reference-library table (validation flag plus validated retention time per metabolite), as was done to construct the 571-metabolite library for the HILIC LC-MS platform.

## Examples

```
git clone git@github.com:CMDM-Lab/MetaHILIC.git && docker-compose up --build  # then use MetaMOPE at http://localhost:13002 to evaluate triplicate standards and emit the retention-time reference library
```

## Evaluation signals

- Every retained peak satisfies all three criteria: Std/Blk intensity ratio > r, retention-time RSD < c, and peak intensity > I
- Each metabolite carries an explicit validation flag consistent with whether it passed the thresholds
- Validated retention times match the retention time determined from the EICs of the three replicate injections
- Output table matches the reported reference-library format (validation column plus retention time), reproducible at the scale of the 571-metabolite HILIC LC-MS library
- EICs were baseline-corrected (IRLS) and smoothed (Savitzky-Golay) before metric computation, consistent with the MetaMOPE workflow

## Limitations

- Validation depends entirely on user-specified thresholds (r, c, I); poorly chosen thresholds will drop valid metabolites or retain poor peaks.
- The workflow requires three replicate injections of each standard mixture plus blank runs to compute Std/Blk ratios.
- No changelog/limitations were discussed in the article's discussion section (none available for extraction).
