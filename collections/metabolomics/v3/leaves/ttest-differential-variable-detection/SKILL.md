# ttest-differential-variable-detection

## Summary

Assess how an imputation method affects statistical sensitivity by comparing t-test-detectable differential variables between complete and imputed data, using TPR = |S ∩ S'| / |S| at p-cut 0.05 and 0.01 across increasing MNAR missingness.

## When to use

Use when evaluating whether a missing value imputation method (e.g., GSimp, QRILC, kNN-TN) preserves the ability to detect differential variables between two groups on MNAR-degraded metabolomics data.

## When NOT to use

- When the goal is imputation accuracy (NRMSE) or distribution preservation rather than downstream statistical power — use the dedicated accuracy/distribution evaluations instead
- When missing values are MCAR/MAR rather than left-censored MNAR — the TPR sensitivity comparison in the paper is designed for MNAR (LOD/LOQ-type) missingness
- When the data has no defined two-group comparison, since S and S' depend on t-tests between group labels

## Inputs

- Complete two-group data matrix (e.g., data_sim.csv, scaled, 80 observations per group)
- Group label factor for the two experimental conditions
- MNAR-degraded data matrices generated by MNAR_gen_imp
- Imputed data matrices from each imputation method wrapper

## Outputs

- TPR values table keyed by imputation method, missing proportion, and p-cutoff (tpr_results.csv)
- TPR vs Miss_Num curves at p_cut=0.05 and p_cut=0.01 comparing GSimp, QRILC, and kNN-TN

## How to apply

Take a complete two-group data matrix (e.g., the scaled data_sim.csv simulation dataset with 80 observations per group) and define the reference set S of variables significant by two-sample t-test in the original data. Generate MNAR-degraded versions with MNAR_gen_imp (mis_var_prop=seq(.1,.8,.1), var_mis_prop=seq(.3,.6,.1), MNAR cut-off drawn from U(0.3,0.6)), impute each with the method wrappers (sim_QRILC_wrapper, sim_GS_wrapper with iters_each=50, iters_all=10, initial='qrilc', lo=-Inf, hi='min', n_cores=2, imp_model='glmnet_pred'; sim_trKNN_wrapper with k=3, distance='truncation', perc=0), and recompute t-tests on the imputed data to obtain S'. Use Ttest_P_cal_plot to compute TPR = |S ∩ S'| / |S| at p_cut=0.05 and p_cut=0.01, plot TPR against Miss_Num, and assemble the results into a table keyed by method, missing proportion, and p-cutoff. The method whose TPR curve stays highest across Miss_Num impairs detection sensitivity the least.

## Evaluation signals

- TPR is bounded in [0, 1] and computed as |S ∩ S'| / |S| against the t-test significant set from the original complete data
- TPR curves should decrease with increasing Miss_Num; a correct run shows GSimp achieving the highest overall TPR at both p_cut=0.05 and p_cut=0.01
- tpr_results.csv must contain one row per (imputation method, missing proportion, p-cutoff) combination covering mis_var_prop=seq(.1,.8,.1) and both p-cutoffs
- Two TPR plots (p_cut=0.05 and p_cut=0.01) are produced with TPR on the y-axis and Miss_Num on the x-axis

## Limitations

- Results depend on the simulation design (N(0, 0.5^2) variable means, covariance from the diabetes dataset with P=76); parameter choices are not fully justified in the discussion
- Reduced Gibbs sampler iterations (iters_all=10, iters_each=50) are used for speed; authors recommend iters_all=20, iters_each=100 for MCMC convergence
- No specific version numbers reported for glmnet or imputeLCMD; QRILC and kNN-TN parameter details are not fully specified outside the wrappers
