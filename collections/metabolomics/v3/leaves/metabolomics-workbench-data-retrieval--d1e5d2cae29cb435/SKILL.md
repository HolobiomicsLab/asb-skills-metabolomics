# metabolomics-workbench-data-retrieval

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Retrieves the deposited LC-HRMS feature tables, raw files, and metabolite annotation results for PharmMet DB from Metabolomics Workbench Study ST003991 (Project DOI 10.21228/M8W55K), providing the raw inputs needed to reproduce per-drug-class metabolite counts and reaction-type breakdowns.

## When to use

Use when an analysis needs the deposited ST003991 feature tables, m/z–RT paired entries, or per-drug metabolite annotations underlying PharmMet DB, e.g. to reproduce class-level or reaction-type counts from 1114 S9-incubated drugs.

## When NOT to use

- When only in silico metabolite predictions are needed and no experimental LC-HRMS features are required — BioTransformer 3.0 predictions can be used directly without the deposited study data
- When the target metabolites were generated in extrahepatic compartments or by enzymes not active in liver S9 — PharmMet DB is expected to lack these

## Inputs

- Metabolomics Workbench Study ID ST003991 (Project DOI 10.21228/M8W55K)
- Deposited LC-HRMS feature tables (m/z, RT, peak area per feature)
- Supplemental Table 1 drug-class mapping of 1114 therapeutic drugs from the PharmMet GitHub repository

## Outputs

- Locally downloaded raw and processed feature-table files for the 0-hour and 24-hour S9 incubations
- Joined data frame mapping each metabolite feature to its parent drug and therapeutic class
- Aggregated tables such as drug_class_metabolite_counts.csv or reaction-type count tables

## How to apply

Locate Study ST003991 on metabolomicsworkbench.org (Project DOI 10.21228/M8W55K) and download both the raw files and the processed feature tables, which contain MS1 accurate m/z, retention time, and peak area for 0-hour preincubation and 24-hour postincubation human liver S9 samples. Supplement the feature tables with the Supplemental Table 1 drug-class mapping (1114 therapeutic drugs) from github.com/ClinicalBiomarkersLaborabory/PharmMet so each detected or unpredicted feature can be joined to its parent drug's therapeutic class. Load the files with R 4.0.3 or pandas, using the sample/plate metadata in the deposited files to associate paired m/z–RT entries with drug incubations. Validate retrieval by confirming the downstream aggregates can reproduce reported values (e.g. 486,215 unpredicted features; 30,752 oxidized and 6311 glucuronidated metabolites).

## Related tools

- **R 4.0.3** (Used to load, join, and aggregate the downloaded ST003991 feature tables against the drug-class mapping)
- **NIH Common Fund’s National Metabolomics Data Repository (Metabolomics Workbench), Study ID ST003991** (Source repository hosting the raw and processed LC-HRMS data files for retrieval) — https://doi.org/10.21228/M8W55K
- **ClinicalBiomarkersLaborabory/PharmMet** (Hosts the published per-drug-class reporting file and Supplemental Table 1 drug-class mapping used alongside the deposited data) — https://github.com/ClinicalBiomarkersLaborabory/PharmMet

## Examples

```
download.file('https://www.metabolomicsworkbench.org/data/StudyID_ST003991', 'st003991.zip'); ft <- read.csv('feature_table.csv')
```

## Evaluation signals

- The retrieved dataset corresponds to Study ID ST003991 under Project DOI 10.21228/M8W55K
- Joining detected metabolites to the drug-class mapping allows reproduction of reported per-class counts (e.g. 13,089 cardiovascular detected of 28,302 predicted)
- Aggregated unpredicted-feature counts per class total 486,215, with anti-inflammatory (126,210), antimicrobial (100,617), cardiovascular (88,653), and CNS (62,693) as the top classes
- Reaction-type tallies from the retrieved annotations match reported values within exact-match tolerance (oxidation 30,752; reduction 7114 of 10,899; glucuronidation 6311)
- The joined table covers all 1114 therapeutic drugs from Supplemental Table 1

## Limitations

- A limitation of the underlying design was reliance upon the liver S9 fraction for biotransformation; not all drug-metabolizing activities are present in this fraction
- The deposited data is expected to lack metabolites formed by enzymes not abundant or active in liver S9, or generated in extrahepatic compartments (eg, intestine, kidney)
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression
