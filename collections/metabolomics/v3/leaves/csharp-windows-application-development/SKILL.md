# csharp-windows-application-development

## Summary

Develops a C#-based Windows Application (EVA) that embeds a trained CNN model to automatically classify extracted ion chromatogram (EIC) plots from LC-MS metabolomics feature tables as good or poor quality without leaving the desktop environment.

## When to use

Reference for embedding a trained deep learning model (e.g. a CNN trained on 25095 annotated EIC plots) into a C# Windows Application that scores vendor LC-MS metabolic features for chromatographic peak quality in metabolomics pipelines.

## When NOT to use

- You need cross-platform (Mac/Linux) execution — EVA is a C# Windows Application; use the Python pyEVA port instead
- Input is raw unprocessed LC-MS data rather than vendor feature tables — the skill scores metabolic features already processed by vendor software

## Inputs

- Serialized/embeddable trained CNN model for EIC quality classification
- Metabolic feature tables (e.g. m/z and retention time columns) exported from various LC-MS systems and data processing software
- Associated raw LC-MS data files (.mzXML or .mzML) from which EIC plots are reconstructed

## Outputs

- Per-feature good/poor EIC quality classification (Boolean predictions for each metabolic feature)
- FinalTable.csv with analysis results and PredictionOutcomes.csv with per-EIC Boolean values
- Reconstructed EIC plots for each scored metabolic feature

## How to apply

Obtain the trained CNN model (from the 25095-EIC training run over 22 LC-MS-based metabolomics projects) and serialize it into a form embeddable in .NET. Build the C# application layer (EVA) that imports metabolic features generated by various LC-MS systems and data processing software, reconstructs EIC plots from the features, and scores each imported EIC as good or poor quality with the embedded model in-app. Validate the embedded-model application against the reported >90% classification accuracy so desktop scoring reproduces offline model performance. Publish the Windows Application so LC-MS metabolomics users can use it freely — EVA is distributed on the Microsoft Store by searching 'EVA Metabolomics'; note that a Python rewrite (pyEVA) also exists for Mac/PC/Linux.

## Related tools

- **EVA** (The C#-based Windows Application that embeds the trained CNN model to score EIC plot quality for metabolic features) — https://github.com/HuanLab/pyEVA
- **pyEVA** (Python reimplementation of EVA offering multi-platform (Mac, PC, Linux) usage of the same EIC fidelity-checking functionality) — https://github.com/HuanLab/pyEVA

## Examples

```
python main.py
```

## Evaluation signals

- Embedded-model scoring on imported EIC plots reproduces the reported >90% classification accuracy reported for EVA
- Every feature in the input table receives a Boolean good/poor prediction (no unclassified features remain)
- PredictionOutcomes.csv row count matches the number of features in the input m/z–rt feature table
- EIC plots reconstructed in-app are visually consistent with the vendor data processing software's chromatograms
- Application installs and runs as a standalone Windows program without an external Python/MATLAB dependency

## Limitations

- EVA is a C# Windows Application — platform-bound to Windows; the Python pyEVA was rewritten to ease multi-platform use on Mac, PC, and Linux
- The C# implementation depends on .NET packaging of the trained model; converting the model between frameworks may degrade fidelity
- EVA is a reimplementation path — the original was published as a Windows Application and later rewritten in Python, so users on non-Windows systems must verify the pyEVA build in their environment
