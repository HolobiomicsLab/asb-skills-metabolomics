# flux-balance-analysis-sampling

## Summary

Samples steady-state flux distributions from genome-scale metabolic network reconstructions (GENREs) built with Reconstructor, so that functional metabolic differences between strains, species, and classes of bacteria can be quantified and ordinated (e.g., via NMDS) rather than inferred from network content alone.

## When to use

Use when you have multiple gap-filled genome-scale metabolic models (SBML GENREs, e.g. Reconstructor outputs) and need to compare their functional metabolic behavior by sampling flux distributions and clustering/ordinating the samples.

## When NOT to use

- Input is a single model with no comparison set — flux sampling plus NMDS is designed for cross-model functional comparison, not single-model analysis
- Models lack gap-filling or use inconsistent naming/media across the set, making sampled flux distributions non-comparable
- Input is raw annotation data (e.g. unannotated .fasta) rather than assembled metabolic models — reconstruct first with Reconstructor

## Inputs

- Gap-filled SBML genome-scale metabolic network reconstructions (GENREs) generated by Reconstructor (file_type 1/2/3 pipeline)
- Draft SBML models loaded into COBRApy for parsimony-based gap-filling
- Media condition specification as ModelSEED-namespace metabolite strings ending in _e (e.g. 'rich' default)
- Annotated amino acid .fasta files per strain (Type 1 input) or DIAMOND BLASTp output (Type 2)

## Outputs

- Sampled steady-state flux distributions for each gap-filled model
- Pairwise dissimilarity matrix among sampled flux profiles
- NMDS ordination of reconstructions (e.g. fig1c_nmds_ordination.png) showing clustering by strain, species, and taxonomic class

## How to apply

Build or obtain draft SBML GENREs with Reconstructor (COBRApy-compatible, KEGG/DIAMOND-annotated, ModelSEED-consistent naming) and apply Reconstructor's parsimony-based gap-filling after loading them in COBRApy. Sample steady-state flux distributions from each gap-filled model via flux balance analysis sampling, keeping the model, media condition (e.g. 'rich'), and Gram classification consistent across models so fluxes are comparable. Compute pairwise dissimilarities among the sampled flux profiles across all models, then fit a nonmetric multidimensional scaling (NMDS) ordination of the reconstructions (e.g., the 20-strain set: 5 strains each of P. aeruginosa, M. tuberculosis, E. coli, and R. rickettsii). The rationale is that sampled fluxes capture functional differences in metabolism that network topology alone does not, enabling validation that reconstructions capture strain-, species-, and class-level metabolic distinctions.

## Related tools

- **Reconstructor** (Builds the COBRApy-compatible SBML GENREs and provides parsimony-based gap-filling whose output models are then flux-sampled) — http://github.com/emmamglass/reconstructor
- **COBRApy** (Loads the draft SBML models, supports gap-filling, and provides the flux balance analysis sampling of steady-state flux distributions)
- **DIAMOND** (Sequence aligner used to obtain KEGG annotations from protein .fasta inputs prior to model building and sampling) — https://github.com/bbuchfink/diamond

## Examples

```
python -m reconstructor --input_file Osplanchnicus.aa.fasta --file_type 1 --gram negative --media rich
```

## Evaluation signals

- NMDS ordination reproduces the published pattern of distinct clustering of samples by strain, species, and higher taxonomic class as reported in Fig. 1C
- Each of the 20 strain reconstructions (5 each of P. aeruginosa, M. tuberculosis, E. coli, R. rickettsii) yields a valid steady-state flux sample
- Pairwise dissimilarity matrix is computed over all sampled flux profiles with consistent media and model namespace across models
- Gap-filled models retain ModelSEED-consistent reaction and metabolite naming conventions before sampling

## Limitations

- Maintenance of the Reconstructor repository has moved to csbl/reconstructor; emmaglass/reconstructor is no longer updated
- Installation test suite (python -m reconstructor --test yes) takes ~1 hour and downloads a DIAMOND database and binary, which may need --skip-diamond in restricted environments
- Documentation was noted as still under development in the source repository
- Draft models may require additional (Type 3) gap-filling 'if necessary' before flux sampling is meaningful
