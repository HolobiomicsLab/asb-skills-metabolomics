# molecular-network-visualization

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Visualize the NP3 MS Workflow filtered spectral similarity molecular network (SSMN) in a graph tool such as Cytoscape so bioactive natural product candidates and their spectral relationships can be inspected interactively.

## When to use

Reference for inspecting the NP3 MS Workflow step-10 filtered SSMN in Cytoscape after clustering, cleaning, IVAMN [M+H]+ selection, and damped pruning have produced the final molecular network.

## When NOT to use

- The workflow has not yet reached step 10 — a raw, unpruned clustering output from steps 3-5 still contains links that step 10 would remove, so visualizing it in Cytoscape would misrepresent the final SSMN.
- The goal is quantitative ranking of bioactive candidates by BCC rather than structural/spectral relationship inspection; the BCC-ranked clean consensus spectra table (e.g. bcc_ranking_table.csv) should be filtered directly instead of opening the network.
- The input is only per-sample MGF files or a Metadata Table; these are preprocessing inputs (steps 1-2) and cannot be visualized as a molecular network until steps 3-10 have run.

## Inputs

- filtered spectral similarity molecular network (SSMN) produced by NP3 MS Workflow step 10
- clean consensus spectra annotation table (e.g. bcc_ranking_table.csv) mapping node m/z values to GNPS library hits and BCC scores
- clean count table from NP3 MS Workflow final reports (used by the ssmn_mount post-process script)

## Outputs

- interactive Cytoscape network session visualizing SSMN nodes and edges
- visualization-based confirmation of spectral cluster membership for candidate ions (e.g. m/z 589.31 isomers or m/z 679.272 TMC-95)
- SSMN-derived reports generated by the src/post_process_analysis/ssmn_mount/ script

## How to apply

After running NP3 MS Workflow steps 2-10 (preprocessing of LC-MS/MS features, clustering/quantification/cleaning with the NP3-shifted cosine function, Tremolo library identification against the UNPD-ISDB, IVAMN deconvolution with PageRank [M+H]+ selection, and construction of the filtered SSMN), load the SSMN into a graph visualization tool such as Cytoscape. The SSMN is filtered during step 10 to remove links below the minimum number of matched peaks, keeping only the K-most similar neighbors of each node, and further constrained by damped pruning to limit the size of each component; these constraints shape what the practitioner should expect to see on screen. Inspect clean consensus spectra nodes together with their annotated identities (e.g. GNPS entries such as CCMSLIB00000840551 or CCMSLIB00000840365) and bioactivity correlation scores (BCC) to confirm that candidate ions like m/z 589.31 or 679.272 fall into coherent spectral clusters. For automated post-processing, NP3 MS Workflow 1.6.0 adds a script under src/post_process_analysis/ssmn_mount/ to build the SSMN in Cytoscape and generate reports from the clean count table, so manual visualization can be complemented or replaced by that programmatic mount.

## Related tools

- **NP3 MS Workflow** (Produces the filtered SSMN (step 10) and provides the post-process ssmn_mount script that automatically builds the network in Cytoscape.) — https://github.com/danielatrivella/NP3_MS_Workflow
- **Cytoscape** (Graph visualization tool used to open and interactively inspect the filtered SSMN produced by NP3 MS Workflow.)
- **GNPS (Global Natural Products Social Molecular Networking)** (Source of spectral library annotations (e.g. CCMSLIB00000840551, CCMSLIB00000840552, CCMSLIB00000840365) that label SSMN nodes for visual identification.)

## Examples

```
cytoscape -i ssmn.graphml  # or open the SSMN produced by NP3 MS Workflow step 10 in the Cytoscape GUI; alternatively run the ssmn_mount post-process script from src/post_process_analysis/ssmn_mount/ after the run command completes
```

## Evaluation signals

- The network opened in Cytoscape must be the step-10 filtered SSMN — links below the minimum matched-peak threshold and non-K-most-similar edges should be absent, and component sizes should reflect damped pruning limits.
- Nodes corresponding to known annotated ions (e.g. m/z 589.31 with GNPS annotations, or m/z 679.272 as TMC-95 with GNPS score 0.75) should appear in the expected spectral clusters.
- The count of distinct isomer nodes within a target cluster must match the count in the source table — e.g. exactly 11 distinct m/z 589.31 isomers for the Euphorbia dendroides data set (MSV000080502).
- If using the automated mount script, the generated reports must be consistent with the clean count table filtering logic implemented in src/post_process_analysis/ssmn_mount/.
- Edge and node ordering in the exported SSMN should match NP3 MS Workflow's reproducibility guarantee: components sorted by size (largest first) and edges sorted by source node ID in numerical ordering.

## Limitations

- Visualization alone does not confirm bioactivity; candidates still need the BCC ranking filter that removes ions appearing in blank or culture media samples before interpretation.
- The SSMN's component sizes are constrained by damped pruning, so visually large clusters are not necessarily complete — pruning intentionally limits network size to keep components manageable.
- NP3 MS Workflow results depend on correct pre-processing parameters; isomer resolution (e.g. all 11 m/z 589.31 isomers) requires parameters mirroring the original GNPS processing for the target m/z, and incorrect parameters will propagate into a misleading network.
- Manual Cytoscape inspection is only one route — versions before 1.6.0 lack the automated ssmn_mount post-process script, so reproducibility of the visualization workflow depends on the pipeline version.
