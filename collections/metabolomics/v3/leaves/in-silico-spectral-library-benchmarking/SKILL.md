# in-silico spectral library benchmarking

## Summary

Benchmark in-silico lipidomics MS/MS libraries (MAVEN2's novel library, MS-DIAL, CalicoLipids) by tabulating library entries and annotated features per lipid class and adduct form, and flagging classes represented in only one library (e.g., OxPC only in MS-DIAL, CE only in CalicoLipids).

## When to use

Use when comparing two or more in-silico lipid fragmentation libraries by enumerating per-class and per-adduct library entry counts and feature annotation counts to reveal coverage gaps such as classes unique to one library.

## When NOT to use

- The input is already a per-class count matrix or single-library summary rather than paired annotation/library-composition tables from multiple libraries
- The analysis targets experimental/empirical MS/MS spectral libraries rather than in-silico lipid fragmentation libraries
- Only one library is available, so cross-library comparison of entries and annotations is impossible

## Inputs

- Thresholded feature annotation table from MAVEN2 library-comparison searches
- Library composition statistics exported from MAVEN2 searches against each in-silico library (MAVEN2 novel library, MS-DIAL, CalicoLipids)
- CalicoLipidLibrary MSP-format library files generated by generateDB.py

## Outputs

- Per-class, per-adduct count matrix of library entries and annotated features
- List of lipid classes represented in only one library (e.g., OxPC only in MS-DIAL, CE only in CalicoLipids)
- dataset_s5_lipid_class_counts.csv

## How to apply

Load the thresholded annotation table and library composition statistics exported from the MAVEN2 library-comparison searches. Group records by lipid class and adduct form (e.g., '[M+H]+', '[M+NH4]+', '[M-H]-', '[M+FA-H]-') and count library entries per class per library — for example, sphingomyelin spectra totaled 14,076 vs 117 across libraries. Separately count annotated features per class (e.g., Ceramide 36,288 vs 39,882 annotations) to capture how entry-count differences propagate into identifications. Build a per-class, per-library count matrix and flag any class present in only one library — in this benchmark, oxidized phosphatidylcholines (OxPCs) appeared only in MS-DIAL while cholesterol esters (CEs) appeared only in CalicoLipids. Write the count matrix and single-library class list to dataset_s5_lipid_class_counts.csv. CalicoLipids libraries can be regenerated for specific classes via the CalicoLipidLibrary generateDB.py script with -c class lists, since enumerating all theoretical spectra over all classes is time-consuming.

## Related tools

- **MAVEN2** (Performs the LC-MS/MS library-comparison searches whose annotation tables and library composition statistics are the inputs to the benchmark) — https://github.com/eugenemel/maven
- **CalicoLipidLibrary** (Generates the in-silico lipid fragmentation spectra (MSP library) for comparison; specific lipid classes can be subset with -c) — https://github.com/calico/CalicoLipidLibrary

## Examples

```
python2.7 generateDB.py -m "pos" -c "PC,PE,PS" -n "pos_glycerophospholipids.msp"
```

## Evaluation signals

- Per-class library entry counts match values in Figure 4 / Dataset S5 of the article (e.g., SM spectra 14,076 vs 117 across libraries)
- Per-class annotated-feature counts match reported values (e.g., Ceramide 36,288 vs 39,882)
- Single-library class assignments reproduce the finding that OxPCs are present only in MS-DIAL and CEs only in CalicoLipids
- Every lipid class/adduct combination in the count matrix has counts in all libraries being compared, with zeros distinguishing single-library classes
- The exported dataset_s5_lipid_class_counts.csv schema contains per-class, per-adduct, per-library entry and feature counts plus the single-library class list

## Limitations

- CalicoLipidLibrary enumeration over all lipid classes can be time-consuming; subsetting via the -c option trades coverage for speed
- CalicoLipidLibrary spectrum generation is Python 2 only, and unsupported class/adduct combinations raise errors rather than producing spectra
- Class coverage gaps between libraries (e.g., OxPC, CE) mean annotation-count differences reflect library composition, not necessarily search-algorithm quality
