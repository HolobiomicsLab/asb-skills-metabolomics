# spectral-cluster-medoid-selection

## Summary

Select representative (medoid) spectra from MS/MS spectral clusters — produced by GLEAMS embedding-based clustering — so that a single spectrum search per cluster (e.g., ANN-SoLo open modification search) can annotate all member spectra at once.

## When to use

Use when you have GLEAMS cluster assignments (GLEAMS_cluster.npy) and medoid indexes (GLEAMS_cluster_medoids.npy) and need to pick one representative spectrum per cluster of previously unidentified spectra for downstream search/annotation.

## When NOT to use

- Input spectra are already individually identified by a database search (e.g., the 185 million PSMs at 1% FDR obtained using MSGF+), so clustering/medoid propagation adds no annotations.
- You have fewer spectra than the minimum cluster size (2) or no precomputed GLEAMS embeddings/clusters — you must first run 'gleams embed' and 'gleams cluster' before medoids exist.
- You need per-spectrum modifications rather than a single representative identification per cluster; medoid propagation assigns one peptide label to all members.

## Inputs

- GLEAMS_cluster.npy — NumPy array of cluster labels per spectrum (-1 = noise, minimum cluster size 2)
- GLEAMS_cluster_medoids.npy — NumPy array of indexes of the cluster representative (medoid) spectra
- GLEAMS_embed.npy — n x 32 NumPy array of spectrum embeddings plus GLEAMS_embed.parquet metadata (produced upstream by gleams embed)
- MS/MS peak files (e.g., mzML) containing the spectra to be clustered and searched

## Outputs

- Set of selected medoid spectra (cluster centroids) for previously unidentified spectra, excluding noise points
- Mapping of medoid PSM identifications to all member spectra, yielding propagated PSMs (~44 million from ~5.3 million medoid identifications in the paper)
- List of precursor mass differences from the open modification search of cluster centroids (top 500 compiled in the supplementary)

## How to apply

Load the cluster labels from GLEAMS_cluster.npy and the medoid indexes from GLEAMS_cluster_medoids.npy; cluster labels of -1 indicate noise points and the minimum cluster size is 2, so exclude noise points when selecting representatives of previously unidentified spectra. Because GLEAMS hierarchical clustering (distance_threshold 0.3 on 32-dimensional embeddings) groups spectra generated by the same peptide, the medoid serves as the cluster representative: run a single search (e.g., ANN-SoLo v0.3.3 against the MassIVE-KB v1 Human HCD spectral library) on each medoid, then propagate the resulting peptide-spectrum match to all member spectra of that cluster via the cluster labels. Filter search results at 1% FDR before propagation so only confident identifications are spread to cluster members.

## Related tools

- **GLEAMS** (Embeds mass spectra into a 32-dimensional space and hierarchically clusters them, producing GLEAMS_cluster.npy labels and GLEAMS_cluster_medoids.npy medoid indexes used for medoid selection) — https://github.com/bittremieux/GLEAMS
- **ANN-SoLo** (Open modification search run on the selected cluster medoid spectra against the MassIVE-KB (v1) Human HCD spectral library, filtered at 1% FDR)
- **Python** (Loads the .npy cluster and medoid files and propagates medoid PSM labels to cluster members)

## Examples

```
gleams cluster --embed_name GLEAMS_embed --cluster_name GLEAMS_cluster --distance_threshold 0.3
```

## Evaluation signals

- GLEAMS_cluster_medoids.npy contains one medoid index per cluster label in GLEAMS_cluster.npy, with no medoids selected for noise points labeled -1
- Medoid counts correspond to clusters of previously unidentified spectra; searching ~45 million medoid spectra should yield ~5.3 million PSMs at 1% FDR
- Propagating medoid PSMs to cluster members yields ~44 million additional PSMs, consistent with cluster membership counts
- Search results are filtered at 1% FDR before propagation, confirming FDR control on the retained peptide-spectrum matches
- Embeddings file has shape n x 32 and matches the number of MS/MS spectra read from the input peak files

## Limitations

- Noise points (cluster label -1) and clusters smaller than the minimum cluster size of 2 have no usable medoid propagation
- GLEAMS requires Python 3.8, a Linux operating system, and a CUDA-enabled GPU
- Propagation assigns the medoid's single peptide identification to all cluster members, so mis-clustered spectra inherit incorrect labels
- Model weights are large Git LFS files; a 'data quota' error may require manually downloading gleams_82c0124b.hdf5 from the release and placing it in data/
