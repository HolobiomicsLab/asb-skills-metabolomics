# peptide-label-propagation-across-clusters

## Summary

Propagate peptide identifications from identified spectra to unassigned spectra within pure GLEAMS embedding clusters, converting cluster co-membership into newly transferred PSMs (~82 million across the 669-million-spectrum MassIVE-KB run).

## When to use

Use when spectra are already embedded (32-dimensional GLEAMS vectors) and clustered (GLEAMS_cluster.npy, minimum cluster size 2), a subset carries peptide identifications such as MSGF+ PSMs at 1% FDR, and the goal is to label unassigned spectra in pure clusters.

## When NOT to use

- Spectra have not yet been embedded and clustered — run gleams embed and gleams cluster first; propagation has no input without cluster labels.
- A cluster's labeled spectra disagree on peptide (impure), or the cluster is noise (-1) or a singleton — propagating there would inject incorrect identifications (threshold 0.35 still yields ~1.16% incorrectly clustered spectra).
- The goal is de novo identification of unclustered spectra rather than transferring existing PSM labels within clusters.

## Inputs

- GLEAMS_cluster.npy — NumPy array of cluster labels per embedding (-1 indicates noise, minimum cluster size 2)
- GLEAMS_embed.npy — n x 32 NumPy array of GLEAMS embeddings
- GLEAMS_embed.parquet — metadata for embedded spectra (filename, scan, precursor mass) used for precursor-mass postprocessing and joining identifications
- Peptide identifications (PSMs) for a subset of spectra, e.g. MSGF+ results at 1% FDR from MassIVE mzTab files
- MassIVE-KB metadata TSV listing the peak files and scan numbers for all 669 million spectra

## Outputs

- Peptide annotations transferred to previously unassigned spectra in pure clusters
- Count of newly propagated PSMs (~82 million at full MassIVE-KB scale)

## How to apply

Run `gleams cluster` on the 32-dimensional GLEAMS embeddings with hierarchical average linkage at Euclidean distance threshold 0.35 (the README example uses 0.3; the 669M-spectrum MassIVE-KB reproduction used 0.35) to obtain GLEAMS_cluster.npy, where -1 denotes noise and the minimum cluster size is 2. Postprocess clusters by precursor mass, splitting any cluster whose members have inconsistent precursor masses. For each remaining cluster, test label purity: if every spectrum holding an MSGF+ PSM (1% FDR) maps to the same peptide, propagate that peptide to all unassigned spectra in the cluster; skip mixed clusters and noise (-1). Count the newly propagated PSMs — approximately 82 million when applied to the full 669-million-spectrum MassIVE-KB set. The rationale is that GLEAMS places spectra generated by the same peptide close together in the 32-dimensional embedding space, so agreement among labeled members within a cluster makes the transferred annotation reliable.

## Related tools

- **GLEAMS** (Produces the 32-dimensional embeddings (gleams embed) and hierarchical cluster labels (gleams cluster, GLEAMS_cluster.npy) over which peptide labels are propagated) — https://github.com/bittremieux/GLEAMS
- **MSGF+** (Supplies the reference peptide identifications (185 million PSMs at 1% FDR) that seed label propagation in pure clusters)

## Examples

```
gleams cluster --embed_name GLEAMS_embed --cluster_name GLEAMS_cluster --distance_threshold 0.35
```

## Evaluation signals

- Clustered fraction ≈ 76% (511 million of 669 million spectra) using distance_threshold 0.35 before propagation.
- Incorrectly clustered fraction ≈ 1.16% and completeness ≈ 0.837, matching the reported full-dataset reproduction.
- ~82 million newly propagated PSMs counted over the full MassIVE-KB spectrum set.
- No peptide propagated from clusters whose precursor masses are inconsistent — precursor-mass postprocessing must split those clusters first.
- Cluster label array contains -1 entries for noise and no clusters below the minimum size of 2.

## Limitations

- GLEAMS requires Python 3.8, a Linux operating system, and a CUDA-enabled GPU.
- Git LFS bandwidth limits can block the model weights download; work around by cloning with GIT_LFS_SKIP_SMUDGE=1 and manually downloading gleams_82c0124b.hdf5 from the v0.3 release into the data/ directory.
- Only pure clusters can be labeled; spectra in mixed clusters or noise (-1) remain unannotated, and the distance threshold trades completeness against the ~1.16% incorrect-clustering rate.
