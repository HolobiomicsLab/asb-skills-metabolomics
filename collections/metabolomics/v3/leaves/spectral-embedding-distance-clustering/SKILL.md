# spectral-embedding-distance-clustering

## Summary

Clusters large sets of MS/MS spectra by first converting peak files to 32-dimensional learned embeddings (GLEAMS) and then performing hierarchical clustering under an embedding distance threshold, grouping spectra generated by the same peptide.

## When to use

Use when millions of unlabeled MS/MS spectra (e.g. mzML or MGF peak files) must be grouped into peptide-level clusters without per-spectrum identification, as in spectral library or MassIVE-KB-scale analyses.

## When NOT to use

- Spectra already carry trusted peptide identifications (PSMs) — direct ID-based grouping, not embedding-based clustering, is appropriate
- The input is a small spectrum set where exhaustive pairwise identification-based comparison is feasible and the learned embedding offers no efficiency gain
- No CUDA-enabled GPU (and Linux/Python 3.8 environment) is available, since GLEAMS requires a CUDA-enabled GPU to embed spectra

## Inputs

- MS/MS spectra in peak files (mzML; test-set folds exported as MGF in the benchmark)
- Pre-trained GLEAMS model weights (HDF5, e.g. gleams_82c0124b.hdf5)
- Optional: metadata TSV with filename and scan columns for MassIVE-KB spectra retrieval

## Outputs

- GLEAMS_embed.npy: n x 32 two-dimensional NumPy array of embeddings
- GLEAMS_embed.parquet: tabular metadata for the embedded spectra
- GLEAMS_cluster.npy: cluster labels per embedding (-1 indicates noise)
- GLEAMS_cluster_medoids.npy: indexes of cluster representative spectra (medoids)

## How to apply

Run `gleams embed` to convert MS/MS spectra in peak files (mzML) into an n x 32 NumPy embedding array plus a metadata parquet file; embeddings place spectra from the same peptide close together in the learned space. Then run `gleams cluster` to perform hierarchical clustering on the embeddings, supplying the distance threshold (0.3 in the paper's usage) and marking clusters smaller than the minimum size as noise. The clustering step writes cluster labels per embedding to a .npy file (-1 = noise, minimum cluster size 2) and a medoids file with indexes of cluster representative spectra. Full neural-network and clustering configuration can be adjusted in `gleams/config.py`. Model weights (e.g. gleams_82c0124b.hdf5 trained on 30 million MassIVE-KB PSMs) must be present in the `data/` directory of the cloned repository.

- **GLEAMS** (Provides `gleams embed` to produce 32-dimensional spectrum embeddings and `gleams cluster` to hierarchically cluster them under a distance threshold) — https://github.com/bittremieux/GLEAMS

## Examples

```
gleams embed *.mzML --embed_name GLEAMS_embed && gleams cluster --embed_name GLEAMS_embed --cluster_name GLEAMS_cluster --distance_threshold 0.3
```

## Evaluation signals

- GLEAMS_cluster.npy contains one integer label per embedded spectrum, with -1 reserved for spectra in clusters below the minimum size (2)
- GLEAMS_embed.npy has shape n x 32, where n equals the number of MS/MS spectra read from the peak files, and is accompanied by a parquet file with matching metadata
- Cluster labels assigned at distance_threshold 0.3 reproduce the paper's cluster-quality metrics — fraction clustered, fraction incorrectly clustered (spectra grouped with different-peptide spectra), and cluster completeness — relative to MassIVE-KB peptide ground truth
- GLEAMS_cluster_medoids.npy indexes point to valid spectra within each labeled cluster
- On the 84M-spectrum test set (three ~28M-spectrum folds), per-tool metrics should be aggregated into the results table and compared against the reported GLEAMS vs. falcon, MaRaCluster, MS-Cluster, spectra-cluster comparison

## Limitations

- Requires Python 3.8, a Linux operating system, and a CUDA-enabled GPU
- Git LFS bandwidth limits can block installation of the model weights; work around by cloning with GIT_LFS_SKIP_SMUDGE=1 and manually downloading the weights from the release
- Minimum cluster size is fixed at 2; clusters below the minimum size are labeled as noise (-1)
- The distance threshold (e.g. 0.3) must be swept per the tool's stated parameter grid; an inappropriate threshold changes clustered vs. noise fractions
