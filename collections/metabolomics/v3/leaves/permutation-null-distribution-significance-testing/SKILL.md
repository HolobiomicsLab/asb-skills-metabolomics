# permutation-null-distribution-significance-testing

## Summary

Assigns statistical significance (p-values) to SIMILE spectral alignments by generating a null distribution from permuted intra- and inter-spectral fragment similarity scores, rather than relying on raw similarity scores alone. This addresses the paper's point that without statistical significance, intermediate similarity scores are uninterpretable.

## When to use

Use when pairwise MS/MS spectral alignments (e.g. from SIMILE max-weight matching) need p-value-based significance calls so candidate compound pairs can be ranked and compared against cosine-based scoring.

## When NOT to use

- When spectra are expected to differ by adducts other than protonation/deprotonation — SIMILE is currently limited to protonation/deprotonation analysis
- As a standalone identification tool: the authors recommend complementing SIMILE significance testing with well-established cosine-based scoring for compound identification
- When only raw spectral similarity magnitude is needed and no ranking by statistical significance is required

## Inputs

- Fragmentation similarity matrix S from sml.similarity_matrix (row-normalized mass-difference frequencies converted to pseudo-inverse of the normalized Laplacian)
- Max-weight matching matrix M from sml.multiple_match
- Pro/con symmetry comparison matrix C from sml.sym_compare
- spec_ids spectral identifier mapping returned with S

## Outputs

- spec_scores: significance scores for all combinations of spectra
- pval: p-values per interspectral alignment
- null_dist: permutation-based null distribution of fragment similarity scores (returned when return_dist=True)

## How to apply

After building the pair-specific fragmentation similarity matrix S via sml.similarity_matrix(mzs, pmzs=pmzs, tolerance=tolerance) and computing the max-weight matching M = sml.multiple_match(S, spec_ids) plus the pro/con symmetry matrix C = sml.sym_compare(M, spec_ids), call sml.z_test(S, M, C, spec_ids, return_dist=True, log_size=5). The null distribution is generated by permuting intra and inter spectral fragment similarity scores — exploiting that sibling fragment ions are more similar to each other than to parents or children — to yield p-values for every interspectral alignment. Setting return_dist=True returns the null_dist so it can be inspected or reused. Use the resulting p-values to rank candidate alignments, complementing (not replacing) cosine-based scoring for compound identification.

## Related tools

- **SIMILE** (Python library whose sml.z_test function performs the permutation-based significance testing of max-weight matchings) — https://github.com/biorack/simile
- **numpy** (Python dependency for the numerical arrays underlying the similarity matrix and null distribution)
- **scipy** (Python dependency for statistical functions used in z-testing)

## Examples

```
import simile as sml; spec_scores, pval, null_dist = sml.z_test(S, M, C, spec_ids, return_dist=True, log_size=5)
```

## Evaluation signals

- The call must return three objects (spec_scores, pval, null_dist) when return_dist=True, matching the documented signature
- p-values enable ranking of candidate alignments — verify that significant alignment scores correspond to moderate-to-high compound structural similarity as the paper reports
- Significant SIMILE alignments should yield 'different and typically more associations than cosine-based scoring algorithms' when compared side by side
- The null_dist length should reflect the permutation size controlled by log_size=5 as documented
- log_size parameter must be set to 5 per the documented usage example

## Limitations

- Significant SIMILE alignment of fragmentation spectra does not necessitate compound structure similarity
- Without statistical significance, intermediate similarity scores are to some degree uninterpretable for prioritizing metabolites
- Parameters used to compare alignment algorithms were not optimized; further optimization entails trade-offs such as improving specificity vs. number of hits
- Since this is the first application of scoring metabolite-fragmentation spectra using a similarity matrix, close attention must be applied; some molecule classes may be more appropriate for cosine-based scoring
