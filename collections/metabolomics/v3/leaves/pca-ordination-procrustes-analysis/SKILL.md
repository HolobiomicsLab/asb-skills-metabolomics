# pca-ordination-procrustes-analysis

## Summary

Evaluates whether an imputed metabolomics matrix preserves the original sample/observation distribution by ordinating both matrices with PCA (2 PCs via vegan) and computing the Procrustes sum of squared errors between the two ordinations, as used in the GSimp imputation benchmark.

## When to use

Use when comparing imputed vs original data matrices to quantify distortion of the observation/sample distribution, e.g., benchmarking MNAR imputation methods (GSimp, QRILC, kNN-TN) across graded missingness levels.

## When NOT to use

- When the goal is per-element imputation accuracy (e.g., NRMSE) rather than preservation of the multivariate observation distribution
- When the reference matrix itself contains missing values and no complete original ordination can be computed
- When data are MCAR/MAR with no left-censoring context — this evaluation was designed for MNAR (LOD/LOQ) targeted metabolomics imputation benchmarks

## Inputs

- Complete (fully observed) data matrix, e.g., data_sim.csv (160 samples x 76 variables) or its scaled version
- Imputed data matrices produced per method and per MNAR degradation level (MNAR_gen_imp with mis_var_prop=seq(.1,.8,.1), cut-offs from U(0.3,0.6))

## Outputs

- Procrustes sum of squared errors (SSE) table (pro_ss_df) per imputation method and missing-variable proportion
- Plot of Procrustes SSE versus number of missing variables, one series per imputation method with specified colors (#7CAE00, #00BFC4, #C77CFF) and shapes (17, 15, 3)

## How to apply

Load the complete reference matrix (e.g., data_sim.csv, 160 samples x 76 variables, or its scaled version) and each imputed counterpart. Ordinate both matrices by PCA restricted to 2 PCs using vegan. Then run vegan's Procrustes analysis (via Procrustes_cal_plot with DR='PCA', nPCs=2) between the original and imputed ordinations to obtain the sum of squared errors (SSE), which quantifies how far the imputed sample configuration has drifted from the original. Repeat per imputation method and per missing-variable proportion (mis_var_prop=seq(.1,.8,.1), with per-variable missing cut-offs drawn from U(0.3,0.6) generated by MNAR_gen_imp), assemble the SSE values into a table (pro_ss_df), and plot SSE versus number of missing variables per method (e.g., #7CAE00 GSimp, #00BFC4 QRILC, #C77CFF kNN-TN; shapes 17, 15, 3). The rationale: Procrustes SSE on the leading PCs captures distortion of the overall observation distribution, a dimension of imputation quality that per-element accuracy metrics miss.

## Related tools

- **vegan** (R package used for PCA ordination (2 PCs) and Procrustes analysis computing SSE between original and imputed ordinations (v2.4-5 listed))
- **GSimp** (Imputation method under evaluation; its Procrustes SSE is compared against QRILC and kNN-TN (wrapper sim_GS_wrapper)) — https://github.com/WandeRum/GSimp
- **QRILC** (Comparison imputation method (impute.QRILC via sim_QRILC_wrapper) whose Procrustes SSE is benchmarked against GSimp)
- **kNN-TN** (Comparison imputation method (imputeKNN with k=3, distance='truncation' via sim_trKNN_wrapper) benchmarked by Procrustes SSE)
- **R** (Implementation language for the evaluation pipeline, MNAR generation, ordination, and plotting) — https://github.com/WandeRum/GSimp

## Examples

```
source('GSimp_evaluation.R'); sim_MNAR_list <- MNAR_gen_imp(data_c=data_sim_sc, mis_var_prop=seq(.1,.8,.1)); Procrustes_cal_plot(imp_result, DR='PCA', nPCs=2, x='Miss_Num')
```

## Evaluation signals

- Reproduced pattern: GSimp shows the lowest Procrustes SSE among GSimp/QRILC/kNN-TN as missingness increases
- pro_ss_df table contains one SSE value per method (3 methods) per missing-variable proportion (mis_var_prop=seq(.1,.8,.1), i.e., 8 levels)
- Ordinations use exactly 2 PCs (nPCs=2, DR='PCA') for both original and imputed matrices so Procrustes configurations are comparable
- Plot styling matches the protocol: colors #7CAE00 (GSimp), #00BFC4 (QRILC), #C77CFF (kNN-TN); shapes 17, 15, 3

## Limitations

- Procrustes SSE reflects only distributional/ordination distortion; it does not measure per-element imputation accuracy and should be paired with accuracy and sensitivity metrics
- Results depend on the MNAR generation settings (mis_var_prop=seq(.1,.8,.1); per-variable cut-offs from U(0.3,0.6)) and on the wrapper function parameters (GS_impute iters_each=50, iters_all=10, initial='qrilc', lo=-Inf, hi='min'; imputeKNN k=3, distance='truncation')
- Authors note no specific version constraints beyond those in the README dependency table (e.g., vegan 2.4-5); other versions are untested in this context
