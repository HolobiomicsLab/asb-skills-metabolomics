# SMILES canonicalization and Tanimoto matching

## Summary

A post-prediction evaluation routine for NMR2Struct that canonicalizes generated and target SMILES with RDKit to score exact-match hits among sampled predictions, and computes Tanimoto fingerprint similarity to quantify how chemically close incorrect predictions are to the true molecule.

## When to use

Use when scoring SMILES strings generated by the substructure-to-structure transformer or multitask model — deduplicating/canonicalizing predictions, deciding exact-match hits, or measuring near-miss similarity for molecules the model missed.

## When NOT to use

- When the goal is spectral preprocessing or structure prediction itself — this skill only operates after SMILES predictions have been generated by nmr_infer
- When SMILES fail RDKit parsing/sanitization (MolFromSmiles returns None); the model's generated strings must still be checked for chemical validity before fingerprinting
- When stereochemical identity is required — the model does not predict stereochemistry, so exact canonical matches ignore stereo

## Inputs

- Predicted SMILES strings written as hdf5 by nmr_infer (one row per generated prediction)
- Target SMILES array from the smiles_file .npy (binary-encoded strings, decoded via x.decode('utf-8'))
- RDKit Mol objects / fingerprints built from canonical SMILES

## Outputs

- Canonical SMILES strings for all predictions and targets
- Per-molecule hit/miss booleans (hit = canonical target appears among the 15 predictions) used to compute top-15 accuracy, overall and stratified by heavy-atom count
- Tanimoto similarity values between each best incorrect prediction and its canonical target (expected distribution: 89.6% ≥ 0.50, mean 0.68)

## How to apply

Canonicalize every predicted and target SMILES with RDKit (MolToSmiles on a parsed Mol) before any comparison, because the model generates SMILES by autoregressive token sampling and identical molecules can be written many ways. For each test molecule, mark a hit when the canonical target SMILES appears among the 15 predictions generated with top-k sampling (k=5); this is how the paper's 93.2% top-15 accuracy (96.0% at 10 heavy atoms, 92.8% at 17, <80% at 18–19) is computed. For misses, compute a fingerprint (e.g., RDKit RDKFingerprint or Morgan) for the best incorrect prediction and the canonical target and score Tanimoto similarity — the paper used this to show 89.6% of best incorrect predictions had Tanimoto ≥0.50 with an average of 0.68. The same canonicalization step is a prerequisite for the pipeline's other uses: tokenizing SMILES with a regular expression to build the alphabet, and computing the 957-substructure binary vectors via RDKit substructure matching. Read target SMILES from the .npy smiles_file as bytes and decode with x.decode('utf-8') before canonicalization.

## Examples

```
from rdkit import Chem, DataStructs; s1 = Chem.MolToSmiles(Chem.MolFromSmiles('CC(=O)O')); s2 = Chem.MolToSmiles(Chem.MolFromSmiles('OC(C)=O')); DataStructs.TanimotoSimilarity(Chem.RDKFingerprint(Chem.MolFromSmiles(s1)), Chem.RDKFingerprint(Chem.MolFromSmiles(s2)))
```

## Evaluation signals

- Canonicalizing a known SMILES twice (or via different input orderings) yields the identical canonical string, confirming RDKit parse + MolToSmiles is deterministic
- Reproduced top-15 accuracy lands within a few percent of the reported 93.2% overall, with the stratified trend 96.0% (10 heavy atoms) > 92.8% (17) > 80% (18–19 heavy atoms)
- For missed molecules, Tanimoto similarity of best incorrect predictions should cluster high (paper: 89.6% ≥ 0.50, average 0.68) — near-zero scores suggest a canonicalization or parsing failure rather than a genuine chemical mismatch
- Decoded smiles_file strings are valid UTF-8 SMILES after x.decode('utf-8') and every target has at least one non-empty canonical form
- Hit counting is invariant to non-canonical duplicates: removing duplicate canonical predictions per molecule does not change the hit/miss calls

## Limitations

- Exact-match scoring is binary — a prediction differing by one bond counts as a full miss, which is why the Tanimoto near-miss analysis was reported separately
- The framework's models do not predict stereochemistry, so canonical SMILES matching cannot distinguish stereoisomers
- Model predictions can include chemically invalid SMILES that RDKit cannot parse; these must be handled before fingerprint similarity can be computed
