# redundant-annotation-collapsing

## Summary

RowMerger-style collapsing of redundant putative annotation rows in untargeted metabolomics tables: entries sharing the same experimental neutral mass, m/z, adduct, and mass error are merged into a single row with abbreviated metabolite names joined by the '//' delimiter, reducing dataset size by up to 80%-90%.

## When to use

Use when a metabolomics feature table contains many putative annotation rows per feature (e.g., the abbreviated table output by TurboPutative REname) and rows must be consolidated before manual comparison or pathway-level prioritization of metabolites.

## When NOT to use

- Input is a raw feature-intensity table or metadata table rather than an REname-processed putative annotation table
- Rows differ in experimental neutral mass, m/z, adduct, or mass error — these are not redundant and must not be merged
- The goal is scoring/prioritization by adduct probability and feature correlations, which is the TPMetrics module's role, not RowMerger's

## Inputs

- CSV abbreviated annotation table generated by the TurboPutative REname module (per-feature rows with experimental neutral mass, m/z, adduct, mass error, and abbreviated metabolite names)

## Outputs

- rowmerger_output.csv — consolidated, size-reduced annotation table with merged rows and '//'-separated abbreviated metabolite name cells

## How to apply

Load the abbreviated annotation table (CSV) produced by the REname step with pandas. Apply the RowMerger grouping logic with user-customizable criteria: by default, group rows that share identical experimental neutral mass, m/z, adduct, and mass error, leaving the abbreviated name column out of the grouping keys. For each group, concatenate the abbreviated metabolite names into one cell separated by the '//' delimiter, which keeps equivalent/isomeric potential annotations visible while collapsing redundant rows. Write the consolidated table to rowmerger_output.csv; the rationale is that TurboPutative reduces putative annotation entries by 80%-90% in massive datasets, facilitating biological knowledge extrapolation and metabolite prioritization for pathway analysis.

## Related tools

- **TurboPutative** (RowMerger module performs the grouping of redundant putative annotation rows and emits the consolidated CSV) — https://github.com/CNIC-Proteomics/TurboPutative-web

## Examples

```
df = pd.read_csv('renamed_output.csv'); merged = df.groupby(['neutral_mass','mz','adduct','mass_error'])['abbreviated_name'].apply(lambda s: '//'.join(s)); merged.to_csv('rowmerger_output.csv')
```

## Evaluation signals

- rowmerger_output.csv exists and its row count is substantially smaller than the input REname table (TurboPutative reports 80%-90% entry reduction on massive datasets)
- Merged name cells contain the '//' separator joining multiple abbreviated metabolite names
- Every row in the output shares a single identical combination of experimental neutral mass, m/z, adduct, and mass error
- No rows differing in any grouping key (neutral mass, m/z, adduct, mass error) were collapsed together
- Rerunning the merge on the output yields no further row reduction (idempotence of the grouping)

## Limitations

- Default grouping ignores the abbreviated name column, so distinct isomers/equivalent compounds sharing a mass/adduct/error combination are concatenated into one cell rather than separated
- Grouping criteria are user-customizable; changing the default keys changes which rows are considered redundant
- RowMerger reduces dataset size for manual comparison but does not itself classify compounds (Tagger) or score features (TPMetrics)
