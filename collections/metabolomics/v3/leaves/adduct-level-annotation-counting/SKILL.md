# adduct-level-annotation-counting

## Summary

Enumerates library entries and annotated features per lipid class and adduct form across in-silico lipidomics libraries (MAVEN2's novel library, MS-DIAL, CalicoLipids) to identify lipid classes represented in only one library, such as OxPCs only in MS-DIAL and CEs only in CalicoLipids.

## When to use

Use when comparing coverage of two or more in-silico lipid fragmentation libraries and you need a per-lipid-class, per-adduct count matrix of library entries and annotated features to flag classes present in only one library.

## When NOT to use

- Input is already a completed per-class/per-library count matrix or the final comparison table — the enumeration step is redundant
- The task requires spectrum-level scoring or FDR estimation of individual identifications rather than class-level coverage comparison across libraries
- Only a single lipid library is being analyzed with no second library to cross-compare against

## Inputs

- Thresholded annotation table exported from MAVEN2 library-comparison searches
- Library composition statistics for each in-silico lipidomics library (MAVEN2 novel library, MS-DIAL, CalicoLipids)
- MSP-format lipid fragmentation library files (e.g., generated by CalicoLipidLibrary's generateDB.py)

## Outputs

- Per-lipid-class, per-adduct, per-library count matrix of library entries and annotated features
- List of lipid classes represented in only one library (e.g., OxPC only in MS-DIAL, CE only in CalicoLipids)
- dataset_s5_lipid_class_counts.csv

## How to apply

Load the thresholded annotation table exported from the MAVEN2 library-comparison searches together with the library composition statistics for each in-silico library (e.g., SM spectra 14,076 in one library vs 117 in another; Ceramide features 36,288 vs 39,882). Group records by lipid class and adduct form, then for each class/adduct combination count both the number of library entries (theoretical spectra) and the number of annotated features (experimental identifications). Cross-compare the counts across the in-silico libraries — MAVEN2's novel in-silico lipidomics library, MS-DIAL, and CalicoLipids — to build a per-class, per-library count matrix. Flag any lipid class represented in only one library, such as oxidized phosphatidylcholines (OxPCs) present only in MS-DIAL and cholesterol esters (CEs) present only in CalicoLipids. Write the count matrix and the single-library class list to dataset_s5_lipid_class_counts.csv and validate against Figure 4 / Dataset S5 of the article.

## Examples

```
python2.7 generateDB.py -m "pos" -c "PC,PE,PS"  # generate library subset, then group annotation records by lipid class and adduct to build the per-class/per-library count matrix
```

## Evaluation signals

- Per-class library entry counts match published figures, e.g., SM spectra 14,076 vs 117 across libraries
- Per-class annotated-feature counts match published values, e.g., Ceramide 36,288 vs 39,882
- Single-library class list reproduces the article's findings: OxPC present only in MS-DIAL and CE present only in CalicoLipids
- Output CSV (dataset_s5_lipid_class_counts.csv) reconciles with Figure 4 / Dataset S5 of the article
- Every lipid class/adduct combination appears in the matrix with a count for each library (zero counts explicit, not missing)

## Limitations

- Coverage conclusions depend on which adducts each library enumerates; not all adduct names are valid for all lipid classes in CalicoLipidLibrary
- Enumerating all theoretical spectra over all lipid classes in CalicoLipidLibrary may be time-consuming, so subsets (e.g., -c 'PC,PE,PS') are often generated instead, which can understate library coverage
- The comparison is restricted to the in-silico libraries used in the article (MAVEN2 novel library, MS-DIAL, CalicoLipids); other libraries would require regenerating the count matrix
