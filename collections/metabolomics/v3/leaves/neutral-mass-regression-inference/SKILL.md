# neutral-mass-regression-inference

## Summary

Infers the neutral mass of the M0 original compound from an annotated khipu tree by linear regression of matched m/z values against the theoretical khipu grid of isotope/adduct patterns, as implemented in the khipu Python package for LC-MS metabolomics and isotope tracing data.

## When to use

Use when a mass distance network of LC-MS features (e.g. from asari-preprocessed feature tables like ecoli_pos.tsv) has been converted into a 2-tier adduct/isotope tree and the neutral M0 mass of each empirical compound must be recovered.

## When NOT to use

- Input is a raw centroided or profile mass spectrum rather than a preprocessed feature table — khipu expects a tab-delimited feature table with feature ID, m/z, rtime and intensities columns, typically from asari
- Annotation already requires chromatographic or tandem-MS confirmation of isomers — regression infers a neutral mass but cannot resolve N1- vs N8-acetylspermidine-like isomer mixtures; LC-MS/MS with authentic standards is needed
- Only a subset of ions is matched to neither trunk nor branch — the regression depends on matched m/z values; singleton features that failed the DAG/tree conversion carry no usable ion-to-grid match

## Inputs

- A khipu/empirical-compound tree: adduct trunk plus isotopic branches, with matched m/z values per ion, produced from an asari 1.9.2 feature table (e.g. ecoli_pos.tsv) after searching mass difference patterns (1.0034 Da for 13C/12C, 22.9893 Da for Na+)
- The theoretical khipu grid of isotope patterns and adduct patterns (M0 through 13C/12C*6 rows x M+H/NH4/Na/HCl+H/K/ACN+H columns)

## Outputs

- An inferred neutral M0 mass per empirical compound, reported in khipu's transparent JSON format (e.g. 187.1686 for the acetylspermidine tree)
- JSON and tab-delimited preannotation files (this_test.json / this_test.tsv) listing empirical compounds with inferred neutral masses

## How to apply

After isotopic branches are assigned to the adduct trunk and realigned to the khipu grid (e.g. M+H[+], M+NH4[+], M+Na[+], M+HCl+H[+], M+K[+], M+ACN+H[+] with 13C/12C steps of 1.0034 Da), gather the m/z values of ions matched to the tree. The neutral mass of the M0 compound is then obtained via linear regression using the available ions and the theoretical khipu grid offsets, so that each observed m/z is explained as a linear combination of the neutral mass and known isotope/adduct mass shifts. This is the final step of khipu's two-step trunk/branch optimization, which first maximizes the number of explained nodes in the adduct trunk, then assigns isotopic branches. Regression recovers a single neutral mass per tree that is independent of which adduct was assumed as the base ion, avoiding the assumption-dependent assignment that limited prior network tools. Validate the inferred mass against known chemistry, e.g. a tree inferred at 187.1686 matching acetylspermidine (C9H21N3O) in U-13C-labeled E. coli data.

- **asari** (Preprocessing tool that generates the feature table input (ecoli_pos.tsv was generated by asari 1.9.2) consumed by khipu before neutral-mass regression) — https://github.com/shuzhao-li/asari

## Examples

```
khipu -i testdata/ecoli_pos.tsv -o this_test
```

## Evaluation signals

- The inferred neutral mass must reproduce known-formula compounds: e.g. 187.1686 must match acetylspermidine (C9H21N3O) with 9 carbons
- On ecoli_pos.tsv (3,602 features from asari 1.9.2), an independent implementation should recover 548 empirical compounds from 1,745 features, each carrying an inferred neutral mass
- Trees built from U-13C-labeled E. coli samples must show the expected isotopic pattern, e.g. highest isotope peak at M9 (13C/12C*9) for the acetylspermidine tree, consistent with its inferred carbon count
- Each inferred mass must be consistent across all matched ions in the tree: M+H, M+Na and M+K adduct rows should regress to the same neutral mass within the specified ppm tolerance (default configurable via --ppm)
- Output must be valid khipu JSON where every empirical compound record contains a neutral mass field derivable from the theoretical grid offsets used in the regression

## Limitations

- Annotation of untargeted metabolomics data, including isotopic tracing data, is still not fully solved; regression gives a neutral mass but not a complete annotation
- Complete annotation requires additional resources (contaminants, authentic libraries, tandem MS data) beyond khipu's preannotation and inferred masses
- Some ions may enter the initial network by mistakes or unresolved signals and are removed from the established khipu before regression, potentially weakening the fit
- Isotope/adduct search patterns depend on the biochemical experiment; default patterns may not cover derivatization shifts or custom labels without user-supplied patterns
- Benchmarking results are deferred to future work, so no external performance claims are established yet
