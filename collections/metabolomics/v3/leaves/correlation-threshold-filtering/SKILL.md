# correlation-threshold-filtering

## Summary

Constructs a Metabolite Correlation Network (Metabolite CN) by computing the Pearson Correlation Coefficient between every pair of metabolites across samples and retaining only edges with |r| ≥ 0.3 and p ≤ 0.01, applied both to real metabolomics profiles and to artificial Augmentation networks generated by simulated metabolic activity.

## When to use

Use when you have a metabolite-by-sample abundance matrix (e.g., tomato pericarp metabolomics for 2001, 2003, 2004 seasons) and need to convert it into a correlation-based network with an explicit significance cutoff for downstream hyperlink prediction.

## When NOT to use

- Input is already an edge list or adjacency structure rather than a metabolite-by-sample abundance matrix requiring correlation computation
- The downstream task requires weighted correlation values rather than a thresholded binary network, since the filter discards edges below |r| ≥ 0.3 or with p > 0.01
- The data are not metabolite abundance profiles (e.g., generic graph or sequence data), where Pearson correlation over concentration vectors is not meaningful

## Inputs

- Metabolite abundance/concentration matrix (metabolites × samples), e.g., tomato pericarp metabolomics profiles from harvesting seasons 2001, 2003, 2004
- Final sample states from simulated metabolic activity (for artificial Augmentation Metabolite CNs)
- Correlation threshold parameters: |r| ≥ 0.3 and p ≤ 0.01

## Outputs

- Metabolite correlation network (Metabolite CN) where edges connect metabolite pairs passing the |r| ≥ 0.3, p ≤ 0.01 filter
- Augmentation Metabolite CNs (10 per augmentation run) with degree-0 nodes added for metabolites missing from dropped pathways

## How to apply

Load the metabolite abundance matrix so each metabolite is represented by a vector of concentration values across samples (or across final states of simulated samples). Compute the Pearson Correlation Coefficient between every pair of metabolites over these vectors (Supplementary Fig 8.f in the source paper). Apply the selected correlation threshold |r| ≥ 0.3 and p ≤ 0.01: an edge between two metabolites is kept only if both the magnitude and significance criteria are satisfied. When applying this to Augmentation networks produced by the metabolic-activity simulation, metabolites missing from the final states (e.g., those from dropped pathways) are added with degree 0 so their waveform is ones. The resulting Metabolite CN (real or artificial) feeds waveform extraction and hyperlink prediction, so the same threshold must be applied consistently across genuine and augmented networks to keep node degrees comparable.

## Evaluation signals

- Verify that every retained edge satisfies both criteria of the correlation threshold (|r| ≥ 0.3 and p ≤ 0.01); no edge outside these bounds should appear in the Metabolite CN
- Confirm that each metabolite missing from the Augmentation networks (from dropped pathways) is added with degree 0 so its waveform is ones
- For augmentation runs, confirm exactly 10 Augmentation networks are produced, each being a valid Metabolite CN with node degrees consistent with the simulated metabolic activity (Supplementary Fig 8)
- Check network dimensions: the Metabolite CN should span the metabolite set of the input matrix (e.g., the 52 common metabolites used in the tomato pericarp experiments)
- Downstream consistency: the same threshold applied to genuine and artificial networks should yield comparable node-degree distributions feeding the auralization step

## Limitations

- The threshold |r| ≥ 0.3 and p ≤ 0.01 is a fixed choice from the tomato pericarp study; other datasets may require recalibration
- Correlation-based networks are sensitive to sparsity of labeled data, which the paper identifies as the most important challenge in metabolic pathway prediction
- Metabolites from dropped pathways enter the Augmentation networks with degree 0, so their waveforms carry no relational information
