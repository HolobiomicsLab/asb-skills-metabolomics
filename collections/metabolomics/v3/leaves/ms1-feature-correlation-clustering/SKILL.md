# ms1-feature-correlation-clustering

## Summary

Groups LC-MS1 features that are likely to be generated by the same metabolite (co-eluting isotopologues, adducts, in-source fragments) by correlation of per-sample intensities plus retention-time proximity, using the ipaPy2 clusterFeatures() function or equivalent processing software, before running IPA annotation.

## When to use

Use when you have an unclustered MS1 feature table with per-sample intensities (e.g., ExampleDatasets/README/df_test_pos_not_clustered.csv) and need to consolidate features from the same metabolite into single rows before ipaPy2 annotation.

## When NOT to use

- The feature table is already clustered (i.e., already has rel.ids grouping features per metabolite) — re-clustering would be redundant and may alter groupings.
- The input is raw vendor mass-spec data rather than a post-peak-picking feature table — peak detection/grouping must first be done with mzMatch or CAMERA.
- You only have MS2 fragmentation data with no measured per-sample MS1 intensities — clusterFeatures() requires a dataframe of measured intensities across several samples.

## Inputs

- Unclustered MS1 feature dataframe with columns ids, mzs, RTs and per-sample intensity columns (e.g., ExampleDatasets/README/df_test_pos_not_clustered.csv)
- Python 3.9+ environment with ipaPy2 installed (pip install ipaPy2 or conda install ipaPy2)

## Outputs

- Clustered feature dataframe containing ids, rel.ids (related-feature ids linking members of a cluster), mzs, RTs and a representative Int column, ready for map_isotope_patterns()/MS1annotation() in the IPA pipeline
- Optionally the clustered table saved as clustered_features.csv

## How to apply

Load the unclustered feature table with pandas (df2=pd.read_csv('ExampleDatasets/README/df_test_pos_not_clustered.csv')); the table carries ids, mzs, RTs and per-sample intensity columns. Call ipa.clusterFeatures(df) from ipaPy2, which clusters features by correlation of measured intensities across samples combined with retention-time proximity (default Cthr=0.8 minimum within-cluster correlation, RTwin=1 maximum RT difference in units of RTwin, Intmode='max' for the representative intensity). The rationale is that peaks from one metabolite co-elute and co-vary, so they must be merged into a single representative feature entry; alternatively the article notes this step can be done with widely used data processing software such as mzMatch or CAMERA. Confirm the output dataframe contains the required columns ids, rel.ids, mzs, RTs and Int (e.g., save as clustered_features.csv), since these are the columns the downstream IPA pipeline expects.

## Related tools

- **ipaPy2** (Provides the clusterFeatures() function that performs the correlation-based grouping of MS1 features prior to annotation) — https://github.com/francescodc87/ipaPy2
- **pandas** (Loads and validates the unclustered feature CSV and inspects the clustered output dataframe columns)

## Examples

```
import pandas as pd; import ipaPy2 as ipa; df = pd.read_csv('ExampleDatasets/README/df_test_pos_not_clustered.csv'); df_clustered = ipa.clusterFeatures(df)
```

## Evaluation signals

- Output dataframe contains exactly the required columns ids, rel.ids, mzs, RTs and Int (column schema check).
- Every row belonging to the same cluster shares an identical rel.ids value.
- Within each cluster, pairwise intensity correlations across samples are at least Cthr=0.8 and RT differences stay within RTwin=1.
- The Int column holds the representative intensity chosen per Intmode='max' (maximum intensity among cluster members).
- Downstream IPA functions accept the clustered table without raising missing-column errors.

## Limitations

- Alternatives such as mzMatch and CAMERA are explicitly recommended in the article; results may differ depending on which grouping software is used.
- The dataframe column names/order must match what ipaPy2 expects or downstream steps will fail.
- Exotic adducts or in-source fragments require user modification of the adducts file, and unusual clustering behavior may follow if such peaks are not captured by the correlation/RT thresholds.
