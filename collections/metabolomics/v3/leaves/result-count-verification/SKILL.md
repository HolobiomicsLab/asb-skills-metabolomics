# result-count-verification

## Summary

Verifies a reported count of Paired Omics Data Platform (PoDP) projects matching a keyword search by re-executing the platform's List-tab keyword filter over the archived Zenodo JSON dump of community-curated project records. This reproduces paper-reported search results, e.g. 18 projects for the query 'Streptomyces | Salinispora'.

## When to use

Use when a reported PoDP List-tab search result count (e.g. 18 projects for 'Streptomyces | Salinispora') must be independently reproduced from the Zenodo JSON archive of project records.

## When NOT to use

- When the target is ontological metadata selection (e.g. only metagenomic datasets from aquatic invertebrates, or only positive ionization mode) rather than free-text keyword matching — the article describes ontology-based selection as a distinct, more reliable mechanism
- When the query relies on free text entered in 'Other' boxes, which the article notes is 'inherently not machine-readable'
- When verifying counts against the live PoDP rather than the archived snapshot — the platform database changes continuously, so results will not match a publication-time figure

## Inputs

- Archived PoDP project records in JSON format from the Zenodo dataset (Zenodo deposition, e.g. 10.5281/zenodo.6091663)
- Keyword query string in List-tab syntax using '|' as OR, e.g. 'Streptomyces | Salinispora'
- Reported count to verify (e.g. 18 projects) from the source article

## Outputs

- Count of projects matching the keyword query (target: 18 for 'Streptomyces | Salinispora' at publication time)
- List of matching project identifiers whose records contain Streptomyces or Salinispora references
- Discrepancy note comparing recomputed count against the reported count, flagging Zenodo archive drift if any

## How to apply

Download the Zenodo JSON dataset that regularly archives all community-curated PoDP project records (Zenodo DOI 10.5281/zenodo.6091663, generated by monthly uploads of the iomega/paired-data-form service). Load each project record and apply a keyword filter mirroring the platform's List-tab search semantics: match the query terms case-insensitively across project fields including genome labels, organism/genus text, and user-specified metadata labels. The platform itself builds a full-text search index (Elasticsearch v7.6.2) over these records, so field-substring OR semantics — e.g. 'Streptomyces | Salinispora' matching either genus — approximate the online query. Collect matching project identifiers, count them, and compare against the reported count (18 for the genera query at publication time). Report the matched project list and count, and treat discrepancies as evidence of database drift rather than automatically failing the claim, since the article's count is explicitly 'currently 18' at publication time.

## Related tools

- **Paired Omics Data Platform** (Source of the project records being counted; its List-tab keyword search defines the query semantics ('Streptomyces | Salinispora') being reproduced offline)
- **Zenodo** (Hosts the regularly archived JSON dump of all community-curated PoDP project records that is downloaded and filtered for the count verification)
- **iomega/paired-data-form** (Repository of the platform web application whose Elasticsearch v7.6.2 full-text search index defines the keyword-matching behavior being mirrored) — https://github.com/iomega/paired-data-form

## Evaluation signals

- The recomputed project count equals the reported value of 18 for the 'Streptomyces | Salinispora' query (count at publication time)
- Every matched project record contains at least one occurrence of 'Streptomyces' or 'Salinispora' in its genome labels, organism/genus text, or metadata fields
- The JSON records parse cleanly against the platform's published JSON schema (app/public/schema.json in the iomega/paired-data-form repository)
- The matched project list is a subset of the full archived record set, and no project lacking either genus term appears in the result
- Any count mismatch is explainable by database growth/changes since the article's publication-time snapshot, not by a parsing or filter-logic error

## Limitations

- The reported count is time-sensitive ('currently 18'): the platform database is continuously updated and monthly Zenodo uploads move the snapshot forward, so later archives may return more than 18 projects
- Free text entered in 'Other' boxes is inherently not machine-readable, so keyword matching over archived JSON may miss genus names recorded only in such free-text fields
- The offline field-substring filter approximates, but is not guaranteed to reproduce exactly, the platform's Elasticsearch full-text search semantics and scoring
