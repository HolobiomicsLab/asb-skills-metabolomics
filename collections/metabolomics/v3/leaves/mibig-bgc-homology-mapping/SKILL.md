# mibig-bgc-homology-mapping

## Summary

Identify, within a strain-mapped NPLinker dataset, the BigScape-clustered gene cluster families (GCFs) homologous to known MIBiG BGCs (e.g. BGC0001228 retimycin A, BGC0000241 lomaiviticin A), then score and rank their links to all GNPS molecular families using standardised metcalf correlation, IOKR, and combined ℓ1/ℓ2/ℓ1.5 scores.

## When to use

Use when a validated or known MIBiG BGC (e.g. BGC0001228, BGC0000241) must be mapped to its homologous GCF in an antiSMASH/BigScape-annotated genome set, and the corresponding metabolomic links in GNPS molecular families must be ranked.

## When NOT to use

- The dataset has no GNPS molecular networking data as input — NPLinker requires it and the metcalf/IOKR scoring cannot be computed
- No BigScape output exists and antiSMASH BGC data are absent, so no GCFs can be clustered or mapped to MIBiG homologues
- The goal is scoring links for molecular families not tied to any strain-mapped BGC, since strain_mapping.json is required to connect BGCs and spectra to strains

## Inputs

- GNPS molecular networking data (spectra.mgf, molecular_families.tsv, annotations.tsv, file_mappings.tsv)
- AntiSMASH BGC data organised in the antismash subdirectory of the working directory
- BigScape GCF clustering output (auto-generated by NPLinker if absent)
- strain_mapping.json mapping strains to genomics and metabolomics data
- MIBiG metadata (automatically downloaded by NPLinker)
- List of validated MIBiG BGC accessions (e.g. BGC0001228 retimycin A, BGC0000241 lomaiviticin A)

## Outputs

- Link data (link graph) between target GCFs and all molecular families with metcalf scores
- Standardised correlation scores and IOKR scores for GCF–molecular-family pairs
- Combined ℓ1, ℓ2 and ℓ1.5 scores per GCF–molecular-family link
- Ranks of validated links (count of candidates with equal or higher score), e.g. table4_link_ranks.csv in the layout of Table 4

## How to apply

Load the Crüsemann data set (GNPS spectra.mgf, molecular_families.tsv, annotations.tsv, file_mappings.tsv, and antiSMASH-derived BigScape GCFs) into NPLinker via npl.load_data(), using strain_mappings.json to connect BGCs and spectra to strains. Identify the GCFs homologous to the target validated MIBiG BGCs, then compute link data between these GCFs and all molecular families with npl.get_links using the metcalf scoring method as the base correlation score. Standardise the correlation scores and compute Input-Output Kernel Regression (IOKR) scores for all GCF–molecular-family pairs. Combine the standardised scores into ℓ1, ℓ2 and ℓ1.5 combined scores via the Eq 2 sign-weighted sum, then for each validated link count the candidate links whose combined score is equal to or higher (the rank), recording the best rank under the ℓ1.5 combination.

## Related tools

- **nplinker** (Framework used to load the Crüsemann dataset (npl.load_data), identify GCFs, and compute metcalf-scored links (npl.get_links) between homologous GCFs and molecular families) — https://github.com/NPLinker/nplinker
- **AntiSMASH** (Provides the BGC data input from which homologous GCFs are derived; organised in the antismash directory of the working directory)
- **BigScape** (Clusters antiSMASH BGCs into GCFs; NPLinker can run BigScape automatically if the bigscape directory does not exist (versions 1 and 2 supported))
- **Python** (Runtime for the nplinker framework (Python version ≥3.11) used to execute the scoring and ranking workflow)

## Examples

```
npl.load_data(); link_graph = npl.get_links(npl.gcfs[:3], "metcalf")
```

## Evaluation signals

- The combined ℓ1.5 (ℓ12) score assigns the best rank to the validated link in 10 out of 15 cases — reproduce this count from table4_link_ranks.csv
- Validated link for BGC0001228 (retimycin A) ranks at number 253 and BGC0000241 (lomaiviticin A) at number 5 under the ℓ1.5 combination, better than either score alone
- Rank for each validated link equals the count of candidate links whose combined score is equal to or higher than the validated link's score
- Strain connectivity holds: every BGC and spectrum used resolves to a strain via strain_mappings.json
- Combined scores match the Eq 2 sign-weighted sum of the standardised metcalf correlation scores and IOKR scores

## Limitations

- Even with the best combined score (ℓ1.5), some validated links rank poorly (e.g. rank 253 for retimycin A), so top-k prioritisation is not guaranteed for all BGCs
- Ranks depend on the specific dataset; the 10/15 success count was established on the Crüsemann data set with its validated links
- The nplinker pip installation requires ~300MB of disk space, and MIBiG metadata must be auto-downloaded, so the skill needs network access on first run
