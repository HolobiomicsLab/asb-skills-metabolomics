# functional-group-threshold-filtering

## Summary

Prunes enumerated derivative functional groups by synthetic accessibility: compute the average SCScore differential (ΔSCScore) of derivatives generated by applying each functional group n times to a drug template, and retain only groups below the threshold α^n.

## When to use

Use when a large enumerated functional-group list (e.g., 204 groups on a cathinone template) must be screened before combinatorial enumeration so that highly challenging-to-synthesize derivative compounds are excluded from the synthetic database.

## When NOT to use

- The analyte's chemical structure is already known and matches a reference spectrum — this skill only supports enumeration of putative derivatives when no reference match exists
- Filtering targets are whole compounds rather than functional groups — use rule-based criteria (e.g., Messy rings, Virshup drug-like criteria) or M+ mass-weight filtering instead
- A different synthetic-accessibility metric or threshold calibration is required — α = 1.2 and the n = 2/3 recursion depths are specific to this pipeline's validation counts

## Inputs

- Enumerated functional-group list (SMILES or equivalent) produced by the enumeration step
- Drug-templated derivative compound set (e.g., cathinone core with hydrogens substitutable by functional groups)
- Pretrained SCScore neural-network model

## Outputs

- Per-functional-group score table (scscore_filter_results.csv) with ΔSCScore values and per-level pass/fail flags
- Filtered functional-group list restricted to groups with ΔSCScore < α^n (131 groups at n = 2, 97 at n = 3 for cathinone)

## How to apply

Load the enumerated functional-group list and the drug-templated derivative set (204 compiled functional groups for cathinone in PS2MS). Compute the SCScore of the parent template (cathinone) as the baseline synthetic-difficulty reference using the pretrained SCScore neural network. For each functional group, iteratively apply it n times to the template (n = 2 and n = 3), score each resulting compound with SCScore, and average per functional group to obtain the synthesis-difficulty differential ΔSCScore relative to the baseline. Retain a functional group only if ΔSCScore < α^n with α = 1.2 at each recursion level, flagging pass/fail at levels 2 and 3; in the paper this reproduces 131 passing groups at n = 2 and 97 at n = 3. Write the per-group score table (ΔSCScore values plus per-level flags) to scscore_filter_results.csv for downstream enumeration and rule-based filtering steps.

## Evaluation signals

- Number of functional groups passing ΔSCScore < α^n equals 131 at the second recursion level (n = 2)
- Number of functional groups passing at the third recursion level (n = 3) equals 97
- Every retained group has an average ΔSCScore strictly below α^n with α = 1.2; no group with ΔSCScore ≥ α^n survives
- scscore_filter_results.csv contains a ΔSCScore row and per-level pass flags for all 204 input functional groups
- Baseline SCScore of the cathinone template is computed once and consistently used as the reference for all group differentials

## Limitations

- The threshold (α = 1.2) and recursion levels (n = 2, 3) were calibrated against the paper's cathinone template; other templates may need recalibration
- SCScore reflects synthetic-difficulty heuristics, not guaranteed synthesizability — derivatives are only ranked as more/less challenging
- Screening discards functional groups before enumeration, so borderline groups with genuinely novel NPS derivatives could be excluded from the synthetic database
