# spectral-precursor-mz-filtering

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

A cleaning step that removes all fragment ions with m/z larger than a metabolic feature's precursor m/z from pseudo MS/MS spectra generated by ms1-id, so that modified cosine similarity can be computed for GNPS2 molecular networking.

## When to use

Use when pseudo MS/MS (composite) spectra built from MS1 in-source fragments contain peaks above the feature's precursor m/z and you need modified cosine-based molecular networking, which cannot tolerate such peaks.

## When NOT to use

- Input spectra are conventional acquired MS/MS whose peaks already lie below the precursor m/z — no filtering is needed
- You only want ms1-id library annotation of pseudo MS/MS spectra (reverse spectral matching), which does not require precursor-bounded peak lists
- The downstream networking uses a similarity measure that tolerates fragments above the precursor m/z, so modified cosine filtering is unnecessary

## Inputs

- pseudo MS/MS spectra (composite spectra) generated by ms1-id from MS1-only LC-MS data, in MGF format
- per-feature precursor m/z values for each metabolic feature

## Outputs

- cleaned pseudo MS/MS MGF file containing only peaks at or below each feature's precursor m/z (e.g. ibd_hilicpos_cleaned_pseudo_msms.mgf)
- GNPS2 molecular network edges table (e.g. molecular_network_edges.tsv) built with modified cosine >= 0.8 and matched peaks >= 6

## How to apply

Start from the pseudo MS/MS spectra produced by ms1-id's correlation-based clustering of MS1 features (e.g., the IBD cohort HILIC-positive LC-MS data from Metabolomics Workbench PR000639). For each metabolic feature, scan its pseudo MS/MS peak list and delete every ion whose m/z exceeds the feature's precursor m/z; this is required because modified cosine scoring in molecular networking assumes fragments lie at or below the precursor. Write all cleaned spectra into a single MGF file (e.g. ibd_hilicpos_cleaned_pseudo_msms.mgf) and submit it to the GNPS2 classical molecular networking workflow (version 2024.09.20). Run networking with edge criteria of minimum modified cosine 0.8 and minimum 6 matched peaks, then save the resulting edge table (e.g. molecular_network_edges.tsv). Validate before submission that every MGF record contains only peaks at or below its precursor m/z.

## Related tools

- **ms1-id** (Generates the pseudo MS/MS spectra (per-feature composite peak lists) that are then cleaned by removing ions above the feature m/z) — https://github.com/Philipbear/ms1_id
- **GNPS2** (Hosts the classical molecular networking workflow (version 2024.09.20) that consumes the cleaned MGF and builds edges under modified cosine >= 0.8 and matched peaks >= 6)

## Evaluation signals

- For every MGF record, the maximum fragment m/z is at or below that record's precursor m/z after cleaning
- The GNPS2 job completes successfully (e.g. task https://gnps2.org/status?task=670aa34a07544a5cbbd1f1d40605f50f as reported for the paper)
- All edges in molecular_network_edges.tsv satisfy modified cosine >= 0.8 and matched peaks >= 6
- Biologically coherent subnetworks emerge, e.g. a tyrosine-related subnetwork containing N-acyl amides with altered levels in non-IBD vs CD/UC comparisons

## Limitations

- Filtering discards ions above the feature m/z that arise in pseudo MS/MS because in-source fragments are matched across co-clustered ion forms; this is unavoidable for modified cosine but removes spectral information
- The paper's scoring and peak-scaling equations are not rendered in the text, so exact score math must be taken from the code or GNPS2 implementation
- The ms1-id package version number is not stated in the article (only MassCube ver 1.0.11 and GNPS2 workflow version 2024.09.20 are given), hindering exact reproduction
