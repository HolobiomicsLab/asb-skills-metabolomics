# mass-spectrometry-parameter-spreadsheet-configuration

## Summary

Configure and drive the IDSL.CSA composite spectra deconvolution workflow via its 39-parameter Excel spreadsheet (CSA_parameters.xlsx), turning IDSL.IPA peaklists from LC/HRMS MS1 data (mzML, mzXML, netCDF) into composite spectra MSP libraries.

## When to use

Use when you have IDSL.IPA-generated 'peaklists' and 'peak_alignment' directories from LC/HRMS MS1 data and need to run CSA correlation-based deconvolution by filling and submitting the IDSL.CSA parameter spreadsheet.

## When NOT to use

- The goal is to annotate existing .msp/.mgf spectra against MS/MS libraries — use the companion IDSL.FSA workflow instead of configuring a CSA run.
- Mass spectrometry data has not yet been processed by IDSL.IPA, so no 'peaklists' or 'peak_alignment' directories exist to supply to CSA0008/CSA0009.
- The task is peak detection itself from raw data rather than configuring the downstream deconvolution — configure the IDSL.IPA parameter spreadsheet first.

## Inputs

- MS1-level HRMS data files (mzML, mzXML, netCDF) from LC/HRMS untargeted metabolomics assays
- IDSL.IPA 'peaklists' directory containing chromatographic peak information (m/z-RT)
- IDSL.IPA 'peak_alignment' directory containing aligned peaklists
- IDSL.CSA parameter spreadsheet (CSA_parameters.xlsx) with 39 parameters in 5 sections

## Outputs

- .msp composite spectra library file in the CSA_MSP directory (e.g., 42 CSA spectra clusters for the pool_P1_A1-A12 test file)
- CSA_adduct_annotation directory with peaklists carrying potential adduct information
- peak_alignment_subset directory with subsets of aligned peak tables for major ions in each CSA cluster
- aligned_spectra_table with information for CSA aggregation on the aligned table

## How to apply

Download the IDSL.CSA parameter spreadsheet (CSA_parameters.xlsx), which distributes 39 parameters into 5 separate sections, and set the key fields: PARAM0001 = YES in the Start tab to restrict processing to the CSA workflow, CSA0005 to the MS1-level HRMS data location, CSA0008 to the peaklists directory and CSA0009 to the peak_alignment directory generated by IDSL.IPA, CSA0011 to the output location, and optionally CSA0004 to control the number of processing threads. Then run library(IDSL.CSA); IDSL.CSA_workflow('<spreadsheet address>') in R/RStudio or a terminal. The rationale is that the spreadsheet is the sole user-facing interface: it encodes peak detection, EIC grouping (e.g., Pearson correlation threshold 0.98 grouped 76.9% of peaks into 42 EIC groups in the pooled-standards test), and spectra aggregation into one reproducible configuration object. Results are parsed at the CSA0011 address, where CSA_MSP holds the .msp file.

## Examples

```
library(IDSL.CSA); IDSL.CSA_workflow("Address of the CSA parameter spreadsheet")
```

## Evaluation signals

- The CSA_MSP directory exists at the CSA0011 output address and its .msp file contains the expected number of CSA spectra clusters (42 for the MSV000088661 pool_P1_A1-A12.mzML 12-standard test file).
- PARAM0001 is set to YES so only the CSA workflow ran; no DDA/DIA outputs are produced.
- All four companion outputs (CSA_MSP, CSA_adduct_annotation, peak_alignment_subset, aligned_spectra_table) are present and the aligned_spectra_table reflects CSA aggregation on the aligned peak table.
- EIC grouping statistics are consistent with the chosen correlation threshold — with Pearson r = 0.98, ~76.9% of detected peaks should fall into the reported EIC groups/clusters.
- CSA0004 thread setting, if changed, did not alter the number of clusters relative to default single-thread processing.

## Limitations

- CSA requires that data were pre-processed by IDSL.IPA specifically; peaklists from other tools (xcms, MZmine 2, MS-DIAL) are not part of the documented input contract.
- Cluster output depends on parameter choices (e.g., the 0.98 Pearson correlation threshold); stricter or looser thresholds change the number of EIC groups and exported spectra.
- Not every detected peak is grouped into a cluster (76.9% in the test case), and not all LC/HRMS peaks can be annotated since MS2 fragmentation data and library coverage of the chemical space are incomplete.
- No changelog was provided in the article context, so version-specific parameter behavior should be verified against the current spreadsheet.
