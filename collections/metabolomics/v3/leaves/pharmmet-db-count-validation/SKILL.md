# pharmmet-db-count-validation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Tallies experimentally detected drug metabolites by biotransformation reaction type (oxidation, reduction, hydrolysis, glucuronidation, etc.) from the PharmMet DB human liver S9 annotations (Metabolomics Workbench Study ST003991) and validates each count against the BioTransformer 3.0 predictions reported in the source paper.

## When to use

Use when reproducing or auditing the per-reaction-type metabolite tally from the PharmMet DB human liver S9 study (ST003991) — e.g. 30,752 oxidations, 6311 glucuronidations — against BioTransformer 3.0 predictions.

## When NOT to use

- The input is raw LC-HRMS mass spectral data rather than curated annotation tables — feature detection (MZmine 2.53, 0-hour vs 24-hour comparison) must run first.
- The goal is structural elucidation or isolation of novel metabolites; the article notes novel metabolites from nearly 1000 drugs require considerable research beyond the database.
- The metabolites of interest form in extrahepatic compartments (intestine, kidney) or via enzymes not abundant or active in human liver S9 — PharmMet DB is expected to lack them.

## Inputs

- Metabolite annotation tables for Metabolomics Workbench Study ID ST003991 (DOI 10.21228/M8W55K), each annotation carrying a BioTransformer 3.0 reaction-type tag
- PharmMet DB export (github.com/ClinicalBiomarkersLaborabory/PharmMet) listing experimentally detected metabolites for 1114 therapeutic drugs
- BioTransformer 3.0 prediction tables giving per-drug predicted metabolites with reaction-type labels

## Outputs

- Tab-separated table with columns: reaction type, detected count, predicted count, detection fraction
- Per-row reconciliation report comparing computed tallies to the paper's reported counts (exact-match validation)

## How to apply

Download the metabolite annotation tables for Study ID ST003991 from the Metabolomics Workbench (DOI 10.21228/M8W55K) or the PharmMet DB release at github.com/ClinicalBiomarkersLaborabory/PharmMet, covering 1114 therapeutic drugs incubated with human liver S9 fraction. Parse the BioTransformer 3.0 reaction-type tag attached to each annotation (oxidation, reduction, hydrolysis, methylation, acetylation, glucuronidation, sulfation, glutathione conjugation); note that curation in the source study cross-referenced detected signals at ±5 ppm against BioTransformer predictions. In R 4.0.3, cross-tabulate reaction type against detection status to obtain, per reaction type, the number of experimentally detected metabolites and the number of BioTransformer 3.0 predictions. Validate each row against the reported values — oxidation 30,752 detected of 59,296 predicted (52%), reduction 7114/10,899 (65%), hydrolysis 3184/5744 (55%), methylation 3136/6235 (50%), glucuronidation 6311 detected, acetylation 45%, glutathione conjugation 21% — using exact-match tolerance. Write the aggregated counts as a tab-separated table with columns reaction type, detected count, predicted count, and detection fraction.

## Related tools

- **R 4.0.3** (Performs the reaction-type cross-tabulation of detected vs BioTransformer-predicted metabolite counts and writes the tab-separated summary; the paper used R version 4.0.3 for statistical analysis and data visualization.)
- **BioTransformer 3.0** (Supplies the in-silico predicted metabolites and reaction-type tags used as the comparison reference; detected mass signals were cross-referenced at ±5 ppm against its predictions.)
- **PharmMet DB** (Source of the experimentally validated metabolite annotations (1114 drugs, human liver S9) that are tallied per reaction type and cross-checked against reported counts.) — https://github.com/ClinicalBiomarkersLaborabory/PharmMet

## Examples

```
Rscript -e 'a <- read.delim("ST003991_annotations.tsv"); t <- table(a$reaction_type); write.table(t, "reaction_counts.tsv", sep="\t")'
```

## Evaluation signals

- Oxidation row shows detected=30,752 and glucuronidation row shows detected=6311 (exact match with the paper's reported values)
- Reduction row reads 7114 detected of 10,899 predicted (65%), hydrolysis 3184/5744 (55%), methylation 3136/6235 (50%), acetylation 45%, and glutathione conjugation 21%
- Output file is tab-separated with exactly the columns reaction type, detected count, predicted count, detection fraction
- Detection fractions recomputed as detected/predicted reproduce the reported percentages (e.g. oxidation 52%) within rounding tolerance
- Per-type tallies reconcile with the ST003991 annotation tables (each tagged annotation counted once, no unexplained extra rows)

## Limitations

- Reliance on human liver S9 for biotransformation: not all drug-metabolizing activities are present in this fraction.
- PharmMet DB is expected to lack metabolites formed by enzymes not abundant or active in liver S9, or generated in extrahepatic compartments (e.g. intestine, kidney).
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression.
- PharmMet DB is not completely comprehensive (1114 drugs); novel metabolites from nearly 1000 drugs still require isolation and structural elucidation.
