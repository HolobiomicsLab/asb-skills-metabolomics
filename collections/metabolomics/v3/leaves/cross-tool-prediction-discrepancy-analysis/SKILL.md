# Cross-tool prediction discrepancy analysis

## Summary

Quantifies where two structure-based ontology prediction tools (CANOPUS via SIRIUS and MolNetEnhancer) disagree on ClassyFire superclass assignments for the same GNPS molecular networking MS/MS spectra, using the Streptomyces/Salinispora dataset as the reference case.

## When to use

Use when the same set of MS/MS spectra has been annotated by two independent classifiers (e.g. CANOPUS and MolNetEnhancer) and you need to tabulate per-class disagreement before choosing one tool's output for downstream scoring such as NPClassScore.

## When NOT to use

- When you already have a single trusted annotation source and only need a classification ranking rather than an inter-tool agreement assessment.
- When the spectra exceed the CANOPUS 850 Da mass cut-off or lack structure-based classes, since missing predictions distort the intersection count.
- When the analysis goal is BGC–spectrum linking (e.g. NPClassScore/Metcalf scoring) rather than evaluating which ontology predictor to use.

## Inputs

- GNPS molecular networking .mgf file with MS/MS spectra (e.g. from the Streptomyces/Salinispora dataset)
- CANOPUS superclass prediction table from SIRIUS output run on the mgf
- MolNetEnhancer superclass annotation table from the GNPS platform run
- Spectrum-to-superclass mappings keyed by spectrum ID for both tools

## Outputs

- Comparison table of per-superclass prediction counts for CANOPUS vs MolNetEnhancer
- Per-superclass discrepancy statistics highlighting divergent categories
- Count of spectra retained (6606) vs excluded (1988) due to missing predictions

## How to apply

Load the CANOPUS superclass predictions (generated by running SIRIUS v4.9.3 directly on the GNPS mgf file within NPLinker) and the MolNetEnhancer superclass annotations (run externally on the GNPS platform) for the paired-omics spectra. Intersect the two annotation sets to retain only the 6606 spectra with predictions from both tools, excluding the 1988 spectra lacking a prediction from either tool. Tabulate the frequency of each ClassyFire superclass separately for each tool, then compute per-category discrepancy statistics — e.g. 'Lipids and lipid-like molecules' is predicted 2686 times by MolNetEnhancer versus 1301 times by CANOPUS. Assemble a comparison table of superclass counts and agreement metrics that reproduces Tables S6–S7, which quantifies how strongly the choice of ontology-prediction tool propagates into downstream NPClassScore outcomes.

## Related tools

- **CANOPUS** (Structure-based ontology predictor run via SIRIUS on the GNPS mgf file; one of the two prediction sources being compared) — github.com/kaibioinfo/canopus_treemap
- **MolNetEnhancer** (External GNPS-platform ontology predictor providing the second superclass annotation set for the discrepancy comparison)
- **NPLinker** (Platform in which SIRIUS/CANOPUS is executed on the mgf and whose downstream NPClassScore filtering depends on the choice between the two tools) — github.com/NPLinker/nplinker
- **ClassyFire** (Shared superclass ontology (e.g. 'Lipids and lipid-like molecules') against which both tools' outputs are tabulated)

## Evaluation signals

- The intersection count equals 6606 spectra with predictions from both tools and 1988 spectra lacking a prediction from either tool.
- The tabulated count for 'Lipids and lipid-like molecules' is 2686 for MolNetEnhancer and 1301 for CANOPUS.
- Comparison table reproduces the reported counts from Tables S6–S7 of the source publication.
- Per-category discrepancy is dominated by categories such as 'Organic acids and derivatives' and 'Phenylpropanoids and polyketides', not by a single outlier class.
- Downstream NPClassScore links differ depending on which tool's predictions are used, confirming the tool choice materially influences results.

## Limitations

- MolNetEnhancer has to be run externally (e.g. on the GNPS platform) because it cannot currently be run within NPLinker.
- CANOPUS coverage is limited by a 850 Da mass cut-off, so larger metabolites are not well handled.
- 1988 MS/MS spectra across the datasets lacked a prediction from one or both tools; discarding those links is necessary for a fair comparison.
- Not filtering out spectra without structure-based classes results in an average decrease of 49% of candidate links per GCF, complicating direct comparison.
