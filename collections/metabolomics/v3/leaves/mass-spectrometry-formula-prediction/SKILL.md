# mass-spectrometry-formula-prediction

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Predicts precursor molecular formulas from HRMS precursor m/z using MSThunder's transformer-based precursor formula prediction stage, benchmarked on the CASMI 2016 positive-mode dataset (127 spectra) at mass tolerance windows of ≤1/≤2, ≤5, ≤10, and ≤20 ppm.

## When to use

Use when given a positive-mode MS2 spectrum (or batch of converted vendor raw files) with an observed precursor m/z and you need a ranked list of candidate precursor molecular formulas scored by candidate score.

## When NOT to use

- The input lacks high-resolution MS2 spectra with mass accuracy to two decimal places — the article excludes such inputs from its validated dataset
- Offline raw-data processing is required — the current MSThunder version does not support offline processing of raw data; raw files must be sent for conversion via MSConvert in a Linux system
- The goal is de novo chemical structure prediction rather than precursor formula assignment — that requires the downstream formula-to-ISMILES transformer stage, not the precursor formula prediction stage

## Inputs

- CASMI 2016 positive-mode benchmark MS2 spectra (127 spectra), or vendor raw files converted via MSConvert
- Observed precursor m/z and retention time per spectrum
- Selected ion mode ('Positive' or 'Negative') for batch-processed file input

## Outputs

- Ranked list of candidate precursor molecular formulas per spectrum with candidate scores in the Ranking list
- prediction_accuracy_by_ppm_tolerance.csv — rows for ≤1/≤2, ≤5, ≤10, ≤20 ppm tolerance bins, columns for number of correct spectra and accuracy percentage

## How to apply

Load the CASMI 2016 positive-mode benchmark (127 spectra), converting vendor raw files (ThermoFisher, Agilent, others) to an open format via MSConvert if needed. Run the MSThunder precursor formula prediction stage from the msthunder package (Python 3.10.5, torch 1.13.0+cu116) on each spectrum; the Ranked candidate formulas are generated by double-clicking the precursor formula in the Candidate section, with scores shown in Ranking. Compare each top-ranked predicted formula's exact mass against the observed precursor m/z and count hits within tolerance windows of ≤1/≤2 ppm, ≤5 ppm, ≤10 ppm, and ≤20 ppm. Compute top-1 accuracy per tolerance as the fraction of the 127 spectra whose top-ranked candidate satisfies the tolerance; the article reports 87.4% at ≤1/≤2 ppm, 89.0% at ≤5 ppm, 94.5% at ≤10 ppm, and 92.1% at ≤20 ppm. Optionally confirm the precursor formula via ISMILES retrieval in PubChem through PubChemPy (pubchempy 1.0.4) before downstream structure prediction.

## Evaluation signals

- Top-1 precursor formula accuracy on the 127-spectrum CASMI 2016 positive-mode benchmark should approach ~94.5% at ≤10 ppm and ~87.4% at ≤1/≤2 ppm tolerances
- Accuracy should be monotone/non-decreasing with looser tolerance bins (≤1/≤2 ≤ ≤5 ≤ ≤10 ppm), with the article's ≤20 ppm value (92.1%) below the ≤10 ppm peak
- Each top-ranked candidate formula's exact mass must fall within the tested ppm window of the observed precursor m/z
- Output CSV must contain exactly four tolerance bins (≤1/≤2, ≤5, ≤10, ≤20 ppm) with correct-spectra counts summing consistently against the 127-spectrum denominator

## Limitations

- Current MSThunder version does not support offline processing of raw data due to environment configuration issues; analysis of new UPLC-HRMS data requires sending raw files or uploading to Zenodo/GNPS
- Interface requires decompressing msthunder.rar (2.2 GB RAR, password '2024V1.0') with msthunderfile.rar unzipped under the msthunder folder
- Dataset filtering excluded ISMILES containing K, Na, Au, Se, B, Fe, As, Ca, Mg, Cr, Al and '.', ISMILES longer than 130 characters, and inputs without high-resolution MS2 spectra with mass accuracy to two decimal places, so performance on excluded chemical space is unvalidated
