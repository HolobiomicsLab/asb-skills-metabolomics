# in-silico-fragmentation-tool-benchmarking

> **License: restricted** — no clear open-source license detected for the underlying tool; verify licensing before commercial use or redistribution. <!-- asb-license-banner -->
## Summary

A reproducible protocol for benchmarking in silico MS/MS spectral prediction tools (SingleFrag ANN/GNN/COM, CFM-ID 4.0, 3DMolMS) by scoring predicted spectra against experimental spectra of a held-out test set using precision, recall, accuracy, F1, and cosine similarity.

## When to use

Use when you have SMILES of held-out compounds plus their experimental MS/MS spectra and need to objectively compare whole-spectrum predictions from multiple in silico fragmentation tools (e.g., SingleFrag vs CFM-ID vs 3DMolMS).

## When NOT to use

- When the compound's experimental spectrum already exists in a curated library (e.g., NIST MS/MS) — direct library matching is preferred over in silico prediction and no benchmark is needed
- When the goal is annotating a single unknown spectrum rather than quantitatively comparing prediction tools across a test set
- When molecules fall outside predictor coverage (e.g., more than 300 atoms or atom types unsupported by 3DMolMS such as Si), where the comparison is no longer fair

## Inputs

- SMILES strings and experimental MS/MS spectra of the 2,929 test compounds (inputMols file from the SingleFrag Figshare dataset)
- Trained per-MZ-position SingleFrag models (ANN/GNN/COM ModelVal*.pickle) for the 1,000 most frequented MZ positions
- Per-position classification thresholds (thresholdsANN.pickle, thresholdsGNN.pickle, thresholdsCOM.pickle)
- Mol2vec model (Mol2vecModelGeneral_rep_dades1.model) for 300-dimensional molecular embeddings
- In silico spectra generated by CFM-ID 4.0 and 3DMolMS for the same test compounds

## Outputs

- Per-MZ-position prediction files (results/dfPredictionPeak_*.pickle)
- Reconstructed full predicted spectra per tool (results/predSpectra.json)
- Per-tool per-molecule benchmark table of precision, recall, accuracy, F1, and cosine similarity (fig3g-i_tool_metrics.csv)

## How to apply

Load the test-compound SMILES and experimental spectra (2,929 compounds from the SingleFrag Figshare dataset inputMols file), generate 300-dimensional mol2vec embeddings, and run each predictor — ANN, GNN, and combined (COM) SingleFrag models over the 1,000 most frequented MZ positions using the per-position thresholds in thresholdsANN/GNN/COM.pickle, plus CFM-ID 4.0 and 3DMolMS — on the same compounds. Merge the per-MZ-position prediction files (results/dfPredictionPeak_*.pickle) and reconstruct full predicted spectra (results/predSpectra.json), discretizing all predicted and experimental spectra on a common 0.2 m/z grid so the tools are compared on identical bins. For each tool and molecule, compute precision, recall, accuracy, F1, and cosine similarity of predicted versus experimental spectrum, then assemble the five metrics into a per-tool per-molecule table (fig3g-i_tool_metrics.csv) for the benchmark comparison.

## Related tools

- **SingleFrag** (Deep learning tool whose ANN, GNN, and COM variants predict individual peaks per MZ position; benchmarked against CFM-ID and 3DMolMS) — github.com/MaribelPR/SingleFrag
- **mol2vec** (Generates the 300-dimensional molecular embedding used as input to the SingleFrag ANN models)
- **CFM-ID** (Rule-based in silico fragmentation baseline run on the same test compounds for comparison)
- **3DMolMS** (Deep learning baseline predicting MS/MS spectra from 3D conformations; its predictions are scored against the same experimental spectra) — josiehong/3DMolMS

## Evaluation signals

- All predicted and experimental spectra are discretized on the identical 0.2 m/z grid before any metric is computed — verify the binning grid is shared across all five tools
- The output table contains exactly five metrics (precision, recall, accuracy, F1, cosine similarity) for every tool-molecule pair from the 2,929 test compounds
- Expected outcome: all three SingleFrag variants exceed CFM-ID and 3DMolMS on precision, accuracy, and cosine similarity, with recall comparable to 3DMolMS (slightly better for ANN and COM)
- Peak-calling must apply the per-MZ-position threshold from thresholdsANN/GNN/COM.pickle — a prediction is a peak only if it is >= the position-specific threshold
- Reconstructed spectra in results/predSpectra.json must be consistent with the merged dfPredictionPeak_*.pickle files (same peak set after thresholding)

## Limitations

- Only the 1,000 most frequented MZ positions of the training set are predicted; peaks outside these bins are never called, capping recall for rare fragments
- The GNN model shows slightly lower performance than the ANN model, attributed to deliberately simple, unoptimized architectures rather than a fundamental limitation of graph neural networks
- The toy input file's integer-m/z spectrum format is lower resolution than the model's 2-decimal fragment prediction
- Public spectral libraries (GNPS, MSDial, MassBank) often lack spectra at multiple collision energies and sufficient curation, limiting ground-truth quality for benchmarking
