# candidate-derivative-tie-resolved-ranking

## Summary

Ranks candidate derivative structures generated from a known anchor molecule by applying biotransformation rules and scoring each derivative with GNN-SOM site-of-metabolism likelihoods, resolving rank ties using the average-rank method so that the suspect's true structure surfaces in a ranked top-k table.

## When to use

Use when a molecular-networking anchor–suspect pair is known (anchor SMILES plus observed precursor mass difference) and a ranked list of derivative candidates is needed to assign the suspect's structure.

## When NOT to use

- No anchor molecule with high spectral similarity to the query spectrum has been identified — candidate generation and ranking depend on an anchor–suspect mass difference from a molecular network edge.
- SIRIUS-based molecular formula annotation has not succeeded for the query — the BAM workflow only performs structure annotation if the correct molecular formula was generated first.
- The task is full reaction-template promiscuity prediction rather than ranking candidate derivatives from one anchor — use PROXIMAL2's standalone pipeline instead.

## Inputs

- Candidate derivative SMILES generated by PROXIMAL2 for a given anchor–suspect pair
- Anchor molecule SMILES and suspect identifier from the molecules_of_interest CSV (with suspect and anchor masses)
- Biotransformation rule metadata identifying the reaction center atom for each applied rule
- GNN-SOM model state and configuration files from the HassounLab/GNN-SOM data directory

## Outputs

- Ranked candidate table of derivative structures ordered by predicted site-of-metabolism likelihood
- Top-5 ranked candidate list per suspect (with rank-1 assignments flagged)
- Per-derivative average rank in case of ties

## How to apply

After PROXIMAL2 has generated candidate derivatives for the anchor (using the observed precursor mass difference from the molecules_of_interest CSV to select matching biotransformation rules), convert each candidate derivative and the anchor to a molecular graph with RDKit. Run GNN-SOM, the PyTorch Geometric graph neural network, on each graph to obtain a per-atom site-of-metabolism likelihood. Assign each derivative candidate the likelihood of the atom to which its biotransformation rule was applied. Sort candidates by this likelihood, and when multiple candidates share a rank, apply the average-rank tie resolution: sum all ranks including duplicates and divide by the number of tied candidates. Validation is successful when the true suspect structure — defined by an exact match on the first 14 characters of the InChIKey — appears among the top-5 ranked candidates; the paper reports a 24.2% top-ranked assignment rate on 30,184 structurally unique anchor–suspect pairs derived from a global molecular network of 454,091 annotated nodes.

## Evaluation signals

- The true suspect structure is present in the top-5 ranked candidates, verified by an exact InChIKey match on the first 14 characters.
- Rank-1 assignments should appear in roughly 24% of cases across a large anchor–suspect validation set (paper reports 24.2%).
- When ranks are tied, the reported rank equals the sum of all ranks (including duplicates) divided by the number of tied candidates.
- Each derivative's ranking score is the GNN-SOM likelihood for the specific atom targeted by its biotransformation rule, not the maximum likelihood over all atoms.
- Every ranked candidate must correspond to one of the biotransformation rules whose mass difference matched the observed suspect–anchor precursor difference.

## Limitations

- Ranking accuracy depends on the candidate being generated in the first place — only ~41% of RetroRules rules matched observed precursor mass differences at unit resolution, so missed candidates cannot be recovered by ranking alone.
- SIRIUS comparison showed BAM's structure annotation had lower coverage than SIRIUS in some settings; the two methods are complementary rather than interchangeable.
- GNN-SOM scores are site-of-metabolism likelihoods trained on enzymatic reaction data; they do not incorporate MS/MS spectral features of the derivative.
- Tie handling via average rank may place a correct candidate in a fractional rank position rather than rank 1, so top-5 inclusion, not exact rank, is the success criterion.
