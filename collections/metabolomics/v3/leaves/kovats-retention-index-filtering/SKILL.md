# kovats-retention-index-filtering

## Summary

Restrict GC-MS library search matches against the GNPS reference library (19,808 spectra / 19,708 standards) to candidates consistent with a compound's Kovats retention index, improving annotation specificity of deconvoluted .mgf spectra beyond cosine-similarity spectral matching alone.

## When to use

Use when annotating deconvoluted GC-MS spectra from an .mgf file via GNPS library search and candidate spectral matches must be filtered by agreement with the compound's Kovats retention index.

## When NOT to use

- Input is raw, un-deconvoluted GC-MS chromatographic data — run MSHub/GNPS auto-deconvolution first, since library search expects deconvoluted compound fragmentation patterns
- The task is LC-MS/MS molecular networking or chemical-class enrichment (e.g. pyMolNetEnhancer workflows) rather than GC-MS EI spectral library search
- No reference library is loaded — filtering by Kovats retention index is only meaningful when applied to candidate matches from the GNPS GC-MS library search

## Inputs

- Deconvoluted GC-MS spectra in .mgf format (generated by GNPS-MSHub auto-deconvolution or imported from another tool)
- GNPS GC-MS reference library (19,808 spectra for 19,708 standards) plus optional public and user libraries
- Kovats retention index values for query compounds, where available

## Outputs

- library_search_annotations.tsv containing the best matching library standard and match score per query spectrum

## How to apply

Parse the freely released GNPS GC-MS reference library, verifying it contains exactly 19,808 spectra for 19,708 unique standards. Load the deconvoluted spectra from the input .mgf file produced by the MSHub/GNPS auto-deconvolution (unsupervised non-negative matrix factorization) step. Score each deconvoluted spectrum against library standards using the GNPS GC-MS library search with cosine similarity on fragment ions. Where a Kovats retention index is available for a compound, restrict candidate library matches to those consistent with that retention index before selecting the best hit. Write the best matching library standard per query spectrum, with match scores, to library_search_annotations.tsv.

## Related tools

- **GNPS** (Runs the GC-MS library search workflow (cosine similarity on fragment ions) against public, user, and the released reference libraries on the GNPS platform) — http://github.com/CCMS-UCSD/GNPS_Workflows
- **MSHub** (Upstream producer of the deconvoluted .mgf fragmentation patterns that serve as library-search queries) — https://github.com/bittremieux/GNPS_GC

## Evaluation signals

- Parsed reference library contains exactly 19,808 spectra for 19,708 unique standards
- library_search_annotations.tsv contains exactly one best-match entry with a match score per query spectrum
- Retained matches are consistent with the compound's Kovats retention index wherever an RI is available
- Match scores are computed by cosine similarity on fragment ions between query and library spectra

## Limitations

- Retention-index restriction can only be applied where a Kovats retention index is available for the compound; spectra without RI rely on spectral matching alone
- The workflow depends on the GNPS/ProteoSAFe web server, whose status is tracked by integration tests rather than a local changelog (no changelog found in the companion repository)
