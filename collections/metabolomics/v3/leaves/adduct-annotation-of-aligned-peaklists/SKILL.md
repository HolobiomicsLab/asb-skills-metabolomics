# adduct-annotation-of-aligned-peaklists

## Summary

Annotates aligned peaklists with potential adduct information as part of the IDSL.CSA deconvolution workflow, where correlating MS1 ions are grouped into composite spectra and their adduct relationships are flagged using the CSA_adduct_annotation output.

## When to use

Use when processing MS1-only untargeted LC/HRMS data (mzXML, mzML, netCDF) with IDSL.CSA and the aligned peak table needs potential adduct information attached to grouped correlating ions.

## When NOT to use

- When the input data already contains MS2 fragmentation spectra and a standard MS2-library search (e.g. via IDSL.FSA on a conventional MSP file) is preferred over MS1-only composite spectra annotation.
- When raw mass spectrometry data have not yet been processed by IDSL.IPA to generate the peaklists and peak_alignment directories — the adduct annotation step depends on those IDSL.IPA outputs.
- When the goal is simply grouping correlating ions to flag peaks as isotopologues or assign molecular formulas without producing reusable composite spectra libraries, since existing MS1 approaches already cover that narrower use case.

## Inputs

- Aligned peak table (peak_alignment directory) generated by the IDSL.IPA workflow
- Peaklists directory from the IDSL.IPA workflow containing individual and aggregated aligned peaklists
- MS1-level HRMS raw data in mzXML, mzML, or netCDF format
- IDSL.CSA parameter spreadsheet (CSA_parameters.xlsx) with CSA0005, CSA0008, CSA0009, and CSA0011 configured

## Outputs

- CSA_adduct_annotation folder containing peaklists with potential adduct information
- CSA_MSP folder with the .msp composite spectra library
- peak_alignment_subset folder with subsets of aligned peak tables for the major ions in each CSA cluster
- aligned_spectra_table with information for the CSA aggregation on the aligned table

## How to apply

After running the IDSL.IPA workflow on the mass spectrometry data to acquire chromatographic information of the peaks (m/z-RT), configure the IDSL.CSA parameter spreadsheet (CSA_parameters.xlsx) by setting PARAM0001 to YES to process the CSA workflow and pointing CSA0005 to the MS1-level HRMS data location, CSA0008 to the IDSL.IPA peaklists directory, CSA0009 to the IDSL.IPA peak_alignment directory, and CSA0011 to the output location. Run IDSL.CSA_workflow with the spreadsheet as input; during the chromatogram deconvolution step, correlating MS1 ions are aggregated into composite spectra (CSA) clusters, and the workflow flags potential adduct relationships among the major ions in each CSA cluster. The adduct assignment is written to the CSA_adduct_annotation folder, which contains the peaklists annotated with potential adduct information, complementing the CSA_MSP composite spectra library and the aligned_spectra_table aggregation output. This is one of four primary outputs (CSA_MSP, CSA_adduct_annotation, peak_alignment_subset, aligned_spectra_table) so verify the folder exists and inspect the adduct-labelled peaklists before using them for downstream chemical structure aggregation by InChIKey, SMILES, precursor type, or molecular formula.

## Examples

```
library(IDSL.CSA); IDSL.CSA_workflow("Address of the CSA parameter spreadsheet")
```

## Evaluation signals

- Confirm the CSA0011 output location contains a CSA_adduct_annotation folder whose peaklists carry potential adduct information for the major ions of each CSA cluster.
- Verify the CSA_MSP folder contains a .msp composite spectra library derived from the same run, since the adduct-annotated peaklists and the .msp library come from the same aggregation step.
- Check that the aligned_spectra_table includes information for the CSA aggregation on the aligned table, consistent with the adduct annotation applied to the aligned peaklists.
- Validate that PARAM0001 was set to YES and the required paths CSA0005, CSA0008, CSA0009, and CSA0011 were correctly configured in the parameter spreadsheet before the run.
- Downstream consistency: the adduct-labelled peaklists should support aggregation of annotated chemical structures using meta-variables such as InChIKey, SMILES, precursor type, and molecular formula (PARAM0006).

## Limitations

- The adduct annotation operates on MS1-only deconvoluted composite spectra, so coverage is limited to correlating MS1 ions and depends on the quality of the upstream IDSL.IPA peak detection and chromatogram deconvolution.
- Adduct assignments are flagged as 'potential adduct information' in the CSA_adduct_annotation peaklists; they are not validated MS2-based chemical identifications.
- Only four primary CSA output folders (CSA_MSP, CSA_adduct_annotation, peak_alignment_subset, aligned_spectra_table) are produced, so adduct information is only as comprehensive as the CSA clustering of major ions.
