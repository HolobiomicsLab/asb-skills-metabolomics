# molecular-structure-representation-translation

## Summary

Decodes spectra embeddings produced by the Spec2Mol encoder into candidate SMILES strings of molecular structures using a decoder pre-trained on a massive corpus of chemical structures, with RDKit validation of the reconstructed molecules.

## When to use

Use when you have four MS/MS spectra files ([M+H]+ and [M-H]- at 35% and 130% NCE) with spectra embeddings and need de-novo SMILES structures reconstructed by a pre-trained decoder.

## When NOT to use

- Input is a single spectrum CSV or spectra in other precursor/energy conditions than [M+H]+/[M-H]- at 35% or 130% NCE — the decoder expects the four specific input spectra files
- You only need spectra embeddings (encoder output) without molecular structure prediction — use the encoder filter stage instead
- SMILES structures already exist and you only need to compare against known reference structures rather than generate de-novo molecules

## Inputs

- Four spectra CSV files: pos_low_file ([M+H]+, 35% NCE), pos_high_file ([M+H]+, 130% NCE), neg_low_file ([M-H]-, 35% NCE), neg_high_file ([M-H]-, 130% NCE)
- Spectra embeddings generated by the Spec2Mol encoder (predict_embs.py output)
- Pre-trained decoder weights (trained on a massive dataset of chemical structures for translating between different molecular representations)

## Outputs

- predicted_smiles.csv containing SMILES sequences of the recommended chemical structures
- RDKit-validated SMILES strings for each reconstructed molecule

## How to apply

Set up the spec2mol conda environment (Python 3.7, RDKit from conda-forge, PyTorch 1.6.0 with torchvision from the PyTorch channel). First run predict_embs.py on the four input spectra CSV files — [M+H]+ and [M-H]- at 35% and 130% NCE, each with m/z values in column 1 and intensities in column 2 separated by commas — to obtain the spectra embeddings the encoder generates. Then load the pre-trained decoder, which was trained on a massive dataset of chemical structures for translating between different molecular representations, and initialize it with the spectra embeddings. Autoregressively generate SMILES token sequences from each embedding to reconstruct candidate molecular structures de-novo. Finally, parse and validate each generated SMILES string with RDKit to confirm chemical validity, and collect all predicted SMILES sequences into predicted_smiles.csv.

## Examples

```
conda create -n spec2mol python=3.7 && conda install rdkit -c rdkit && conda install pytorch=1.6.0 torchvision -c pytorch
```

## Evaluation signals

- Each output row of predicted_smiles.csv contains a SMILES string parseable by RDKit without error (the decoder's objective is to reconstruct valid SMILES representations)
- The conda environment has Python 3.7, RDKit, PyTorch 1.6.0 and torchvision installed before decoding
- predict_embs.py was run on all four input spectra files (pos_low, pos_high, neg_low, neg_high) before invoking the decoder
- Generated SMILES correspond to chemically valid molecules that Spec2Mol could reconstruct from the spectra embeddings
- Substructure signals identified in the spectra embeddings (e.g. presence of key molecular substructures) are reflected in the decoded structures

## Limitations

- The pre-trained decoder requires the specific four spectra conditions ([M+H]+ and [M-H]- at 35% and 130% NCE); other precursor or energy conditions are not covered
- The spectra encoder was trained on the NIST Tandem Mass Spectral Library 2020, a commercial dataset, so performance may degrade on spectra outside that distribution
- No changelog found in the repository, so version drift or reproducibility caveats must be tracked manually
