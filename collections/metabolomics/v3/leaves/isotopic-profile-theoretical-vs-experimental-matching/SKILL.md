# isotopic-profile-theoretical-vs-experimental-matching

## Summary

Assigns molecular formulas to LC/HRMS peaks by matching experimental MS1 isotopic profiles against theoretical isotopic profiles computed from candidate formulas, using IDSL.UFA with a pre-built IPDB formula source. This enables high-confidence MS1-only formula annotation for metabolomics and exposomics studies without requiring MS2 data.

## When to use

Use when annotating untargeted LC/HRMS peaks (mzXML, mzML, netCDF) with molecular formulas from only MS1-level data, especially when database-dependent tools (MetDNA, SIRIUS, ZODIAC) risk missing exposome compounds absent from biochemical databases.

## When NOT to use

- Input is already a formula-annotated feature table (apply downstream rank/frequency statistics instead of re-matching isotopic profiles)
- The analysis requires structural identification from MS2 spectra — UFA annotates formulas only and must be complemented by MS2-based annotation pipelines
- Elements outside C, B, Br, Cl, K, S, Si, N, H, As, F, I, Na, O, P are expected (that enumeration task belongs to IDSL.UFAx, not UFA/IPDB matching)

## Inputs

- Raw untargeted LC/HRMS mzXML, mzML, or netCDF files (MS1 level)
- peaklists directory generated by the IDSL.IPA workflow
- peak_alignment directory generated by the IDSL.IPA workflow
- IPDB (.Rdata) of pre-computed theoretical isotopic profiles for a formula source (e.g. IDSL.ExposomeDB, RefMetDB)
- UFA parameter spreadsheet (UFA_parameters.xlsx)

## Outputs

- Aligned annotated peak table with ranked molecular formula hits per peak (top rank <= 30, number of hits <= 30)
- Individual-file annotated peak tables
- Batch untargeted isotopic profile match figures
- Median-rank summaries (median rank <= 5) of formula annotations across samples

## How to apply

First process raw MS1-level HRMS data with the IDSL.IPA workflow (IPA_workflow/IPA_targeted) to extract peaklists (m/z-RT pairs) and the aligned peak table. Download or build an IPDB (Isotopic Profile DataBase) of theoretical isotopic profiles for your formula source, e.g. the IDSL.ExposomeDB IPDB with 209,592 and 129,122 ion formulas in positive and negative modes. Fill the 30-parameter UFA parameter spreadsheet (PARAM0004 = IPDB .Rdata address, PARAM0005/PARAM0006 = YES, PARAM0009 = HRMS data location, PARAM0011 = peaklists directory, PARAM0012 = peak_alignment directory, PARAM0014 = output location, PARAM0008 = threads), then run UFA_workflow. Rank candidate formulas for individual and aligned peak lists; report annotations filtered to top rank <= 30 and number of hits <= 30, using median rank <= 5 for confident per-peak formulas in aligned tables. Rationale: theoretical isotopic patterns derive from IUPAC atomic mass tables via combinatorial rules, and the MS1 match requires only formulas with plausible isotopic envelopes — no MS2 or database reaction network is needed.

## Related tools

- **IDSL.UFA** (Computes theoretical isotopic profiles for candidate molecular formulas and matches them against experimental MS1 isotopic profiles from LC/HRMS data; accepts UFA parameter spreadsheet + IPDB) — https://cran.r-project.org/package=IDSL.UFA
- **IDSL.IPA** (Preprocessing peak-picking step that generates the individual peaklists (m/z-RT) and aligned peak tables consumed by IDSL.UFA via IPA_workflow/IPA_targeted) — github.com/idslme/IDSL.IPA
- **R** (Runtime environment in which the IDSL.UFA and IDSL.IPA packages are installed and executed)

## Examples

```
library(IDSL.UFA); UFA_workflow("Address of the UFA parameter spreadsheet")
```

## Evaluation signals

- Top-hit formula assignment rates for MSI 1-3 annotated peaks fall in the reported 54.31-85.51% window across studies (ST001154 61.85%, ST001683 54.31%, MTBLS1684 70.58%, MTBLS2542 85.51%)
- Top-five-hit rates fall in the reported 90.58-100% window (ST001154 96.90%, ST001683 90.58%, MTBLS1684 100%, MTBLS2542 99.29%)
- Unique formulas on the aligned table respect the reporting filter top rank <= 30 and number of hits <= 30 (e.g. 199,837 unique molecular formulas in the paper's aligned table)
- Reported confident annotations have median rank <= 5 in the aligned annotated peak table
- Per-mode IPDB sizes match expectations (209,592 positive-mode and 129,122 negative-mode ion formulas for IDSL.ExposomeDB)

## Limitations

- Formula ranking is MS1-only; annotations are formula-level and must be complemented by tandem mass spectrometry for structural confirmation
- Version numbers of IDSL.UFA/IDSL.IPA used for the benchmark are not stated in the article, complicating exact reproduction
- IPDB-dependent matching is bounded by the formula source: compounds absent from the chosen IPDB cannot be annotated; use IDSL.UFAx exhaustive enumeration when the space is unknown
- The theoretical-profile approach presumes carbon-containing compounds and standard IUPAC isotopic abundances; performance depends on HRMS mass accuracy
