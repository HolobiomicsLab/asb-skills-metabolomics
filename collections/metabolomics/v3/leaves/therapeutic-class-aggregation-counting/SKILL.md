# therapeutic-class-aggregation-counting

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Aggregates LC-HRMS metabolite feature counts by the therapeutic class of the parent drug incubated with human liver S9, using the PharmMet Supplemental Table 1 mapping for 1114 drugs, to characterize which drug classes generate the most unpredicted BioTransformer 3.0 metabolites.

## When to use

Use when you have per-drug LC-HRMS feature counts (e.g., unpredicted BioTransformer features from the ST003991 human liver S9 study) and need per-therapeutic-class totals such as 486,215 features split by anti-inflammatory, antimicrobial, cardiovascular, and CNS drugs.

## When NOT to use

- Input is already a class-aggregated summary table rather than raw paired m/z–RT features linked to individual drug incubations
- The goal is to classify a single unknown metabolite feature rather than aggregate counts across drug classes

## Inputs

- Metabolomics Workbench ST003991 feature/annotation files containing paired m/z and RT entries for unpredicted metabolites detected at 24 hours
- Supplemental Table 1 drug-class mapping assigning each of the 1114 therapeutic drugs to its therapeutic class (from the PharmMet GitHub repository)
- Sample/plate metadata linking each feature to its parent drug incubation

## Outputs

- Per-therapeutic-class counts of unpredicted LC-HRMS features (e.g., 126,210 anti-inflammatory/immunomodulatory, 100,617 antimicrobial, 88,653 cardiovascular, 62,693 CNS)
- A per-drug and per-class aggregated table whose grand total equals 486,215 unpredicted features

## How to apply

Join each paired m/z–RT feature to its parent drug incubation using the deposited sample/plate metadata from Metabolomics Workbench Study ST003991, then map each drug to its therapeutic class via Supplemental Table 1 from the PharmMet GitHub repository. In R 4.0.3, aggregate the joined table by counting features per parent drug and then summing per class, verifying the grand total equals 486,215. Report per-class counts and confirm the distribution matches the paper's finding that anti-inflammatory/immunomodulatory (126,210), antimicrobial (100,617), cardiovascular (88,653), and CNS (62,693) drugs produced the most unpredicted features. The rationale is that therapeutic class is the pharmacologically meaningful unit for identifying which drug families produce metabolites BioTransformer 3.0 failed to predict.

## Related tools

- **R 4.0.3** (Used to join feature-to-drug metadata, map drugs to therapeutic classes via Supplemental Table 1, and perform the aggregation/counting.) — https://github.com/ClinicalBiomarkersLaborabory/PharmMet
- **GraphPad Prism 6.0** (Used for statistical analysis and data visualization of the per-class aggregated counts.) — https://github.com/ClinicalBiomarkersLaborabory/PharmMet

## Examples

```
Rscript aggregate_by_class.R --features st003991_features.csv --class-map SupplementalTable1.csv
```

## Evaluation signals

- Grand total of per-class counts must equal the reported 486,215 unpredicted LC-HRMS features.
- Per-class counts must reproduce the paper's top four classes: 126,210 anti-inflammatory/immunomodulatory, 100,617 antimicrobial, 88,653 cardiovascular, and 62,693 CNS.
- Every joined feature must have a valid parent drug and a valid therapeutic class assignment from Supplemental Table 1 (no unmapped drugs).
- Aggregation must be reproducible in R 4.0.3, matching the source study's analysis environment.

## Limitations

- Coverage depends entirely on the 1114 drugs included in PharmMet DB; the mapping is not completely comprehensive of all US drugs.
- Counts reflect only features detected in the human liver S9 incubation system at 24 hours; extrahepatic or non-liver-S9 biotransformations are not represented.
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression.
