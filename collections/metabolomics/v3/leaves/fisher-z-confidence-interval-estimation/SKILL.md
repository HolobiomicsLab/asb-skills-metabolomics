# fisher-z-confidence-interval-estimation

## Summary

Quantifies whether batch effect correction with dbnorm statistical models (ber, bagging ber, parametric/nonparametric ComBat) genuinely improves biological signal by transforming Pearson correlations (e.g., LC-MS vs clinical creatinine, raw r≈0.18 → corrected r≈0.61) into Fisher's z with 95% confidence intervals so raw and corrected coefficients can be formally compared.

## When to use

Use when you must decide if batch-corrected metabolomics data improves association with a clinical reference (e.g., LC-MS creatinine vs routine clinical creatinine) and need 95% confidence intervals on Pearson r to compare raw vs corrected data versions.

## When NOT to use

- The association must be computed with a rank-based (Spearman/Kendall) coefficient or the data are ordinal — Fisher's z interval assumes Pearson product-moment r and normality-based sampling assumptions.
- The variables are not paired per-participant (e.g., no per-sample linkage between the LC-MS feature and the clinical creatinine measurement) — the correlation and its interval are then meaningless.
- The goal is per-metabolite differential testing against batch, already handled by dbnorm's adjusted-R² scoring or limma regression with Bonferroni correction, rather than interval estimation of an association strength.

## Inputs

- log2-transformed SKIPOGH plasma metabolomics feature table in .csv format (samples in rows, features in columns, batch level in the first column)
- paired clinical measurements per participant (clinical creatinine, CKD-EPI for the 934 participants, plus age and sex covariates)
- batch-corrected datasets produced by dbnorm statistical models (lowess, ber, bagging ber, parametric ComBat, nonparametric ComBat)

## Outputs

- Per-correction-model comparison table (creatinine_correlation_regression_stats.csv) listing Pearson r, Fisher's z with 95% CI, and regression coefficients with Bonferroni-corrected p-values
- Assessment of whether corrected-data r significantly exceeds raw-data r based on non-overlapping 95% confidence intervals

## How to apply

Compute Pearson's r between the LC-MS metabolite feature and the clinical measurement separately for raw data and each batch-corrected data version generated by dbnorm models (lowess, ber, bagging ber, parametric ComBat, nonparametric ComBat). Transform each r to Fisher's z and derive a 95% confidence interval at alpha < 0.05, using the same 934 participants for raw, lowess- and ber-corrected comparisons. In the SKIPOGH evaluation this yielded raw r ≈ 0.18 (Fisher's z CI 0.12–0.24), lowess r ≈ 0.5 (z CI 0.48–0.60), and statistical-model-corrected r ≈ 0.61. Assemble r, Fisher's z with 95% CI, and regression coefficients/Bonferroni-corrected p-values (from lm on CKD-EPI adjusted for age and sex) into a comparison table such as creatinine_correlation_regression_stats.csv.

## Examples

```
ct <- cor.test(lcms_log2$creatinine, clinic$creatinine, method="pearson", conf.level=0.95)
```

## Evaluation signals

- Raw-data Pearson r must fall near 0.18 with 95% CI ≈ 0.12–0.24, confirming the known raw-data attenuation.
- Lowess-corrected data must show r ≈ 0.5 (Fisher's z CI 0.48–0.60), with statistical-model-corrected data (ber, bagging ber, parametric and nonparametric ComBat) reaching r ≈ 0.61.
- The confidence intervals of raw vs corrected r must support the reported monotonic improvement from ~0.18 to ~0.61 after correction.
- The regression of CKD-EPI on creatinine (adjusted for age and sex) must be non-significant in raw data but significant after appropriate correction (Bonferroni-corrected p < 0.05) for the 934 participants.
- The output CSV must contain one row per data version with columns for Pearson r, Fisher's z, 95% CI bounds, and regression statistics.

## Limitations

- Only creatinine was used to validate the correlation/interval workflow; the article does not generalize the exact r progression values to other metabolites.
- dbnorm itself does not report software version numbers or precise ComBat/ber version numbers used, complicating exact reproduction.
- Improvement depends on adequate correction: lowess- and nonparametric ComBat-corrected data retained residual batch association, and lowess filtered out some features (e.g., xanthosine 5′-monophosphate), which must be considered when comparing corrected versions.
