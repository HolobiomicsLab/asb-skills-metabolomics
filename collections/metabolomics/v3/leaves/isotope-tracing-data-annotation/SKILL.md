# isotope-tracing-data-annotation

## Summary

Annotates LC-MS features into empirical compounds (khipu trees) by building mass-distance networks over isotope and adduct patterns (e.g. 1.0034 Da 13C/12C, 22.9893 Da Na+), then converting subnetworks into 2-tier adduct-trunk/isotope-branch trees to infer neutral masses — applicable to both untargeted metabolomics and stable isotope tracing.

## When to use

Use when you have a preprocessed LC-MS feature table (e.g. from asari 1.9.2) and need to group degenerate ions (isotopologues/adducts) into empirical compounds with inferred neutral masses, especially for 13C isotope tracing experiments.

## When NOT to use

- When you already have an annotated list of empirical compounds with known formulas — khipu is a preannotation step for unlabeled feature tables, not a formula-refinement tool.
- When the goal is full annotation including tandem MS library matching, contaminants, or authentic-standard confirmation — the article notes complete annotation requires additional resources beyond khipu preannotation.
- When features are not m/z-resolved peak measurements (e.g. raw vendor files or spectra not yet peak-picked) — khipu requires a preprocessed feature table.

## Inputs

- Tab-delimited LC-MS feature table (first columns: feature ID, m/z, rtime, then intensities) from asari 1.9.2 or any preprocessing tool
- User-supplied isotope/adduct search patterns (optional, e.g. for chemical labeling or derivatization experiments)

## Outputs

- Empirical compound (khipu) trees in JSON format
- Empirical compound (khipu) trees in tab-delimited format
- Inferred neutral masses (M0) per empirical compound via linear regression

## How to apply

Start from a feature table (columns: feature ID, m/z, rtime, intensities) generated by preprocessing such as asari 1.9.2. Run khipu in the correct ionization mode (-m pos or -m neg), optionally tuning --ppm mass tolerance and --rtol retention-time tolerance. Khipu searches for mass-difference pairs (1.0034 Da for 13C/12C, 22.9893 Da for Na+), partitions the mass-distance network into per-adduct isotopic subnetworks, converts each to a directed acyclic graph, and uses a two-step optimization to align the adduct trunk and isotopic branches to the khipu grid; the neutral mass of the M0 compound is then obtained by linear regression on the matched m/z values. For isotope tracing, supply custom search patterns to overwrite defaults when the biochemical labeling scheme differs from the standard 13C/12C series. Output is an empirical compound tree in JSON and tab-delimited formats.

## Evaluation signals

- On the E. coli reverse-phase ESI+ test data (ecoli_pos.tsv, 3,602 features), khipu must annotate exactly 548 empirical compounds from 1,745 features.
- On the yeast ESI+ / ESI− data (MassIVE MSV000087434), khipu must yield 1,775 empirical compounds in ESI+ and 908 in ESI− mode.
- Every exported empirical compound JSON tree must be a directed acyclic graph with a unique root and at most one predecessor per node (DAG/rooted-tree constraint from the conversion step).
- For a known 13C-labeled compound (e.g. the 187.1686 neutral-mass compound matching acetylspermidine, C9H21N3O), the unlabeled samples must peak at M0 and the U-13C-labeled samples must peak at 13C/12C*9 (M9) — a 9-carbon envelope check.
- The inferred neutral mass must be reproducible by linear regression on the matched m/z values across the adduct/isotope grid for each empirical compound.

## Limitations

- Annotation of untargeted metabolomics data, including isotopic tracing data, is still not fully solved — khipu is a preannotation foundation, not a complete annotation pipeline.
- Adding extra adducts beyond the default grid improves feature coverage (yeast ESI+ features explained rose from 6,310 to 8,049) but increases ambiguity; the initial adduct patterns are trimmed to reduce ambiguity.
- Ions that enter the initial network by mistake or unresolved signals are removed from established khipus and sent off to form new ones — noisy networks can fragment into spurious empirical compounds.
- The isotopologue search pattern is experiment-dependent; default patterns must be overwritten for non-13C labeling or derivatization experiments.
- Benchmarking is deferred to future work in the original article.
