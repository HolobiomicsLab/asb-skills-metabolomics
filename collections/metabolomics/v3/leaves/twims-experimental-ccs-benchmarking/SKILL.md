# twims-experimental-ccs-benchmarking

## Summary

Benchmark in silico CCS predictions (e.g., Boltzmann-average CCS from the Snakemake CCS workflow) against Traveling Wave IM-MS (TWIMS) measurements, literature CCS database values, and the consensus average of the two, judging agreement against a ±3% percent-error criterion.

## When to use

Use when predicted CCS values (e.g., from an ML+DFT workflow) must be validated against TWIMS experimental values and literature CCS database values for metabolites in protonated/deprotonated/neutral states.

## When NOT to use

- The metabolite of interest has no TWIMS measurement and no literature CCS database entry, so no experimental reference set (and hence no consensus value) can be assembled.
- The prediction comes from a source other than the Snakemake CCS workflow and no ccs.txt with Boltzmann-average CCS values is available for comparison.
- The goal is annotating metabolites without authentic standards from scratch rather than validating CCS predictions against experimental references.

## Inputs

- ccs.txt file with Boltzmann-average CCS values from the Snakemake CCS workflow (ensemble or ensemble_fast folder)
- TWIMS experimental CCS values and instrumental parameters from Supporting Information Tables S1 and S2
- Literature CCS database values for the same metabolites in protonated/deprotonated/neutral molecular states
- SMILES structures of benchmark metabolites (atom counts 10–40) with their molecular states

## Outputs

- Agreement table listing metabolite, molecular state, calculated CCS, TWIMS reference CCS, literature reference CCS, consensus average, and percent errors against each reference set
- Pass/fail verdict of whether each comparison meets the ±3% agreement criterion

## How to apply

Load the computed Boltzmann-average CCS values from the workflow output file ccs.txt generated by the Snakemake CCS workflow (written to the ensemble or ensemble_fast folder). Load TWIMS experimental CCS values and instrumental parameters from Supporting Information Tables S1 and S2 for the 20 benchmark metabolites, and compile literature CCS database values for the same metabolites in their protonated/deprotonated/neutral molecular states. Compute the percent error of each calculated CCS value against (a) the TWIMS values measured in this work, (b) the literature values, and (c) the consensus average of the two reference sets. Assemble an agreement table listing metabolite, molecular state, calculated CCS, each reference CCS value, consensus value, and percent errors. Validate that calculated CCS values agree with each reference set within ±3%; note that state multiplicity matters (e.g., carnosine required five states: one neutral, three monoprotonated ions, and one doubly protonated ion).

## Evaluation signals

- Percent error between workflow-calculated CCS and literature experimental values must fall within ±3%.
- Percent error between workflow-calculated CCS and TWIMS values measured in this work must fall within ±3%.
- Percent error against the consensus average of the TWIMS and literature values must also fall within ±3%.
- The ccs.txt output must contain Boltzmann average CCS values and reside in the ensemble (or ensemble_fast) folder after job completion.
- All molecular states of each metabolite (e.g., five states for carnosine: one neutral, three monoprotonated ions, one doubly protonated ion) should be represented in the agreement table.

## Limitations

- Agreement was demonstrated only for 20 benchmark metabolites with atom counts ranging from 10 to 40; accuracy for metabolites outside this size range is not established here.
- Detailed workflow step descriptions are deferred to the Supporting Information, so reproducibility of the reference setup depends on SI Tables S1 and S2.
- No standardized procedures exist for IM data collection, collation, standardization, and sharing, making cross-source CCS reference comparisons inherently uncertain.
