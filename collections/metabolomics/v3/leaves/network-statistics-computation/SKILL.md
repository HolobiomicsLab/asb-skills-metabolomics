# network-statistics-computation

## Summary

Builds mass-difference transformation networks from FT-ICR MS peak pairs in Cytoscape (nodes = detected peaks colored by molecular class, edges = putative biochemical transformations) and computes per-network and per-transformation-type statistics exported as .csv tables and bar plots.

## When to use

Use when you have FT-ICR MS peak abundance data with assigned molecular formulas and need to construct transformation networks from mass differences and summarize network metrics.

## When NOT to use

- Input is raw FT-ICR MS spectra — molecular formula assignment must be performed before using MetaboDirect
- You need chemical isomer separation or LC-MS-level structural connectivity — DI-MS mass-difference networks cannot separate chemical isomers
- The goal is pathway-level annotation rather than ab initio mass-difference connectivity — use the KEGGREST query step instead

## Inputs

- Edge-list files from MetaboDirect's transformation calculation phase (mass differences with ≤1 ppm error vs reference biochemical transformation keys)
- Node metadata table of detected peaks with assigned molecular formulas (molecular class assignments)
- Cytoscape network session files

## Outputs

- Cytoscape transformation network visualization (nodes colored by molecular class, force-directed layout)
- Network statistics as .csv tables (per-network and per-transformation-type)
- Bar plot image files summarizing network metrics

## How to apply

Load the edge-list files produced by MetaboDirect's transformation calculation phase — mass differences retained with a maximum error of 1 ppm against reference biochemical transformation keys — into Cytoscape (3.8+, with the FileTransfer app for py4cytoscape connectivity). Import the node metadata table of detected peaks with assigned molecular formulas and map node fill color to molecular class via a discrete-mapping visual style, then apply a force-directed layout. Run the network_stats.R script generated by MetaboDirect (R 4+, tidyverse environment) on the network files to compute per-network and per-transformation-type statistics; MetaboDirect's Python stack (pandas, NetworkX, Matplotlib, seaborn) supports the underlying data handling. Rationale: nodes represent peaks detected in the different samples and edges represent putative chemical transformations, so statistics summarize how metabolites are biochemically connected within a sample or complex metabolic system. Export the statistics as .csv tables and render bar plots summarizing network metrics as image files, alongside the Cytoscape network visualization colored by molecular class.

## Evaluation signals

- Edge list entries correspond to mass differences with ≤1 ppm error against reference biochemical transformation keys
- Network nodes match detected peaks in the sample set and each node carries a molecular class annotation for color mapping
- Statistics outputs include both .csv tables and bar plot image files
- Network stats are reported per network and per transformation type (not only globally)
- All peaks passed the upstream filters: m/z range, 13C isotopic-formula removal, 0.5 ppm formula-assignment error, and user-defined minimum sample count

## Limitations

- Transformation networks are ab initio mass-difference based; edges are putative chemical transformations, not confirmed reactions
- DI-MS direct injection cannot separate chemical isomers and suffers signal suppression/enhancement that can confound downstream data analysis
- Requires Python 3.5+, R 4+, and Cytoscape 3.8+ with the FileTransfer library installed
