# continuous-per-ion-fdr-computation

## Summary

Reconstructs METASPACE-ML's computationally-efficient False Discovery Rate estimation by merging target and SD-weighted decoy ions into a single descending ranking and computing a Laplace-smoothed FDR value at every ion position.

## When to use

Use when you have METASPACE-ML prediction scores for target ions and sampled decoy ions with associated standard deviations (SD), and need per-ion continuous FDR confidence values rather than a single thresholded FDR cutoff.

## When NOT to use

- You only need a single global FDR threshold at one significance level rather than continuous per-ion confidence values
- Decoys were not generated by SD sampling, so no per-decoy standard deviation is available for weighting
- You are using the older rule-based MSM scoring system (Metabolite Signal Matching), which does not use this target-decoy FDR framework

## Inputs

- Scores table of METASPACE-ML prediction scores for target ions
- Scores of SD-sampled decoy ions with the standard deviation (SD) of each decoy's sampled similarities
- Target/decoy labels per ion

## Outputs

- fdr_estimates.csv containing per-ion continuous FDR values alongside prediction scores and target/decoy labels
- Validation report comparing computed FDR values against Supplementary Data 10

## How to apply

Load target and SD-sampled decoy prediction scores from the scores table into a pandas DataFrame, assigning each decoy a weight of 1/SD derived from the standard deviation of its sampled similarities. Merge targets and decoys into one ranking sorted in descending order by METASPACE-ML prediction score. Traverse the ranking with numpy cumsum to obtain cumulative weighted-decoy counts and target counts at each position. Apply the Laplace rule-of-succession pseudocount correction — (cumulative weighted decoy + 1) / (target count + 1) — to yield a smoothed, continuous FDR value for every ion. Rationale: METASPACE-ML's GBDT model is robust to noisy outliers, which can significantly impact the separation of target and decoy ions, making a single ranking-based FDR estimator computationally efficient; decoy SD weighting accounts for heterogeneous decoy similarity to targets.

## Examples

```
df = pd.concat([targets, decoys]).sort_values('pred_score', ascending=False); df['fdr'] = (np.cumsum(np.where(df.is_decoy, 1/df.sd, 0)) + 1) / (np.cumsum(~df.is_decoy) + 1); df.to_csv('fdr_estimates.csv', index=False)
```

## Evaluation signals

- Per-ion FDR values in fdr_estimates.csv agree with the reported scores/FDR table in Supplementary Data 10 across the prediction-score range
- FDR is monotonically non-decreasing as the ranking is traversed from highest to lowest prediction score
- Laplace correction ensures no FDR value is exactly zero (minimum value approaches 1/(target_count+1))
- Cumulative weighted decoy counts match the hand-computed sum of 1/SD weights over each ranking prefix
- Target and decoy ions are fully interleaved in a single ranking sorted in descending order by prediction score with no ties in sort order

## Limitations

- Decoy ions show heterogeneity in similarity to target ions; reliable decoy generation method needs further investigation — 'Further investigations are needed into how this affects FDR estimation and in finding the most reliable way of decoy generation'
- rho_chaos had only a minor impact on model performance and target-decoy separation was mainly driven by rho_spectral, so FDR estimates inherit this separation behavior
- QTOF-based datasets are underrepresented in the model due to lack of publicly available data needed for statistically reliable model evaluation
