# cluster-hit-propagation-to-spectra

## Summary

Annotate representative (medoid) spectra of de novo spectral clusters via open modification searching, then propagate each medoid's peptide-spectrum match (PSM) to all member spectra of its cluster, multiplying identifications at low compute cost.

## When to use

Use when a spectral clustering result (cluster labels plus medoid indexes) exists for unidentified MS/MS spectra and you want to annotate whole clusters by searching only one representative spectrum per cluster and fanning out the hit.

## When NOT to use

- Spectra have not been clustered — medoid selection and label propagation require an existing clustering (GLEAMS_cluster.npy with per-spectrum labels); without it, search every spectrum directly.
- Clusters span heterogeneous peptides — propagation assumes cluster members were generated by the same peptide, so low-quality embeddings or an inappropriate distance threshold (e.g. the 0.3 used with gleams cluster) will propagate incorrect labels.
- The analysis requires modification-level resolution per individual spectrum — propagation assigns the medoid's peptide to all members and does not capture member-specific variation.

## Inputs

- GLEAMS_cluster.npy — NumPy array of cluster labels per spectrum (-1 = noise, minimum cluster size 2)
- GLEAMS_cluster_medoids.npy — NumPy array of indexes of cluster representative (medoid) spectra
- Unidentified MS/MS spectra in peak files (e.g. mzML) corresponding to the clustered embeddings
- MassIVE-KB (v1) Human HCD spectral library for the ANN-SoLo search

## Outputs

- PSM identifications for cluster medoid spectra (ANN-SoLo search results filtered at 1% FDR)
- Propagated PSMs for all member spectra of annotated clusters (~44 million in the paper)
- Table of top 500 precursor mass differences from the open modification search of GLEAMS cluster centroids

## How to apply

Load cluster assignments from GLEAMS_cluster.npy and medoid indexes from GLEAMS_cluster_medoids.npy, selecting medoids of clusters of previously unidentified spectra while excluding noise points labeled -1. Run ANN-SoLo (v0.3.3) open modification search on only the medoid spectra against the MassIVE-KB (v1) Human HCD spectral library, which reduces the search space from millions of spectra to tens of thousands of cluster representatives. Filter the ANN-SoLo results at 1% FDR to retain confident PSMs, then propagate each medoid's peptide label to every member spectrum of its cluster using the GLEAMS cluster labels. In the GLEAMS paper this yielded ~5.3 million PSMs from 45 million medoid spectra and ~44 million additional propagated PSMs; the top 500 precursor mass differences from the open search of cluster centroids can also be compiled as a modification-profile summary. Validate by expert review that direct and propagated PSM counts match the reported ~5.3M/~44M figures and that FDR remains controlled at 1%.

## Related tools

- **GLEAMS** (Provides the learned 32-dimensional embeddings and hierarchical clustering (gleams cluster) that produce the cluster labels and medoid indexes used for propagation) — https://github.com/bittremieux/GLEAMS
- **ANN-SoLo** (Performs the open modification search of cluster medoid/centroid spectra against the MassIVE-KB (v1) Human HCD spectral library at 1% FDR)

## Examples

```
gleams cluster --embed_name GLEAMS_embed --cluster_name GLEAMS_cluster --distance_threshold 0.3
```

## Evaluation signals

- Direct PSM count from medoid search is approximately 5.3 million (as reported for 45 million cluster medoid spectra)
- Propagated PSM count is approximately 44 million after labeling cluster members
- All retained ANN-SoLo hits pass a 1% FDR filter
- Noise points labeled -1 in GLEAMS_cluster.npy are excluded from propagation
- Compiled precursor mass differences table contains the top 500 mass differences from the cluster-centroid search

## Limitations

- Propagation quality depends on the embedding/clustering fidelity; GLEAMS requires Python 3.8, Linux, and a CUDA-enabled GPU, and the distance threshold (e.g. 0.3) controls cluster purity.
- Git LFS bandwidth issues can block installation of the model weights; work around by cloning with GIT_LFS_SKIP_SMUDGE=1 and downloading gleams_82c0124b.hdf5 manually from the v0.3 release into the data/ directory.
- Members of a cluster receive the medoid's peptide identity without an individual spectrum-level validation, so incorrectly clustered spectra inherit wrong labels.
