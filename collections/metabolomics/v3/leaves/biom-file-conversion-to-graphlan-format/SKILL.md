# biom-file-conversion-to-graphlan-format

## Summary

Converts BIOM-format 16S abundance tables (e.g., from QIIME/mothur pipelines such as a saliva microbiome dataset) into the two GraPhlAn input files — a tree file and an annotation file — using export2graphlan, enabling rendering of a circular taxonomic tree with GraPhlAn.

## When to use

Use when the input abundance table is in BIOM format (e.g., QIIME or mothur output) and a circular taxonomic tree visualization with GraPhlAn is the target output.

## When NOT to use

- Input is already a MetaPhlAn/LEfSe-style tab-separated abundance table that does not need BIOM parsing (though export2graphlan still accepts it, the BIOM-specific path is unnecessary).
- The goal is an interactive tree explorer rather than a static publication-quality circular figure — tools like iTOL or Krona target interactive analyses instead.
- BIOM library (ver. 2.0.1) is unavailable and the input cannot be converted, since BIOM input support depends on the biom-format package.

## Inputs

- BIOM-format 16S abundance table (e.g., produced by QIIME or mothur pipelines, such as a saliva microbiome dataset)

## Outputs

- tree.txt — GraPhlAn tree file generated by export2graphlan
- annot.txt — GraPhlAn annotation file generated by export2graphlan
- outtree.txt — annotated tree produced by graphlan_annotate.py
- outimg.png — rendered circular taxonomic tree figure
- outimg_annot.png and outimg_legend.png — annotated figure and legend images

## How to apply

Add the export2graphlan directory to PATH (export PATH=`pwd`/export2graphlan/:$PATH) so export2graphlan.py is callable, ensuring pandas 0.13.1, BIOM 2.0.1 (for BIOM inputs), and SciPy are installed. Invoke export2graphlan.py with the BIOM file as LEfSe-style input via -i, requesting a tree file with -t and an annotation file with -a; defaults can be kept (def_clade_size 10, min_clade_size 20, max_clade_size 200, def_font_size 10, min_font_size 8, max_font_size 12, annotation_legend_font_size 10) or adjusted via the documented flags. The rationale is that export2graphlan accepts MetaPhlAn, LEfSe, and/or HUMaN-style tabular inputs including BIOM, automatically generating the annotation file that highlights important sub-trees. Then attach annotations with graphlan_annotate.py to produce an annotated tree, and render the circular taxonomic tree with GraPhlAn (matplotlib-backed), which also emits annotation-legend and biomarker-legend images. Validation consists of confirming all expected outputs exist and the rendered image is a non-empty circular tree figure.

## Related tools

## Examples

```
export PATH=`pwd`/export2graphlan/:$PATH; export2graphlan.py -i saliva_microbiome.biom -t tree.txt -a annot.txt
```

- BIOM input requires the biom-format library (ver. 2.0.1) in addition to pandas 0.13.1 and SciPy; without it, BIOM files cannot be parsed.
