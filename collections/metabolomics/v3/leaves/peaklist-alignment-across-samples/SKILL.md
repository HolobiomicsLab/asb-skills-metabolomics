# Peaklist alignment across samples

## Summary

Cross-reference and align per-sample IDSL.IPA peaklists (m/z–RT pairs) into a single study-level matrix by correcting retention time drift with a dynamic pool of indigenous retention index reference markers. This removes systematic RT drift so that the same chemical signal is matched across hundreds to thousands of LC/HRMS samples.

## When to use

Use when per-sample IDSL.IPA peaklists (m/z–RT pairs from mzXML/mzML/netCDF HRMS files) must be RT-corrected and cross-referenced into one aligned table for a population-scale untargeted LC/HRMS study.

## When NOT to use

- A single HRMS file is being processed with no cross-sample alignment needed (RT correction across batches has no reference pool to draw from).
- The aligned data matrix already exists and the goal is adduct/fragment identification, statistics filtering, or molecular formula annotation — those are handled by IDSL.UFA/IDSL.UFAx downstream.
- The dataset lacks recurring indigenous reference peaks, so the dynamic retention index marker pool and its median-drift fallback cannot be reliably constructed.

## Inputs

- Per-sample IDSL.IPA peaklists (m/z–RT pairs per HRMS file, generated by the IPA_workflow function)
- IPA parameter spreadsheet configuring the IDSL.IPA pipeline run
- Raw untargeted LC/HRMS files (mzXML, mzML, or netCDF) from which peaklists were extracted

## Outputs

- Aligned peak table CSV containing corrected retention time columns for every sample
- Study-level aligned peak intensity matrix with cross-referenced peaks across samples
- peak_alignment directory consumed by downstream IDSL.UFA annotation

## How to apply

Load the per-sample IDSL.IPA peaklists (m/z–RT pairs extracted from each raw HRMS file, e.g. Thermo Orbitrap .d converted to mzXML/mzML/netCDF) and build a dynamic pool of indigenous (endogenous) reference peak markers by clustering recurring m/z–RT pairs across samples. For each peak in a sample, locate the nearest preceding and following reference markers and apply the retention-index correction (equation 5) to estimate and remove the systematic retention time drift. Repeat the correction over several steps, re-estimating drift from the reference-marker pool to increase statistical significance; when a sample lacks sufficient local markers, fall back to the median drift of the reference marker pool. Write the corrected retention time columns for every sample into a single CSV aligned table, and use the pipeline's parallel computation of the alignment step for studies of hundreds to >1,600 samples. As an alternative/comparison, polynomial regression RT correction can be evaluated against the retention index method on the same study.

## Related tools

- **IDSL.IPA** (Implements the dynamic retention index marker approach for retention time correction and cross-referencing peaks from multiple samples; alignment step runs in parallel for large studies) — https://github.com/idslme/IDSL.IPA
- **R** (Runtime environment; IDSL.IPA is an R CRAN package whose IPA_workflow function is driven by a parameter spreadsheet) — https://cran.r-project.org/package=IDSL.IPA

## Examples

```
library(IDSL.IPA); IPA_workflow("IPA_parameters.xlsx")
```

## Evaluation signals

- Corrected retention times show reduced systematic RT drift across samples compared with uncorrected RTs (as reported for MTBLS136, n=1,649).
- Every sample's peaks have a corrected RT entry; samples with too few local reference markers fall back to the median drift of the marker pool rather than dropping peaks.
- The aligned CSV contains one corrected RT column per sample, and peak m/z values are consistent with the recurring reference-marker clusters across samples.
- Corrected RT variation from the retention index method is compared against polynomial regression-based correction as a sanity check.
- Alignment completes in reasonable time on population-scale studies (200–1,600 samples) when the parallel computation option for the alignment step is enabled.

## Limitations

- The correction relies on indigenous reference peaks; samples with insufficient local markers fall back to median drift, which is less precise locally.
- Aligned IDSL.IPA data matrices still require further downstream processing for adducts, fragments, statistical filtering, and molecular formula annotation.
- The alignment is one component of a pipeline that assumes upstream 12C/13C isotopologue pairing and peak quality thresholds have already been applied.
