# Pathway enrichment with Fisher's exact test and Gamma-modeled null p-values

## Summary

A statistical procedure within mummichog that tests pathway enrichment of significant m/z features using Fisher's exact test with the EASE score, and computes p-values against a Gamma-modeled null distribution generated by random permutations of m/z features.

## When to use

Use when analyzing untargeted LC/MS metabolomics feature tables (significant vs reference m/z lists) to identify which metabolic pathways are enriched without prior metabolite identification.

## When NOT to use

- When metabolites are already confidently identified and standard pathway over-representation on named metabolites suffices — mummichog's FET-on-m/z approach is designed to bypass metabolite identification, not replace well-annotated analyses
- When the goal is definitive metabolite identification — mummichog is not designed to replace tandem mass spectrometry in metabolite identification

## Inputs

- Significant list of m/z features (e.g. 601 features selected by cutoff from the moDC YF17D vs mock LC/MS experiment)
- Reference list of all 7,995 spectral features detected after quality control (Dataset S1 feature table)
- Genome-scale metabolic model with pathway definitions (KEGG/UCSD Recon1/Edinburgh human metabolic network, or BioCyc human model)

## Outputs

- Per-pathway enrichment statistics with Fisher's exact test / EASE score, raw and adjusted p-values
- Gamma-modeled null p-value distribution parameters from random permutations of m/z features
- JSON strings from pathway analysis for programmatic use, plus result.html tables

## How to apply

Provide mummichog with two lists of m/z features: a significant list (e.g. 601 features selected by univariate statistics with a cutoff from the moDC YF17D vs mock data) and the reference list of all 7,995 features detected after quality control. Run mummichog's pathway analysis, which performs Fisher's exact test (FET) on pathway enrichment against the genome-scale human metabolic model built from KEGG, UCSD Recon1, and the Edinburgh human metabolic network; adopt the EASE score for robustness on small overlap counts. Compute the null p-value distribution by random permutations of m/z features and model it as a Gamma distribution, then report an adjusted p-value per pathway. Output JSON strings from pathway analysis for programmatic use alongside result.html tables. An alternative human model from BioCyc can be used to confirm comparable results.

## Evaluation signals

- Adjusted p-values are reported per pathway and the null distribution follows a Gamma model fitted to permutation p-values
- On the moDC YF17D data, the arginine/citrulline (nitric oxide synthase) pathway and the glutathione/GSSG pathway show significant enrichment consistent with the reported findings
- Results are robust when the alternative BioCyc human metabolic model is used (comparable results, Figure S6)
- Pathway analysis output is emitted as JSON strings parseable for programmatic use, alongside result.html

## Limitations

- A single m/z feature may match several metabolites in the same module/pathway, inflating the overlap number and the enrichment statistic
- The basic FET is computed on tentative matches, since a single m/z feature can match multiple metabolites even with high instrumental accuracy
- Quantification and feature selection, the steps upstream of mummichog, can still be problematic and affect enrichment results
