# chemical-formula-count-parsing

> **License: restricted** — no clear open-source license detected for the underlying tool; verify licensing before commercial use or redistribution. <!-- asb-license-banner -->
## Summary

Parses chemical formula strings into per-element integer counts (over the 18 elements MIST-CF considers) and encodes each count via a non-negative sinusoidal embedding, yielding the 144-dimensional Enc(F) vector consumed by the Formula Transformer.

## When to use

Use when featurizing a chemical formula candidate (e.g. a precursor formula from MIST-CF/SIRIUS decomposition) into a fixed-length numerical vector for a neural network, or when reproducing MIST-CF's count-based formula encoder.

## When NOT to use

- The input is already a numeric feature table or embedding — this skill only converts formula strings to counts and embeddings.
- Only raw spectra are available with no formula candidates — candidate generation (SIRIUS decomp or BUDDY) must happen first.
- Negative-mode or MS1-only data without an accompanying formula candidate to encode.

## Inputs

- Chemical formula candidate string (e.g. precursor formula candidate, possibly user-defined via notebooks/demo_mist_cf.ipynb)
- Ordered list of the 18 elements considered by MIST-CF
- Maximum period / embedding size (8 dims, i.e. log2(256), periods 1–256)

## Outputs

- Per-element count array (18 integers) for the parsed formula
- 144-dimensional non-negative integer encoding vector Enc(F) ∈ R^144 for input to the Chemical Formula Transformer
- encoder_verification_report.txt recording dimensionality and non-negativity checks

## How to apply

Parse each candidate formula string (e.g. generated by SIRIUS's dynamic-programming `SIRIUS decomp` module or user-defined candidates from `notebooks/demo_mist_cf.ipynb`) into integer counts for each of the 18 supported elements. For every element count v, compute an 8-dimensional embedding (= log2(256)) using sinusoidal features at periods 1, 2, 4, ..., 256 (powers of two up to 256), as specified in Equation 5 of the paper. Apply an absolute-value (non-negative) transformation so all components are ≥ 0, mirroring the scheme from SCARF's sinusoidal formula embeddings. Concatenate the 8-dim embeddings across all 18 elements to assemble Enc(F) ∈ R^144, which is then passed into the Chemical Formula Transformer alongside spectrum-peak and instrument-type covariates. Implement with NumPy (or torch) inside the MIST-CF codebase and unit-test on edge cases such as count 0 and large counts before wiring into training or inference.

## Related tools

```
Enc = mist_cf.featurize.formula_to_enc('C8H12NO5', elements=DEFAULT_ELEMENTS)  # returns (144,) non-negative vector
```

## Evaluation signals

- Enc(F) has exactly 144 dimensions (18 elements × 8 embedding dims) for every test formula
- All entries of Enc(F) are ≥ 0 (non-negativity invariant after absolute-value transform)
- Edge-case tests: count 0 and large counts produce valid, finite embeddings
- Min entry of the output array is 0 when any element count is 0 (no artificial floor introduced)
- Output vector feeds a downstream model without shape errors (assert shape (144,))

## Limitations

- Only the 18 elements considered by MIST-CF are supported; formulas containing other elements will fail or be dropped
- Purely counts-based; encodes no positional or graph-structured information about the formula
- Qualitative acceptance only (shape and non-negativity), as the paper does not report a separate quantitative evaluation metric for this encoder
- Models (and hence this encoder) were trained only for positive-mode data
