# prediction-accuracy-statistics

## Summary

Quantify the accuracy of in silico CCS predictions from the snakemake_ccs workflow by computing percent errors of Boltzmann-averaged and single-conformer CCS values against experimental TWIMS reference values, using the paper's ±3% agreement criterion.

## When to use

Decision support for judging whether computationally predicted collision cross sections agree with experimental TWIMS CCS values within ±3%, per metabolite or per adduct state.

## When NOT to use

- Input is raw MS peak list data rather than already-computed CCS values needing accuracy assessment against a reference.
- The user wants to compare a molecular ML model (e.g. MI-CCS-style pre-trained models) to the QM workflow, rather than evaluate the snakemake_ccs workflow's own predictions.
- The metabolite set falls outside the benchmark scope of atom counts 10–40 with protonated/deprotonated adduct states explored here.

## Inputs

- ccs.txt file with Boltzmann average CCS values per metabolite (from snakemake_ccs ensemble/ensemble_fast folder)
- HPCCS trajectory outputs containing individual conformer CCS values and relative energies
- Experimental TWIMS CCS reference values from Supporting Information Tables S1 and S2

## Outputs

- ccs_averaging_comparison.csv with per-metabolite percent errors for Boltzmann-averaged and global-minimum-conformer CCS
- Summary statistics of error distributions against the ±3% agreement threshold

## How to apply

Load the ccs.txt file generated by the snakemake_ccs workflow in the ensemble (or ensemble_fast) folder, which contains the Boltzmann average CCS values per metabolite, and extract individual conformer CCS values and relative energies from HPCCS trajectory outputs to identify the global-minimum conformer. Load experimental TWIMS CCS reference values from Supporting Information Tables S1 and S2. For each of the 20 benchmark metabolites (atom counts 10–40) and each protonated/deprotonated adduct state ([M + H]+ or [M − H]−), compute the percent error of both the Boltzmann-averaged CCS and the global-minimum-conformer CCS against the experimental TWIMS value. Judge agreement using the paper's ±3% criterion — values that fall within ±3% of experimental CCS are deemed in good agreement. Compare the two error distributions to assess whether Boltzmann averaging outperforms reliance on the single global-minimum conformer (e.g. for L-tryptophan model 3, the Boltzmann average of 159.69 Å² beat the global-minimum conformer's 166.44 Å² against the experimental 154.22 Å²). Write per-metabolite error tables and summary statistics to ccs_averaging_comparison.csv.

## Related tools

- **Snakemake** (Workflow manager whose ccs.txt output supplies the Boltzmann-averaged CCS values used as the computed predictions to score.) — https://github.com/DasSusanta/snakemake_ccs
- **HPCCS** (Produces per-conformer CCS trajectory outputs from which the global-minimum conformer CCS and relative energies are extracted for comparison.) — https://github.com/cepid-cces/hpccs

## Examples

```
python compare_ccs.py --predictions ensemble/ccs.txt --trajectory hpccs_outputs/ --twims_reference tables_S1_S2.csv --output ccs_averaging_comparison.csv
```

## Evaluation signals

- Every metabolite's percent error is computed against its specific experimental TWIMS CCS value from Tables S1/S2, not against a literature-only average.
- The error table separates Boltzmann-averaged CCS errors from global-minimum-conformer CCS errors per metabolite.
- Errors that fall within ±3% of the experimental value are flagged as in good agreement, matching the paper's stated threshold.
- For the L-tryptophan model 3 example, the reported Boltzmann-averaged CCS (159.69 Å²) must yield a lower percent error than the global-minimum conformer CCS (166.44 Å²) against the experimental CCS (154.22 Å²).
- The output CSV (ccs_averaging_comparison.csv) contains one row per benchmark metabolite (20 metabolites and their adduct states).

## Limitations

- Accuracy is judged against TWIMS CCS values, so agreement depends on the traveling-wave instrument calibration and the ±3% acceptance band may not transfer to other IM-MS platforms.
- Only protonated/deprotonated/neutral molecular states and atom counts 10–40 were benchmarked; CCS accuracy for larger or more exotic adducts is not established here.
- The workflow's agreement claims are supported by both literature CCS values and values measured in this study; using this skill with a different experimental reference may shift the error distribution.
- No standardized procedures exist for IM data collection, collation, standardization, and sharing, so cross-study comparison of percent errors is inherently limited.
