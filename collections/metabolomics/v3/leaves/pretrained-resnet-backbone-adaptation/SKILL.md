# pretrained-resnet-backbone-adaptation

## Summary

Adapts a pretrained ResNet18 backbone as the twin parameter-sharing encoder of a self-supervised contrastive model (DeepION, built on SimSiam), so each ion image is transformed into a 512-dimensional representation vector without manual annotation.

## When to use

Use when building a self-supervised representation model for ion images (MSI) where a pretrained CNN backbone must be converted into a twin shared-parameter encoder feeding projection/prediction MLPs and a SimSiam-style contrastive loss with stop-gradient.

## When NOT to use

- The downstream goal is supervised classification with labeled ion images rather than self-supervised representation learning without manual annotation.
- Input data are not ion images from MSI (e.g. spectra-only profiles without spatial X*Y pixel structure), since the ResNet18 encoder expects 2D image-like inputs.
- Only a single (non-paired) view per ion image is available, because the twin encoder and SimSiam contrastive loss require two augmented views of the same image.

## Inputs

- Two augmented ion image views generated by the T_COL (color jitter, filtering, Poisson noise, random missing value) or T_ISO (adds intensity-dependent missing value) augmentation module
- Pretrained ResNet18 backbone (torchvision)
- Preprocessed MSI matrix data with two-dimensional shape [X*Y, P] (e.g. DATASET/Pos_brain_data_matrix.txt)

## Outputs

- 512-dimensional representation vectors r1 and r2 for each of the two augmented views
- Projection outputs h1 and h2 (from the 3-layer MLP) and prediction outputs p1 and p2 (from the 2-layer MLP)
- SimSiam-style contrastive loss value used to update encoder and prediction module

## How to apply

Instantiate the encoder f(·|θf) as twin networks that share identical parameters and adopt the pretrained ResNet18 as the backbone network; the encoder takes two augmented views (produced by T_COL or T_ISO augmentation) of the same ion image and outputs two 512-dimensional representation vectors r1 and r2. Downstream, attach the projection module g(·|θg) as an MLP of three fully connected layers mapping representations to h1 and h2, then the prediction module as an MLP of two fully connected layers mapping projections to p1 and p2 to prevent collapse. Train with the SimSiam-style contrastive loss: apply the stop-gradient operation so the encoder on x2 receives no gradient from h2 in the first loss term but receives gradients from h2 in the second term, and vice versa for x1. Optimize the encoder and prediction module with Adam (learning rate 0.0003, beta1 0.5, beta2 0.99), initializing all DeepION model parameters from a normal distribution N(0, 0.02). The rationale for the pretrained backbone is that it extracts high-level spatial features from ion images without manual labels, which the 512-d embedding then supports distance-based similarity measurement for colocalized and isotope ion identification.

## Evaluation signals

- The encoder produces 512-dimensional (d = 512) representation vectors for each of the two augmented input views.
- The twin encoders share identical parameters (a single set of weights updated from both branches).
- The contrastive loss executes the asymmetric stop-gradient: encoder on x2 receives no gradient from h2 in the first loss term but gradients from h2 in the second term, and vice versa for x1.
- All model parameters initialize from N(0, 0.02) and the Adam optimizer uses lr = 0.0003, beta1 = 0.5, beta2 = 0.99 during training.
- Training on a rat brain MSI dataset reproduces the paper's downstream benchmark, e.g. the COL mode reaching about 86.73% colocalization classification accuracy, roughly 25% above the second-best SimSiam model.

## Limitations

- The reduced dimension is set to 20 downstream by a trade-off between space–time complexity and information utilization, so the 512-d encoder output is not the final embedding size.
- The prediction module is required to avoid the model producing collapse results; omitting it can lead to degenerate representations.
- Training was performed on a workstation with an Nvidia GTX 2080Ti GPU; resources may be a constraint for larger MSI matrices.
- The stop-gradient asymmetry is subtle to implement correctly; misplacement breaks the SimSiam anti-collapse mechanism.
