# metabolic-network-visualization-export

## Summary

Interactive visualization and export of metabolomic networks generated by MetaMapR, covering edge-type hierarchy tuning, node-ID-to-uploaded-row mapping, and export of edge-list/node-attribute CSVs, SVG graphics, and Cytoscape-ready tables for downstream network analysis.

## When to use

Use when metabolite association networks (biochemical, structural, spectral, or empirical edges) have been calculated and need interactive thresholding, node attribute mapping, or export to CSV/SVG/Cytoscape for interpretation.

## When NOT to use

- The metabolite table has not yet passed identifier translation (CTSgetR to KEGG/PubChem CIDs) or network calculation — there are no edges to visualize or export
- The analysis goal is pathway-enriched network mapping rather than pathway-independent metabolite association networks
- A pre-existing Cytoscape network only needs layout or styling, not re-export of MetaMapR edge lists or node-ID mapping

## Inputs

- Combined metabolomic network edge list computed in MetaMapR (biochemical, structural, spectral, empirical edge types)
- Uploaded metabolite data table (e.g. GC-TOF-MS plasma metabolite measurements with BinBase identifiers for unknowns)
- Node attributes including identifier-to-numeric-ID mapping
- User-set edge thresholds (Tanimoto >0.7, cosine correlation >0.7, Spearman FDR p<0.05)

## Outputs

- Edge list comma separated value (.csv) file
- Node attributes comma separated value (.csv) file
- Network graphic exported as SVG
- Cytoscape session with empirical and domain-knowledge variables mapped to node attributes

## How to apply

After computing the combined network in MetaMapR from KEGG RPAIR biochemical transformations, PubChem Substructure Fingerprint Tanimoto similarity (>0.7), mass spectral cosine correlation (>0.7), and Spearman empirical correlations (FDR p<0.05), use the network tab's 'unique edges' checkbox to decide whether edges are returned by the hierarchy Biochemical > Structural > Mass Spectral > Correlation or all edge types are kept. Numeric node IDs are assigned by uploaded data row order (node 1 = first row analyte); verify the mapping in the node attributes tab, or supply a unique custom ID under network > more options > edge index. Export the edge list and node attributes as comma-separated (.csv) files and optionally the graphic as SVG; import the CSVs into Cytoscape and map empirical and domain-knowledge variables onto node attributes for figure-level enhancement. Judge success when the exported CSVs parse as delimited files, node identifiers correspond to uploaded metabolites, and edge types/thresholds match those set during calculation.

## Related tools

- **MetaMapR** (R/Shiny web or desktop application that renders interactive metabolomic networks, supports edge-threshold tuning and the unique-edges hierarchy, exposes the node attributes tab for ID mapping, and exports CSV edge lists/node attributes and SVG graphics) — https://github.com/dgrapov/MetaMapR
- **Cytoscape** (Import of MetaMapR-exported network tables for downstream enhancement by mapping empirical and domain-knowledge-based variables to node attributes)
- **Shiny server** (Hosts MetaMapR as a standalone web application so the interactive visualization UI is available over the web) — https://github.com/rstudio/shiny-server

## Examples

```
sudo cp -R ~/MY-APP /srv/shiny-server/ && open http://<hostname>:3838/MY-APP/  # host MetaMapR's Shiny UI, then export edge list and node attributes as .csv from the network and node attributes tabs
```

## Evaluation signals

- Exported edge-list and node-attribute files exist and parse as delimited (.csv) files
- Numeric node identifiers in the edge list correspond to rows in the uploaded metabolite data (node 1 = first-row analyte), verifiable via the node attributes tab
- Edge types present in the export match the unique-edges setting (hierarchy Biochemical > Structural > Mass Spectral > Correlation) if selected
- Retained edges respect the chosen thresholds, e.g. Tanimoto score >0.7 and cosine correlation >0.7
- Imported network in Cytoscape reproduces the MetaMapR edge count and supports node attribute mapping without orphan nodes

## Limitations

- KEGG's limited description of the directionality of biochemical transformations constrains what biochemical edges mean in the visualized network
- By default, numeric node IDs reflect uploaded row order, so any row reordering between export and downstream analysis breaks the ID-to-metabolite mapping unless a custom unique edge index ID is used
- Custom node IDs must be unique; non-unique IDs will break edge indexing
