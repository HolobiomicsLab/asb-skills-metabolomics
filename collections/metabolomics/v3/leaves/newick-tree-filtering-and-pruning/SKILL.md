# newick-tree-filtering-and-pruning

## Summary

Filters an NCBI lineage taxonomy tree to only taxa whose spectra matched in a domainMASST batch search, aggregates match counts and proportions across ranks, and converts the result into a D3-consumable JSON hierarchy for rendering an interactive taxonomic HTML tree.

## When to use

Use when you have microbeMASST/microbeMASST-style batch search outputs (_matches.tsv, _count_microbe.tsv) plus NCBI lineage Newick/JSON taxon data and need a lineage-consistent taxonomic tree showing which microbes may produce a queried metabolite.

## When NOT to use

- Input is a per-scan search result alone (_matches.tsv, _library.tsv, _datasets.tsv) with no taxonomic lineage data — the tree cannot be built without NCBI lineage information.
- You only need library hits for MSI Level 2 annotation; use _library.tsv output rather than taxonomic tree pruning.
- The batch search output has not been re-run to convergence (skip_existing=True) — incomplete matches would produce a tree missing taxa.

## Inputs

- _matches.tsv per-scan match results from a domainMASST batch search
- _count_domain.tsv per-domain match counts (e.g. _count_microbe.tsv)
- NCBI taxonomy lineage table / Newick or JSON lineage tree for domainMASST taxa
- Optional: _microbe.json JSON tree file generated by the batch search

## Outputs

- Filtered, lineage-consistent JSON taxonomic hierarchy with per-node match counts and proportions
- Interactive D3 HTML tree file (e.g. _microbe.html) with per-taxon match-proportion pie charts
- JSON tree file (e.g. _microbe.json) encoding the filtered hierarchy

## How to apply

Load the per-scan match results (_matches.tsv) and per-domain match counts (_count_microbe.tsv) from the jobs.py batch search alongside the lineage table for the NCBI taxonomy IDs used by the domainMASST (e.g. microbeMASST covers 8 kingdoms, 20 phyla, 48 classes, 124 orders, 278 families, 561 genera, 1379 species, 542 strains). Aggregate matches per taxon at every rank, propagating counts up through kingdom, phylum, class, order, family, genus, species, and strain levels. Filter the full lineage Newick/JSON tree to retain taxa with at least one match, then attach per-node match counts and proportion values to the hierarchy. Convert the filtered tree into a JSON object consumable by D3 JavaScript and render it as an HTML file (e.g. _microbe.html) with collapsible nodes and per-taxon match-proportion pie charts; a matching JSON tree file (e.g. _microbe.json) is also emitted. Validate that per-taxon counts reconcile with the _count_domain.tsv totals.

## Related tools

- **microbeMASST** (Source of batch search outputs that feed the tree filtering; provides the domain-specific taxonomy coverage) — https://masst.gnps2.org/microbemasst/
- **Fast Search API** (Backend used by jobs.py to execute the batch MS/MS search whose results are mapped onto the taxonomy tree) — https://fasst.gnps2.org/fastsearch/
- **jobs.py** (Script that runs the batch search and generates _matches.tsv, _count_domain.tsv, _microbe.json and _microbe.html outputs that this skill consumes) — https://github.com/robinschmid/microbe_masst/blob/master/code/jobs.py

## Examples

```
python code/jobs.py && ls output/*_microbe.html output/*_microbe.json output/*_count_microbe.tsv
```

## Evaluation signals

- Per-taxon match counts in the rendered HTML tree reconcile with the totals in _count_microbe.tsv.
- Output _microbe.html is non-empty, renderable HTML containing a complete lineage-consistent tree.
- Taxon nodes display taxon name, NCBI ID, file counts, and match proportion visualized as pie charts.
- Filtered tree covers every matched lineage rank (kingdom, phylum, class, order, family, genus, species, strain) with propagated counts.
- A companion _microbe.json tree file is generated alongside the HTML output.

## Limitations

- Some Fast Search API calls fail during the batch search; jobs.py must be re-run a couple of times with skip_existing=True until no new output is generated, otherwise the tree will be incomplete.
- Per the README, _matches.tsv also includes samples not part of the curated domain-specific MASSTs, so upstream filtering is needed before taxonomic propagation.
- Python 3.10 is required by the pipeline.
- No changelog exists to track changes to the lineage data or tree-building code.
