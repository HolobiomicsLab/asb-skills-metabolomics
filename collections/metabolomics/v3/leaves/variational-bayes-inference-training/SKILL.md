# variational-bayes-inference-training

## Summary

Train an MS2LDA latent Dirichlet allocation model on preprocessed MS/MS spectra using variational Bayes inference so the whole fragmentation dataset is decomposed into co-occurring fragment/neutral-loss sets called Mass2Motifs, enabling unsupervised substructure discovery and spectral connectivity in metabolomics.

## When to use

Use when you have preprocessed bag-of-fragments MS/MS spectra (e.g. a GNPS MGF set of 5,670 spectra or a ~1,000-peak beer extract) and need unsupervised decomposition into Mass2Motifs rather than supervised spectral matching.

## When NOT to use

- Input is already a spectral-similarity feature table or a Molecular Networking result — MS2LDA is unsupervised and needs raw bag-of-fragments documents, not precomputed similarities
- Spectra come from simple mixtures with sparse, information-poor MS2 (single fixed collision energy and few fragments) — the paper notes MS2LDA 'works best for complex mixtures where a large number of metabolites are fragmented and information-rich MS2 spectra are available (e.g., generated by ramped or stepped collision energy)'
- MS1-to-MS2 matching is unreliable — the workflow depends on 'reliable matching of MS1 peaks to MS2 spectra' before topic inference

## Inputs

- Preprocessed MS/MS spectra as bag-of-fragments documents (fragments plus neutral losses, noise-filtered), e.g. from an MGF file such as the GNPS/CSI:FingerID dataset of 5,670 spectra or a Beer3 positive-ionization file
- Mass2Motif count parameter (e.g. 300 for one beer data file, 500 for the GNPS corpus)
- Optional: set of previously characterized Mass2Motifs to keep fixed during inference (e.g. beer-characterized motifs applied to Mass Bank/GNPS data)

## Outputs

- Trained LDA model decomposing each spectrum into topic proportions over Mass2Motifs (motif loadings per spectrum)
- Mass2Motif definitions as fragment/neutral-loss topic distributions, exportable as motifset.json plus a binary LDA model dump
- Runtime and convergence record (metrics.json) with inferred motif count and elapsed time per stage

## How to apply

First convert each MS/MS spectrum into a bag-of-fragments representation, extracting neutral losses and filtering out noise peaks, so spectra become documents of fragment/loss terms. Then run the MS2LDA topic-modeling workflow with the number of Mass2Motifs set to match the corpus size — 300 motifs per beer data file with ~1,000 peaks, or 500 motifs for the 5,670-spectrum GNPS dataset from the CSI:FingerID study — selecting between Gibbs sampling (~1 h per single beer sample on laptop-class hardware) and the faster variational Bayes decomposition (~30 min for the same sample). Use variational Bayes when a large corpus must be decomposed or when many Mass2Motifs must be inferred jointly, since the paper demonstrates it can decompose the 5,670-spectrum GNPS dataset into 500 motifs; previously characterized beer Mass2Motifs can be supplied as fixed (frozen) topics so all other motifs are learned during inference. After training converges, export the motif set (motifset.json) with per-spectrum motif loadings and record the inferred motif count and runtime in metrics.json; motifs are then judged biochemically by whether they carry structurally interpretable fragment/neutral-loss combinations (30–40 per positive-mode beer file were characterizable) and by their degree, which may range from 1 to over 200 spectra.

## Examples

```
pip install ms2lda  # then run MS2LDA with --n_topics 500 on the preprocessed 5,670-spectrum GNPS bag-of-fragments corpus (variational Bayes engine)
```

## Evaluation signals

- The inferred motif count matches the requested number of Mass2Motifs (e.g. exactly 500 for the 5,670-spectrum GNPS run, 300 per beer file) with no unconverged topics
- Stage runtimes fall within the reported order-of-magnitude band: ~20 min feature extraction, ~30 min variational Bayes (vs ~1 h Gibbs) per single beer sample on laptop-class hardware
- A biochemically meaningful fraction of inferred motifs carries structurally interpretable fragment/neutral-loss combinations — reference point is 30–40 structurally characterized motifs per positive-ionization beer file
- Motif degree (number of spectra containing each motif) spans the reported range from 1 to over 200 spectra, rather than collapsing onto one or two dominant motifs
- motifset.json, per-spectrum loadings, and the binary LDA model dump all serialize without loss and a metrics.json records motif count and elapsed runtime for reproducibility

## Limitations

- Computationally more costly than simpler tools, 'but not prohibitively so' — feature extraction alone took ~20 min per beer sample, and inference ranged from ~30 min (variational Bayes) to ~1 h (Gibbs) on a laptop
- Neutral losses cannot be used in downstream automated spectral matching because matching tools do not support losses, so automated annotation of motifs must omit them
- Requires reliable MS1-to-MS2 matching and information-rich MS2 spectra from complex mixtures (ramped or stepped collision energy); works poorly on simple or sparse spectra
