# molecular-fingerprint-baseline-benchmarking

## Summary

Establishes a molecular-structure-only baseline for metabolite-protein interaction prediction by training the same random forest classifier on 128-bit RDKit fingerprints and comparing accuracy, AUC, and F1 against SARTRE's constraint-based shadow price features (e.g., on the Piazza E. coli gold standard).

## When to use

Use when a new feature set for metabolite-protein interaction prediction (e.g., shadow prices) must be benchmarked against a molecular-structure baseline under identical classifier, sampling, and cross-validation settings.

## When NOT to use

- The goal is standalone MPI prediction from structure only — this skill is a benchmark control, not the primary prediction method
- The comparison should isolate constraint-based (shadow price) information: using fingerprints alongside shadow prices as combined features would defeat the controlled comparison
- Gold standard metabolites lack structures retrievable via Bio.Entrez/PubChem, so 128-bit RDKit fingerprints cannot be generated

## Inputs

- Preprocessed 128-bit molecular fingerprint feature table `met_fp128.csv` (generated by generate_fp.py with RDKit)
- Gold standard metabolite-protein interaction labels (e.g., Piazza et al. 2018 chemoproteomic gold standard in the piazza directory of the SARTRE repository)
- Shadow price features `met_sps_t80_replaced.csv` for the paired comparison

## Outputs

- Accuracy, AUC, and F1 metrics for the fingerprint-based random forest classifier
- Comparison table of fingerprint vs. shadow-price metrics per gold standard (e.g., piazza_evaluation_metrics.csv) with significance assessment

## How to apply

Generate 128-bit molecular fingerprints for all metabolites in the gold standard by running `generate_fp.py` (RDKit; the script prompts for an email to use Bio.Entrez), saving results to `met_fp128.csv`. In the gold standard directory (e.g., piazza), construct the training/testing dataset and train the scikit-learn random forest classifier with class undersampling and 5-fold cross-validation using the fingerprint features via `python3 evaluate.py fp`, mirroring exactly the procedure used for shadow prices (`python3 evaluate.py sp`). Compute accuracy, ROC-AUC, and F1 with sklearn metrics for both feature sets and record them (e.g., in piazza_evaluation_metrics.csv). The rationale is a controlled comparison: any advantage of shadow-price features over fingerprints is attributable to constraint-based information rather than classifier or sampling differences. The benchmark is considered passed when the shadow-price classifier significantly outperforms the fingerprint baseline (reported P<1e-5) and reaches an average AUC near 0.86 on the E. coli Piazza gold standard.

## Related tools

- **RDKit** (Generates the 128-bit molecular fingerprints used as the baseline feature set) — https://www.rdkit.org/
- **scikit-learn** (Supplies the random forest classifier (with class undersampling and 5-fold cross-validation) and the accuracy/AUC/F1 metrics applied identically to both feature sets) — https://scikit-learn.org/stable/
- **SARTRE** (Framework whose evaluate.py script runs the fingerprint baseline (`evaluate.py fp`) and shadow-price (`evaluate.py sp`) comparisons) — https://github.com/fayazsoleymani/SARTRE
- **Bio.Entrez** (Used by generate_fp.py (which prompts for an email) to retrieve metabolite information needed for fingerprint generation) — https://biopython.org/docs/1.76/api/Bio.Entrez.html

## Examples

```
cd piazza && python3 evaluate.py fp && python3 evaluate.py sp
```

## Evaluation signals

- Fingerprint baseline metrics (accuracy, AUC, F1) are computed with the same sklearn pipeline, class undersampling, and 5-fold CV as the shadow-price run, so the two runs differ only in feature set
- On the Piazza E. coli gold standard, the shadow-price classifier must show significantly higher accuracy, AUC, and F1 than the fingerprint baseline (reported P-value <1e-5)
- Shadow-price average AUC should land near the reported 0.86 for E. coli (and 0.85 for S. cerevisiae)
- The metrics file (piazza_evaluation_metrics.csv) contains accuracy, AUC, and F1 entries for both the `sp` and `fp` feature sets
- `met_fp128.csv` is produced with the expected 128-bit fingerprint width for all metabolites

## Limitations

- A valid GUROBI license is required upstream for shadow-price calculation, so the fingerprint baseline alone cannot substitute for the comparison
- Fingerprints capture only molecular structure and are expected to underperform constraint-based shadow prices, which the paper reports as the key features
- STITCH-derived gold standards require an additional confidence-score argument (150/400/700/900) when running evaluate.py
