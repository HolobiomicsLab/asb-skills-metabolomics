# pixel-wise peak picking of imaging spectra

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Converts raw MALDI MSI pixel spectra into a per-pixel peak list within msiFlow's Snakemake-based msi_preprocessing_flow, so that each pixel retains its own detected m/z peaks for downstream spatially-aware filtering and normalisation.

## When to use

Use when raw MALDI MSI data (e.g. t-MALDI-2 measurements) must be transformed into pixel-wise peak lists before spatial coherence filtering or intensity normalisation.

## When NOT to use

- Input is already a peak-picked feature/centroid table rather than raw imaging spectra.
- The goal is segmentation, registration (msi_if_registration_flow) or analysis/visualisation rather than peak-list generation from raw data.
- The data are immunofluorescence microscopy (IFM) images, which are handled by if_segmentation_flow instead of MSI pre-processing.

## Inputs

- raw MALDI MSI data (e.g. t-MALDI-2 high-resolution imaging acquisitions)
- msiFlow configuration (config.yaml) for the pre-processing workflow

## Outputs

- pixel-wise peak list of detected m/z peaks per pixel, generated by msi_preprocessing_flow

## How to apply

Run msiFlow's pre-processing workflow (msi_preprocessing_flow), a Snakemake workflow packaged in the msiFlow Docker image, on raw MALDI MSI data (example data available via Zenodo 10.5281/zenodo.11913042 or the repo's demo dataset). The workflow performs peak picking independently for each pixel so that spatial information is preserved across the imaging run. Retain the pixel-wise peak list as the bridge input to the follow-on spatial-coherence peak filtering step, which removes non-informative or exogenous signals using the spatial coherence metric. Validate that the resulting peak list contains detected m/z peaks per pixel and is readable by subsequent msiFlow workflow steps.

## Related tools

- **msiFlow** (provides the msi_preprocessing_flow Snakemake workflow that performs pixel-wise peak picking and generates the peak list from raw MALDI MSI data) — https://github.com/Immunodynamics-Engel-Lab/msiflow
- **Snakemake** (workflow engine automating and parallelising the pixel-wise peak-picking pre-processing steps)
- **MALDI-2** (the acquisition modality (laser-induced postionisation MALDI MSI) whose raw imaging spectra are peak-picked per pixel)

## Evaluation signals

- The msi_preprocessing_flow workflow completes without error in the Snakemake/Docker environment.
- Output peak list exists, is readable tabular data with ion m/z (and intensity) columns.
- Peaks are present per pixel, enabling downstream computation of the spatial coherence metric per ion.
- For the demo dataset (github.com/Immunodynamics-Engel-Lab/msiflow/tree/main/demo), outputs match the expected output files shipped with the demo.

## Limitations

- msiFlow does not include an annotation or interpretation step; peak picking only yields preliminary candidates.
- Downstream cell-specificity is limited because consecutive tissue sections and lateral lipid diffusion during MSI sample preparation blur assignment.
- Pixel-wise peak picking alone leaves non-informative or exogenous signals in the peak list; the separate spatial-coherence peak filtering step is required.
