# pathway-enrichment-result-comparison

## Summary

Compares mummichog pathway enrichment results from MetaboAnalystR 4.0 run twice on the same MS1 feature table — once unfiltered and once filtered by MS2-based compound identifications — to quantify how spectral annotation improves functional interpretation on clinical LC-MS metabolomics data.

## When to use

Use when raw LC-MS/MS data (DDA or SWATH-DIA, e.g. mzML from Metabolomics Workbench ST002796/ST002798) has been processed to MS1 features plus MS2 compound IDs and the goal is to test whether MS2 filtering yields more significant mummichog pathways than MS1 alone.

## When NOT to use

- Input is already a curated list of identified metabolites with no unannotated MS1 features — traditional enrichment on confirmed compounds does not need the MS2-filtering-vs-unfiltered comparison
- No MS2 spectra or compound identification results are available (e.g. MS1-only acquisition), since the second arm of the comparison cannot be built
- The data are not LC-MS metabolomics (e.g. proteomics or transcriptomics), since mummichog empirical-compound permutation is designed for metabolomic feature tables

## Inputs

- Raw centroided mzML files for clinical metabolomics datasets (Metabolomics Workbench ST002796 and ST002798)
- MS1 feature table generated by MetaboAnalystR 4.0 auto-optimized processing (peak picking, alignment, gap filling, annotation), used as the MS2 target list
- MS2-based compound identification results from PerformDBSearchingBatch exported as a data frame via PerformResultsExport
- Consensus MS2 spectra built with PerformSpectrumConsenus at a 50% fragment frequency threshold

## Outputs

- Two mummichog pathway enrichment tables (MS1-only and MS2-filtered) from Convert2Mummichog
- A side-by-side comparison table (.csv) distinguishing the unfiltered vs MS2-filtered runs, e.g. the Fig. 5c-e comparison
- Set of additional significant pathways recovered only with MS2 filtering (expected: phosphatidylinositol phosphate metabolism, vitamin D, vitamin C, arachidonic cascade for the SWATH-DIA dataset)

## How to apply

Process the centroided mzML files with MetaboAnalystR 4.0's auto-optimized LC-MS1 workflow to obtain the feature table, then deconvolve MS2 with PerformDDADeconvolution (DDA) or PerformDIADecolution's counterpart PerformDIADeconvolution (SWATH-DIA), build consensus spectra across replicates keeping only fragments above a 50% frequency threshold, and identify compounds with PerformDBSearchingBatch, exporting candidates via PerformResultsExport. Run the improved mummichog functional analysis twice via Convert2Mummichog: once on MS1 features alone and once using the MS2-based identifications to filter out unfeasible empirical-compound candidates before the permutation test. Compile both pathway tables side by side (reproducing Fig. 5c-e) and count additional significant pathways in the MS2-filtered run. In the published case study, the SWATH-DIA clinical COVID-19 dataset gained four extra significant pathways — phosphatidylinositol phosphate metabolism, vitamin D, vitamin C, and arachidonic acid cascades — confirming the article's rationale that functional activity prediction is improved by utilizing MS2 spectral data.

## Evaluation signals

- The comparison output exists as a .csv and clearly distinguishes the MS1-unfiltered run from the MS2-filtered run
- The MS2-filtered SWATH-DIA enrichment table contains the four additional significant pathways: phosphatidylinositol phosphate metabolism, vitamin D, vitamin C, and arachidonic acid cascades
- Both Convert2Mummichog runs use the identical MS1 feature table so pathway differences are attributable to MS2 filtering, not upstream processing
- Consensus spectra fed to the database search keep only fragments with frequency above the user-defined 50% threshold
- The MS1-only arm reports no significant hits among those four pathways, matching the published Fig. 5c-e contrast

## Limitations

- MS2-based identification relies on reference spectra databases that remain incomplete, and the built-in libraries are compiled from various instruments and experimental conditions with potentially varying qualities
- The published gain of four additional significant pathways was demonstrated on the SWATH-DIA clinical dataset; results on other datasets or acquisition modes may differ
- Compound identification matching m/z, retention time, and MS2 patterns typically yields multiple candidates requiring further curation before functional interpretation
