# spectral-purity-assessment-for-lipid-matches

## Summary

Assess the purity of MS2/MS3+ lipid spectral matches against co-eluting isobaric species and enforce LipiDex 2 thresholds (≥75% spectral purity, dot product ≥500, reverse dot product ≥700) so that only high-confidence lipid identifications annotate chromatographic features.

## When to use

Use when MS2/MSn spectra from LC-MS lipidomics runs are being matched to an in silico lipid spectral library and you must reject matches confounded by co-eluting isobaric lipids before annotating features.

## When NOT to use

- Input is a raw MS spectrum without any library match or candidate lipid assignment — spectral purity of a match cannot be computed without a matched reference spectrum.
- Analyzing untargeted metabolomics (non-lipid) features where isobaric co-elution is not the dominant confounder and lipid-specific purity thresholds do not apply.
- Validating features where the lipid identification comes from retention-time (ECN vs. RT) or dilution-series evidence rather than spectral matching — Degreaser QC evidence types handle those, not purity/dot-product scores.

## Inputs

- Annotated spectral match table (.csv) exported from LipiDex 2 Spectrum Searcher
- Experimental MS2 and MS3+ spectra from LC-MS lipidomics runs (e.g. Thermo .raw via RawFileReader)
- In silico lipid spectral library generated by LipiDex 2 Library Generator (with MSn tree-based fragmentation logic)
- Chromatographic feature/peak table (e.g. Compound Discoverer 3.3 .cdResult files)

## Outputs

- Per-match spectral purity estimate (fraction of fragment ion intensity from matched lipid)
- Per-match dot-product and reverse dot-product similarity scores
- Flagged/filtered table of lipid spectral matches passing the 75% purity, ≥500 dot-product, ≥700 reverse dot-product criteria
- Annotated fragment peak table from Lipid Spectral Annotator

## How to apply

Load the annotated spectral match table (.csv) exported from the LipiDex 2 pipeline into pandas. For each MS2 and MS3+ spectral match, compute the spectral purity as the fraction of fragment ion intensity attributable to the matched lipid versus coeluting isobaric species, mirroring LipiDex 1's rationale of using spectral purity to estimate the purity of the associated chromatographic feature. Compute the cosine dot-product and reverse dot-product scores between each experimental MSn spectrum and its in silico library spectrum (generated via the LipiDex 2 Library Generator with MSn tree-based fragmentation). Apply the match-quality thresholds: spectral purity ≥75%, dot product ≥500, reverse dot product ≥700, flagging any match that fails a criterion. Retain only passing matches and pass them to the LipiDex Spectral Annotator, which uses Spectrum Searcher MS2 and MS3+ spectral matches to annotate fragment peaks. Compare per-match scores and pass/fail calls against the deposited reference table (MSV000091033) to validate.

## Examples

```
python score_matches.py --input annotated_spectral_matches.csv --min-purity 0.75 --min-dot 500 --min-reverse-dot 700 --output annotated_spectral_matches_scored.csv
```

## Evaluation signals

- Per-match spectral purity, dot-product, and reverse dot-product values agree with the deposited LipiDex 2 reference annotations (MSV000091033).
- Only matches meeting all three criteria (purity ≥75%, dot product ≥500, reverse dot product ≥700) are retained in the output table.
- Matches failing any single threshold are flagged, not silently dropped, so the filtering action is auditable.
- Passing matches feed cleanly into Lipid Spectral Annotator fragment-peak annotation without downstream errors on missing scores.
- Output CSV schema matches the LipiDex 2 pipeline's .csv hand-off between modules (all modules pass .csv results files through the pipeline).

## Limitations

- Spectral purity only estimates the purity of the associated chromatographic feature — coeluting isobaric species below the detection threshold or with atypical fragmentation may still inflate scores.
- The thresholds (75% purity, 500/700 dot products) are calibrated for the LipiDex 2/Spectrum Searcher scoring scale; applying them to a different spectral-matching tool's raw scores would be invalid.
- LipiDex 1 is no longer supported, and LipiDex 2 Peak Finder requires Compound Discoverer 3.3 .cdResult files, so older peak-table formats (mzMine 2 CSV from LipiDex 1) need conversion.
- MS3+ matches can be present but purity/dot-product statistics for them must be computed separately from MS2 spectra since fragment trees differ.
