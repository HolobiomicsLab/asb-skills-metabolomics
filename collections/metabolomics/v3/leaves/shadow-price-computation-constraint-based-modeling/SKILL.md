# shadow-price-computation-constraint-based-modeling

## Summary

Compute FBA shadow prices from curated genome-scale metabolic models (iJO1366 for E. coli, Yeast-GEM/Yeast8 for S. cerevisiae) using the GUROBI optimizer within flux variability analysis, to serve as metabolite features for SARTRE's random-forest prediction of metabolite-protein interactions.

## When to use

Use when metabolite features are needed for MPI prediction or classification and a genome-scale metabolic model (GEM) plus a gold-standard interaction set (piazza, reznik, stitch_ecoli, stitch_yeast) is available; shadow prices from constraint-based optimization can replace or complement molecular fingerprints.

## When NOT to use

- You only need metabolite structural features: 128-bit molecular fingerprints generated by generate_fp.py with RDKit achieved comparable AUC (~0.85) on the stitch_yeast gold standard, so optimization overhead is unnecessary if fingerprints suffice.
- No active GUROBI license or no curated GEM is available — shadow-price calculation cannot run and fingerprint-based features are the fallback.
- The task is protein-only or requires non-metabolic features; shadow prices are defined only for metabolites mapped to GEM reactions.

## Inputs

- Curated irreversible GEM file (ModelIrrevOpt90.mat from iJO1366.mat; yeast_IrrevOpt90.mat from Yeast-GEM.mat)
- Gold-standard metabolite-protein interaction sets: piazza, reznik, stitch_ecoli, stitch_yeast
- Active GUROBI license (optimizer and its Python interface)
- COBRAToolbox in MATLAB for GEM curation
- Optional: media-composition settings (carbon source or uptake-bound manipulation of iJO1366)

## Outputs

- Per-reaction shadow-price optimization results saved in the opt directory (one file per reaction number), also provided as .zip archives
- Preprocessed metabolite shadow-price feature table met_sps_t80_replaced.csv for downstream classifiers

## How to apply

First curate the GEM with COBRAToolbox in MATLAB: modelPreparing_iJO1366.m turns iJO1366.mat into ModelIrrevOpt90.mat, and modelPreparing_yeastGEM.m turns Yeast-GEM.mat into yeast_IrrevOpt90.mat (irreversible, optimized models). Then, for each gold-standard directory (piazza, reznik, stitch_ecoli, stitch_yeast), run optimization.py with the GUROBI optimizer and its Python interface (an active GUROBI license is required); per-reaction optimization results are saved in the opt directory, one file per reaction number, and are also distributed as .zip archives that must be unzipped. Downstream, preprocess the shadow prices with cleaning.py to yield met_sps_t80_replaced.csv for the random-forest classifiers in sklearn. For media-composition robustness analyses, manipulate the iJO1366 model bounds (alternate carbon sources acetate, fructose, glycerol, mannose, succinate; limiting vs non-limiting carbon/nitrogen/phosphorus uptake) and recompute shadow prices per condition.

```
cd piazza && python3 optimization.py && python3 cleaning.py
```

## Evaluation signals

- opt directory populated with one result file per reaction number for each gold standard (piazza, reznik, stitch_ecoli, stitch_yeast)
- cleaning.py produces met_sps_t80_replaced.csv in each gold-standard directory
- Random forest trained on shadow prices (evaluate.py sp) reaches mean AUC ~0.86 for E. coli and ~0.85 for S. cerevisiae
- Label and feature permutation tests reject the null hypothesis with P<1e-7 on stitch_yeast
- Metrics (accuracy/AUC/F1) remain stable when shadow prices are recomputed under alternate carbon sources (acetate, fructose, glycerol, mannose, succinate) relative to the glucose baseline

## Limitations

- Shadow prices were not consistently superior: on stitch_yeast, SARTRE with shadow prices and with 128-bit fingerprints gave comparable performance (Table 4), showing no added benefit for that gold standard.
- GUROBI requires an active license beforehand; the optimization step cannot run without it.
- Optimization result archives (.zip) must be manually unzipped before preprocessing; media-composition sensitivity is limited to models with manipulable uptake bounds (e.g., iJO1366).
