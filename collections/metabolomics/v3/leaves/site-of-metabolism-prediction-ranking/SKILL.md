# site-of-metabolism-prediction-ranking

## Summary

Rank candidate biotransformation products (derivatives of an anchor molecule) using GNN-SOM, a graph neural network that predicts the likelihood of each atom being the site-of-metabolism, to prioritize plausible structures for an unknown suspect molecule.

## When to use

Use when enumerating ranked candidate structures for a suspect molecule: after PROXIMAL2 has generated derivatives from an anchor molecule by applying biotransformation rules, and you need to order them by reaction-center likelihood.

## When NOT to use

- When no biotransformation rules have yet been applied and no candidate derivatives exist — GNN-SOM scores pre-existing structures rather than generating them (generation is PROXIMAL2's role).
- When the anchor–suspect pair shares no spectral similarity or no biotransformation rule matches the observed precursor mass difference (only 17,254 of 42,307 RetroRules rules matched unit-resolution mass differences).
- When molecular formula annotation fails — in the SIRIUS comparison, structure annotation was only attempted if the correct formula was generated first.

## Inputs

- Candidate derivative structures generated by PROXIMAL2 (SMILES/molecular graphs) from an anchor molecule
- Anchor molecule structure (SMILES) and the observed anchor–suspect precursor mass difference (molecules_of_interest CSV)
- GNN-SOM model state and configuration files (data directory of the GNN-SOM repository)
- The biotransformation rule (reaction pair) and its atom-mapping that indicates which atom in the derivative was transformed

## Outputs

- Per-atom site-of-metabolism likelihood scores for each candidate derivative
- A ranked list of candidate derivatives, ordered by reaction-center likelihood, with ties resolved by average rank
- In the BAM pipeline, the rank of the true suspect identity among candidates (proportion ranked at positions 1–5)

## How to apply

After PROXIMAL2 applies biotransformation rules to the anchor molecule and produces candidate derivatives, convert each derivative (and the anchor) to a molecular graph with RDKit and feed it to the GNN-SOM model (PyTorch Geometric/PyTorch) to predict, per atom, the likelihood of being the site of a biotransformation. Assign each candidate derivative the likelihood of the atom to which its biotransformation rule was applied; rank derivatives by this score, highest first. When multiple candidates tie, resolve using the average-rank method: sum all ranks (including duplicates) and divide by the number of tied candidates. In the BAM pipeline, derivatives can then be matched to the anchor–suspect precursor mass difference, and correct structural assignment is checked by comparing the first 14 characters of InChIKeys.

## Evaluation signals

- Each derivative's assigned score equals the GNN-SOM likelihood of the atom to which its biotransformation rule was applied — verify the score corresponds to the mapped atom, not an arbitrary atom.
- Tied candidates must receive the same average rank (sum of duplicate ranks / number tied), not distinct integers.
- Report the proportion of true suspect identities ranked at positions 1 to 5; the paper's top-ranked correct assignment rate was 24.2%.
- Candidate is considered structurally correct when its InChIKey matches the suspect on the first 14 characters.
- GNN-SOM output is a likelihood per atom in [0,1] for every atom in the molecular graph; missing scores for an atom indicate the derivative was not properly converted by RDKit.

## Limitations

- Ranking quality depends on PROXIMAL2's reaction-center identification; if PROXIMAL2 cannot find suitable reaction centers, no derivatives can be ranked.
- Tie resolution by average rank can leave many candidates sharing ranks when likelihood scores are close, diluting the top-5 hit-rate.
- GNN-SOM predictions are probabilistic; the correct derivative is not always ranked first (only 24.2% of examined anchor–suspect cases were correctly assigned at rank 1).
- The comparison against SIRIUS required correct molecular formula annotation as a prerequisite — structural annotation is skipped when formula annotation fails.
