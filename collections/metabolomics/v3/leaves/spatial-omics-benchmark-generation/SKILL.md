# spatial-omics-benchmark-generation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Generates pseudo-paired spatial transcriptome / MALDI-MSI benchmark data by splitting gene features into disjoint pseudo-spatial-transcriptome and pseudo-MALDI-MSI sections and applying Gaussian translation to coordinates of one section, mimicking the morphological disagreement observed between neighboring tissue sections.

## When to use

Use when no real paired spatial-omics sections exist but a ground-truth reference is needed to evaluate spot-to-spot integration or label transfer methods such as haCCA against morphological alignment baselines like STUtility.

## When NOT to use

- When a real paired spatial transcriptome + MALDI-MSI dataset from the same or neighboring tissue sections is already available — use the real data instead of synthesising pseudo-pairs.
- When the downstream integration method relies on true shared genes or shared spots rather than high-correlated feature pairs across modalities.
- When higher-resolution spatial data (e.g. sub-cellular or single-cell resolution) is required, since haCCA and this pseudo-pair generation have not been evaluated on higher resolution data.

## Inputs

- Spatial transcriptome count matrix as AnnData (.h5ad) with spatial coordinates in obsm['spatial']
- Feature/gene expression matrix (X) and spatial location matrix (D) for each of the source tissues

## Outputs

- Pseudo-paired sections stored as a.h5ad and b_prime.h5ad, one pair per split (15 pairs per source tissue)
- Disjoint gene feature subsets representing pseudo-spatial-transcriptome and pseudo-MALDI-MSI sections
- Gaussian-translated spatial coordinate matrices for the pseudo-MALDI-MSI section

## How to apply

Load each source tissue's spatial transcriptome matrix as an AnnData object using Scanpy. Randomly split the feature (gene) set into two disjoint subsets — one representing the pseudo-spatial-transcriptome section and the other the pseudo-MALDI-MSI section. Apply Gaussian translation to the spatial coordinates of one section to simulate the morphological disagreement observed between neighboring tissue sections. Emit each pair as a.h5ad and b_prime.h5ad; validate that the pair retains the same number of spots and that translated coordinates deviate from the original by the Gaussian perturbation amount. The haCCA paper uses this procedure on 3 mouse brain, 1 rat brain and 1 human gastric cancer spatial transcriptome datasets, yielding 15 pairs per source tissue, then evaluates haCCA versus STUtility by label transfer accuracy and label transfer ARI.

## Related tools

- **Scanpy** (Used to load and process the spatial transcriptome matrices as AnnData objects before splitting genes and applying coordinate translation.)
- **haCCA** (Downstream integration method evaluated on the pseudo-paired spatial-omics data generated by this skill.) — github.com/LittleLittleCloud/haCCA
- **STUtility** (Morphological-alignment baseline benchmarked against haCCA on the pseudo-paired MSI-MALDI data.)

## Examples

```
a_h5ad = sc.read_h5ad(os.path.join('/path/to/a.h5ad'))
b_prime_h5ad = sc.read_h5ad(os.path.join('/path/to/b_prime.h5ad'))
a = Data(X=a_h5ad.X.toarray(), D=a_h5ad.obsm['spatial'])
b_prime = Data(X=b_prime_h5ad.X.toarray(), D=b_prime_h5ad.obsm['spatial'])
```

## Evaluation signals

- Each generated pair must retain the same number of spots as the original tissue section.
- Translated coordinates must deviate from the original coordinates by the Gaussian perturbation amount applied.
- The feature/gene sets of the two pseudo-sections must be disjoint after splitting.
- Downstream evaluation should report label transfer accuracy and label transfer ARI, with haCCA expected to outperform morphological alignment (e.g. STUtility) by roughly 6–20% on the pseudo-paired data.
- Files must follow the naming convention a.h5ad and b_prime.h5ad as expected by the haCCA Data object loading step.

## Limitations

- No real shared spots or features exist between the modalities by construction — the pseudo-pair is synthetic, so findings may not fully generalise to real paired sections.
- No data accession or dataset identifier is given in the discussion for the spatial transcriptome or pseudo-paired MSI-MALDI data used in the evaluation.
- No software version number is stated for STUtility used as the benchmark comparator.
- Behavior of haCCA on higher resolution data has not been evaluated, so benchmark pairs generated at spot resolution may not transfer to higher-resolution settings.
