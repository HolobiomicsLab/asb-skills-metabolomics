# massive-deposit-data-retrieval

## Summary

Retrieves the deposited original and PreProcessor-preprocessed LC-IM-MS lipid feature and annotation lists for the triplicate NIST SRM 1950 human plasma lipid extract from the MassIVE repository (MSV000087295) so replicate-consistency and annotation outcomes can be independently recomputed.

## When to use

Use when a reproduction task depends on the raw vs preprocessed feature tables or lipid annotation lists referenced in the Bilbao et al. 2021 PreProcessor paper and hosted at ftp://massive.ucsd.edu/MSV000087295.

## When NOT to use

- The goal is to re-run preprocessing on raw LC-IM-MS .d files with the PNNL PreProcessor itself rather than reuse the already-deposited original and preprocessed feature/annotation lists
- The analysis targets a different dataset (e.g. the HeLa cell digest) with no corresponding MassIVE deposit identified
- Only the paper's reported numbers are needed and no recomputation or per-replicate inspection is planned

## Inputs

- MassIVE deposit identifier MSV000087295 (ftp://massive.ucsd.edu/MSV000087295)
- Deposited detected-feature tables for 3 LC-IM-MS replicates of the NIST SRM 1950 human plasma lipid extract (original data)
- Deposited detected-feature tables for the same 3 replicates (PNNL PreProcessor-preprocessed data)
- Deposited lipid annotation lists per replicate, original and preprocessed

## Outputs

- Locally downloaded per-replicate feature lists (original and preprocessed) loadable into pandas
- Locally downloaded per-replicate lipid annotation lists for querying specific lipids (e.g. Sphingomyelin d34:5, m/z 695.5088, RT 6.2 min, AT 36.7 ms)
- Derived per-condition counts and summaries such as replicate_feature_counts.csv (downstream skill outputs)

## How to apply

Access the MassIVE deposit MSV000087295 at ftp://massive.ucsd.edu/MSV000087295 and download the deposited lists of detected features and lipid annotations for the 3 replicates of the NIST SRM 1950 human plasma lipid extract, keeping the original-data and preprocessed-data files separate. Load each replicate's original-data and preprocessed-data feature list (a feature being an ion with one or multiple isotopic peaks detected in the MS1 data) into pandas, preserving feature coordinates (m/z, RT, AT) for later cross-checking. These retrieved tables are the substrate for downstream recomputation, e.g. intersecting replicate-specific feature sets to count features consistently detected across all 3 replicates, or tallying per-replicate detection of a specific lipid annotation such as Sphingomyelin d34:5. Verify download integrity by confirming that replicate-specific lists exist for both data types (original and PreProcessor-preprocessed) before proceeding to any counting step.

## Related tools

- **PNNL PreProcessor** (Source of the preprocessed-data branch of the deposit: the retrieved preprocessed feature/annotation lists were generated by multidimensional smoothing (3 points in LC and 7 in IM), demultiplexing with 75% pulses, 50-count intensity threshold and spike removal) — https://omics.pnl.gov/software/pnnl-preprocessor
- **Lipid Annotator** (Producer of the lipid annotation lists retrieved from the deposit, having processed the original and PreProcessor-generated Agilent .d MS-files for feature finding and lipid annotation)

## Examples

```
wget -r ftp://massive.ucsd.edu/MSV000087295/ && python -c "import pandas as pd; orig=[pd.read_csv(f) for f in sorted(__import__('glob').glob('MSV000087295/original/*.csv'))]"
```

## Evaluation signals

- Both data types (original and preprocessed) are present for all 3 replicates of the NIST SRM 1950 plasma lipid extract in the downloaded tree
- Feature lists load into pandas with coordinates (m/z, RT, AT) preserved, enabling the 70.7% replicate-consistency recomputation to fall within approximately 70-71%
- The annotation tables allow querying Sphingomyelin d34:5 (m/z 695.5088, RT 6.2 min, AT 36.7 ms) and returning per-replicate presence flags for original vs preprocessed data
- Feature counts computed from the retrieved original-data lists are consistent with the paper's baseline against which the reported 70.7% and 19.4% increases were measured

## Limitations

- The retrieved files are processed feature/annotation lists, not raw instrument files, so this skill cannot reproduce upstream PreProcessor parameter choices (e.g. smoothing 3 points in LC / 7 in IM, 50-count threshold) directly
- The deposit provides results for the human plasma lipid extract and HeLa cell digest described in the paper only; the discussion notes extensions to other IM-MS instrumentation would require conversion to UIMF and are not covered by this deposit
- No tool version for the PreProcessor is specified in the paper, so preprocessing settings behind the preprocessed lists cannot be fully pinned down from the deposit alone
