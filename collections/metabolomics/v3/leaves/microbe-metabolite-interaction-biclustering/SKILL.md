# microbe-metabolite-interaction-biclustering

## Summary

Biclusters the MiMeNet microbe-metabolite interaction-score matrix into module sets via consensus clustering, then collapses scores into a weighted bipartite module-module network. Provides organism-level structure from per-pair attribution scores.

## When to use

Use when you have a cross-validated interaction-score matrix (microbes x metabolites) from MiMeNet and need to group features into modules and build a module-level interaction network.

## When NOT to use

- You have raw abundance tables only (microbial taxa/metabolite abundances) and no interaction-score matrix — run MiMeNet's cross-validated prediction first; this skill operates on the score matrix, not on raw counts.
- You need per-metabolite well-predicted lists (SCC above the 95th-percentile threshold) — that is a separate MiMeNet output step, not module construction.
- You are using NED as the underlying model — NED models metabolites via a microbiome latent space, so its interactions do not reveal shared interaction-pattern modules in the way MiMeNet's biclustering does.

## Inputs

- Mean microbe-metabolite interaction-score matrix (samples-normalized attribution values, microbes x metabolites) generated by cross-validated MiMeNet models
- Feature identifier lists for microbial taxa and metabolite features matching the matrix rows/columns
- Optional sample-label file to associate biclusters with biological covariates (-labels input of MiMeNet_train.py)

## Outputs

- Microbe module assignments (microbes partitioned into k1* modules)
- Metabolite module assignments (metabolites partitioned into k2* modules)
- Weighted bipartite module-module interaction network (nodes = microbe modules and metabolite modules, edges weighted by mean normalized block attribution) as a Cytoscape-compatible network file

## How to apply

Load the mean microbe-metabolite interaction-score matrix produced by cross-validated MiMeNet models (microbes x metabolites). Run consensus clustering on the microbe axis with Euclidean distance and complete linkage, computing the delta-area criterion across candidate cluster numbers and selecting k1* where the delta-area falls below the threshold 0.025. Repeat the identical procedure (Euclidean distance, complete linkage, delta-area threshold 0.025) on the metabolite axis to select k2*. Assign features to the resulting microbe and metabolite modules — in the article's application this yielded 8 microbe modules and 8 metabolite modules. Aggregate the normalized interaction-score matrix into a k1* x k2* block structure and score each module-pair edge by the mean normalized attribution within that block. Export the weighted bipartite module-module network (nodes = microbe and metabolite modules, edges weighted by block-mean attribution) as a Cytoscape-compatible file.

## Examples

```
python MiMeNet_train.py -micro ibd_micro.csv -metab ibd_metab.csv -output out/ -micro_norm RA -metab_norm CLR -threshold 0.025 -num_run_cv 10 -num_cv 10
```

## Evaluation signals

- The number of microbe modules (k1*) and metabolite modules (k2*) must satisfy the delta-area < 0.025 stopping criterion from consensus clustering on each axis independently.
- The exported network file contains exactly k1* microbe-module nodes and k2* metabolite-module nodes; edges exist only between opposite-axis modules.
- Every edge weight equals the mean of the normalized interaction scores in the corresponding block of the original microbe-metabolite score matrix (block-mean attribution).
- Feature assignments are consistent across the microbe and metabolite axes: each original feature appears in exactly one module per axis.
- The output is Cytoscape-compatible (loads without schema errors) and edge weights fall within the [0, 1] range of normalized attribution scores.

## Limitations

- MiMeNet, including this module-construction step, is limited in providing biological plausibility and mechanistic insights; interactions are statistical associations, not validated mechanisms.
- The delta-area threshold of 0.025 is a stopping heuristic; alternative k values slightly below/above the threshold can yield different module numbers and network topology.
- The soil dataset showed a higher threshold value, possibly due to longitudinal observations — module counts may not transfer directly across environments or time-series data.
- Not all metabolites are necessarily microbe-associated, so some metabolites may sit in modules whose edges carry low attribution signal.
