# cell-relative-metabolic-model-flux-sampling-context

## Summary

Sample the feasible flux region of INTEGRATE-generated cell-relative metabolic models (ENGRO2-derived, per cell line) and compare inter-model separation of the sampled flux distributions across constraint scenarios (medium, YSI extracellular flux ratios, transcriptomics-derived RAS constraints, alone vs. combined) using 2D t-SNE.

## When to use

Use when randomSampling CSVs from multiple cell-relative models (MCF102A, SKBR3, MCF7, MDAMB231, MDAMB361) must be embedded (e.g. t-SNE) to test whether combined constraints better separate cell lines than each constraint type alone.

## When NOT to use

- The goal is to classify fluxes as metabolically vs. transcriptionally regulated via intersection of RAS and metabolomics outputs (Steps 7–10: mannWhitneyUTest, rasTtest, concordanceAnalysis) rather than to compare whole-distribution separation
- Cell-relative models have not yet been generated by rasIntegration — sampling requires the per-cell-line SBML/mat models, not the generic ENGRO2 model
- The analysis concerns a single model or a scenario set that omits one of the three constraint families (medium, YSI, RAS), since the scenario comparison requires all four configurations

## Inputs

- Cell-relative SBML models produced by rasIntegration (modelId + '_' + cellLine + '.xml'), converted to irreversible .mat format (Step 5)
- randomSampling_' + modelId + '_nSol_' + nSamples + '_' + cellLine + '_' + timeStamp + '.csv' sampled flux distribution files per cell line per constraint scenario
- ysi_ratio.csv (extracellular flux ratio constraints) and medium.csv (nutrients availability constraints) controlling the scenario definitions
- Default lcellLines list: ['MCF102A', 'MDAMB231', 'SKBR3', 'MCF7', 'MDAMB361']

## Outputs

- Sampled flux distribution CSVs (nSamples solutions per cell-relative model per constraint batch)
- 2D t-SNE embedding with per-sample cell-line/cluster labels written to fig3_tsne_embedding.csv
- Per-scenario inter-model separation metric (contiguity of each model's points in the 2D embedding) used to rank constraint configurations

## How to apply

Run Step 4 (rasIntegration) with imposeMedium, imposeYSI and imposeRasConstraints toggled independently to generate four constraint scenarios (type 1, type 2, type 3, all combined), yielding one SBML model per cell line per scenario; convert each model to irreversible .mat format (Step 5, MATLAB) before sampling. Run randomSampling.py with nSamples/nBatches arguments, keeping epsilon=1e-4 as the lower bound on the biomass reaction, to produce 'randomSampling_' + modelId + '_nSol_' + str(nSamples) + '_' + cellLine + '_' + timeStamp + '.csv' files per cell line. For each scenario, load the sampled flux vectors of the five cell lines, apply t-SNE dimensionality reduction in Python (scikit-learn) to embed each model's solutions in 2D, assign each embedded sample to its source cell-line model, and quantify inter-model separation as the contiguity of each model's points in the embedding. Compare separation across the four scenarios; the all-constraints-combined configuration is expected to give the best separation, and the 2D coordinates plus per-sample model/cluster labels are written to fig3_tsne_embedding.csv.

## Examples

```
python pipeline/randomSampling.py nSamples nBatches
```

## Evaluation signals

- Output filenames match the pattern 'randomSampling_' + modelId + '_nSol_' + str(nSamples) + '_' + cellLine + '_' + timeStamp + '.csv' for each of the five cell lines
- In the combined-constraints t-SNE embedding, each cell line's sampled solutions form a spatially separated cluster from the other cell lines (the reported best inter-model separation)
- Separation under all-constraints-combined exceeds separation under each single constraint type applied alone
- The biomass reaction lower bound epsilon=1e-4 is respected in all sampled solutions
- fig3_tsne_embedding.csv contains 2D t-SNE coordinates plus per-sample model/cluster labels for all five cell lines across the four scenarios

## Limitations

- Sampling depends on prior model conversion: each model must be converted to a mat file to exploit the MATLAB function converting the model from the reversible into the irreversible format
- Default cell line lists and reaction names (Biomass, EX_lac__L_e, EX_glc__D_e, EX_gln__L_e, EX_gluOUT__L_e) assume the ENGRO2 breast-cell-line setup; other systems require overriding these inputs
- Extracellular flux constraints are limited to the selected flux ratios (glucose, glutamine, glutamate, lactate) provided in ysi_ratio.csv; other extracellular fluxes are unconstrained
