# mrlist-object-construction

## Summary

Constructs the margheRita mRList container from two tab-delimited input files (an MS-Dial-generated feature data file and a sample annotation file) via read_input_file(), producing the five-element object (data, metab_ann, sample_ann, QC, QC_ann) that serves as the main input/output of all margheRita functions.

## When to use

Use when MS-Dial-derived LC-MS/MS feature abundances (m/z, retention times, MS/MS spectra) and sample metadata must be ingested into margheRita as a single mRList object before preprocessing or metabolite identification.

## When NOT to use

- The input is already an mRList object or the output of an earlier margheRita preprocessing step (e.g. after m_z_filtering or filter_NA) — skip straight to the downstream function
- The feature table is an Excel spreadsheet from MS-DIAL rather than a tab-delimited text file — that ingestion path belongs to other packages such as notame, not margheRita's read_input_file()
- You only need the filtering, normalization or statistical steps and no ingestion — those are separate skills operating on an existing mRList

## Inputs

- Tab-delimited feature data file (usually generated by MS-Dial) with feature identifiers, m/z, retention times, MS/MS spectra and abundances
- Tab-delimited sample annotation file with columns id, injection_order, batch, class, biological_rep, technical_rep
- QC sample annotations (to be placed in the QC and QC_ann slots)

## Outputs

- mRList object with exactly five elements: data, metab_ann, sample_ann, QC and QC_ann

## How to apply

Prepare two tab-delimited text files: the feature data file, usually generated by MS-Dial, containing feature identifiers, m/z, retention times, MS/MS spectra and abundances, and the sample annotation file with columns id, injection_order, batch, class, biological_rep and technical_rep. Call read_input_file() on both files; it assembles the feature data and sample metadata into the mRList structure. Quality-control sample annotations must be routed into the dedicated QC and QC_ann elements rather than the main data and sample_ann slots. Technical replicates are later collapsed over samples sharing the same concatenation of class and biological_rep values, so those columns must be populated correctly at ingestion. Validate that the returned mRList contains exactly the five expected elements: data, metab_ann, sample_ann, QC and QC_ann; this object is the required input/output for all downstream margheRita functions (e.g. m_z_filtering, filter_NA, mR_pca).

## Related tools

- **margheRita** (Provides read_input_file(), which reads the two tab-delimited files and creates the mRList object used by most margheRita functions) — https://github.com/emosca-cnr/margheRita
- **R** (Runtime environment in which the margheRita package and the mRList construction are executed)

## Examples

```
library(margheRita); mR <- read_input_file(feature_data_file, sample_ann_file)
```

## Evaluation signals

- names(mRList) returns exactly the five elements data, metab_ann, sample_ann, QC and QC_ann
- sample_ann contains the six expected columns: id, injection_order, batch, class, biological_rep, technical_rep
- The data slot carries feature identifiers, m/z, retention times, MS/MS spectra and abundance values read from the MS-Dial feature file
- QC and QC_ann are populated with quality-control sample annotations, distinct from the biological samples in data/sample_ann
- The constructed mRList is accepted without error by downstream margheRita functions (e.g. m_z_filtering, filter_NA, mR_pca)

## Limitations

- read_input_file() expects text files in tab-delimited format; Excel or CSV exports of MS-Dial output are not covered by this skill
- The workflow is demonstrated on the Urine dataset (Zenodo 10.5281/zenodo.11243781) with its specific sample annotation schema; other study designs must be mapped onto the id/injection_order/batch/class/biological_rep/technical_rep columns
- This skill only performs ingestion; no quality control, filtering (mass defects, CV samples vs QCs) or normalization is applied at this stage
