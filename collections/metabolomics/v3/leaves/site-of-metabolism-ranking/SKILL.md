# site-of-metabolism-ranking

## Summary

Rank candidate biotransformation derivatives generated by BAM using GNN-SOM, a graph neural network that predicts the likelihood of each atom being the site of metabolism, so that the most plausible suspect structures are prioritized.

## When to use

Use when BAM/PROXIMAL2 has generated multiple candidate derivatives for an anchor-suspect pair and you must rank them by enzymatic plausibility before evaluating exact InChIKey matches.

## When NOT to use

- No candidate derivatives exist for the pair (PROXIMAL2 generated none), so there is nothing to rank
- You need molecular formula or full structure annotation rather than ranking of biotransformation-derived candidates — use SIRIUS for that stage
- Ranking non-enzymatic or rule-free candidate structures where site-of-metabolism likelihood is not meaningful

## Inputs

- Candidate derivative structures generated by PROXIMAL2 from anchor molecules (SMILES, json product files)
- Anchor-suspect pairs from the global molecular network (molecules_of_interest csv: suspect and anchor identifiers, masses, anchor SMILES)
- GNN-SOM model state and configuration files (data directory of the GNN-SOM repository)

## Outputs

- Ranked list of putative derivatives per anchor-suspect pair by GNN-SOM site-of-metabolism likelihood
- Tie-resolved average ranks for candidates sharing identical rank positions
- Per-pair benchmark outcomes feeding benchmark_results.csv (correct-structure assignment rate, e.g. 24.2%)

## How to apply

After PROXIMAL2 applies RetroRules (or KEGG) biotransformation rules to the anchor molecule and generates candidate derivatives matching the observed precursor mass difference, run the GNN-SOM graph neural network (PyTorch, PyTorch Geometric, RDKit) on each derivative to score the likelihood of each atom being the reaction center. Rank the putative derivatives by these site-of-metabolism likelihoods. When multiple candidates receive identical ranks, resolve ties by computing the average rank: sum all ranks, including duplicates, and divide by the number of tied candidates. The ranked list feeds the per-pair correctness evaluation, where a derivative is counted correct if its first 14 InChIKey characters match the suspect.

```

```

## Evaluation signals

- Every generated derivative for a pair receives a numeric rank based on GNN-SOM site-of-metabolism likelihood
- Tied candidates receive identical average ranks computed as (sum of tied ranks)/(number of tied candidates)
- On the 60,368-pair global molecular network benchmark, ranked BAM outputs reproduce 4,171 correct suspect assignments among 17,271 queries with derivatives (24.2% recall)
- Correct assignments verified by exact first-14-character InChIKey match between ranked derivative and suspect

## Limitations

- GNN-SOM ranks by enzymatic site-of-metabolism likelihood only; it does not use MS/MS spectral evidence, so high-ranked candidates can still be structurally wrong
- Ties are common and must be resolved by average-rank computation rather than arbitrary ordering
- Ranking quality depends on the upstream biotransformation rules; only 17,254 of 351,704 RetroRules rules (41%) matched observed precursor mass differences at unit resolution
