# dda-target-selection

## Summary

Exports a curated subset of in silico lipid precursor entries from the Lipid Spectrum Generator as an Excalibur-compatible precursor list (.CSV) targeting data-dependent acquisition (DDA) on Orbitrap instruments; a Skyline-compatible transition list is the alternative .CSV output.

## When to use

Use when entries from a generated lipid/precursor library must be targeted for DDA on an Orbitrap and an Excalibur-compatible precursor list (.CSV) — not an '.MSP' spectral library — is the required deliverable.

## When NOT to use

- The downstream consumer requires an '.MSP' spectral library (fragmentation spectra), not an acquisition target list — in that case select '.MSP' instead.
- The instrument/acquisition workflow expects a Skyline-compatible transition list rather than an Excalibur-compatible DDA precursor list.

## Inputs

- Lipid Spectrum Generator lipid/precursor library output (lipids generated by class and fatty acid composition, spectra by adduct)
- Selection of lipid/precursor entries intended for DDA targeting

## Outputs

- precursor_list.csv — Excalibur-compatible precursor list for DDA analysis via Orbitrap
- (alternative) Skyline-compatible transition list exported via the same '.CSV' option

## How to apply

Load the lipid/precursor library output produced by the Lipid Spectrum Generator, where lipids are generated with respect to class and fatty acid composition and spectra with respect to their adducts. Select the entries intended for data-dependent acquisition (DDA) precursor targeting. Invoke the tool's export mechanism and choose the '.CSV' file extension rather than '.MSP'; per the README, selecting '.CSV' yields an Excalibur-compatible precursor list (for DDA analysis via Orbitrap) or alternatively a Skyline-compatible transition list, so confirm which of the two the workflow requires before export. Write the result to precursor_list.csv following the Excalibur precursor-list field convention. Validate that the file exists, carries the .CSV extension, and parses as a comma-separated precursor table; content-level correctness of the precursor entries (masses/adducts matching the selected lipids) is verified by expert review.

- Export was produced via the '.CSV' option of the Lipid Spectrum Generator rather than the '.MSP' spectral-library path.

## Limitations

- Selecting '.CSV' can produce either an Excalibur-compatible precursor list or a Skyline-compatible transition list; the exact distinction depends on the tool's export configuration and is not further specified in the README.
- The article/README do not specify exact column names, mass tolerance, or numeric formatting of the Excalibur precursor list; content correctness is left to expert_review.
- The fragmentation patterns underlying the library are based on peer-reviewed studies, so precursor targeting inherits the accuracy limits of in silico spectra.
