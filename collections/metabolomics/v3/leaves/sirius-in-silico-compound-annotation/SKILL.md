# sirius-in-silico-compound-annotation

## Summary

In silico compound annotation of untargeted LC-MS2 features using SIRIUS (CSI:FingerID) inside the MAW-R segment, run on preprocessed MS1 data against compound databases such as COCONUT or SIRIUS 'bio' to assign chemical structures per feature when spectral dereplication alone is insufficient.

## When to use

Use when MS2 .mzML features remain structurally unannotated after spectral database dereplication (GNPS/HMDB/MassBank .rda matching) and ranked candidate structures with formulas and compound classes are needed per feature.

## When NOT to use

- When the feature already has a confident spectral match from GNPS/HMDB/MassBank dereplication, since spectral matching precedes and can shortcut in silico annotation
- When a MetFrag-based compound database dereplication run is required instead, since only SIRIUS (CSI:FingerID) is integrated for compound databases in MAW v1
- When no MS2 spectra are available for the features (SIRIUS in MAW operates on tandem MS input)

## Inputs

- MS1DATA_SiriusP.tsv generated by MAW-R preprocessing/dereplication
- MS2 .mzML input data files
- SIRIUS user credentials (for 'sirius login')
- Choice of compound database ('coconut', 'bio') and instrument profile ('orbitrap')

## Outputs

- Ranked SIRIUS candidate lists (formulas, structures, CSI:FingerID scores, CANOPUS classes) per feature
- Per-feature chemical structure assignments for import into a chemical structure similarity network
- Tallied annotation coverage (e.g. 881/933 features with structures, 92 class+formula only, 18 formula only on MTBLS709)

## How to apply

After MAW-R preprocessing and spectral dereplication produce MS1DATA_SiriusP.tsv, log in to SIRius ('sirius login') and execute Rscript Run_Sirius.r in the zmahnoor/maw-sirius5-old:1.0.0 container with the 'orbitrap' profile and a compound database such as 'coconut' or 'bio', using run_sirius settings ppm_max=5, ppm_max_ms2=15, QC=FALSE, SL=FALSE, candidates=30. SIRIUS retrieves top-scoring candidate structures via CSI:FingerID and CANOPUS class annotations, which MAW-Py then merges with spectral dereplication results and post-processes with RDKit (Tanimoto structural matching) for final candidate selection. Run the SIRIUS step with both 'coconut' and 'bio' databases when benchmarking, since database choice materially changes candidate ranking: natural-product databases like COCONUT raise the probability of ranking the true structure within the top candidates, whereas the 'bio' database ranked actual compounds lower. Count per-feature annotation completeness (structures vs class+formula only vs formula only) from the merged results to judge coverage.

## Examples

```
docker pull zmahnoor/maw-sirius5-old:1.0.0 --platform=linux/amd64 && sirius login && Rscript Run_Sirius.r MS1DATA_SiriusP.tsv orbitrap coconut ppm_max=5 ppm_max_ms2=15 QC=FALSE SL=FALSE candidates=30
```

## Evaluation signals

- The merged results file is produced and per-feature tallies match expected coverage (881/933 features with structures, 92 with only class+formula, 18 with only formula on the MTBLS709 bryophytes dataset)
- Candidate ranking respects the configured run_sirius settings: precursor ppm_max=5, ppm_max_ms2=15, 30 candidates, orbitrap profile
- Known compounds appear within top-25 candidates at expected ranks (e.g. Marchantin M and D at rank 2, Marchantin F at rank 8, Perrottetin E at rank 10)
- A comparative run with db='bio' vs db='coconut' confirms database-dependent rank shifts, with COCONUT ranking true compounds higher
- Each annotated feature carries a chemical structure suitable for the chemical structure similarity network import

## Limitations

- SIRIUS CLI does not provide a deterministic probability score, so candidate ranking thresholds cannot be applied uniformly and the idea was discarded
- SIRIUS lipid class annotation can produce false positives due to the complex nature of lipids, with lipid isomers co-eluting
- Using the SIRIUS 'bio' database ranked actual compounds lower than the COCONUT database
- Macrocyclic structures such as Marchantins are hard to annotate because their spectra are challenging to obtain due to complex fragmentation patterns; suspect lists are recommended
- Mismatch between experimental spectra in spectral databases and structures in compound databases limits how many features can be annotated
