# pearson-correlation-spectral-similarity-assessment

## Summary

Quantifies how closely a simulated metabolomic 1H NMR spectrum matches a real reference spectrum by computing the Pearson correlation between their aligned intensity profiles, as demonstrated in MetAssimulo 2.0 for 1D blood spectra (Pearson correlation ~0.82).

## When to use

Use when you have generated a simulated 1D or 2D metabolomic 1H NMR spectrum (urine, blood, or CSF) and need an objective, scalar measure of its resemblance to a real experimental spectrum before using the simulation for algorithm development or validation.

## When NOT to use

- When the input is raw, unaligned FID or free-induction-decay data requiring baseline correction and phase adjustment before any profile comparison is meaningful
- When the biofluid or pulse sequence has no corresponding real reference spectrum available — a Pearson correlation cannot be computed against an absent ground truth
- When you need peak-by-peak metabolite quantification rather than a whole-spectrum global similarity metric; correlation alone will not identify which specific resonances diverge

## Inputs

- Simulated 1D or 2D metabolomic 1H NMR spectrum (e.g. generated by MetAssimulo 2.0 with 52 urine metabolites or a blood spectrum with protein background)
- Real reference 1H NMR spectrum from the same biofluid and pulse sequence (e.g. urine J-Res spectrum, deposited in MetaboLights MTBLS12081)
- Aligned ppm axis and intensity vectors for both spectra after normalisation/rescaling

## Outputs

- Pearson correlation coefficient quantifying similarity between simulated and real spectral profiles (target benchmark ~0.82 for blood spectra)
- Overlaid comparison figure showing simulated and real spectra in a restricted ppm window (e.g. 0.8–4.5 ppm)
- Qualitative/quantitative note on which metabolite peaks coincide (e.g. creatinine and citric acid in urine J-Res)

## How to apply

First run MetAssimulo 2.0 to generate the simulated spectrum, either from the web app at http://127.0.0.1:8060/ or by executing `python3 apps/index.py -p Input/parameters.txt` with the parameters file configured for the target biofluid. For 2D spectra such as J-Res, compute a skyline projection along the vertical J-dimension to produce a 1D-like profile, then restrict both simulated and real spectra to the comparable ppm window (e.g. 0.8–4.5 ppm for urine J-Res) and normalise intensities so they are directly comparable. Compute the Pearson correlation coefficient between the aligned intensity vectors of the simulated and real spectra — MetAssimulo 2.0 achieved approximately 0.82 for simulated blood spectra incorporating a broad protein background. Use the coefficient to judge fidelity: values near 0.82 or higher indicate the simulation captures the dominant spectral features, while systematically lower values signal that key metabolites or backgrounds are missing from the simulation parameters. Record the reduced spectral density of the simulation relative to the real spectrum (e.g. only 52 metabolites simulated versus a more densely populated real urine spectrum) as a caveat alongside the correlation value.

## Evaluation signals

- Pearson correlation between the aligned simulated and real spectral intensity vectors should reach approximately 0.82 or higher for blood spectra with protein background
- The simulated urine J-Res projection should show peaks coinciding with the real spectrum for high/medium-abundance metabolites such as creatinine and citric acid
- Simulated spectrum should be visibly less densely populated than the real one (52 metabolites simulated) — reduced spectral density must be noted rather than treated as a failure
- Both spectra must be restricted to the same ppm window (e.g. 0.8–4.5 ppm) and normalised before the correlation is computed
- For 2D J-Res spectra, the skyline projection along the J-dimension must be computed before correlation to produce a comparable 1D profile

## Limitations

- The simulated urine J-Res spectrum is less densely populated than the real spectrum because only 52 metabolites are included in the simulation, so the Pearson correlation will not reflect minor-metabolite features
- For blood spectra the ~0.82 Pearson correlation is only achievable when the broad protein background is incorporated into the simulation — omitting it will substantially lower the coefficient
- Pearson correlation is a global scalar and does not pinpoint which individual resonances or metabolites diverge between simulated and real spectra
