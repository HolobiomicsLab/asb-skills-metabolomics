# rule-based-lipid-identification

## Summary

Rule-based annotation of lipids from UHPLC-HRMS/MS data in which a feature is only identified when user-selected required fragments for its lipid type are observed, and each identification is assigned a structural-resolution level (1–4) so that e.g. PC(16:0_18:1) is distinguished from class-level PC(32:1).

## When to use

Use when you have a feature table (m/z + retention time) plus .ms2 MS/MS spectra from ddMS2-topN or AIF acquisition and need lipid identifications annotated at the structural resolution actually supported by the observed fragments.

## When NOT to use

- Input lacks tandem MS/MS spectra (e.g. MS1-only feature tables) — only level-4 precursor-m/z annotations would be possible, defeating the purpose of rule-based confirmation
- Data are Waters vendor files — the README states LipidMatch does not currently support Waters files
- Goal is spectral-library identification from experimental spectra (e.g. LipidBlast-style matching) rather than rule-based fragment confirmation against in silico libraries

## Inputs

- Binary fragment matrix (Step 4 output; fragments 0/1 by intensity and scan thresholds)
- In silico lipid fragmentation libraries (.csv, >250,000 lipid species across 56 lipid types)
- Excel fragmentation-rules sheet specifying required fragments per lipid type
- Feature table from MZmine/XCMS/MS-DIAL peak picking (m/z, retention time)
- .ms2 MS/MS files generated by MSConvert

## Outputs

- Output CSV of identified lipids with assigned identification level (1–4) appended to each feature table
- Per-feature lipid ranking by summed fragment intensity

## How to apply

Load the binary fragment matrix from Step 4 (fragments assigned 1 if above user-defined minimum intensity and scan-count thresholds, 0 otherwise) and the in silico lipid library for the queried lipid types. For each feature–lipid pair, evaluate the required-fragment criteria chosen for the lipid class in the Excel fragmentation-rules sheet — e.g. both fatty acyl anions for formate-adduct PCs, or the m/z 184.0733 head group for protonated PCs — and identify the lipid only if all necessary fragments are observed. Assign an identification level: 1 for class plus fatty acyl constituents, 2 for data-independent analysis, 3 for class-only, 4 for precursor m/z without confirmatory fragments. Finally rank candidate lipids for a feature by the summed intensity of all fragments with in silico exact-mass matches, including those not used for confirmation, and write identified lipids with their levels to the output CSV.

## Evaluation signals

- Every output identification satisfies the required-fragment rule for its lipid type (e.g. protonated PCs carry the m/z 184.0733 head group fragment as observed)
- Each output row carries an identification level in 1–4 consistent with the fragments marked observed (1) in the binary fragment matrix
- Identifications by fatty acyl constituents should reach ~92% corroboration by other software in positive mode and ~98% in negative mode (article benchmark)
- Total identifications should meet or exceed MS-DIAL and Greazy on comparable plasma data (LipidMatch gave the most identifications for Red Cross plasma)

## Limitations

- Tested only on Windows 7 through 10; R version pinned to 3.3.3
- Depends on external peak-picking software (MZmine, XCMS, MS-DIAL) and MSConvert for .ms2 generation
- Users must develop their own fragmentation libraries in Excel for full customization of required fragments
- Key artifacts (software zip, libraries) were provided only as article additional files, not archived in a public repository (at publication time)
