# Neutral-loss extraction from MS/MS spectra

## Summary

Extracts neutral losses alongside fragment peaks from MS2 fragmentation spectra and encodes each spectrum as a bag-of-fragments representation, so that co-occurring fragments and losses can be learned as Mass2Motifs by MS2LDA's latent Dirichlet allocation.

## When to use

Use when raw MS2 fragmentation spectra (e.g., XCMS/mzMatch-preprocessed peaks paired via RMassBank, or MGF spectra such as the 5,670-spectrum GNPS set) must be converted into bag-of-fragments documents with neutral losses before LDA topic modeling.

## When NOT to use

- Automated spectral annotation against libraries such as Mass Bank or NIST: neutral losses are not currently supported by spectral matching tools and had to be omitted there
- Spectra from simple mixtures lacking information-rich MS2 data (i.e., not generated by ramped or stepped collision energy), where MS2LDA works best but such extraction adds little
- Computationally constrained pipelines where simpler tools suffice, since MS2LDA is more costly than simpler tools

## Inputs

- MS2 fragmentation spectra paired to MS1 peaks via RMassBank (e.g., from four beer raw files preprocessed with XCMS + PeakML/mzMatch)
- MGF-format MS/MS spectra such as the 5,670 public GNPS spectra from the CSI:FingerID study
- Mass Bank reference spectra used as fixed-seed or comparison motifs

## Outputs

- Bag-of-fragments corpus per spectrum, including extracted neutral losses
- Feature matrix with fragments/losses as rows and MS2 spectra as columns, containing integer occurrence counts
- Corpus CSV consumed downstream for LDA inference into Mass2Motifs

## How to apply

Start from MS1-peak–to–MS2-spectrum pairs produced by XCMS, PeakML/mzMatch, and RMassBank (roughly 1,000 MS peaks per preprocessed beer sample in both ionization modes). Run the MS2LDA preprocessing module load_and_clean on the paired spectra to remove noise entries from the fragment and neutral-loss lists. Then invoke the generate_corpus module to align MS2 features across all spectra of each sample, building a bag-of-fragments representation that includes extracted neutral losses. Assemble the aligned features into a matrix whose rows are MS2 features (fragments and losses) and whose columns are MS2 spectra, with values transformed from intensities into integer occurrence counts. The rationale is that Mass2Motifs are defined as sets of co-occurring fragments and neutral losses, so omitting losses would destroy the substructure signal that LDA learns.

## Related tools

- **MS2LDA** (Provides the load_and_clean and generate_corpus preprocessing modules that filter noise from fragment and neutral-loss lists and build the bag-of-fragments corpus with neutral losses) — https://github.com/vdhooftcompmet/MS2LDA
- **RMassBank** (Reliably pairs each MS1 peak with its corresponding MS2 fragmentation spectrum, supplying the input spectra from which neutral losses are extracted)
- **XCMS** (Upstream MS1 peak detection that defines the features whose MS2 spectra undergo neutral-loss extraction)

## Evaluation signals

- Output CSV exists, is well-formed, and contains only nonnegative integer values (intensities transformed to occurrence counts)
- Per-sample peak counts are consistent with the reported ~1,000 MS peaks per sample in both positive and negative ionization mode
- Neutral losses are present in the bag-of-fragments representation alongside fragments before LDA inference
- Downstream check: running the corpus through MS2LDA on the 5,670-spectrum GNPS set decomposes into approximately 500 Mass2Motifs
- Noise entries removed from fragment and neutral-loss lists by load_and_clean, verifiable by inspecting filtered peak lists

## Limitations

- Neutral losses are not currently supported by spectral matching tools and had to be omitted in automated Mass2Motif annotation
- MS2LDA works best for complex mixtures with information-rich MS2 spectra (e.g., generated by ramped or stepped collision energy)
- Computationally, MS2LDA is more costly than simpler tools, but not prohibitively so
- No version number for MS2LDA is stated in the article section
