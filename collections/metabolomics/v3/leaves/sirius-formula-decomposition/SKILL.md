# sirius-formula-decomposition

> **License: restricted** — no clear open-source license detected for the underlying tool; verify licensing before commercial use or redistribution. <!-- asb-license-banner -->
## Summary

Enumerates candidate chemical formulae for an observed MS1 precursor exact mass using SIRIUS's dynamic-programming decomposition module, supplying the candidate list that MIST-CF scores, or running full SIRIUS/CSI:FingerID as the comparison baseline on CASMI2022 spectra.

## When to use

Use when you have positive-mode MS/MS spectra (e.g., mzML exports) with an MS1 precursor exact mass and need a database-independent candidate formula list to feed MIST-CF scoring, or when benchmarking against SIRIUS/CSI:FingerID as in Table 2 of the MIST-CF paper.

## When NOT to use

- Negative-mode spectra — the article states 'We have trained models only for positive-mode data', so this positive-mode pipeline is the wrong choice
- You already have user-defined formula candidates (e.g., via notebooks/demo_mist_cf.ipynb) and do not need SIRIUS mass decomposition
- The input lacks an MS1 precursor exact mass, since SIRIUS decomp enumerates formulae from the observed MS1 mass

## Inputs

- Positive-mode MS/MS spectra in mzML format (extracted with MZmine 3 feature detection/export; 304 CASMI2022 challenge spectra)
- Preprocessed CASMI 2022 challenge data (casmi22.zip from Zenodo record 8151490, extracted under ./data/casmi22)
- MS1 precursor exact masses per spectrum
- Ground-truth formula/adduct assignments for scoring (CASMI 2022 challenge annotations)

## Outputs

- Per-spectrum candidate chemical formula lists generated by SIRIUS decomp
- MIST-CF scored formula predictions (ranked per spectrum)
- SIRIUS/CSI:FingerID top-1 predictions wrangled into a comparison table (results_table.tsv with joint formula+adduct and formula-only accuracies)

## How to apply

Download the headless SIRIUS build (v5.5.7 from the boecker-lab/sirius GitHub releases for Linux) and set the SIRIUS_PATH environment variable; the 'SIRIUS decomp' independent module is used because it lists all potential formulae for an observed MS1 mass via dynamic programming, which MIST-CF relies on 'due to their fast implementation'. Run the pretrained MIST-CF scorer (src/mist_cf/mist_cf_score/predict_mgf.py) over the SIRIUS-generated formula candidates for each exported spectrum. For the baseline comparison, run out-of-the-box SIRIUS/CSI:FingerID with the run_scripts/casmi22_eval/run_sirius.sh configuration and reformat output with wrangle_sirius.py. Score top-1 formula and joint formula+adduct predictions against ground truth with analysis/evaluate_pred.py, expecting ~0.842 vs 0.516 top-1 formula accuracy (MIST-CF vs CSI:FingerID) and 0.862 joint accuracy on the 304 CASMI2022 positive-mode spectra.

## Evaluation signals

- SIRIUS decomp returns a non-empty candidate formula list for each spectrum's MS1 exact mass (mass-decomposition invariant: candidates must match the precursor mass within instrument tolerance)
- CASMI2022 top-1 formula accuracy lands near 0.842 for MIST-CF (vs 0.516 for CSI:FingerID) and joint formula+adduct accuracy near 0.862 (vs 0.868 for the winning SIRIUS submission)
- Per-spectrum predictions and the Table 2 comparison are written to results_table.tsv via analysis/evaluate_pred.py
- SIRIUS baseline output is successfully reformatted by run_scripts/casmi22_eval/wrangle_sirius.py before scoring
- Demo sanity check: quickstart/run_model.sh over data/demo_specs.mgf (10 CASMI22 spectra) produces predictions in quickstart/mist_cf_out/

## Limitations

- MIST-CF still depends on SIRIUS for mass decomposition: 'we still rely upon SIRIUS's algorithmic decomposition of exact masses into formula candidates due to their fast implementation'
- The quickstart model (trained on public NPLIB1/CANOPUS data) may underperform on Orbitrap or higher-resolution data compared to NIST20-trained models, which require a NIST license
- MIST-CF considers multiple adduct types beyond [M+H]+ but only in positive mode; no MS1 isotopic information is used
