# drug-class-metabolite-count-aggregation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Aggregates BioTransformer-predicted and experimentally detected human liver S9 metabolites per therapeutic drug class into a summary table (e.g. 17,967/36,406 detected for CNS, 13,089/28,302 for cardiovascular), enabling coverage comparisons across the 1114 drugs in PharmMet DB.

## When to use

Use when you have per-drug metabolite annotations plus a drug-class mapping (Supplemental Table 1) and need per-class counts of predicted vs detected metabolites or detection-rate percentages.

## When NOT to use

- You need structurally elucidated novel metabolites — the skill only counts features; novel metabolites from ~1000 drugs require isolation and structural elucidation research
- Your metabolites are formed extrahepatically or by enzymes absent from liver S9 — PharmMet DB and these counts will systematically miss them
- You only have raw instrument files and no per-drug annotations — run the 0-hour vs 24-hour differential detection and BioTransformer cross-referencing first

## Inputs

- LC-HRMS feature tables with per-drug metabolite annotations (Metabolomics Workbench Study ST003991, DOI 10.21228/M8W55K)
- Supplemental Table 1 drug-class mapping for the 1114 therapeutic drugs in PharmMet DB
- BioTransformer 3.0 predicted-metabolite lists per parent drug

## Outputs

- drug_class_metabolite_counts.csv with predicted and detected metabolite counts per drug class
- Per-class detection-rate percentages (e.g. CNS 49%, cardiovascular ~46%)

## How to apply

Download the LC-HRMS feature tables from Metabolomics Workbench Study ST003991 (Project DOI 10.21228/M8W55K) and the per-drug-class file from the PharmMet GitHub repo, then load both in pandas or R 4.0.3 and join each detected feature to its parent drug's class via Supplemental Table 1 (1114 therapeutic drugs). For each class, count metabolites predicted by BioTransformer 3.0 and metabolites detected in 24-hour postincubation samples passing the paper's criteria: exclusive detection in precursor-plus-cosubstrate samples, mass accuracy within ±5 ppm, and ≥10-fold time-dependent signal increase from 0 to 24 hours. Group by the paper's classes (cardiovascular, CNS, antimicrobial, anti-inflammatory/immunomodulatory, endocrine/metabolic, respiratory, musculoskeletal, GI, hematological, other) and write drug_class_metabolite_counts.csv. Validate by checking overall totals against the reported 30,752 oxidized and 6311 glucuronidated metabolites and by confirming that novel-metabolite enrichment appears in anti-inflammatory, CNS, and antimicrobial classes.

## Related tools

- **R 4.0.3** (Joining feature tables to drug classes and aggregating counts per class)
- **BioTransformer 3.0** (Source of predicted metabolites against which detected features are classified as predicted vs novel)
- **PharmMet DB** (Reference database supplying the 1114-drug per-class metabolite annotations being aggregated) — https://github.com/ClinicalBiomarkersLaborabory/PharmMet

## Examples

```
df = pd.merge(features, drug_classes, on='parent_drug'); counts = df.groupby('drug_class')[['predicted','detected']].sum(); counts.to_csv('drug_class_metabolite_counts.csv')
```

## Evaluation signals

- Overall aggregated counts reproduce the reported totals: 30,752 oxidized and 6311 glucuronidated metabolites
- Per-class rates fall in the reported ~46–49% detection band (CNS 17,967/36,406 = 49%; cardiovascular 13,089/28,302; endocrine/metabolic 4,685/10,064; anti-inflammatory 11,578/24,929)
- Novel (non-BioTransformer-predicted) metabolites enrich in anti-inflammatory, CNS, and antimicrobial classes
- Every detected feature maps to exactly one of the 1114 drugs' classes with no unmapped rows
- Counts only include features meeting ±5 ppm mass accuracy and ≥10-fold 0→24 h signal increase criteria

## Limitations

- Reliance on liver S9 fraction means metabolites from enzymes not abundant/active in that fraction, or formed extrahepatically (e.g. intestine, kidney), are absent from the counts
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression, depressing per-class detection rates
- The 1114 active therapeutic agents are not completely comprehensive, so class-level totals undercount less common drugs
