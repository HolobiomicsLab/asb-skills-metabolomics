# consensus-spectrum-candidate-ranking

## Summary

Annotate a molecule with multiple query MS/MS spectra by first aggregating the constituent spectra into a consensus spectrum, then ranking candidate molecules against it with MVP's mol-cs view; this aggregate-then-rank strategy outperforms rank-then-aggregate (e.g. 35.99% vs 26.37% rank@1 for candidates by mass).

## When to use

Use when a molecule has multiple query MS/MS spectra (e.g. three collision-energy levels from MZmine3 feature extraction) and you need a single ranked candidate list rather than per-spectrum rankings.

## When NOT to use

- When each molecule has only one query spectrum — there is no consensus to build; rank candidates directly on that spectrum instead.
- When the goal is de novo molecule generation or spectrum simulation (MassSpecGym challenges other than retrieval), not candidate ranking.
- When constituents have inconsistent precursor masses or adducts so a consensus spectrum is not meaningful — rank per spectrum and aggregate instead, but expect lower rank@1 per the article's finding.

## Inputs

- Molecule's multiple constituent MS/MS spectra as a TSV (e.g. data/sample/data.tsv) with collision-energy levels
- Candidate molecule list retrieved by mass or formula (candidates_mass.json), e.g. within 0.01 Da tolerance from FoodDB/HMDB/MassSpecGym/NIST23/GNPS Multiplex
- MVP params YAML (params_formSpec.yaml or params_binnedSpec.yaml) pointing at dataset and candidate paths
- Pretrained MVP checkpoint trained on MassSpecGym

## Outputs

- Consensus spectra files and fingerprints generated by data_preprocess.py
- Ranked list of candidate molecules per query molecule from the mol-cs (consensus spectrum) view
- rank@1 (and rank@k) metrics for aggregate-then-rank versus rank-then-aggregate strategies, saved as a structured CSV comparison table

## How to apply

Build a consensus spectrum from the molecule's constituent spectra (MVP's data_preprocess.py generates consensus spectra files from the spectra TSV and candidate list, e.g. candidates_mass.json), then score candidates using MVP's mol-cs ranking view. Restrict the evaluation to molecules with a fixed number of spectra — the paper's comparison on MassSpecGym test molecules with exactly three spectra shows consensus-spectrum annotation achieves higher rank@1 (35.99% vs 26.37% for mass-candidates; 13.96% vs 11.10% for formula-candidates) than aggregating per-spectrum rankings via average rank or reciprocal rank. Run test.py with params_formSpec.yaml (formSpec requires subformula labels via assign_subformulae.py, max-formulae 60) or params_binnedSpec.yaml against the pretrained MassSpecGym checkpoint, and compare against rank-then-aggregate baselines using rank@1 (and rank@k).

## Related tools

- **MVP** (Multiview contrastive model providing the mol-cs (consensus spectrum) ranking view used to score candidate molecules against an aggregated spectrum) — github.com/HassounLab/MVP

## Examples

```
python data_preprocess.py --spec_type formSpec --dataset_pth ../data/sample/data.tsv --candidates_pth ../data/sample/candidates_mass.json --output_dir ../data/sample/; python test.py --param_pth params_formSpec.yaml
```

## Evaluation signals

- Consensus-spectrum (mol-cs) rank@1 should exceed the rank-then-aggregate baseline: 35.99% vs 26.37% (mass-candidates) and 13.96% vs 11.10% (formula-candidates) on molecules with exactly three spectra.
- The comparison subset must contain only test molecules with exactly three constituent spectra (1,531 cases in the paper).
- All candidate rankings should use the pretrained MassSpecGym checkpoint via test.py with the same params YAML across strategies for a fair diff.
- For high-confidence annotations downstream, filter to molecule–spectra scores > 0.5 with a ≥ 0.01 margin between top- and second-ranked candidates.
- Reproducing MVP on the meat-study data should yield ~640 annotated spectra / 146 unique molecules after the same score/margin filters.

## Limitations

- Reported annotations are putative and require experimental validation.
- Losses that prioritize ranking molecular candidates are not currently included in MVP; ranking-specific losses could improve performance.
- Representation quality could benefit from more accurate peak labeling and additional views.
- The aggregate-then-rank advantage was established on a subset of test molecules with exactly three spectra, not the full benchmark.
