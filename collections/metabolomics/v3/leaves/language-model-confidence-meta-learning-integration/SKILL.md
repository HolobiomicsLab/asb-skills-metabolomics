# language-model-confidence-meta-learning-integration

## Summary

Integrate a chemical language model's sampling-frequency confidence with MS/MS spectral matching scores via meta-learning to produce calibrated metabolite annotation probabilities.

## When to use

Use when annotating experimental MS/MS spectra against candidate structures generated by a chemical language model, and you need to combine spectral similarity scores with generative confidence to rank and calibrate annotations.

## When NOT to use

- When the task is de novo structure elucidation of a single unknown without a generative model's candidate set — the skill depends on a pre-existing library of language-model-predicted candidates.
- When spectra lack adequate MS/MS fragmentation (e.g., only MS1 accurate-mass data) — spectral dot-product matching cannot be performed.
- When the biological system is evolutionarily distant from the model's training set (e.g., plant or bacterial metabolism) — DeepMet was trained on human metabolite structures and may not extrapolate.

## Inputs

- DeepMet-generated candidate structures (SMILES) with recorded sampling frequencies
- CFM-ID–predicted MS/MS spectra (positive and negative ion mode) for each candidate
- Experimental MS/MS peak lists from metabolomics analyses (e.g., human blood)

## Outputs

- Per-candidate annotation probability (calibrated via meta-learning)
- Ranked list of candidate structures per spectrum
- Exact-structure assignment rates (e.g., 52% positive / 49% negative mode)

## How to apply

First, generate a database of candidate metabolite-like structures using DeepMet (34.4 million structures; retain the 2.4 million sampled at least five times, using sampling frequency as the language-model confidence). Next, predict ESI MS/MS spectra for each candidate with CFM-ID in both positive and negative ionization modes to build an in silico spectral library. Preprocess experimental spectra from human blood analyses (peak listing, m/z binning) and score each against library candidates using spectral dot-product matching. Finally, integrate the spectral score with the DeepMet sampling-frequency confidence via a meta-learning combiner that merges outputs of multiple independent machine-learning models to distinguish correct from incorrect annotations, yielding calibrated probabilities for each candidate.

## Related tools

- **DeepMet** (Generates candidate metabolite structures; its sampling frequency supplies the language-model confidence signal integrated by meta-learning.) — https://github.com/skinniderlab/clm
- **CFM-ID** (Predicts ESI MS/MS spectra in positive and negative ion modes for each candidate structure, building the in silico library used for spectral matching.)
- **RDKit** (Used for preprocessing candidate structures — converting to molecules, removing light fragments, neutralizing charges, filtering valid elements.)
- **PyTorch** (Supports the meta-learning model that fuses spectral scores with language-model confidence to output calibrated annotation probabilities.)

## Examples

```
cfm-id -p candidate.smiles -o predicted_spectra.msp --ion-mode both; python meta_learning_annotate.py --spectra blood.mzML --library predicted_spectra.msp --lm-confidence deepmet_freqs.tsv --out msms_annotation_evaluation.csv
```

## Evaluation signals

- Exact-structure assignment of held-out metabolites should reach approximately 52% in positive ion mode and 49% in negative ion mode.
- Top-3 and top-10 hit rates on held-out metabolites should show measurable improvement over spectral matching alone.
- Tanimoto chemical-similarity metrics for the top-ranked annotations should be reported and compared against baseline methods.
- Meta-learning outputs should be well-calibrated — predicted probabilities should match empirical annotation accuracy across confidence bins.
- The 2.4 million candidates retained should each have a sampling frequency ≥ 5 from the 34.4 million generated structures.

## Limitations

- DeepMet was trained and evaluated on human metabolite structures; applying it to evolutionarily distant systems (plant or bacterial metabolism) likely requires a bespoke model.
- The language model has inherent limitations in anticipating metabolites that originate from divergent, as-of-yet undiscovered biosynthetic routes.
- Predicting MS/MS spectra or retention times from chemical structures remains an open problem, which constrains the accuracy of the in silico spectral library.
- The opportunity to more tightly integrate DeepMet with analytical data beyond MS/MS (e.g., retention time, isotope patterns) has not yet been realized.
