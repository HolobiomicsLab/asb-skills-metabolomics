# per-mz-position-fragment-classifier-training

> **License: restricted** — no clear open-source license detected for the underlying tool; verify licensing before commercial use or redistribution. <!-- asb-license-banner -->
## Summary

Trains one binary deep learning classifier per MZ position (e.g. ANNmodel.py, GNNmodel.py, COMmodel.py in SingleFrag) to predict peak presence/absence at that m/z bin, rather than predicting the whole MS/MS spectrum with a single model.

## When to use

Use when you need to predict MS/MS peak presence per m/z bin from molecule structures (SMILES), or to retrain/augment per-bin classifiers — e.g. adding 3D features to a mol2vec-based classifier.

## When NOT to use

- You need full-spectrum intensity prediction from a single model rather than binary peak presence per m/z bin
- Your spectra contain peaks at MZ positions outside the most frequented bins covered by trained models/thresholds

## Inputs

- SingleFrag dataset from Figshare (training, validation, test splits)
- Molecule SMILES (e.g. inputMols_git.xlsx)
- 300-dimensional mol2vec embeddings from Mol2vecModelGeneral_rep_dades1.model
- AllMostFreqMolGeneral_rep_dades1.pickle (peak counts per MZ bin in training set)
- Optional: 3D atom-location / conformer descriptors per molecule

## Outputs

- Per-MZ-position trained models (results/ModelVal*.pickle per ANN/GNN/COM)
- Per-MZ-position prediction files (results/dfPredictionPeak_***.pickle)
- Per-position decision thresholds (thresholdsANN/GNN/COM.pickle)
- Reconstructed spectra (results/predSpectra.json)
- Per-bin F1 scores on the held-out test set

## How to apply

Download the SingleFrag dataset from Figshare (figshare.com/articles/dataset/SingleFrag/27266787) containing the training, validation and test splits used with ANNmodel.py, GNNmodel.py and COMmodel.py. For each of the most frequented MZ positions in the training set spectra (the ~1,000 most frequented 1,000 MZ bins are tracked in AllMostFreqMolGeneral_rep_dades1.pickle), train one model per position that predicts whether a molecule presents a peak at that specific MZ position; the MZ position is specified as script input, with file names encoding the position as mz*100. Represent each molecule as input features — the baseline ANN uses a 300-dimensional mol2vec vector generated by Mol2vecModelGeneral_rep_dades1.model from SMILES — and optionally augment with 3D conformer-derived features (3DMolMS-style). After training, determine a decision threshold per MZ position (thresholdsANN/GNN/COM.pickle): if a prediction for a position is greater than or equal to its threshold, a peak at that bin is predicted; reconstruct the full spectrum by combining all per-MZ predictions.

## Related tools

- **SingleFrag** (Framework providing ANNmodel.py, GNNmodel.py and COMmodel.py scripts, per-MZ-position trained pickles and threshold files; run with Python 3.8.19) — https://github.com/MaribelPR/SingleFrag
- **mol2vec** (Generates the 300-dimensional molecule embedding used as classifier input)
- **3DMolMS** (Source of 3D molecular structure representations for augmenting per-bin classifiers) — https://github.com/JosieHong/3DMolMS

## Examples

```
python ANNmodel.py <mz_position>  # train the per-bin model for one MZ position (files encode MZ as mz*100)
```

## Evaluation signals

- Per-bin F1 on the held-out test set must meet or exceed the mol2vec-ANN reference mean F1 of 0.411
- Threshold application rule holds: prediction >= per-position threshold implies predicted peak at that MZ bin
- Trained model files exist only for MZ positions listed as most frequented in AllMostFreqMolGeneral_rep_dades1.pickle
- All pickle artifacts load under Python 3.8.19 (the version used to create every .pickle)

## Limitations

- Only the most frequented MZ positions in the training set spectra have trained models and thresholds; rare bins are uncovered
- GNN per-bin models showed slightly lower performance than ANN models, which the authors attribute to unoptimized graph features and architectures rather than a fundamental limitation
- Toy input spectra in inputMols_git.xlsx contain integer m/z only, while models predict fragments with 2-decimal resolution
