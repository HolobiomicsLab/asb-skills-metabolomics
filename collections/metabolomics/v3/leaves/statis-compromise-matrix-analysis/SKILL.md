# statis-compromise-matrix-analysis

## Summary

Computes eight pairwise distance measures between normalized draft genome-scale metabolic reconstructions and combines them into STATIS compromise matrices, then tests whether these structural distances correlate with 16S rRNA phylogenetic distance.

## When to use

Use when you have multiple draft GEMs of the same isolate set (e.g. 432 At-SPHERE genomes reconstructed by four pipelines) and need to quantify structural differences and test their biological relevance against phylogeny.

## When NOT to use

- Only a single draft reconstruction is available — STATIS requires multiple reconstructions of the same isolates to compute pairwise distances
- Reconstructions still use pipeline-specific identifiers without MNXref translation — structural overlap would be artificially low and distances meaningless
- The goal is functional community gap-filling rather than structural comparison — use the COMMIT gap-filling workflow instead

## Inputs

- Draft SBML genome-scale metabolic reconstructions of 432 At-SPHERE isolates generated by KBase, CarveMe, RAVEN 2.0, and AuReMe/Pathway Tools
- MNXref reference files: reac_prop.tsv, reac_xref.tsv, chem_prop.tsv, chem_xref.tsv
- One-to-one BLAST mappings between pipeline-specific gene IDs
- 16S rRNA sequence (phylogenetic) distance matrix for the 432 isolates

## Outputs

- Matlab workspaces (.mat) of models per habitat and reconstruction approach under data/models/<habitat>/<method>
- Eight pairwise distance matrices between normalized reconstructions
- STATIS compromise matrices
- Correlations (e.g. Jaccard distance vs. 16S rRNA distance) with significance values

## How to apply

First normalize the reconstructions: read each pipeline's SBML models with the COBRA toolbox readCbModel, collect them into cell arrays, and save them as Matlab workspaces (.mat) under data/models/<habitat>/<method>. Translate metabolite, reaction, and gene identifiers to a common MNXref namespace using the MNXref reference files (reac_prop.tsv, reac_xref.tsv, chem_prop.tsv, chem_xref.tsv via createMnxrefTranslationTables), using one-to-one BLAST mapping (translateGeneIDs) where pipelines used different gene IDs. Then compute the eight pairwise distance measures between the normalized reconstructions and combine them into the STATIS compromise matrices. Finally, correlate the computed distance measures (including Jaccard distance) with the 16S rRNA sequence distance to assess biological relevance. Judge success by reproducing the reported summary statistics: average compromise distance 0.64 (range 0.54–0.72), Jaccard–16S correlations 0.63–0.75 (mean 0.70, p < 0.001), SVD/cofactor rho ~0.25, and dead-end rho ~0.04.

## Evaluation signals

- Average STATIS compromise distance reproduces 0.64 with range 0.54–0.72 across the 432 isolates
- Jaccard distance vs. 16S rRNA distance correlation falls in 0.63–0.75 (mean 0.70, p < 0.001)
- SVD/cofactor measure correlates with rho ~0.25 and dead-end measure with rho ~0.04
- All four pipelines' models load successfully via readCbModel into cell arrays per habitat and method before distance computation
- Identifier normalization is complete: metabolites, reactions, and genes share a common MNXref namespace across pipelines

## Limitations

- Definitions of all eight distance measures are deferred to supplementary S1 Text, not the main text
- Comparison to reference models was hampered by the lack of reaction cross-references to other name spaces; translations were only done 'whenever possible'
- 16S rRNA sequences were only available via personal provision (from Ruben Garrido Oter), not a public accession
- Only sensitivity and precision could be computed against reference models since true negatives could not be determined
