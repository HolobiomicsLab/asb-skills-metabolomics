# maccs-and-morgan-fingerprint-computation

## Summary

Computes MACCS-key and Morgan fingerprint Tanimoto similarity scores between TeFT-predicted candidate structures and real structures (converted to SMILES) to quantify how closely de novo MS2-spectrum structure predictions match ground truth.

## When to use

Use when scoring de novo molecular structure predictions from tandem MS spectra — e.g. evaluating TeFT candidates on the 660-spectrum GNPS/HMDB(5.0)/MoNA test set — by comparing predicted vs. real structures at Tanimoto 1.0, 0.9, and 0.8 thresholds.

## When NOT to use

- Spectra recorded in negative ion mode: TeFT was only trained on spectra in positive ion mode (H+), so predicted candidates fed into this similarity scoring would be out of applicability
- Structure predictions already supplied with a computed similarity table or exact-match labels — recomputing fingerprints adds no information
- Evaluating methods that output molecular formulas or fingerprints directly (e.g. fingerprint-only models like MSNovelist) without a full candidate SMILES structure to convert

## Inputs

- Predicted molecular structures (SMILES) generated by the TeFT pipeline for each MS2 spectrum
- Real/reference molecular structures (SMILES) paired with the 660 non-repetitive MS2 test spectra from GNPS, HMDB (5.0), and MoNA

## Outputs

- Per-spectrum MACCS-key fingerprint Tanimoto similarity scores
- Per-spectrum Morgan fingerprint Tanimoto similarity scores
- Aggregate results table (results_table.csv) with counts/percentages at Tanimoto 1, >0.9, and >0.8 (expected: 195/660, 311/660, 439/660)

## How to apply

Take the best candidate structure emitted by the TeFT pipeline (thumingo/TeFT) for each MS2 spectrum, convert both the predicted and the real structure to SMILES, and ensure SMILES are standardized with duplicates removed, mirroring how the training set standardized SMILES representations. Encode each standardized SMILES as both a MACCS-key fingerprint and a Morgan fingerprint, then compute the Tanimoto similarity between predicted and reference fingerprints for each spectral entry. Treat Tanimoto = 1 as an exact structural identification, and count entries exceeding the 0.9 and 0.8 similarity thresholds used by the paper. Aggregate counts over the 660 non-repetitive MS2 test spectra into a results table (results_table.csv), reporting exact matches (195/660, 30%), >0.9 (311/660, 47%), and >0.8 (439/660, 67%), and optionally compare against the SIRIUS4 baseline (27.6% exact, 39% >0.9). The rationale is that fingerprint Tanimoto scoring yields graded, thresholded similarity metrics even when de novo generation returns a near-miss rather than an exact structure.

## Related tools

- **Transformer enabled Fragment Tree (TeFT)** (Generates the best candidate molecular structure per MS2 spectrum; its predicted SMILES are the query side of the fingerprint Tanimoto comparison) — https://github.com/thumingo/TeFT
- **SIRIUS4** (Baseline structure-prediction method whose exact-match and >0.9 similarity percentages the Tanimoto-thresholded counts are compared against)

```
from rdkit import Chem, DataStructs; fp = DataStructs.AllChem.GetMorganFingerprintAsBitVect(Chem.MolFromSmiles(pred_smiles), radius=2); tc = DataStructs.TanimotoSimilarity(fp, fp_reference)
```

## Evaluation signals

- Exact-structure invariant: fingerprint Tanimoto = 1 corresponds to identical structures; the test-set reproduction should yield exactly 195/660 (30%) at Tanimoto 1
- Threshold counts reproduce 311/660 (47%) above 0.9 and 439/660 (67%) above 0.8 similarity
- Monotonicity check: count(Tanimoto > 0.8) >= count(Tanimoto > 0.9) >= count(Tanimoto = 1) must hold
- Comparison against the reported SIRIUS4 baseline (27.6% exact matches, 39% above 0.9) on the same 660-spectrum set
- Total denominator invariant: all percentages computed out of 660 spectra

## Limitations

- TeFT was only trained on spectra recorded in positive ion mode (H+), restricting the applicability of the downstream similarity evaluation to positively charged MSn spectra
- The article notes the model 'may not exhibit exceptional performance advantages in predicting high-quality resolution spectra compared to other deep models' (e.g. MassGenie, SIRIUS4/CSI:FingerID), so these similarity metrics should not be generalized to high-resolution data
- Tanimoto similarity below 1 is a graded proxy, not proof of structural identity; only Tanimoto = 1 constitutes a confirmed exact identification
