# cluster-representative-selection-for-qm-refinement

## Summary

Applies the paper's in-house AutoGraph unsupervised clustering code to ANI-1ccx-optimized RDKit conformer ensembles, condensing hundreds of generated conformers (e.g., carnosine's 990–996 per-state conformers) into a small set of structurally distinct representatives (12–16 per state) before Gaussian 16 DFT optimization.

## When to use

Use when a large RDKit-generated conformer ensemble (hundreds of geometries per protonation state) has been relaxed with ASE-ANI and must be reduced to structurally distinct representatives before DFT-level geometry optimization.

## When NOT to use

- The input is still raw SMILES or unoptimized RDKit conformers — clustering should be applied after ASE-ANI minimization, not before
- The conformer ensemble is already small or contains a single structure per state, so no conformational-complexity reduction is needed
- The goal is ionization-state determination or adduct enumeration (Dimorphite-DL handles those upstream steps), not 3D-geometry redundancy reduction

## Inputs

- ANI-1ccx/ASE-ANI-optimized conformer geometries for a given protonation state, originally generated by RDKit
- Conformer ensemble per molecular state (e.g., the five carnosine states: one neutral, three monoprotonated, one doubly protonated)

## Outputs

- cluster_representatives.sdf containing one representative conformer per cluster with coordinates and cluster assignments
- Structurally distinct conformer set feeding the Gaussian 16 DFT step (e.g., 16, 13, 15, 12, and 14 conformations for carnosine's five states)

## How to apply

Load the conformer ensemble generated with the RDKit toolkit for the selected protonation state ([M + H]+ or [M − H]−), as relaxed by the ASE_ANI QM-based ML model geometry optimization. Run the in-house AutoGraph unsupervised clustering code on the optimized conformer geometries to group structurally similar conformers without human supervision — no distance cutoffs or cluster count are set manually. Extract one representative conformation from each cluster to yield the structurally distinct conformations, then write the representative coordinates and cluster assignments to cluster_representatives.sdf. These representatives feed the downstream Gaussian 16 DFT step; in the paper's carnosine benchmark this reduced per-state ensembles of 990, 994, 994, 994, and 996 conformers down to 16, 13, 15, 12, and 14 unique conformations, respectively. Validate that the number of clusters is smaller than the input ensemble and that each representative is structurally distinct.

## Related tools

- **RDKit** (Generated the conformer ensemble that AutoGraph clusters (upstream step)) — https://www.rdkit.org
- **ASE-ANI** (QM-based ML model geometry optimization (ANI-1ccx) that relaxes conformers before clustering) — https://github.com/isayev/ASE_ANI
- **Snakemake** (Workflow manager orchestrating the clustering stage within the CCS prediction pipeline) — https://github.com/DasSusanta/snakemake_ccs

## Evaluation signals

- Number of clusters output by AutoGraph is smaller than the input conformer ensemble (e.g., carnosine: 990–996 input conformers reduced to 12–16 clusters)
- Each extracted representative is a structurally distinct conformation, confirming no duplicate/near-identical representatives survive
- Exactly one representative per cluster is extracted, with no manual cluster selection applied
- cluster_representatives.sdf is written with both coordinates and cluster assignments
- Downstream Gaussian 16 DFT optimization runs successfully on the representative set

## Limitations

- AutoGraph is in-house unsupervised clustering code; no external parameter documentation or versioned release is described in the article
- The workflow's detailed step descriptions are deferred to the Supporting Information, and Figure 1 (workflow diagram) is referenced but not embedded in the methods text
- No software version numbers are stated for RDKit, ASE_ANI, or Gaussian 16, complicating exact reproduction of the clustering input geometries
