# composite-spectra-clustering-from-ms1-ions

## Summary

Deconvolves LC/HRMS MS1-only data into composite mass spectra by grouping correlating co-eluting extracted ion chromatograms (EICs) with IDSL.CSA, enabling chemical annotation of peaks that lack MS2 fragmentation spectra.

## When to use

Use when you have MS1-only LC/HRMS data (mzXML, mzML, netCDF) already peak-picked with IDSL.IPA and need composite spectra libraries (MSP) for annotating co-eluting ions such as adducts, isotopologues, and in-source fragments.

## When NOT to use

- You already have DDA MS/MS data or an MS/MS library (e.g. NIST 2020) sufficient to annotate the peaks — CSA targets datasets that lack MS2 fragmentation spectra.
- The peak tables and aligned peaklists have not yet been generated by IDSL.IPA — CSA expects IDSL.IPA outputs, not raw vendor files or generic feature tables.
- The data are not LC/HRMS (e.g. low-resolution MS), since CSA relies on high-resolution EIC correlation.

## Inputs

- MS1-level LC/HRMS raw data files (mzXML, mzML, netCDF), e.g. pool_P1_A1-A12.mzML
- IDSL.IPA 'peaklists' directory containing chromatographic peak information (m/z-RT)
- IDSL.IPA 'peak_alignment' directory containing aggregated aligned peaklists
- IDSL.CSA parameter spreadsheet (CSA_parameters.xlsx) with 39 parameters in 5 sections

## Outputs

- CSA_MSP directory containing a .msp file of composite spectra clusters (e.g. 42 CSA spectra from the pooled-standards test)
- CSA_adduct_annotation directory with peaklists carrying potential adduct information
- peak_alignment_subset directory with subsets of aligned peak tables for major ions in each CSA cluster
- aligned_spectra_table with CSA aggregation information on the aligned peak table
- Batch untargeted aligned EIC figures for the CSA analysis

## How to apply

First process the raw MS1 data (e.g. pool_P1_A1-A12.mzML from MSV000088661) with the IDSL.IPA workflow to generate the 'peaklists' and 'peak_alignment' directories. Then download the IDSL.CSA parameter spreadsheet (39 parameters in 5 sections) and set PARAM0001=YES for CSA-only processing, CSA0005 to the HRMS data location, CSA0008 to the peaklists directory, CSA0009 to the peak_alignment directory, CSA0011 to the output location, and optionally CSA0004 to increase processing threads. The key deconvolution decision point is the Pearson correlation threshold between EICs — in the pooled-standards validation, a threshold of 0.98 grouped 76.9% of detected peaks into 42 EIC groups, exported as 42 CSA spectra in MSP format. Run library(IDSL.CSA); IDSL.CSA_workflow('Address of the CSA parameter spreadsheet') in R/RStudio or a terminal, then parse the results at the CSA0011 address.

- Parameter counts and required entries are satisfied: 39 CSA parameters across 5 sections, with PARAM0001, CSA0004, CSA0005, CSA0008, CSA0009, and CSA0011 filled.
- Peak-detection results from IDSL.IPA are reproducible — the workflow completes without errors when run as IDSL.CSA_workflow on the filled spreadsheet.

## Limitations

- Annotation coverage is incomplete: MS2 fragmentation data are not available for every detected peak and available MS2 libraries poorly cover the expected chemical space, motivating MS1-only composite spectra.
- Existing MS1 annotation approaches are limited to flagging peaks as potential isotopologues, adducts, or in-source fragments; CSA spectra are composite and not true MS/MS spectra.
