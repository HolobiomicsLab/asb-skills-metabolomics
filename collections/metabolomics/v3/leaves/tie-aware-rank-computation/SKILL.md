# tie-aware-rank-computation

## Summary

A ranking post-processing step within BAM that resolves ties among candidate derivative structures by computing an average rank: the sum of all ranks, including duplicates, divided by the number of tied candidates. This yields a stable, deterministic rank for the true suspect when multiple derivatives share the same site-of-metabolism likelihood from GNN-SOM.

## When to use

Use when GNN-SOM assigns identical site-of-metabolism likelihoods to multiple candidate derivatives generated by PROXIMAL2 from an anchor molecule, and a single unambiguous rank must be reported for each suspect.

## When NOT to use

- Candidate likelihoods are all distinct, so no tie groups exist and standard ordinal ranking suffices
- The ranking criterion is not GNN-SOM site-of-metabolism likelihood (e.g. ranking by spectral similarity or formula score)

## Inputs

- Ranked list of candidate derivative structures for a suspect, each scored by GNN-SOM site-of-metabolism likelihood
- GNN-SOM likelihood values for the atom to which the biotransformation rule was applied in each candidate

## Outputs

- Final rank for each candidate derivative with ties resolved to an average-rank value
- Reported rank position of the true suspect among all ranked candidates

## How to apply

After applying biotransformation rules to the anchor molecule and scoring each generated derivative with GNN-SOM, candidates whose reaction-center atoms receive identical likelihood values form a tie group. Sort candidates by GNN-SOM likelihood; for a tie group, sum the ordinal ranks (including duplicate positions occupied by the tied members) and divide by the number of tied candidates, assigning this average rank to each member. This resolves ambiguity so the reported rank of the true suspect is deterministic rather than dependent on arbitrary tie-breaking. Acceptance is judged by whether the true suspect falls within ranks 1–5 of the resulting candidate list.

## Evaluation signals

- Every member of a tie group receives the same average rank, equal to (sum of occupied ordinal positions) / (number of tied candidates)
- The average rank of a tie group falls within the range of the ordinal positions it spans (e.g. a two-way tie at positions 2 and 3 yields 2.5)
- Sum of all final ranks equals the sum of all ordinal positions (invariant preserved by averaging)
- Reported rank of the true suspect is deterministic across repeated runs on identical candidate lists
- Performance is reported as the proportion of true suspects ranked within positions 1 to 5

## Limitations

- Averaged ranks are non-integer, so downstream consumers expecting strict integer rank positions must handle fractional values
- Ties reflect equal GNN-SOM likelihood, not necessarily equal structural plausibility; the average rank may under- or over-represent a candidate whose true correctness differs from its likelihood peers
- Only applies after GNN-SOM scoring; candidates generated but rejected earlier by PROXIMAL2 never enter the tie-resolution stage
