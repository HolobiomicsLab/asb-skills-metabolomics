# targeted-metabolomics-data-elaboration

## Summary

Applies the GetFeatistics R-package targeted-analysis pipeline, using get_targeted_elaboration to fit calibration curves from intensity and nominal-concentration tables with internal-standard normalization and different weighting options, converting raw peak intensities into calibrated absolute concentrations with QC accuracy metrics.

## When to use

Use when you have targeted metabolomics peak-intensity tables with internal-standard and nominal-concentration (calibration curve point) information and need absolute concentrations plus curve/QC accuracy and internal-standard CV metrics.

## When NOT to use

- Input is an untargeted feature table from patRoon or MS-DIAL — use the GetFeatistics untargeted functions (feature import, annotation confidence levels, pooled QC filtering) instead
- Raw mass-spectrometry data files requiring feature extraction (e.g. via XCMS) — targeted elaboration starts from peak-intensity tables, not raw data
- Input already contains calibrated absolute concentrations and you only need downstream statistics such as mixed-effects or Tobit regression models

## Inputs

- Targeted-analysis intensity table (peak intensities per molecule per sample)
- Nominal-concentration table for calibration-curve points
- Internal-standard assignment table
- Mock example tables generated by create_df_examples (for workflow testing)

## Outputs

- results_concentrations: calibrated absolute concentrations per molecule/sample
- results_accuracy: accuracy (%) for calibration-curve points and quality controls
- cv_internal_standards: internal-standard CVs
- summary_regression_models: fitted calibration regression-model summaries
- Per-molecule calibration-curve ggplot objects from plot_calibration_curves

## How to apply

First generate or load the three targeted-analysis input tables (intensity table, nominal-concentration table for calibration points, and internal-standard assignments); GetFeatistics provides create_df_examples to produce mock versions of these for testing. Run get_targeted_elaboration on these tables: it fits per-molecule calibration curves from the intensity and nominal-concentration data using the package's supported data weighting options, normalizes by internal standards, and back-calculates absolute concentrations. Inspect the four returned objects: results_concentrations (calibrated absolute concentrations), results_accuracy (accuracy (%) for calibration-curve points and quality controls), cv_internal_standards (internal-standard CVs), and summary_regression_models (fitted regression-model summaries). Visualize curve fits per molecule with plot_calibration_curves, which renders ggplot objects you can customize via the ggplot grammar. Save all returned tables and plots to files for verification.

## Examples

```
library(GetFeatistics); df_example_targeted <- create_df_examples(); res <- get_targeted_elaboration(df_example_targeted); plot_calibration_curves(res)
```

## Evaluation signals

- results_accuracy contains accuracy (%) values for both calibration-curve points and quality controls, confirming back-calculated concentrations were compared against nominal values
- summary_regression_models is non-empty and reports the fitted calibration regression-model summaries (including weighting) for each molecule
- cv_internal_standards reports CVs for each internal standard; anomalous CVs indicate normalization problems
- results_concentrations cover the same molecule/sample dimensions as the input intensity table, with concentrations derivable from the fitted curves
- plot_calibration_curves yields one calibration ggplot per molecule from the elaboration results, and all tables/plots save to file without error

## Limitations

- Requires R (version ≥ 4.3.1), Java with the same architecture as R (64-bit or 32-bit), and git; dependency installation may take significant time
- Package targets pooled QC filtering, mixed-effects and Tobit regression primarily for untargeted studies; targeted quantification is limited to calibration-curve-based workflows with the package's supported weighting options
- Mock example data must be generated via create_df_examples before the workflow can be reproduced end-to-end without user-supplied tables
