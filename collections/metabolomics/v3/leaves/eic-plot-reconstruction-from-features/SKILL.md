# eic-plot-reconstruction-from-features

## Summary

Reconstruct extracted ion chromatogram (EIC) plots from vendor-generated metabolic feature tables (m/z + RT pairs) paired with LC-MS raw files (.mzXML/.mzML), so that each EIC can be scored for peak quality by a deep learning model embedded in EVA/pyEVA.

## When to use

Use when you have a metabolic feature table with m/z and retention-time columns and the corresponding .mzXML or .mzML raw file, and need rendered EIC plots that a CNN-based quality classifier (EVA/pyEVA) can score.

## When NOT to use

- Input is already rendered EIC images rather than a feature table + raw file pair — pyEVA expects m/z and rt columns to reconstruct the EICs itself.
- Raw spectra are in a format other than .mzXML or .mzML; the README only documents those two formats as valid inputs.
- The goal is vendor-native peak picking rather than post-hoc feature-fidelity scoring; EVA/pyEVA judges features already produced by LC-MS data processing software, it does not pick peaks from raw data.

## Inputs

- .csv feature table with first two columns 'm/z' and 'rt' (successive columns carry sample data)
- .mzXML raw LC-MS file paired with the feature table
- .mzML raw LC-MS file paired with the feature table

## Outputs

- EIC plot images written to the EICplots folder under 'classifier'
- FinalTable.csv containing the analysis results in the 'output' folder
- PredictionOutcomes.csv with Boolean true/false quality labels for each input feature

## How to apply

Prepare a .csv feature table whose first two columns are m/z and rt (successive columns carry sample data), and place it together with the matching .mzXML or .mzML file(s) in the pyEVA 'input' folder. Run the program from the terminal (python main.py) and choose a smoothing level (0, 1, or 2) when prompted; smoothing is applied before EIC rendering so that poor-shaped peaks remain recognizable by the CNN. The program reconstructs an EIC for every feature row and writes the plots to the EICplots folder under 'classifier'. This EIC-reconstruction step is the prerequisite for the downstream CNN scoring that flags features with poor EIC shapes — likely false positives — which EVA accomplishes with over 90% classification accuracy on a model trained with 25095 manually annotated EIC plots from 22 LC-MS-based metabolomics projects.

## Related tools

- **pyEVA** (Python reimplementation of EVA that reads the feature table and .mzXML/.mzML file, applies user-selected smoothing (0, 1, or 2), reconstructs the EICs, and hands them to the CNN classifier) — https://github.com/HuanLab/pyEVA
- **EVA** (C#-based Windows Application platform that processes metabolic features generated by various LC-MS systems and data processing software; embeds the trained CNN model to score EIC quality) — github.com/HuanLab-backup/EVA

## Examples

```
python main.py
```

## Evaluation signals

- Each feature row in the input .csv yields exactly one EIC image in the EICplots folder under 'classifier' — plot count must match the feature table row count.
- Output folder contains both FinalTable.csv (results) and PredictionOutcomes.csv (Boolean values), with one entry per input feature.
- The embedded CNN model should classify EIC quality at over 90% accuracy, so spot-check a subset of rendered EICs manually (good vs poor) and confirm agreement with PredictionOutcomes.csv.
- Running with each smoothing level (0, 1, 2) must be accepted by the program; an invalid level should be rejected at the prompt.
- Feature table schema check: first two columns must be named 'm/z' and 'rt'; a malformed header should cause the reconstruction step to fail or misalign.

## Limitations

- The original EVA is a C#-based Windows Application; Mac and Linux users must use the Python reimplementation (pyEVA) instead.
- Only .mzXML and .mzML raw file formats are documented as valid inputs in the pyEVA README.
- EIC quality labels are Boolean (good/poor); the classifier does not provide graded quality scores beyond this binary classification.
- Setup requires a specific conda environment (Python 3.7.9/3.7.12) plus R packages (XCMS, ggplot2, scales, dplyr); differences may occur with older IDE versions.
