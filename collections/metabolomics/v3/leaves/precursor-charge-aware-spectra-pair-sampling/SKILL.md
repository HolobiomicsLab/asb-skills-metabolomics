# Precursor-charge-aware spectra pair sampling

## Summary

Constructs balanced positive and negative spectrum pairs — pairing spectra generated by the same peptide as positives and mismatched spectra as negatives, grouped per precursor charge state — to train the GLEAMS Siamese embedder with a contrastive loss.

## When to use

Use when training the GLEAMS spectral embedding network on MassIVE-KB PSMs and you need balanced same-peptide/mismatched spectrum pairs stratified by precursor charge for contrastive-loss training.

## When NOT to use

- Input spectra lack peptide identifications (PSMs) — positive pairs require ground truth that spectra come from the same peptide
- The goal is clustering already-computed 32-dimensional embeddings — use `gleams cluster` with a distance threshold (e.g. --distance_threshold 0.3) instead of pair sampling
- Spectra are not from HCD acquisition matching the Human HCD Spectral Library training distribution — the learned embedding may not transfer

## Inputs

- MassIVE-KB (v1) Human HCD Spectral Library candidate library spectra (~30 million PSMs) as metadata TSV plus peak files (mzML) from the MassIVE FTP server
- Precursor-mass, fragment-peak, and reference-spectrum feature encodings of each spectrum
- Precursor charge state annotations per PSM

## Outputs

- Balanced positive/negative spectrum pair sets grouped per precursor charge state
- Trained GLEAMS model weights saved as HDF5 (e.g. gleams_82c0124b.hdf5)
- Per-iteration training and validation contrastive-loss history and a loss-curve PNG figure

## How to apply

Start from the ~30 million PSMs in the Human HCD Spectral Library candidate library spectra of MassIVE-KB (v1), retrieved via the 'filename' and 'scan' columns of the metadata TSV. Preprocess each spectrum into the precursor-mass, fragment-peak, and reference-spectrum feature encodings consumed by the VGG-inspired GLEAMS network. Form positive pairs from spectra generated by the same peptide and negative pairs from mismatched spectra, keeping pairs balanced and grouped per precursor charge state so charge is held constant within each pair. Feed the pairs to the Siamese pair network, which concatenates the precursor, fragment, and reference-spectrum branches through a final L2-regularized fully-connected layer of dimension 32, and compile with the contrastive loss and the rectified Adam optimizer. Training and pair-sampling hyperparameters (e.g. number of epochs/iterations, batch size) are configured in the `gleams/config.py` file before running the training for 50 iterations on a CUDA-enabled GPU.

## Related tools

- **GLEAMS** (Provides the Siamese embedder, pair-sampling and training configuration (gleams/config.py), and the contrastive-loss training procedure) — https://github.com/bittremieux/GLEAMS
- **Python 3.8** (Runtime required to train the neural network on a CUDA-enabled GPU)
- **conda** (Creates the environment with compiler tools and GPU runtime needed for training)

## Evaluation signals

- Pairs are balanced between positives (same peptide) and negatives (mismatched spectra) and are grouped per precursor charge state
- Validation contrastive loss decreases and converges below the training-loss plateau over the 50 training iterations
- The trained weights file (e.g. gleams_82c0124b.hdf5) loads successfully into the GLEAMS network
- The final fully-connected layer outputs 32-dimensional embeddings with L2 regularization
- Training/validation loss curves can be plotted to a PNG figure documenting convergence

## Limitations

- Requires Python 3.8, a Linux operating system, and a CUDA-enabled GPU
- Training data are not available as a single download — spectra must be retrieved per file/scan from the MassIVE FTP server using the metadata TSV
- Downloading model weights via Git LFS can hit repository data-quota errors, requiring manual download of the HDF5 weights from the release
