# TP structural similarity filtering

## Summary

A patRoon 2.0 prioritization filter that removes transformation products (TPs) whose component-level MS spectral similarity is high but whose candidate structures are chemically dissimilar, separating plausible parent-TP links from spurious spectral matches.

## When to use

Use when TP components from patRoon 2.0 componentization must be prioritized and spectral similarity alone is insufficient to reject dubious parent/TP pairs, e.g. TPs matched by MS similarity to the parent with chemically unrelated candidate structures.

## When NOT to use

- Input is still raw LC-HRMS data or a feature table from the 'classical' patRoon workflow — TP components do not yet exist, so componentization must run first
- The goal is parent/TP grouping itself rather than prioritization of already-componentized TPs
- Only MS similarity information is available and no candidate TP structures (from in silico prediction or library search) exist to compare structurally against the parent

## Inputs

- TP components generated by the patRoon 2.0 componentization step (e.g. on patRoonData standard-X vs solvent-X LC-HRMS data, positive and negative ionization)
- Parent features and candidate TP structures from patRoon TP suspect screening or in silico prediction (BioTransformer, enviPath, CTS, MetFrag, library search)
- MS spectral similarity comparisons between parent and TP features

## Outputs

- Prioritized TP component table with per-filter verdicts, including the structure-similarity filter decision per TP
- Filtered set of TP components with low-structural-similarity TPs removed

## How to apply

After the TP screening workflow has grouped each parent feature with its candidate TP features into TP components (Figure 1F), run the patRoon component prioritization routine in R with the structural-similarity filter enabled. The filter compares the structural similarity of candidate TP structures against the parent and removes TPs that score high on MS spectral similarity but low on structural similarity, since such matches are unlikely to represent a true chemical transformation. Apply it alongside the complementary filters (RT direction based on chemical polarities, explained transformation versus feature formula annotations, isomer removal, and duplicate removal) so each retained TP component carries a per-filter verdict. The logic is that MS similarity can be shared by unrelated structures, so structural plausibility must be verified independently before prioritizing the TP.

## Evaluation signals

- Every retained TP component row in the exported table carries an explicit structure-similarity filter verdict
- TPs with high MS similarity but low structural similarity to the parent are absent from the prioritized output
- The output file (e.g. tp_components_prioritized.csv) exists and contains one row per TP component with verdict columns for all five filters (script_runs, file_exists, field_present)
- The number of TP components after filtering is less than or equal to the componentization output, with removals traceable to the filter verdicts

## Limitations

- Isomeric TPs can be difficult or impossible to distinguish with MS, so structural similarity alone cannot fully resolve isomer ambiguity (the separate isomer-removal filter addresses this)
- The filter can only be applied after TP componentization has linked parent and TP features; it is a prioritization step, not a detection step
- Duplicate TPs formed from the same parent through different pathways remain until the separate duplicates filter is applied
