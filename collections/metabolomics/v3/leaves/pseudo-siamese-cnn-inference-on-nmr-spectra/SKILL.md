# pseudo-siamese-cnn-inference-on-nmr-spectra

## Summary

Reload a pretrained pseudo Siamese convolutional neural network (pSCNN) to predict which compounds are present in NMR spectra of mixtures, and quantify its robustness to chemical shift variation by feeding 980 chemically shifted spectral pairs and checking predicted probabilities stay above 0.5.

## When to use

Use when you have NMR spectral pairs of mixture components with chemical shift variation and need to identify mixture components, or to test how much ppm-level shift a trained pSCNN model tolerates.

## When NOT to use

- Your input is a single pure-compound spectrum rather than mixture spectra / mixture-component spectral pairs — pSCNN was built for compound identification in NMR spectra of mixtures
- You need to train the pSCNN model from scratch on augmented data rather than reload the pretrained Zenodo model for prediction
- Your chemical shift variation exceeds the tested +/-0.052 ppm range, beyond which the paper's robustness guarantee (probabilities > 0.5 within (-0.015, 0.015) ppm) no longer applies

## Inputs

- Pretrained pSCNN model and example NMR data from Zenodo (DOI 10.5281/zenodo.6504814)
- 980 varied NMR spectral pairs generated by applying 35 chemical shift variations within +/-0.052 ppm to 8 augmented mixture-component pairs
- Python 3.8.13 environment with TensorFlow 2.5.0-GPU and tqdm

## Outputs

- Predicted probabilities for each of the 980 chemically shifted spectral pairs, saved to pSCNN_shift_predictions.csv
- Minimum chemical shift interval within which predicted probabilities remain above 0.5 (expected: (-0.015, 0.015) ppm)

## How to apply

Set up a Python 3.8.13 environment with TensorFlow 2.5.0-GPU via Anaconda (conda create --name pSCNN python=3.8.13; install requirements.txt and tqdm), then git clone https://github.com/yuxuanliao/pSCNN.git. Download the pretrained model and example NMR data from the Zenodo deposit (DOI 10.5281/zenodo.6504814). For the robustness experiment, generate 980 varied spectral pairs by applying 35 chemical shift variations within +/-0.052 ppm (Table S6 scheme) to each of 8 augmented mixture-component pairs. Run the file 'pSCNN.py' to reload the pretrained pSCNN model and feed the 980 varied spectral pairs for prediction, recording the predicted probability for every shift variation (e.g. to pSCNN_shift_predictions.csv). Rationale: the translational invariance of convolutional neural networks is expected to absorb chemical shift variation, so the correct result is a contiguous interval of shifts within which all predicted probabilities remain above 0.5.

## Evaluation signals

- The minimum interval with predicted probabilities above 0.5 is (-0.015, 0.015) ppm, which exceeds the experimentally observed variation interval (-0.013, 0.010) ppm
- pSCNN_shift_predictions.csv contains one predicted probability per chemical shift variation across all 980 varied spectral pairs (35 shifts x 8 pairs)
- The pretrained model reloads and predicts without retraining, confirming the Zenodo (10.5281/zenodo.6504814) artifact and requirements.txt environment (Python 3.8.13, TensorFlow 2.5.0-GPU) are correctly installed
- On the augmented test set the pretrained model reproduces ACC = 99.80%, TPR = 99.70%, FPR = 0.10%, confirming the correct checkpoint was loaded

## Limitations

- Robustness is demonstrated only for chemical shift variations within +/-0.052 ppm; probabilities are guaranteed above 0.5 only within (-0.015, 0.015) ppm, tighter than the applied variation range
- The model exceeded the repository size limit, so the model and all NMR data must be downloaded separately from Zenodo rather than from the GitHub repo
- No discussion-section content was available, so limitations and reproducibility gaps (e.g. failure modes under peak overlap on real mixtures, where FPR reached 10.53% on the additional flavor mixture dataset) are not documented
