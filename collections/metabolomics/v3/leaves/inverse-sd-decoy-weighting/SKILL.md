# inverse-sd-decoy-weighting

## Summary

Weight each sample-deviation (SD)-sampled decoy ion by 1/SD of its sampled similarities within the METASPACE-ML target-decoy ranking, so that noisy decoys contribute proportionally less to cumulative FDR, and apply the Laplace rule-of-succession correction to yield smooth per-ion FDR values.

## When to use

Use when estimating per-annotation false discovery rates in imaging mass spectrometry where decoys were generated by SD-sampling of ion similarities, and each decoy carries a standard-deviation value that should modulate its decoy weight.

## When NOT to use

- Decoys are not SD-sampled and carry no standard-deviation values, so the 1/SD weighting is undefined
- The goal is discrete FDR thresholds from a plain target-decoy counting scheme without weighted decoys or Laplace smoothing

## Inputs

- Scores table with METASPACE-ML prediction scores for target ions and SD-sampled decoy ions
- Per-decoy standard deviation (SD) values of sampled similarities
- Target/decoy labels for each ion
- Supplementary Data 10 scores/FDR reference table for validation

## Outputs

- fdr_estimates.csv containing per-ion continuous FDR values, prediction scores, and target/decoy labels
- Validation report comparing computed FDR values to Supplementary Data 10

## How to apply

Load prediction scores of target ions and SD-sampled decoy ions into a pandas DataFrame from the scores table, then merge targets and decoys into a single ranking sorted in descending order by METASPACE-ML prediction score. Assign each decoy a weight of 1/SD, where SD is the standard deviation of that decoy's sampled similarities, so decoys with high variability (less reliable negatives) are down-weighted. Traverse the ranking cumulatively with numpy, summing weighted decoy counts and target counts at each ion position, then apply the Laplace rule-of-succession pseudocount correction to the cumulative decoy-weight/target-count ratio to obtain a smoothed, continuous FDR value for every ion. Write the per-ion FDR values together with prediction scores and target/decoy labels to fdr_estimates.csv, and validate against the reported scores/FDR table in Supplementary Data 10.

## Related tools

- **METASPACE-ML** (Produces the prediction scores for target and SD-sampled decoy ions that feed the weighted target-decoy ranking and FDR estimation) — https://github.com/metaspace2020/metaspace

## Examples

```
df = pd.read_csv('scores.csv').sort_values('score', ascending=False); df['w'] = df.label.map({'decoy': 1/df.sd, 'target': 0}); df['fdr'] = (df.w.cumsum()+1)/(df.label.eq('target').cumsum()+1)
```

## Evaluation signals

- Computed FDR values agree across the prediction-score range with the reported scores/FDR table in Supplementary Data 10
- Every ion in the merged ranking receives a finite, smoothed continuous FDR value (no division-by-zero artifacts from target counts)
- Cumulative weighted decoy counts are monotonically non-decreasing along the descending prediction-score ranking
- Decoys with larger SD receive strictly smaller weights (1/SD), confirming correct weighting direction
- Target/decoy labels in fdr_estimates.csv are consistent with the input scores table

## Limitations

- Decoy ions show heterogeneity in similarity to target ions; the article notes that 'further investigations are needed into how this affects FDR estimation and in finding the most reliable way of decoy generation'
- rho_chaos had minor impact on the model, and target-decoy separation was mainly driven by rho_spectral, which limits how much spatial features differentiate targets from decoys
