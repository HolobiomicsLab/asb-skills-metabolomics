# gcms-molecular-networking

## Summary

Builds GNPS molecular networks from deconvoluted EI GC-MS fragmentation spectra without precursor/molecular-ion mass constraints (the molecular ion is usually absent in EI). Pairwise cosine similarity of deconvoluted spectra yields per-dataset networks exported as molecular_networks.graphml for downstream annotation and visualization.

## When to use

Use when clustering co-eluted EI GC-MS compounds into similarity networks: deconvoluted spectra exist but molecular ions/precursor masses are absent, so edges must come from cosine similarity of fragmentation spectra.

## When NOT to use

- Input is LC-MS/MS data where precursor/molecular-ion masses are known — precursor-mass-constrained GNPS networking applies instead of EI spectral-similarity networking.
- Input is raw, undeconvoluted GC-MS data — MSHub auto-deconvolution must precede networking; the networking input must already contain deconvoluted compound fragmentation spectra.
- The goal is library identification of individual spectra rather than linking spectrally related compounds across a dataset into molecular families.

## Inputs

- Deconvoluted compound fragmentation spectra produced by the MSHub/GNPS auto-deconvolution step (the input spectral file for networking; GNPS-style spectra, e.g. MGF-format)
- Per-dataset GC-MS acquisitions whose scans were auto-deconvolved upstream by MSHub (pairs are computed within each dataset)

## Outputs

- molecular_networks.graphml per dataset — networks with deconvoluted spectra as nodes and cosine similarity scores as edge attributes
- Filtered spectral-pair (edge) lists that passed the workflow's cosine-similarity and matched-peak criteria

## How to apply

Take the deconvoluted compound fragmentation spectra generated by the MSHub/GNPS auto-deconvolution step (unsupervised non-negative matrix factorization) as the input spectral file for networking. Run the GNPS molecular networking workflow released as the CCMS-UCSD/GNPS_Workflows scripts in its gas chromatography configuration, which operates on EI spectra without precursor/molecular-ion mass constraints — the key difference from LC-MS/MS networking where the precursor ion mass is known. The workflow computes pairwise cosine similarity between all deconvoluted EI fragmentation spectra within each dataset, then filters spectral pairs against the workflow's cosine-similarity and matched-peak criteria so only high-confidence similarity relationships survive. Assemble the retained edges into per-dataset molecular networks whose nodes are deconvoluted spectra and whose edge attributes carry the similarity scores, and export as molecular_networks.graphml. Visualize the graph in Cytoscape and optionally annotate molecular families with chemical-class/substructure information via pyMolNetEnhancer.

## Evaluation signals

- The GNPS job produces molecular_networks.graphml that parses as valid GraphML (loadable in networkx/Cytoscape) with nodes corresponding to the deconvoluted EI spectra submitted per dataset.
- Every retained edge carries a cosine-similarity score attribute and satisfies the workflow's cosine-similarity and matched-peak criteria; below-threshold spectral pairs are absent from the graph.
- Edge construction used no precursor/molecular-ion mass — unlike LC-MS/MS networks, edges derive purely from similarity of deconvoluted fragmentation spectra.
- Spectra sharing dominant fragment ions (reproduced fragmentation patterns of the same compound) fall into the same connected component, while dissimilar spectra remain singletons.
- Node count matches the number of deconvoluted spectra supplied for each dataset, with edges computed only within (not across) datasets.

## Limitations

- Edges encode spectral similarity only: because the molecular ion is often absent in EI spectra, networking proceeds without precursor-mass constraints, so connected nodes may be structurally related rather than identical compounds.
- Network quality is bounded by the upstream MSHub auto-deconvolution; artifacts from imperfectly separated co-eluting compounds propagate into network nodes and edges.
- The paper does not state concrete cosine-similarity or matched-peak cutoff values in the extracted text — actual thresholds must be taken from the GNPS_Workflows GC configuration for the job.
