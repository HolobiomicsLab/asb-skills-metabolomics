# chimeric-spectrum-cofragmentation-quantification

## Summary

Quantifies co-fragmentation (chimeric MS2 spectra) in a simulated LC-MS/MS run by annotating each MS2 spectrum against theoretical fragment ions generated by the SMITER PeptideFragmentor, then tallying how many distinct peptides contribute fragments per spectrum.

## When to use

Use when you have a SMITER-simulated mzML with known precursor peptides and overlapping retention times and need to predict how many peptides co-fragment into each MS2 spectrum before running a real MS experiment.

## When NOT to use

- The data are real (non-simulated) LC-MS/MS runs where precursor ground truth is unknown — this skill relies on SMITER's known simulated composition to attribute fragments to peptides
- The goal is de novo or database-search peptide identification from spectra rather than quantifying co-fragmentation multiplicity
- The simulated dataset has no overlapping retention times, so chimeric spectra are not expected to arise

## Inputs

- SMITER-simulated complex-mixture mzML dataset (MS2 spectra with scan retention times)
- Peak properties for the simulated peptides (e.g. from smiter.lib.csv_to_peak_properties), including chemical formulas and retention times
- Theoretical fragment ions per candidate precursor peptide generated by fragmentation_functions.PeptideFragmentor

## Outputs

- chimeric_spectra_statistics.csv with per-dataset tallies: number of chimeric spectra (two molecules selected simultaneously), number of spectra with fragments of three or more peptides, and maximum peptides-per-spectrum multiplicity

## How to apply

Load the simulated complex-mixture mzML (e.g. 74,067 peptides with overlapping simulated and measured retention times) and parse its MS2 spectra. For each scan, determine which peptides co-elute at the scan retention time and annotate the spectrum's peaks against theoretical fragment ions produced by the SMITER fragmentation_functions.PeptideFragmentor for the candidate precursor peptides. Count, per scan, the number of distinct peptides contributing fragments, then tally chimeric spectra with exactly two simultaneously selected molecules versus spectra carrying fragments of three or more peptides, and record the maximum peptides-per-spectrum multiplicity. Verify tallies against ground-truth expectations from the simulation (in the reference study: 13,830 chimeric spectra, 2032 spectra with ≥3 peptides, max of nine peptides per spectrum occurring twice) and write the statistics to chimeric_spectra_statistics.csv. This exploits SMITER's known ground truth to expose analytical hurdles — co-elution and co-fragmentation — that hinder detection or quantification of co-eluents before an actual MS experiment.

## Related tools

- **SMITER** (Simulates the LC-MS/MS run and provides the PeptideFragmentor used to generate theoretical fragment ions for annotating MS2 spectra) — https://github.com/LeidelLab/SMITER
- **Python** (Parsing mzML MS2 spectra, matching peaks to theoretical fragments, tallying chimeric spectra, and writing chimeric_spectra_statistics.csv)

## Examples

```
from smiter.lib import csv_to_peak_properties; from smiter.fragmentation_functions import PeptideFragmentor; from smiter.synthetic_mzml import write_mzml; peak_properties = csv_to_peak_properties('example_data/peptides.csv'); write_mzml('simulated_cofragmentation.mzML', peak_properties, fragmentor=PeptideFragmentor())
```

## Evaluation signals

- Tallied chimeric-spectrum counts match the simulation's ground truth (reference values: 13,830 chimeric spectra; 2032 spectra with ≥3 peptides)
- Maximum peptides-per-spectrum multiplicity reproduces the expected extreme (nine peptides per spectrum, occurring twice in the reference study)
- Every MS2 spectrum's attributed peptide count is consistent with the co-elution window implied by the simulated and measured retention times of the 74,067-peptide set
- chimeric_spectra_statistics.csv is produced with the expected tally fields and totals that sum consistently across the parsed scans

## Limitations

- Results depend on SMITER's default fragmentation and noise models; the library's modular design means different fragmentation models may change chimeric-spectrum counts
- The article's discussion-section content (potential limitations prose) was not available for extraction
- SMITER requires Python 3.7 or higher (LeidelLab README; the MKoesters README states 3.6+), and a virtual environment is recommended
