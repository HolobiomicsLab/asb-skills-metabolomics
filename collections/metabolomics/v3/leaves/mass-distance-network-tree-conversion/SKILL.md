# mass-distance-network-tree-conversion

## Summary

Khipu's core algorithm that converts mass distance networks of feature pairs into rooted trees and infers each M0 neutral mass by regression. This method reconstructs isotopic branches and adduct trunks so untargeted and stable isotope tracing data can be pre-annotated without prior chemical identities or formulas.

## When to use

Use when LC-MS feature tables (e.g. from asari 1.9.2) contain isotope and adduct ions of the same compound that must be grouped into empirical compounds and neutral masses inferred, in ESI+ or ESI- mode, for untargeted metabolomics or 13C isotope tracing.

## When NOT to use

- When a complete annotation with metabolite identities is required — khipu is a pre-annotation step and complete annotation still requires contaminants, authentic libraries, and tandem mass spectrometry data.
- When the input is already a group of empirical compounds or a validated metabolite identity list — the tree conversion is meant for raw feature tables from preprocessing, not for downstream analysis of already-annotated compounds.
- When the feature table was produced by a tool other than a preprocessing pipeline that yields tab-delimited feature ID/m/z/rtime/intensity rows without specifying start and end intensity columns — the CLI expects that exact column layout.

## Inputs

- Tab-delimited LC-MS feature table with columns: feature ID, m/z, rtime, followed by intensity columns (e.g. testdata/ecoli_pos.tsv or yeast_pos/yeast_neg tables generated by asari 1.9.2)
- Start and end column indices for intensity data in the feature table
- Ionization mode (pos or neg)
- Optional user-supplied isotope and adduct search patterns to overwrite khipu defaults
- Parameters: mass precision in ppm (mz_tolerance_ppm), retention time tolerance (rtol), start/end intensity columns

## Outputs

- Empirical compound (empCpd) pre-annotation files in JSON format, one record per inferred khipu tree
- Tab-delimited empirical compound file (e.g. this_test.tsv)
- Inferred neutral mass for each M0 compound (e.g. 187.1686 for acetylspermidine, C9H21N3O)
- Tree structure describing isotope branches assigned to adduct trunks per empirical compound

## How to apply

Run khipu on a tab-delimited feature table (feature ID, m/z, rtime, intensities) using the packaged Python 3 CLI or its library API, with `khipu -i testdata/ecoli_pos.tsv -o this_test` as the canonical invocation. The algorithm first searches the feature list for all pairs matching isotope patterns (e.g. 1.0034 Da for 13C/12C) and adduct patterns (e.g. 22.9893 Da for Na+), connects matched pairs into a mass distance network, and partitions it into connected subnetworks. Each subnetwork becomes a khipu instance: redundant nodes are removed and the network is converted to a directed acyclic graph where erroneous edges that cannot satisfy a rooted tree are weeded out, after which isotopic branches are assigned to an optimized adduct trunk via two-step optimization against the khipu grid (M0, 13C/12C, 13C/12C*2, ... 13C/12C*6). Based on the matched m/z values, the neutral mass of the M0 compound is obtained by a regression model. Outputs are written as JSON and tab-delimited empirical compound files, and the search patterns can be overwritten by the user to tailor annotation to a specific biochemical experiment (e.g. adding extra adducts from Chen et al. raised explained ESI+ features from 6,310 to 8,049).


## Evaluation signals

- The inferred neutral mass of the M0 compound must equal the value reported by the regression model — e.g. for the E. coli U-13C-labeled tree, the neutral mass inferred by khipu must be 187.1686, matching acetylspermidine (C9H21N3O, 9 carbons).
- The output must contain the expected number of empirical compounds (trees) — e.g. 548 from 1,745 of 3,602 E. coli reverse phase ESI+ features; 1,775 and 908 for the yeast ESI+ and ESI- data sets.
- Each converted tree must be a rooted tree whose subnetwork survived conversion to a directed acyclic graph — erroneous edges that do not satisfy DAG and a rooted tree must have been weeded out.
- In stable isotope tracing runs, the tree must show the highest isotope peak at the expected isotope position (e.g. M9 for acetylspermidine in U-13C-labeled samples) and carry protonated plus Na and K adduct ions for the more abundant isotopes.
- Output files this_test.json and this_test.tsv must be written with consistent empirical compound counts between formats, and the `python3 -m khipu.test` run must succeed using the remotely downloaded ecoli_pos.tsv.

## Limitations

- Annotation of untargeted metabolomics data, including isotopic tracing data, is still not fully solved; khipu is a pre-annotation step and benchmarking was deferred to future work.
- Some ions may enter the initial network by mistakes or unresolved signals; they are removed from the established khipu and sent off to form a new khipu, so noisy feature tables can fragment trees.
- The search pattern for isotopes is dependent on the biochemical experiment — default isotope/adduct patterns must be overwritten for specific experiments (e.g. isotope tracing or chemical derivatization).
- Complete annotation still requires additional resources beyond khipu pre-annotation, including contaminants, authentic libraries, and tandem mass spectrometry data.
- Chemical derivatization experiments are a future direction — currently separate khipu trees for origin and derivatized compounds must be linked externally by the m/z shift.
