# lcms-feature-grouping-retention-time-coelution

## Summary

Group LC/MS features derived from the same analyte into pseudo-spectra ('compound spectra') by co-elution using Gaussian retention-time peak-shape similarity and EIC intensity correlation across samples, as implemented in CAMERA's groupFWHM and groupCorr functions.

## When to use

Use when processing raw LC/MS feature lists (e.g. from XCMS) where multiple m/z features originate from a single metabolite and you need to reduce feature-list redundancy before adduct or isotope annotation.

## When NOT to use

- Input is already a curated feature table with per-analyte grouping (e.g. annotated by hand or from a reference library).
- Data were acquired with chromatographic separation so poor that retention-time peak shapes cannot be modeled (e.g. flow-injection or very short gradient runs).
- Only a single sample is available, so sample-to-sample intensity correlation (groupCorr) cannot be computed; groupFWHM alone may suffice.

## Inputs

- Peak list from feature detection (e.g. XCMS output) with m/z, retention time, and sample intensity columns
- Raw or processed LC/MS data in the polarity used for feature detection (positive or negative ion mode)
- Optional: xsAnnotate object in R

## Outputs

- xsAnnotate object with features assigned to pseudo-spectra ('compound spectra')
- Grouped feature table where co-eluting, same-analyte features share a pseudo-spectrum ID

## How to apply

Start from a peak list generated by a feature-detection tool such as XCMS, then build an xsAnnotate object and run groupFWHM, which computes peak-shape similarity between the sample correlation intensity (EIC) profile of a pseudo-spectrum seed and each remaining feature using a Gaussian fit to the chromatographic peak; features passing a similarity threshold are grouped. Follow with groupCorr, which refines grouping using the correlation of EIC intensities across samples (calculated via calcCiS/calcCaS) and applies a p-value cutoff to decide whether features are co-eluting. Rationale: grouping related features (same analyte) reduces feature count and is a prerequisite for findIsotopes and findAdducts, which operate on pseudo-spectra rather than isolated peaks. In the MM39 recovery experiment CAMERA applied these grouping functions to features spanning m/z 161–822 Da in both positive and negative ion mode, achieving 89.7% and 90.3% accurate-mass extraction rates, so validated grouping is expected to keep co-eluting isotopic and adduct features together while separating unrelated features.

## Related tools

- **CAMERA** (Provides groupFWHM (peak-shape grouping) and groupCorr (EIC-intensity correlation grouping) that implement this skill within the R/Bioconductor pipeline.) — https://github.com/sneumann/CAMERA

## Examples

```
R> xa <- xsAnnotate(xs); xa <- groupFWHM(xa); xa <- groupCorr(xa); pl <- getPeaklist(xa)
```

## Evaluation signals

- After grouping, features known to belong to a standard compound (e.g. from the MM39 reference list) should fall in the same pseudo-spectrum in ≥ 89.7% (positive mode) and 90.3% (negative mode) of cases.
- The number of pseudo-spectra should be substantially smaller than the number of raw features (prior work reported 50% and 60% size reductions with similar grouping logic).
- Isotopic peaks and adduct features of a compound must not be split across different pseudo-spectra.
- Grouped pseudo-spectra should have a coherent chromatographic peak shape (Gaussian fit) and consistent EIC correlation across samples.
- Features with retention time below 45 s (or otherwise excluded by the analysis protocol) should not form spurious pseudo-spectra.

## Limitations

- Grouping depends on quality of the upstream peak list; poor centroiding or detector saturation shifts m/z and retention-time centroids and can break co-elution.
- In spectra that contain only molecular ion and fragment ions with no further adducts, grouping alone cannot support accurate-mass annotation unless the neutral loss is added to the rule set.
- CAMERA does not assume the most intense feature is the [M+H]+ ion, so grouping relies on peak shape and correlation rather than intensity heuristics.
- When several grouping hypotheses have the same precedence score, the correct group may be ambiguous.
