# hgvs-nomenclature-concordance-analysis

## Summary

Quantifies how consistently ANNOVAR, SnpEff, and VEP reproduce ClinVar reference annotations (HGVSc, HGVSp, predicted coding impact) for high-review-status ClinVar variants, both overall and stratified by variant type (SNV, Ins, Del, Indel, MS, Dup, Inv).

## When to use

Use when benchmarking variant annotation tools against a curated clinical database (e.g., ClinVar two-star variants) to measure HGVS nomenclature and coding-impact concordance, or when discordant annotations must be stratified by variant type.

## When NOT to use

- The goal is functional/gene-level annotation from scratch rather than comparing existing tool annotations against a curated clinical reference set.
- The variant set lacks a high-confidence reference annotation (e.g., no ClinVar high review status variants) to serve as ground truth.
- Variants have not been normalized/phased, so repeat-shifted alleles from different VCF callers would be misclassified as distinct variant types.

## Inputs

- Per-tool annotation records (HGVSc, HGVSp, predicted coding impact) from ANNOVAR, SnpEff, and VEP for 164,549 ClinVar two-star variants
- ClinVar reference annotations (HGVSc, HGVSp, coding impact) for the same variants
- Normalized VCF representation of the variant set for variant-type classification

## Outputs

- variant_type_concordance.csv with columns tool, variant type, annotation field, n variants, and concordance rate
- Per-tool overall concordance rates for HGVSc, HGVSp, and coding impact
- Ranked variant-type concordance profiles per tool

## How to apply

Load per-tool annotation records (HGVSc, HGVSp, predicted coding impact) generated by ANNOVAR, SnpEff, and VEP for the 164,549 ClinVar two-star variants, together with the ClinVar reference annotations. Classify each variant into its type category (SNV, Ins, Del, Indel, MS, Dup, Inv) from the normalized VCF representation, phasing and normalizing multi-nucleotide variants so repeat-shifted alleles are grouped consistently, since VCFs from different callers shift nucleotide repeats left or right relative to the gene or transcript. For each tool, stratify by variant type and compute concordance rates against ClinVar for HGVSc, HGVSp, and coding impact using pandas groupby aggregation, then rank categories per tool. Expected pattern: SNV is the most consistent category; SnpEff and VEP match ClinVar at fractions over 0.995 for Ins, Del, and Indel; MS is the least consistent; the worst category is Inversion for SnpEff and MS/Duplication for VEP. Write stratified metrics to variant_type_concordance.csv with columns for tool, variant type, annotation field, n variants, and concordance rate.

## Related tools

- **ANNOVAR** (One of the three annotation tools whose HGVSc/HGVSp/coding-impact output is compared against ClinVar; showed the lowest PVS1 accuracy and 55.9% PLP downgrades)
- **SnpEff** (Annotation tool compared against ClinVar; achieved the highest HGVSc match (0.988) but performed worst in the Inversion category)
- **Variant Effect Predictor (VEP)** (Annotation tool compared against ClinVar; highest HGVSp match (0.977), worst in MS and Dup categories; can be run with --per_gene and --coding_only to streamline transcripts)

## Examples

```
df.groupby(['tool','variant_type','annotation_field'])['concordant'].mean()  # -> variant_type_concordance.csv
```

## Evaluation signals

- SNV should emerge as the most consistent variant-type category across all three tools.
- For SnpEff and VEP, concordance fractions for Ins, Del, and Indel should exceed 0.995.
- Worst category should be Inversion for SnpEff and MS/Duplication for VEP.
- Overall concordance should fall near the reported baselines: 58.52% for HGVSc, 84.04% for HGVSp, 85.58% for coding impact.
- Output CSV schema check: variant_type_concordance.csv must contain tool, variant type, annotation field, n variants, and concordance rate columns with all seven variant types represented.

## Limitations

- Discrepancies with ClinVar persisted even after restricting transcripts to ClinVar-selected ones; restricting improved consistency but did not eliminate disagreement.
- Some HGVS syntax in ClinVar itself does not adhere to HGVS recommendations (Tables S3 and S4), and inconsistencies exist between ClinVar web pages and its VCF, so the reference is imperfect.
- VCFs generated by different callers shift nucleotide repeats left or right, producing inconsistent HGVS notation that must be handled by phasing and normalizing MNVs.
- No software versions were reported for the compared annotation tools, limiting reproducibility.

## Evidence

- [abstract] per-variant-type concordance: "This study evaluated the annotation concordance between three tools-- ANNOVAR, SnpEff, and Variant Effect Predictor (VEP)--using 164,549 two-star variants from ClinVar"
- [abstract] concordance rates: "The analysis revealed variable concordance rates, with 58.52% agreement for HGVSc, 84.04% for HGVSp, and 85.58% for the coding impact."
- [discussion] MNV normalization: "Multi-nucleotide variants (MNVs) must be phased and normalized in the VCF."
- [intro] repeat-shift HGVS: "the Variant Call Format (VCF) generated by different callers may result in inconsistent HGVS notation. In cases of nucleotide repeats, shifts to the left or right concerning the gene or transcript"
- [discussion] ClinVar reference imperfection: "Some HGVS syntax in ClinVar does not adhere to HGVS recommendations (see Table S3 and Table S4)"
- [discussion] transcript restriction residual discordance: "Restricting transcripts to those selected by ClinVar improved consistency in HGVSc, HGVSp, and coding impact annotations; however, discrepancies with ClinVar persisted."
