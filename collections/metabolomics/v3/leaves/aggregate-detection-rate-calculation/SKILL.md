# aggregate-detection-rate-calculation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Computes the overall proportion of in silico–predicted drug metabolites (from BioTransformer 3.0) that were experimentally detected by LC-HRMS after human liver S9 incubation, yielding the 59,869/130,464 (45.89%) detection-rate summary for PharmMet DB.

## When to use

Use when you have a set of BioTransformer 3.0-predicted metabolites for a panel of drugs and matched LC-HRMS detections from 24-hour S9 incubation samples, and need an aggregate detected/predicted percentage.

## When NOT to use

- Input is already a per-drug or per-metabolite detection table with no aggregate detected/predicted counts to compute
- The metabolite list comes from a different prediction tool or a different mass-accuracy tolerance than ±5 ppm, so the detected/predicted matching is not comparable
- The goal is per-drug or per-metabolite-level statistics rather than a single overall detection-rate summary

## Inputs

- LC-HRMS detection lists for 0-hour and 24-hour S9 incubation samples (Metabolomics Workbench Study ST003991, DOI 10.21228/M8W55K)
- BioTransformer 3.0-predicted metabolite list for the 1114 therapeutic drugs

## Outputs

- summary_stats.csv with rows metric/value giving detected count, predicted count, and detection percentage (59,869 / 130,464 / 45.89%)

## How to apply

1. Load the deposited LC-HRMS detection lists (0-hour and 24-hour samples) for Metabolomics Workbench Study ST003991 (DOI 10.21228/M8W55K) plus the BioTransformer 3.0-predicted metabolite list for all 1114 therapeutic drugs. 2. Match each 24-hour detected metabolite to its BioTransformer 3.0 prediction using the ±5 ppm mass-accuracy criterion applied during curation. 3. Count the total number of unique predicted metabolites across the drug panel (130,464) and the number of those that were detected in the 24-hour S9 incubation samples (59,869). 4. Compute the detection percentage as detected / predicted × 100, which should equal 45.89%. 5. Write the counts and percentage as rows in summary_stats.csv with columns 'metric','value'. The decision point is the ±5 ppm matching tolerance: if totals differ from 130,464 / 59,869 / 45.89%, re-check the matching logic and ppm window before accepting the output.

## Related tools

- **BioTransformer 3.0** (Source of the in silico predicted metabolites whose detection rate is being aggregated)
- **R 4.0.3** (Used for statistical analysis and data visualization when compiling the aggregate detection-rate summary)
- **Metabolomics Workbench ST003991** (Deposited LC-HRMS detection lists (0-hour and 24-hour samples) used as the experimental side of the detected/predicted comparison)

## Evaluation signals

- Total predicted metabolites equals 130,464 across all 1114 therapeutic drugs
- Total detected metabolites equals 59,869 in the 24-hour S9 incubation samples
- Computed detection percentage equals 45.89% (detected / predicted × 100)
- summary_stats.csv has columns 'metric' and 'value' and contains rows for predicted count, detected count, and percentage
- If any count differs from the expected values, re-check the ±5 ppm matching logic before accepting the output

## Limitations

- Detection relies on human liver S9 fraction, which does not capture all drug-metabolizing enzymes or extrahepatic (e.g. intestine, kidney) metabolism, so the detection rate underestimates in vivo metabolite production
- Some metabolites may be missed due to limited cofactor availability or ionization suppression in the LC-HRMS assay
- Identification of novel metabolites from nearly 1000 drugs will require considerable research for isolation and structural elucidation
- PharmMet DB is not completely comprehensive, so the aggregate rate reflects only the 1114 active therapeutic agents included
