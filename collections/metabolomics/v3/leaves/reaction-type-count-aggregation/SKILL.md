# reaction-type-count-aggregation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Aggregates experimentally detected human liver S9 drug metabolites by biotransformation reaction type and compares each detected count against the corresponding BioTransformer 3.0 prediction set, quantifying which phase I/II pathways were observed (e.g. 30,752 of 59,296 predicted oxidations detected; glucuronidation dominant in phase II with 6311).

## When to use

Use when metabolite annotation tables carry BioTransformer reaction-type tags (oxidation, glucuronidation, hydrolysis, etc.) and you need detected-vs-predicted counts and detection fractions per biotransformation reaction, as for PharmMet DB Study ST003991.

## When NOT to use

- Upstream curation is not done: raw MZmine 2.53 feature tables or 0-hour vs 24-hour MS1/RT differential features lack reaction-type tags, so counts cannot be attributed to a biotransformation reaction.
- The goal is identifying which specific novel (unpredicted) metabolites a drug produced rather than aggregate per-reaction totals — 89% of drugs had such products and they require feature-level triage.
- The metabolism of interest is extrahepatic or driven by enzymes not abundant/active in liver S9 (e.g. intestine, kidney), since ST003991 counts reflect only human liver S9 biotransformation.

## Inputs

- Metabolite annotation tables for Study ID ST003991 (Metabolomics Workbench, DOI 10.21228/M8W55K) with per-feature reaction-type tags from BioTransformer 3.0 curation
- BioTransformer 3.0 predicted-metabolite lists (per drug) with reaction-type assignments, serving as per-reaction prediction denominators
- PharmMet DB export (github.com/ClinicalBiomarkersLaborabory/PharmMet) providing experimentally validated metabolite annotations

## Outputs

- Tab-separated table with columns reaction type, detected count, predicted count, and detection fraction (e.g. oxidation | 30752 | 59296 | 0.52)

## How to apply

Download the metabolite annotation tables for Metabolomics Workbench Study ID ST003991 (DOI 10.21228/M8W55K) or the PharmMet DB build from the GitHub release, where every detected signal was curated by cross-referencing MS1 masses (±5 ppm) against BioTransformer 3.0 predictions. Parse the reaction-type tag on each annotation — oxidation, reduction, hydrolysis, methylation, acetylation, glucuronidation, sulfation, glutathione conjugation — and in R 4.0.3 tally the number of experimentally detected metabolites and the number of BioTransformer 3.0 predicted metabolites per reaction type. Emit a tab-separated table with columns reaction type, detected count, predicted count, and detection fraction. Validate by exact-matching each row to the published values: oxidation 30,752 of 59,296 predicted (52%), reduction 7,114 of 10,899 (65%), hydrolysis 3,184 of 5,744 (55%), methylation 3,136 of 6,235 (50%), glucuronidation 6,311, acetylation 45%, glutathione conjugation 21%, confirming oxidation dominates phase I and glucuronidation dominates phase II. The per-type fraction measures how much of the in silico prediction space was experimentally realized, which matters because 89% of tested drugs produced at least one metabolite BioTransformer 3.0 did not predict.

## Related tools

- **R 4.0.3** (Statistical environment used to tally detected and predicted metabolites per reaction type and to write the aggregated tab-separated counts table)
- **BioTransformer 3.0** (Source of predicted metabolites and reaction-type labels; its ±5 ppm cross-referencing supplies the per-reaction prediction denominators for detection fractions)
- **PharmMet DB** (Resource of experimentally validated human liver S9 metabolite annotations whose reaction-type tags are aggregated by this skill) — https://github.com/ClinicalBiomarkersLaborabory/PharmMet

## Examples

```
Rscript -e 'a <- read.delim("ST003991_annotations.tsv"); t <- table(a$reaction_type); write.table(t, "reaction_counts.tsv", sep="\t", row.names=FALSE)'
```

## Evaluation signals

- Row-wise exact-match to published counts: oxidation 30,752; glucuronidation 6,311; reduction 7,114; hydrolysis 3,184; methylation 3,136.
- Detection fractions equal detected/predicted and reproduce reported values: oxidation 52%, reduction 65%, hydrolysis 55%, methylation 50%, acetylation 45%, glutathione conjugation 21%.
- Output is a tab-separated table with exactly the columns reaction type, detected count, predicted count, and detection fraction.
- Detected count ≤ predicted count per reaction type (e.g. 30,752 of 59,296 predicted oxidations), consistent with detection via curation against BioTransformer predictions.
- Only signals curated at ±5 ppm against BioTransformer 3.0 predictions are tallied; uncurated 0-hour vs 24-hour differential features are excluded.

## Limitations

- Counts cover only liver S9 biotransformation; metabolites formed by enzymes not abundant or active in the S9 fraction, or generated in extrahepatic compartments (intestine, kidney), are absent from the tally.
- Limited cofactor availability or ionization suppression may have caused missed metabolites, deflating per-reaction detected counts.
- Detected counts include novel metabolites outside the BioTransformer 3.0 prediction set (89% of drugs produced at least one unpredicted metabolite), so detected counts can exceed predictions for some reactions.
