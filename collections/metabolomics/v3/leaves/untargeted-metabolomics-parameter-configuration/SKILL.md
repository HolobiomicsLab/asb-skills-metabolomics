# untargeted-metabolomics-parameter-configuration

## Summary

Configure IDSL.CSA runs through its 39-parameter Excel spreadsheet, setting the CSA/DDA/DIA workflow selector, data and output addresses, and thread counts so composite spectra deconvolution matches the study design.

## When to use

Use when preparing an IDSL.CSA or IDSL.IPA batch run on mzXML/mzML/netCDF LC/HRMS data — a parameter spreadsheet must be filled with workflow selectors (PARAM0001), directory addresses (CSA0005/0008/0009/0011), and thread counts (CSA0004).

## When NOT to use

- You already have a filled CSA_parameters.xlsx — re-configuring is unnecessary; run IDSL.CSA_workflow directly on the existing spreadsheet.
- Your data are not untargeted LC/HRMS files (mzXML/mzML/netCDF) processed by IDSL.IPA — CSA parameters like CSA0008/CSA0009 expect IDSL.IPA peaklists and peak_alignment directories.
- You need MS2-based spectral library search tooling — use IDSL.FSA parameters instead; this skill configures the CSA (MS1 composite spectra) branch.

## Inputs

- IDSL.CSA parameter spreadsheet (CSA_parameters.xlsx) downloaded from the repository
- Directory of raw mass spectrometry data (mzXML, mzML, netCDF) referenced by CSA0005
- peaklists directory generated by the IDSL.IPA workflow (CSA0008)
- peak_alignment directory generated by the IDSL.IPA workflow (CSA0009)
- Output location address for CSA0011

## Outputs

- Fully configured CSA parameter spreadsheet consumed by IDSL.CSA_workflow
- Parameterized run producing .msp composite spectra libraries, CSA_adduct_annotation peaklists, peak_alignment_subset tables, and aligned_spectra_table at CSA0011

## How to apply

Download the IDSL.CSA parameter spreadsheet (CSA_parameters.xlsx), which distributes the 39 CSA parameters into five separate sections, and fill it per study before invoking IDSL.CSA_workflow. Set PARAM0001 in the Start tab to YES to run only the CSA workflow (other values select DDA or DIA branches). Point CSA0005 to the MS1-level HRMS data location (mzXML, mzML, or netCDF), CSA0008 to the peaklists directory produced by IDSL.IPA, CSA0009 to the peak_alignment directory from IDSL.IPA, and CSA0011 to the output location for .msp files and EICs. Adjust CSA0004 (number of processing threads) according to available compute, since parallel processing is supported on Windows and Linux. For aggregating annotated chemical structures on the aligned peak table using meta-variables such as InChIKey, SMILES, precursor type, and molecular formula, tune PARAM0006 in the Start tab. Rationale: parameter selection through a well-described spreadsheet is the package's designed entry point, and default values presented in the spreadsheet are validated for quick case studies like ST002263 (n = 33, Thermo Q Exactive HF Orbitrap, HILIC-ESI-POS/NEG).

## Related tools

- **IDSL.CSA** (The R package whose 39-parameter spreadsheet is configured; its IDSL.CSA_workflow consumes the filled spreadsheet as its only input.) — https://github.com/idslme/IDSL.CSA
- **IDSL.IPA** (Upstream peak-picking workflow whose peaklists and peak_alignment directories must already exist and be referenced by CSA0008 and CSA0009.) — https://github.com/idslme/IDSL.IPA
- **IDSL.FSA** (Companion downstream package for annotating the .msp files generated at CSA0011; parameter configuration choices here determine what FSA receives.) — https://github.com/idslme/IDSL.FSA

## Examples

```
library(IDSL.CSA); IDSL.CSA_workflow('CSA_parameters.xlsx')
```

## Evaluation signals

- PARAM0001 in the Start tab reads YES for a CSA-only run (no DDA/DIA branches executed).
- CSA0005 points to an existing MS1-level HRMS data directory; CSA0008 and CSA0009 point to directories that actually exist as outputs of a completed IDSL.IPA run.
- CSA0011 output directory contains the expected four artifacts: CSA_MSP (.msp), CSA_adduct_annotation, peak_alignment_subset, and aligned_spectra_table.
- CSA0004 thread count does not exceed available cores, and parallel processing completes without errors on the chosen OS (Windows or Linux).
- Default parameter values, where not overridden, match the validated defaults for the study type (e.g. ST002263 Thermo Q Exactive HF, HILIC-ESI-POS/NEG).

## Limitations

- The parameter spreadsheet must be filled manually per study; mis-addressing CSA0008/CSA0009 to directories not generated by IDSL.IPA will break the workflow.
- PARAM0001 toggles between CSA, DDA, and DIA branches — selecting the wrong branch produces unintended outputs.
- The GitHub quick-batch example documents only a specific validated configuration (ST002263, n = 33); other instrument platforms may require non-default values beyond the documented defaults.
