# compound-annotation-confidence-estimation

## Summary

Automatically assigns Schymanski et al. (2014) identification confidence levels (1–5) to compound/formula annotations of LC-HRMS features using patRoon 2.0's configurable, extensible YAML rule-based approach instead of manual curation.

## When to use

Use when formula and compound structure annotation results exist for LC-HRMS features and each annotated feature needs an automatic, reproducible identification confidence level (Schymanski 2014 levels 1–5) assigned from a rules file.

## When NOT to use

- Input is raw vendor MS data or unprocessed feature lists — features and formula/compound annotations must already be generated by the patRoon workflow
- Identification levels must reflect manual expert curation or reference-standard confirmation evidence that is not expressible in the rule file's score/ranking criteria
- The analysis is not suspect screening or compound annotation confidence assignment (e.g. pure TP screening or blank subtraction tasks)

## Inputs

- patRoon formula annotation candidates object for LC-HRMS features
- patRoon compound structure annotation candidates object
- YAML identification-level rules file (e.g. idlevelrules.yml, generated via genIDLevelRulesFile())

## Outputs

- Annotations enriched with an identification confidence level per annotated feature (integer 1–5 per Schymanski et al., 2014)
- identification_levels.csv: table of features with candidates, scores and assigned identification levels
- Generated YAML rules file (template from genIDLevelRulesFile(), optionally user-adjusted)

## How to apply

Load the formula candidate and compound structure annotation results generated for the patRoon example workflow features (patRoonData standard-X / solvent-X LC-HRMS data). Call genIDLevelRulesFile() to emit a template YAML rule set that maps annotation scores, candidate rankings (e.g., minimum score for a rank-1 candidate) and supporting evidence (reference standard presence, MS/MS match) to identification levels; adjust rule thresholds so levels follow the Schymanski et al. (2014) convention. Run estimateIDConfidence() with the annotation objects and the YAML IDFile so every annotated feature receives a rule-derived level (1–5). The rule file is configurable and extensible, which is what makes the estimation transparent and reproducible rather than a black box.

## Related tools

- **patRoon 2.0** (Provides genIDLevelRulesFile() to generate the YAML rule template and estimateIDConfidence() to apply rule-based confidence levels to annotation results) — https://rickhelmus.github.io/patRoon
- **R** (Runtime platform in which the patRoon confidence-estimation calls are executed)
- **patRoonData** (Supplies the example standard-X / solvent-X LC-HRMS data whose annotation results are level-estimated in the demonstration workflow) — https://github.com/rickhelmus/patRoonData

## Examples

```
rulesFile <- patRoon::genIDLevelRulesFile(); levels <- patRoon::estimateIDConfidence(formulas, compounds, IDFile = rulesFile)
```

## Evaluation signals

- identification_levels.csv exists and contains an identification-level column
- Every annotated candidate carries an identification level within the 1–5 range of Schymanski et al. (2014)
- The generated YAML rules file is present and parseable (valid YAML)
- Levels follow the rule thresholds: e.g. rank-1 candidates meeting the configured minimum annotation score, MS/MS match or reference-standard evidence map to the expected (higher-confidence) levels
- Re-running estimateIDConfidence() with the same YAML rules on the same annotations reproduces identical level assignments

## Limitations

- Level assignment quality is bounded by the rule file: thresholds for scores, candidate rank and supporting data must be sensibly configured; defaults are a template that may need adjustment
- Levels are rule-derived estimates from annotation scores and rankings, not confirmatory evidence — true level 1 requires reference-standard confirmation beyond what the rules can infer from scores alone
- Isomers can be difficult or impossible to distinguish with MS, which limits the confidence distinguishable for isomeric candidates
