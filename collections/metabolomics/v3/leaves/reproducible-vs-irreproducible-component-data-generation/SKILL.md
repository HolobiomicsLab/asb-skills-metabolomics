# reproducible-vs-irreproducible-component-data-generation

## Summary

Generate simulated high-dimensional metabolomics datasets that mix a reproducible component and an irreproducible component according to a chosen proportion pi_1, mimicking BioTech-like bivariate Normal MS-Metabolomics settings, so that the MaRR maximal rank procedure's FDR control, power, and pi_1 bias can be benchmarked.

## When to use

Use when benchmarking a reproducibility method (e.g., MaRR) on synthetic data with a known ground-truth proportion of reproducible signals, under settings calibrated to real MS-Metabolomics replicate data.

## When NOT to use

- The goal is a comprehensive evaluation of pre-processing steps (imputation, normalization) rather than benchmarking reproducibility detection under known ground truth
- Real MS-Metabolomics data are available and the target is assessing actual reproducibility across technical or biological replicates rather than controlled simulation
- The analysis requires modeling dependence structures parametrically; MaRR and this simulation design are nonparametric in detection but the synthetic data generator itself assumes bivariate Normal components

## Inputs

- Simulation setting parameters: mu_R (3.89, 4.01, 4.13), rho_R (0.45, 0.99), pi_1 (0.2, 0.4, 0.75, 0.9), fixed mu_IR=3.2, sigma_R=0.17, sigma_IR=0.05
- Number of metabolites M=2860 and 1000 replicate datasets per setting
- MaRR functions sourced from 'source_MaRR.R' in the 'src' folder

## Outputs

- Simulated bivariate Normal datasets of M=2860 metabolites split into reproducible and irreproducible components according to pi_1
- Aggregated per-setting results saved as .Rdata objects (e.g., B1_sim_results.Rdata, C1_sim_results.Rdata, D4_sim_results.Rdata)
- Simulation plots generated by SIMPLOT_A45.R, SIMPLOT_A99.R and SIMPLOT_B.R

## How to apply

For each of the 24 Simulation I settings — mu_R in {3.89, 4.01, 4.13} x rho_R in {0.45, 0.99} x pi_1 in {0.2, 0.4, 0.75, 0.9}, with mu_IR=3.2, sigma_R=0.17 and sigma_IR=0.05 fixed — simulate 1000 datasets of M=2860 metabolites and split them into reproducible and irreproducible components according to pi_1. In R (>=4.0), source the MaRR functions from 'source_MaRR.R' in the 'src' folder of Ghoshlab/marr_paper_evaluations, then use the SIM_*.R scripts (e.g., SIM_B1.R, SIM_C1.R, SIM_D4.R in folders marr_code_A45, marr_code_A99, marr_code_B) to generate the per-setting R objects. The design uses gradual reduction in correlation between replicate pairs for less highly ranked signals, matching realistic MS-Metabolomics behavior. Save the aggregated results as .Rdata objects (e.g., B1_sim_results.Rdata, C1_sim_results.Rdata, D4_sim_results.Rdata) for downstream FDR, discriminative-power, and bias computation.

## Related tools

- **marr** (Nonparametric maximal rank reproducibility procedure applied to each simulated dataset to estimate the reproducible signal proportion, FDR, and discriminative power) — http://bioconductor.org/packages/marr
- **R** (Runtime environment (>=4.0) in which the simulation scripts, MaRR source functions, and result objects are executed and saved)
- **devtools** (Used to install MSPrep and dependency packages from GitHub for the surrounding simulation/real-data pipeline)

## Examples

```
Rscript -e "source('src/source_MaRR.R'); source('Simulations/marr_code_A45/SIM_B1.R')"  # generates B1_sim_results.Rdata
```

## Evaluation signals

- Across all 24 settings the empirical FDR at the nominal 0.05 level should be at or below 0.05
- Discriminative power (1-NDR, proportion of true reproducible features detected) should be near 100%, except at the smallest pi_1 values (e.g., 0.2)
- Bias (estimated minus true reproducible proportion pi_1) should lie within the narrow range (-0.05, 0.05)
- Each SIM_*.R script must produce the corresponding .Rdata object (B1_sim_results.Rdata, C1_sim_results.Rdata, D4_sim_results.Rdata) with results aggregated over 1000 replicates
- SIMPLOT_A45.R, SIMPLOT_A99.R and SIMPLOT_B.R must render plots for the 3 simulation designs without error

## Limitations

- True signals may fall in undetectable regions due to overlap between reproducible and irreproducible components; the real signals might fall in the undetectable regions because of overlapping between the reproducible and irreproducible components
- Power is reduced at smaller values of the proportion of reproducible metabolites (small pi_1)
- The design is a benchmark, not a comprehensive evaluation of pre-processing steps
