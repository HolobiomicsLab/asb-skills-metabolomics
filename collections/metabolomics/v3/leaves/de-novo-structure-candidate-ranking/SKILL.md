# de-novo-structure-candidate-ranking

## Summary

Orders validated and dereplicated de novo SMILES candidates generated by the MSNovelist encoder–decoder RNN, using the modified Platt fingerprint-match score against the CSI:FingerID-predicted query fingerprint (with raw decoder sequence probability as an ablation baseline), to select the top-1 structure per MS2 spectrum.

## When to use

Use when an encoder–decoder RNN has produced k candidate SMILES from a predicted molecular formula and structural fingerprint and you must re-rank them to pick the top-1 structure per MS2 query spectrum.

## When NOT to use

- No reliable formula/fingerprint prediction is available (SIRIUS formula error rates rise above 50% for individual spectra up to m/z 800), since ranking quality is bounded by these inputs
- Spectra are in negative ion mode — the model is trained only on positive-mode data and performance is expected to be lower
- The query spectrum has fewer than three fragment ions, below the minimum MSNovelist processes

## Inputs

- Query MS2 spectra (MGF, SIRIUS .ms, or a pre-processed SIRIUS 4.4.29 workspace)
- CSI:FingerID-predicted structural fingerprint xF for each spectrum
- k validated and dereplicated candidate SMILES per spectrum with decoder sequence probabilities
- Reference structures for the evaluation spectra (for top-1 / retrieval-rate computation)

## Outputs

- Per-spectrum ranked candidate list with score_mod_platt and rank_score_lim_mod_platt (decode-RUNID.csv / .pkl)
- Top-1 and overall retrieval rates on GNPS and GNPS-OK
- Median modified Platt score and median Tanimoto similarity of best incorrect de novo candidates (e.g. candidate_comparison.csv)

## How to apply

For each query MS2 spectrum, take the k validated and dereplicated candidate SMILES that the encoder–decoder RNN generated under the SIRIUS-predicted formula constraint from the CSI:FingerID-predicted fingerprint xF. Compute the match of each candidate's fingerprint to xF with the modified Platt score and sort candidates descending by score_mod_platt; the top-ranked candidate (rank_score_lim_mod_platt == 1) is the de novo prediction. For the score-only ablation, instead rank by the raw decoder sequence probability without the modified Platt re-ranking step, then compare top-ranked structures to references to obtain top-1 and overall retrieval rates (expected ablation rates: 19% on GNPS, 39% on GNPS-OK). As a quality check on incorrect top candidates, compute Tanimoto similarity (RDKit fingerprints) of the best incorrect de novo structure to the true structure and aggregate median modified Platt scores per candidate set.

## Related tools

- **MSNovelist** (Generates the k de novo candidate SMILES and stores score_mod_platt / rank_score_lim_mod_platt used for ranking) — https://github.com/meowcat/MSNovelist
- **CSI:FingerID** (Provides the predicted query fingerprint xF and the modified Platt score used to re-rank candidates)
- **SIRIUS** (Predicts the molecular formula that constrains candidate generation; MSNovelist is now integrated into SIRIUS 6) — https://bio.informatik.uni-jena.de/software/sirius/

## Examples

```
docker run --init -v "$(pwd)":/msnovelist-data msnovelist predict.sh 377.mgf
```

## Evaluation signals

- Full pipeline reproduces reported GNPS performance: correct structure ranked first for 25% and retrieved for 45% of the 3,863 spectra; CASMI 2016: 26% first-rank, 57% retrieved
- Raw-probability ablation reproduces top-1 of 19% on GNPS and 39% on GNPS-OK, with best RNN-alone candidates at median modified Platt score −5,910 and median Tanimoto similarity 0.74
- Results file is ordered by score_mod_platt descending and the selected top candidate satisfies rank_score_lim_mod_platt == 1
- Best incorrect de novo candidates reach median Tanimoto similarity 0.80, versus 0.76 for best-in-training-set and 0.84 for best incorrect database candidate, with median Platt scores −5,886 / −5,883 / −5,928
- Fingerprint-blind control (naïve generation) should drop to 17% ranked first and 31% retrieved, confirming the fingerprint input drives ranking quality

## Limitations

- Ranking by raw decoder sequence probability instead of the modified Platt score sharply reduces top-1 accuracy (19% vs 25% on GNPS), so skipping re-ranking sacrifices performance
- Certain isomers fragment almost indistinguishably, so structural elucidation is not possible in all cases and top-1 ranking may be inherently ambiguous
- Model may be unable to discover chemistry very different from known molecules, limiting ranking of truly novel structures
