# empirical-compound-annotation

## Summary

Annotates empirical compounds (empCpds) in the pcpfm/metDataModel pipeline by matching mapped experimental MS2 spectra against reference tandem MS libraries (default MoNA, or custom .msp files) using matchms, assigning Level 2 similarity-based compound identifications.

## When to use

Use when an empCpd JSON from a pcpfm experiment has experimental MS2 spectra mapped to features (e.g. moniker 'MS2_mapped') and Level 2 spectral-library annotations are needed against MoNA or user .msp libraries.

## When NOT to use

- Only MS1-based annotation is needed from an authentic compound library or public database (HMDB, LIPID MAPS) — that is the separate MS1 annotation step, not matchms-based Level 2 MS2 annotation
- The empirical compounds have not yet been generated by khipu pre-annotation, or experimental MS2 spectra have not been mapped to features (pre-map_ms2 stage)
- The goal is Level 1 annotation by authentic standards rather than library-similarity (Level 2) matches

## Inputs

- Empirical compound JSON with mapped experimental MS2 spectra (e.g. pcpfm moniker 'MS2_mapped') from the map_ms2 step
- Reference MS2 spectral library files (.msp), e.g. MoNA Orbitrap databases for positive and negative ionization modes downloaded via 'pcpfm download_extras'
- Parameters: --msp_files_pos, --msp_files_neg, --ms2_min_peaks, optional --ms2_similarity_metric

## Outputs

- Updated empCpd JSON (e.g. moniker 'MS2_MS1_annotated') with Level 2 annotations attached to empirical compounds
- Level 2 annotations linking each empCpd to a best-matching reference MS2 library spectrum

## How to apply

Load the MS2-mapped empirical compound JSON produced by the map_ms2 step, then load the reference tandem MS libraries — either the MoNA Orbitrap databases fetched via 'pcpfm download_extras' or user-supplied .msp files, selecting separate files for positive and negative ionization via --msp_files_pos / --msp_files_neg. Run the pcpfm l2_annotate operation, which uses matchms to compute spectral similarity between each mapped experimental MS2 spectrum and library entries (with an interval tree optimization), searching only spectra passing the --ms2_min_peaks peak-count filter and honoring any --ms2_similarity_metric override. Best-matching library entries are attached to each empCpd as Level 2 annotations and the updated empCpd list is serialized as JSON under a new moniker such as 'MS2_MS1_annotated'. This follows the metDataModel convention that pre-annotation groups features into empirical compounds, and annotation then assigns compound identifications with confidence levels.

## Related tools

- **pcpfm** (Pipeline providing the l2_annotate operation that searches mapped empCpd MS2 spectra against reference libraries and writes updated empCpd JSON) — https://github.com/shuzhao-li-lab/PythonCentricPipelineForMetabolomics
- **MatchMS** (Computes spectral similarity between mapped experimental MS2 spectra and library entries (with interval tree optimization))
- **MetDataModel** (Defines the empCpd data structure and annotation-level conventions that the annotations are attached to) — https://github.com/shuzhao-li-lab/metDataModel
- **MoNA** (Default reference tandem MS spectral library (Orbitrap databases, positive and negative mode) used as the matchms search target)

## Examples

```
pcpfm download_extras
```

## Evaluation signals

- Output empCpd JSON exists and parses successfully under the expected moniker (e.g. 'MS2_MS1_annotated')
- Each reported Level 2 annotation corresponds to a reference MS2 spectrum match that met the --ms2_min_peaks minimum-peak-count requirement
- Each match satisfied the configured similarity criterion (--ms2_similarity_metric or matchms default)
- Matches were made against the ionization-mode-appropriate library file (positive vs negative via --msp_files_pos / --msp_files_neg)
- Annotations are attached at Level 2 (similarity to reference MS2), not conflated with Level 1 authentic-standard confirmations

## Limitations

- Library coverage limits annotation: only compounds present in MoNA (or supplied .msp files) can receive Level 2 matches
- Spectra below the --ms2_min_peaks peak-count threshold are not searched or matched
- Empirical compounds may be unresolved isomer mixtures, so Level 2 annotations carry uncertainty at the isomer level
- MoNA/HMDB-like resources are third-party downloads subject to license terms (e.g. HMDB non-commercial restriction) and must be fetched via 'pcpfm download_extras'
