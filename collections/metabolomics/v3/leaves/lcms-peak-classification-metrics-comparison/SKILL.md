# lcms-peak-classification-metrics-comparison

## Summary

Benchmark an image-based deep neural network against a peak-group-parameter logistic regression model for classifying LC-MS spectral peaks, using ROC/AUC, true positive rate, and false positive rate on independent Cohort 1 and Cohort 2 human plasma datasets.

## When to use

Use when evaluating whether a machine learning peak filter (deep neural network or logistic regression) removes false LC-MS peaks without losing true positives, by comparing ROC curves, AUC, TPR/FPR, and retained false peaks across training, test, and independent cohorts.

## When NOT to use

- When the input is already a filtered, high-confidence peak table that has no candidate false peaks to remove — the skill benchmarks a filtering classifier, not peak detection itself.
- When the data are not LC-MS metabolomics peak groups with raster-representable peak shapes — the neural network requires stacked raster images of peak shape (each row a sample, each pixel an intensity) rather than tabular features alone.
- When no independent validation cohort is available and only a single dataset is used — the skill's core value is cross-cohort reproducibility assessment, which requires a held-out cohort like Cohort 2 (N = 526).

## Inputs

- Trained image-based deep neural network model with score threshold 0.4725
- Peak lists generated by MZmine 2 under 'More Restrictive' and 'Less Restrictive' peak extraction parameters
- Manually reviewed peak labels: 1304 training, 740 calibration, 726 test examples (50% true, 50% false)
- Cohort 1 (N = 78) and Cohort 2 (N = 526) human plasma LC-MS metabolomics peak tables from https://doi.org/doi:10.25345/C5FD2F
- Peak group parameters (including medRelFWHM) for each extracted feature
- Stacked raster images representing each candidate peak (rows = samples, columns = time, pixel = intensity)

## Outputs

- ROC curve data with true positive rate, true negative rate, and AUC per model (DNN, logistic regression, Random Forest)
- Optimum score threshold (0.4725) with corresponding TPR (~0.945) and FPR (~0.04)
- Cohort 1 vs Cohort 2 comparison table (e.g., cohort_covariate_shift_analysis.csv) with per-parameter median and interquartile-range summaries
- List of retained false peaks on Cohort 2 with peak-group parameter distributions and raster image rows for manual inspection

## How to apply

Apply the trained model (image-based deep neural network scoring each peak group, or the 15-parameter logistic regression model selected via forward selection) to both training and test sets, then compute receiver operating characteristic curves by sweeping score threshold cutoffs to derive sensitivity and specificity at each point; for the neural network the article reports an optimum score threshold of 0.4725 corresponding to TPR ≈ 0.945 and FPR ≈ 0.04, yielding AUC 0.992 (training) and 0.988 (test). For the independent Cohort 2 dataset (N = 526), recompute metrics under the more restrictive settings (score threshold 0.4725, TPR ~0.945, FPR ~0.04) to confirm 98% true positive peak retention and >50% false peak reduction, and identify retained false peaks (peak splitting outside the window, shoulder or double peaks, spurious high background peaks, low signal-to-noise peaks) as evidence of covariate shift. Also compare against the Random Forest model trained on the original 59 peak group parameters and the logistic regression model using medRelFWHM as the most predictive parameter. Write results as a cohort comparison table (e.g., cohort_covariate_shift_analysis.csv) with median and interquartile-range fields per peak-group parameter.

## Evaluation signals

- Verify recomputed Cohort 2 metrics match the reported 98% true positive peak retention and >50% false peak reduction under more restrictive settings.
- Confirm ROC AUC values reproduce 0.992 (training) and 0.988 (test) for the image-based deep neural network.
- Check that the selected optimum score threshold is 0.4725 with TPR ≈ 0.945 and FPR ≈ 0.04.
- Ensure the output CSV contains one row per peak-group parameter with median and interquartile-range fields populated.
- Confirm the comparison includes the Random Forest model trained on the original 59 peak group parameters and the 15-parameter logistic regression model as alternative benchmarks.

## Limitations

- Retained false peaks on Cohort 2 were attributed to covariate shift — peak shapes differ slightly in this independent dataset relative to training datasets, so the model's metrics will degrade when the independent cohort's peak shape distribution shifts.
- Only 1304 manually reviewed peak examples (50% true, 50% false) were used for training, limiting the model's exposure to rare false peak shapes such as peak splitting outside the window, shoulder or double peaks, spurious high background peaks, and low signal-to-noise peaks.
- The deep neural network requires raster-image representation of peak shapes; the model cannot be applied directly to peak-group parameter tables without generating the stacked peak plot images.
