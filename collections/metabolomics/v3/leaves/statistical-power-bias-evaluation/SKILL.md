# statistical-power-bias-evaluation

## Summary

Simulation-based validation of the nonparametric MaRR (Maximum Rank Reproducibility) procedure, measuring empirical FDR at a 0.05 nominal level, discriminative power (1-NDR), and bias (estimated minus true reproducible-signal proportion) across hundreds of simulated MS-metabolomics-like replicate datasets.

## When to use

Use when evaluating whether a reproducibility-detection method (e.g., MaRR maximal rank statistic) controls FDR, achieves high power, and estimates the proportion of reproducible signals without bias under simulated replicate data.

## When NOT to use

- Analyzing real MS-metabolomics datasets (e.g., Tech, BioTech, Bio from Metabolomics Workbench PR000438/PR000907), where the true reproducible-signal proportion is unknown and bias cannot be computed — the paper adopts a more conservative approach there
- When the goal is a comprehensive evaluation of pre-processing pipelines (imputation/normalization) rather than benchmarking FDR/power/bias of the detection method
- When reproducible and irreproducible components lack separation (overlapping distributions), which limits signal detection and would confound power and bias estimates

## Inputs

- Simulated replicate-pair datasets of M=2860 metabolites with reproducible and irreproducible components split by pi_1 (1000 replicates per setting)
- Simulation design parameters: Simulation I (mu_R in {3.89,4.01,4.13}, rho_R in {0.45,0.99}, pi_1 in {0.2,0.4,0.75,0.9}, mu_IR=3.2, sigma_R=0.17, sigma_IR=0.05); Simulation II (pi_1 x r_0 in {0.4,0.6,0.99}, correlation decreasing linearly with rank)
- MaRR functions sourced from 'src/source_MaRR.R' in the Ghoshlab/marr_paper_evaluations repository

## Outputs

- Per-setting .Rdata result objects (e.g., B1_sim_results.Rdata, C1_sim_results.Rdata, D4_sim_results.Rdata)
- Aggregated empirical FDR, discriminative power (1-NDR), and bias (estimated minus true pi_1) per simulation setting
- FDR, power, and bias plots generated by SIMPLOT_A45.R, SIMPLOT_A99.R, and SIMPLOT_B.R (matching Figs. 3-4 and S6-S7 of the paper)

## How to apply

Source the MaRR functions from 'src/source_MaRR.R' in the marr_paper_evaluations repository, then run the SIM_B1.R ... SIM_D4.R scripts, which each simulate 1000 datasets of M=2860 metabolites split into reproducible and irreproducible components according to pi_1 (Simulation I: mu_R in {3.89, 4.01, 4.13} x rho_R in {0.45, 0.99} x pi_1 in {0.2, 0.4, 0.75, 0.9}, with mu_IR=3.2, sigma_R=0.17, sigma_IR=0.05; Simulation II: pi_1 in {0.2, 0.4, 0.75, 0.9} x r_0 in {0.4, 0.6, 0.99} with replicate-pair correlation decreasing linearly with rank). Apply the nonparametric MaRR maximal rank statistic to each simulated dataset to estimate the proportion of reproducible signals and detect reproducible features per sample pair at the nominal 0.05 significance level. Aggregate per-setting empirical FDR, power (1-NDR), and bias, saving each as the corresponding .Rdata object (e.g., B1_sim_results.Rdata ... D4_sim_results.Rdata), then generate FDR/power/bias plots with the SIMPLOT scripts (SIMPLOT_A45.R, SIMPLOT_A99.R, SIMPLOT_B.R).

## Related tools

- **marr** (Nonparametric maximal rank statistic applied to each simulated dataset to estimate the reproducibility-signal proportion and detect reproducible features at the 0.05 FDR level) — http://bioconductor.org/packages/marr
- **R** (Runtime (>=4.0) for executing the SIM_*.R simulation scripts, aggregating FDR/power/bias metrics, and saving .Rdata objects) — https://github.com/Ghoshlab/marr
- **marr_paper_evaluations** (Repository supplying source_MaRR.R functions, SIM_B1.R-SIM_D4.R scripts, and SIMPLOT plotting scripts for the simulation designs) — github.com/Ghoshlab/marr_paper_evaluations

## Examples

```
source('src/source_MaRR.R'); source('marr_code_A45/SIM_B1.R')  # yields B1_sim_results.Rdata
```

## Evaluation signals

- Empirical FDR is at or below the nominal 0.05 level across all 24 Simulation I settings and all 12 Simulation II settings (with conservative behavior when pi_1 is high and r_0 is low)
- Discriminative power (1-NDR) is near 100%, except at the smallest pi_1 values where power drops
- Bias (estimated minus true reproducible proportion) lies within (-0.05, 0.05) across settings, with the expected negative-bias pattern at low pi_1
- Each setting produces its expected .Rdata object (e.g., SIM_B1.R yields B1_sim_results.Rdata) and the SIMPLOT scripts regenerate figures matching Figs. 3-4 and S6-S7

## Limitations

- True signals may fall in undetectable regions due to overlap between the reproducible and irreproducible components
- Power is reduced for smaller values of the proportion of reproducible metabolites (pi_1)
- FDR can become conservative when pi_1 is high and r_0 is low in the gradual rank-correlation reduction design (Simulation II)

## Evidence

- [abstract] Bias definition and result: "Bias (i.e., the difference between the estimated and the true value of reproducible signal proportions) values for simulations are also close to zero"
