# dbscan-eps-minsamples-tuning

## Summary

Tune DBSCAN clustering parameters (eps and min_samples) to identify contaminant source 'fingerprint' feature clusters from dilution-series HRMS feature tables, using MSS's dm.ms_cluster with Z-score normalization and its eps_assess knee-plot helper.

## When to use

Use when a HRMS feature table from a dilution/mixing series (e.g., roadway runoff diluted into other water samples) must be grouped into fingerprint clusters, and you need principled eps and min_samples values rather than arbitrary DBSCAN defaults.

## When NOT to use

- The input is already a clustered or labeled feature table — clustering again would discard existing groupings
- The dataset is not a dilution/mixing series — eps/min_samples tuned on dilution behavior will not identify meaningful fingerprint clusters in ordinary sample sets
- Features have not been through MSS feature extraction/post-processing (peak width filter, replicated peak filter, background subtraction, data trimming) — poor-quality features will distort density structure and knee-plot readings

## Inputs

- Transposed pandas dataframe of pre-processed HRMS feature intensities from a dilution/mixing series (samples as rows, m/z features as columns)
- Roadway runoff dilution/mixing dataset (Peter et al.) from the mass-suite 'example_data' folder

## Outputs

- Per-feature DBSCAN cluster labels (e.g., fingerprint Cluster label = 0, N = 587)
- eps_assess knee plot supporting the chosen eps value
- Optional cluster report visualizing grouping of features per cluster

## How to apply

Transpose the pre-processed feature table into a pandas dataframe compatible with the MSS dm module so samples are rows and features are columns. Run dm.ms_cluster, which applies Z-score data normalization to the features prior to DBSCAN clustering by default. Choose min_samples from the number of features in the dataset and set eps via the knee plot generated by the MSS eps_assess function; for the packaged Peter et al. roadway runoff dilution/mixing example this converges to eps = 0.6 and min_samples = 10, yielding a fingerprint cluster (e.g., Cluster label = 0, N = 587) whose dilution behavior feeds the downstream dm.feature_model regression. Inspect the optional cluster report output to confirm the source-fingerprint cluster is coherent before using it for source tracking or apportionment; OPTICS is available in ms_cluster as an alternative if density structure is uneven.

## Related tools

- **Mass-Suite (MSS)** (Provides dm.ms_cluster (Z-score normalization + DBSCAN/OPTICS clustering) and eps_assess (knee-plot eps selection) used to tune and run the clustering) — https://github.com/XiminHu/mass-suite
- **Python** (Runtime environment; MSS requires pandas, numpy, scikit-learn, scipy, pymzml and plotly as major dependencies) — https://github.com/XiminHu/mass-suite

## Examples

```
from mss import dm; clusters = dm.ms_cluster(d_transpose, eps_assess=True, eps=0.6, min_samples=10)
```

## Evaluation signals

- The chosen eps is traceable to an eps_assess knee plot rather than picked arbitrarily, and min_samples is justified by the feature count
- Clustering on the packaged roadway runoff example with Z-score normalization recovers a single dominant fingerprint cluster (label = 0, N ≈ 587 features)
- The fingerprint cluster's members show monotonic dilution behavior consistent with the source series before being handed to dm.feature_model
- The optional cluster report groups roadway-runoff-associated features together rather than fragmenting them across many noise clusters (label -1)

## Limitations

- Parameter settings are dataset-dependent — the article's DEMO notes 'parameter settings would typically be different for each example', so eps = 0.6 / min_samples = 10 are example values, not defaults
- MSS's source apportionment tool optimization is still in development and not released, so tuned clustering feeds an evolving capability
- Users are strongly encouraged to understand DBSCAN's limitations and assumptions to avoid misinterpretation; the article does not enumerate them explicitly
