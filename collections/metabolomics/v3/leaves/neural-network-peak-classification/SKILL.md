# neural-network-peak-classification

## Summary

An image-based deep neural network (EDML_deep_learning2.py) that classifies each MZmine 2 peak group as true or false by scoring stacked, rasterised LC-MS peak plots, enabling removal of up to ~90% of false peaks from nontargeted LC-MS metabolomics data without substantially reducing true positive signals.

## When to use

Use when you have non-filtered MZmine 2 peak lists from nontargeted LC-MS data (e.g. HILIC plasma metabolomics) and need to filter false spectral peaks while preserving true positive features, beyond what centWave or local minimum search quality filters achieve.

## When NOT to use

- When peaks have already been classified and filtered (e.g. you have a final curated feature table) — reapplying the DNN would be redundant
- When the input is not peak-level LC-MS data from MZmine 2-style peak detection (e.g. already-summarized feature abundances or MS/MS spectra), since the model consumes rasterized stacked peak plots, not raw spectra or aggregated intensities
- When computational simplicity is preferred and peak group parameters (e.g. medRelFWHM) suffice — the logistic regression or Random Forest alternative on 15 or 59 peak group parameters may be adequate

## Inputs

- Non-filtered peak lists generated by MZmine 2 (v2.14) under 'More Restrictive' or 'Less Restrictive' peak extraction settings
- Raw nontargeted HILIC LC-MS datasets (e.g. human plasma Cohort 1 [N = 78] and Cohort 2 [N = 526]) downloaded from https://doi.org/doi:10.25345/C5FD2F
- Per-peak sample intensity matrices for the 63 most intense samples per feature (used to build raster images)

## Outputs

- Per-peak-group probability score of being a true peak from the image-based deep neural network
- Filtered peak list retaining peaks with score above the 0.4725 threshold
- Filter performance summary (true positive retention, false peak removal fraction) compared against unfiltered lists

## How to apply

Extract raw LC-MS data with MZmine 2 (v2.14) using 'More Restrictive' or 'Less Restrictive' peak extraction parameters to obtain non-filtered peak lists. For each extracted feature, generate stacked peak plots using peak information from the 63 samples in which the candidate peak was most intense, and convert the peak shape information into a raster image (rows = individual samples, columns = time points, pixel value = intensity). Run EDML_deep_learning2.py to train or apply the image-based deep neural network, which assigns each peak group a probability score of being a true peak; apply the optimum operating point score threshold of 0.4725 (corresponding to ~0.945 true positive rate and ~0.04 false positive rate). Retain peaks with score above threshold to produce a filtered peak list. As an independent alternative, classify peak groups with a multiple logistic regression model built via forward selection on 15 peak group parameters (medRelFWHM being the most predictive), or a Random Forest model trained on the original 59 peak group parameters, comparing filtered versus unfiltered lists to quantify false-peak removal and true-positive retention.

## Related tools

- **MZmine 2** (Extracts raw LC-MS data under 'More Restrictive'/'Less Restrictive' settings to generate the non-filtered peak lists that are the input to peak classification)
- **EDML_deep_learning2.py** (Trains and applies the image-based deep neural network that assigns each peak group a probability score of being a true peak) — https://github.com/JainLab/Manuscript-DNNs-for-Classification-of-LCMS-Peaks
- **custom R scripts** (Implement the multiple logistic regression and Random Forest peak-group-parameter filtering models as an alternative/companion to the DNN)

## Examples

```
python EDML_deep_learning2.py --input <mzmine_peak_list> --threshold 0.4725
```

## Evaluation signals

- Filtered peak list should retain ≥98% of true positive peaks under more restrictive settings while reducing false peak detection by >50%
- On the less restrictive MZmine 2 settings with ~75% false positive proportion, the DNN should remove up to ~90% of false peaks with minimal reduction in true positives
- Model performance: ROC AUC should be ~0.992 on training and ~0.988 on test sets
- Applying the optimum score threshold 0.4725 should yield ~0.945 true positive rate and ~0.04 false positive rate
- The peak group parameter multiple logistic regression model should retain ~80% of true peaks while removing ~66% of false peaks on Cohort 2 data

## Limitations

- Requires manually reviewed peak examples for training (e.g. 1304 training, 740 calibration, and 726 test examples from Cohort 1, with 50% true and 50% false peaks)
- The optimum operating point (0.4725) and reported removal percentages are derived from the specific HILIC LC-MS datasets; transfer to other chromatography or instrument types may require recalibration
- The image-based DNN is applied to peak groups already detected by MZmine 2; it does not perform peak detection itself and cannot recover peaks absent from the non-filtered list
