# gnps2-molecular-networking-execution

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Submits cleaned pseudo MS/MS spectra (from ms1-id) to the GNPS2 classical molecular networking workflow (version 2024.09.20) to cluster features into related-metabolite subnetworks, using edges defined by modified cosine similarity ≥ 0.8 with ≥ 6 matched peaks so annotations propagate across structurally related features.

## When to use

Use when you have pseudo MS/MS spectra in MGF format generated from MS1-only data (e.g., ms1-id annotations of HILIC-positive LC-MS) and want a molecular network with propagated structural annotations.

## When NOT to use

- The data already contain genuine MS/MS scans acquired by fragmentation — standard MS/MS-based molecular networking is the appropriate route instead of pseudo MS/MS-based networking.
- The pseudo MS/MS spectra still contain ions above each feature's m/z and you intend to skip cleaning — modified cosine cannot be computed correctly on such uncleaned spectra.

## Inputs

- Pseudo MS/MS spectra generated by ms1-id from MS1-only LC-MS data (e.g., Metabolomics Workbench PR000639 IBD HILIC-positive mode)
- Feature precursor m/z values for each metabolic feature (needed for the peak-cleaning step)
- Single MGF file of cleaned pseudo MS/MS spectra (e.g., ibd_hilicpos_cleaned_pseudo_msms.mgf)

## Outputs

- GNPS2 molecular network with edges built under modified cosine ≥ 0.8 and matched peaks ≥ 6
- Network edges table saved as molecular_network_edges.tsv
- Subnetworks of annotated related metabolites with propagated annotations (e.g., tyrosine-related N-acyl amide subnetwork)

## How to apply

First clean each metabolic feature's pseudo MS/MS by removing all ions with m/z larger than the feature's precursor m/z, because modified cosine calculations require fragments at or below the precursor. Write the cleaned spectra into a single MGF file (e.g., ibd_hilicpos_cleaned_pseudo_msms.mgf) and submit it to the GNPS2 classical molecular networking workflow (version 2024.09.20). Configure networking with a minimum modified cosine of 0.8 and a minimum of 6 matched peaks per edge; these thresholds were the criteria used in the paper's IBD HILIC-positive job. Retrieve the GNPS2 job output and save the network edges table (e.g., molecular_network_edges.tsv). The rationale is that edges under these criteria propagate level 2/3 ms1-id annotations across related metabolites — e.g., the IBD HILIC-positive network revealed a tyrosine-related subnetwork containing N-acyl amides with altered levels in non-IBD vs CD/UC comparisons.

## Related tools

- **GNPS2** (Hosts the classical molecular networking workflow (version 2024.09.20) that computes modified cosine edges and clusters the cleaned pseudo MS/MS MGF into a molecular network) — https://gnps2.org
- **ms1-id** (Upstream generator of the pseudo MS/MS spectra (MGF) from MS1-only LC-MS data that serve as the network's input spectra) — https://github.com/Philipbear/ms1_id

## Evaluation signals

- The cleaned MGF contains only peaks at or below each feature's precursor m/z (no ions larger than the feature m/z survive cleaning).
- The GNPS2 job completes and its edges are built under the modified cosine ≥ 0.8 and matched-peaks ≥ 6 criteria, reproducible against the paper's reference job (https://gnps2.org/status?task=670aa34a07544a5cbbd1f1d40605f50f).
- The retrieved edges table (molecular_network_edges.tsv) is populated and can be used to trace subnetworks such as the tyrosine-related N-acyl amide cluster in the IBD HILIC-positive mode.
- Annotations propagate between connected features via the modified cosine-based MS/MS similarity edges, i.e., related features in a subnetwork share structurally consistent annotations.

## Limitations

- Modified cosine is only computable after removing all ions larger than the feature's m/z from each pseudo MS/MS — skipping this step blocks edge construction.
- Edge thresholds (modified cosine ≥ 0.8, matched peaks ≥ 6) are the paper's specific choices for the IBD HILIC-positive job; other datasets may need re-tuning.
- Network quality is bounded by the quality of the underlying pseudo MS/MS spectra (composite spectra assembled from in-source fragments of MS1-only data), which are lower-energy than typical reference MS/MS.
