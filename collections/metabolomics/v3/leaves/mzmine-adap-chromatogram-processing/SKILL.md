# mzmine-adap-chromatogram-processing

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Reconstructs the PharmMet DB peak-detection stage: raw LC-HRMS files (Thermo Orbitrap ID-X, HILIC/positive-ESI and C18/negative-ESI) are processed per-sample in MZmine 2.53 with the ADAP chromatogram builder to yield m/z, retention-time, and intensity feature lists for 0-hour vs 24-hour drug-metabolite differential detection.

## When to use

Use when raw LC-HRMS files from the PharmMet DB study (Metabolomics Workbench ST003991) must be converted into MS1-derived m/z/RT feature tables to support 0-hour vs 24-hour drug-metabolite feature detection.

## When NOT to use

- Input is already an exported peak/feature table — the ADAP chromatogram builder stage is only needed on raw vendor/LC-HRMS files
- The goal is MS2-based structural elucidation of metabolites — this skill produces MS1-level m/z/RT features only; spectral annotation comes from the downstream 0-h vs 24-h differential analysis and BioTransformer ±5 ppm cross-referencing
- Data were not acquired with the study's dual-column, dual-ESI Orbitrap ID-X setup and no paired 0-hour/24-hour design exists, since the feature lists are meant for pre/postincubation differential comparison

## Inputs

- Raw LC-HRMS data files from Study ST003991 (Metabolomics Workbench, Project DOI 10.21228/M8W55K), acquired on a Thermo Vanquish UHPLC coupled to an Orbitrap ID-X Tribrid mass spectrometer
- Paired 0-hour (preincubation) and 24-hour (postincubation) human liver S9 incubation samples for each therapeutic drug, from HILIC/positive-ESI and C18/negative-ESI platforms

## Outputs

- Per-sample feature list of m/z and retention-time values detected from MS1 spectra
- Tab-separated peak table with m/z, RT, and peak intensities per sample for both 0-hour and 24-hour samples of each drug incubation

## How to apply

Download the raw LC-HRMS files for Study ST003991 (Project DOI 10.21228/M8W55K), covering the HILIC/positive-ESI and C18/negative-ESI platforms, and import them into MZmine 2.53. Build chromatograms with the ADAP chromatogram builder module, processing each sample independently, using the MS1 spectra acquired at 60,000 resolution over m/z 100–1000. Detect m/z features with retention times separately for each 0-hour (preincubation) and 24-hour (postincubation) incubation sample. Export the feature list (m/z, RT, per-sample peak intensities) as a tab-separated peak table; these tables feed downstream candidate drug-metabolite feature detection by comparing MS1 and RT between 0-hour and 24-hour samples, with curation cross-referencing detected signals at ±5 ppm against BioTransformer 3.0 predictions.

## Related tools

- **MZmine 2.53** (Processes each raw LC-HRMS file independently with the ADAP chromatogram builder module to build chromatograms and detect m/z/RT features from MS1 spectral data)
- **Thermo Scientific Orbitrap ID-X Tribrid mass spectrometer** (Instrument that generated the raw MS1 (60,000 resolution, m/z 100–1000) and MS2 (15,000 resolution, HCD 35%) spectra processed at this stage)

## Evaluation signals

- Exported peak table exists and contains explicit m/z and retention-time columns
- Peak table includes entries for both the 0-hour and 24-hour samples of each drug incubation
- Chromatograms were built per-sample (each sample processed independently), not batch-collapsed at this stage
- Feature m/z values fall within the acquired MS1 scan range of 100–1000 m/z and are consistent with the ±5 ppm tolerance used in downstream BioTransformer cross-referencing
- Feature lists are separable by platform (HILIC/positive-ESI vs C18/negative-ESI) so that 0-h vs 24-h comparisons can be run per column/ESI mode

## Limitations

- Reliance on the liver S9 fraction means metabolites formed by enzymes not abundant or active in that fraction, or generated extrahepatically (e.g. intestine, kidney), are absent from the resulting feature space
- Limited detection of some metabolites may have occurred due to limited cofactor availability or ionization suppression
- MS1-level features alone do not confirm structure; candidate metabolites require downstream 0-h vs 24-h differential comparison and ±5 ppm cross-referencing with BioTransformer predictions
