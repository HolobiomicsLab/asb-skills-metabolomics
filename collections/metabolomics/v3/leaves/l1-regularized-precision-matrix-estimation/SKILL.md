# l1-regularized-precision-matrix-estimation

## Summary

Estimate a sparse inverse covariance (precision) matrix among metabolite features using the graphical lasso with cross-validated L1 regularization, then derive an edge list of partial correlations. This is the GLASSO step of the MetaboLINK pipeline applied to NMR metabolomics of hESC-derived neural cell populations.

## When to use

Use when a normalized metabolite-by-sample concentration table must be converted into a conditional-dependence network, and sparse structure (zeroed metabolite pairs) plus both positive and negative partial correlations are required.

## When NOT to use

- Input data has not been mean- and stddev-normalized; the MetaboLINK GLASSO fit assumes the normalized table produced by the PCA-preprocessing step.
- The goal is to identify cell-type-specific sub-networks directly from raw concentrations; MetaboLINK first combines PCA loadings with GLASSO, so raw-table clustering without the PCA layer deviates from the method.
- A dense covariance or correlation analysis (no sparsity) is desired — L1 regularization intentionally zeroes out metabolite pairs with no conditional dependence.

## Inputs

- mean- and stddev-normalized metabolite concentration table (n = 90 small molecules across five neural cell populations)
- choice of regularization-selection strategy (cross-validation via GraphLassoCV)
- maximum iteration count (250)

## Outputs

- sparse precision (inverse covariance) matrix (saved as glasso_precision_matrix.csv)
- edge list of positive and negative partial correlations between metabolites
- cross-validated regularization strength alpha (0.56 in this dataset)

## How to apply

Load the metabolite concentration table (here 90 small molecules quantified by 1H-NMR across five neural cell populations: hESCs, EBs, Rosettes, hNPCs, Neurons) and apply the mean- and stddev-normalization used in MetaboLINK before fitting. Fit GLASSO agnostic of cell type using sklearn.covariance.GraphLassoCV with default cross-validation settings and 250 iterations, letting cross-validation select the regularization strength alpha (reported value: 0.56). Extract the sparse precision (inverse covariance) matrix, in which L1 regularization zeroes out metabolite pairs with no conditional dependence. Convert the precision matrix into an edge list of partial correlations, retaining both positive and negative partial correlations as edges and leaving features with no edges out of the graph. Save the precision matrix and edge list (e.g. glasso_precision_matrix.csv); the graph can subsequently be overlaid with PCA scores per the pcaglasso package to identify significant sub-networks.

- **pcaglasso** (Python package that overlays graphs generated by GLASSO with PCA scores to identify significant sub-networks; hosts the MetaboLINK code.) — github.com/jlichtarge/pcaGLASSO

## Examples

```
from sklearn.covariance import GraphLassoCV; model = GraphLassoCV(max_iter=250); model.fit(X_normalized); P = model.precision_; alpha = model.alpha_
```

## Evaluation signals

- Confirm the cross-validated regularization strength equals alpha = 0.56 as reported for this dataset.
- Verify the precision matrix is sparse: many off-diagonal entries are exactly zero due to L1 regularization.
- Check that the edge list contains both positive and negative partial-correlation values.
- Confirm features with no edges are absent from the final graph rather than plotted as isolated nodes.
- Verify the fit used 250 iterations and default GraphLassoCV cross-validation settings, and that the output precision matrix CSV has the same dimensions as the number of metabolites.

## Limitations

- Regularization strength alpha is data-dependent (0.56 here); it must be re-selected by cross-validation rather than assumed for other datasets.
