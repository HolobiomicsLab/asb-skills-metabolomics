# pseudo-msms-spectrum-cleaning

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Cleans pseudo MS/MS spectra reconstructed from MS1-only data by removing all fragment ions with m/z larger than the metabolic feature's precursor m/z, so that modified cosine-based spectral similarity calculations (e.g. GNPS2 molecular networking) become possible.

## When to use

Use when pseudo MS/MS spectra generated by ms1-id from MS1-only LC-MS data contain extra ion forms above the feature's precursor m/z and must be prepared for modified cosine molecular networking or library matching.

## When NOT to use

- When the target is ms1-id's precursor-tolerant reverse spectral search against reference MS/MS libraries — that search tolerates extra ion forms (adducts, multimers, contaminants) and discards unmatched query peaks, so aggressive cleaning is unnecessary
- When input is real MS/MS (MS2) spectra, whose fragments are inherently below the precursor and need no precursor-m/z filtering

## Inputs

- Pseudo MS/MS spectra in MGF format generated by ms1-id from MS1-only LC-MS data (e.g. IBD HILIC positive mode, PR000639)
- Metabolic feature table with precursor m/z values for each feature

## Outputs

- Cleaned pseudo MS/MS spectra in a single MGF file (e.g. ibd_hilicpos_cleaned_pseudo_msms.mgf) containing only peaks at or below each feature's precursor m/z
- GNPS2 molecular network edges table (e.g. molecular_network_edges.tsv) built under modified cosine >= 0.8 and matched-peaks >= 6 criteria

## How to apply

Start from the pseudo MS/MS spectra produced by ms1-id's correlation-based feature clustering (e.g. from the IBD cohort HILIC-positive LC-MS data, Metabolomics Workbench PR000639). For each metabolic feature's pseudo MS/MS spectrum, remove all ions whose m/z exceeds that feature's precursor m/z, since modified cosine cannot handle query peaks above the precursor. Optionally also exclude isotope peaks (determined by MassCube) during pseudo MS/MS generation before this cleaning step. Write the cleaned spectra into a single MGF file (e.g. ibd_hilicpos_cleaned_pseudo_msms.mgf). Submit the cleaned MGF to the GNPS2 classical molecular networking workflow (version 2024.09.20) using edges built with minimum modified cosine 0.8 and minimum 6 matched peaks. Validate that every peak in the cleaned MGF is at or below the corresponding feature's precursor m/z.

## Related tools

- **ms1-id** (Generates the pseudo MS/MS spectra from MS1-only data that are then cleaned by removing ions above the feature m/z; source code and indexed GNPS libraries (July 17, 2024 version) available on GitHub) — https://github.com/Philipbear/ms1_id
- **GNPS2** (Classical molecular networking workflow (version 2024.09.20) that consumes the cleaned MGF and builds edges via modified cosine similarity)
- **MassCube** (Used upstream to flag isotope peaks, which are excluded from pseudo MS/MS generation before cleaning)

## Examples

```
ms1_id annotate --input_file ibd_hilicpos_cleaned_pseudo_msms.mgf --libs db/gnps.pkl db/gnps_k10.pkl --min_score 0.7 --min_matched_peak 3
```

## Evaluation signals

- The cleaned MGF contains only peaks at or below each feature's precursor m/z — no fragment ion exceeds its feature's m/z
- The GNPS2 job completes and produces network edges built under modified cosine >= 0.8 and matched-peaks >= 6 criteria
- A biologically coherent subnetwork is recovered, e.g. the tyrosine-related subnetwork containing N-acyl amides with altered levels in non-IBD vs CD/UC comparisons
- The output MGF preserves the association between each pseudo MS/MS spectrum and its originating metabolic feature (precursor m/z and retention time intact)

## Limitations

- Cleaning removes adduct, multimer, and co-eluting contaminant peaks above the precursor m/z; this enables modified cosine networking but discards ion-form information that the precursor-tolerant reverse search of ms1-id can exploit
- The molecular networking analysis was specific to LC-MS pseudo MS/MS; the article's networking cleaning procedure (removing ions larger than feature m/z) is described for metabolic features, not for MS imaging pseudo spectra
