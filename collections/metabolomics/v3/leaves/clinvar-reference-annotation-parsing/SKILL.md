# clinvar-reference-annotation-parsing

## Summary

Builds a ClinVar-derived reference annotation set (HGVSc, HGVSp, and predicted coding impact strings) from high-review-status (two-star) ClinVar variants, then string-matches tool-reported HGVS annotations against it to compute concordance rates and per-tool match fractions.

## When to use

Use when you need a trusted ClinVar reference set of HGVSc/HGVSp and coding-impact strings (e.g., 164,549 two-star variants) to benchmark HGVS output from annotation tools like ANNOVAR, SnpEff, or VEP.

## When NOT to use

- When the goal is to annotate novel variants de novo rather than benchmark tool output against a ClinVar-derived reference set
- When ClinVar annotations are taken from ClinVar web pages rather than the VCF, since inconsistencies exist between ClinVar web pages and its VCF
- When the analysis targets low-review-status ClinVar entries, which are not the curated high-review (two-star) reference population used to validate this skill

## Inputs

- ClinVar VCF (downloaded release, filtered to two-star / high review status variants; 164,549 variants in the reference study)
- Per-tool annotation records (HGVSc, HGVSp, and predicted coding impact strings from ANNOVAR, SnpEff, and VEP outputs for the same variants)
- Normalized VCF representation of variants for type classification (SNV, Ins, Del, Indel, MS, Dup, Inv)

## Outputs

- Per-variant match/mismatch tally of tool-reported HGVSc and HGVSp against ClinVar-deposited HGVS strings
- Overall concordance rates (reference values: 58.52% HGVSc, 84.04% HGVSp, 85.58% coding impact) and per-tool match fractions (e.g., SnpEff 0.988 HGVSc, ANNOVAR 0.753 HGVSc)
- variant_type_concordance.csv with columns for tool, variant type, annotation field, n variants, and concordance rate

## How to apply

Download the ClinVar VCF and filter to the high-review-status (two-star) variants (164,549 in the reference study), then parse the ClinVar-deposited HGVS nomenclature and coding impact strings per variant. Phase and normalize multi-nucleotide variants in the VCF so repeat-shifted alleles are grouped consistently, since VCFs generated by different callers shift nucleotide repeats left or right relative to the transcript, producing inconsistent HGVS notation. For each variant, string-match the tool-reported HGVSc and HGVSp from ANNOVAR, SnpEff, and VEP (run with the same reference genome and transcript annotations) against the ClinVar-deposited HGVS strings and tally matches and mismatches. Compute overall concordance rates and per-tool match fractions; optionally stratify by variant type (SNV, Del, Dup, Indel, Ins, Inv, MS) with pandas groupby aggregation. Restricting transcripts to ClinVar-selected ones improves agreement, but expect residual discrepancies because some ClinVar HGVS syntax does not adhere to HGVS recommendations.

## Related tools

- **ClinVar** (Source of the reference HGVSc/HGVSp and coding impact annotations for the filtered two-star variant set)
- **ANNOVAR** (Provides tool-reported HGVSc/HGVSp annotations to be string-matched against the ClinVar reference strings)
- **SnpEff** (Provides tool-reported HGVSc/HGVSp annotations to be string-matched against the ClinVar reference strings)
- **Variant Effect Predictor (VEP)** (Provides tool-reported HGVSc/HGVSp annotations (run with --per_gene and --coding_only to streamline relevant transcripts) matched against the ClinVar reference strings)

## Examples

```
df.groupby(["tool","variant_type","annotation_field"]).agg(n=("match","size"), concordance=("match","mean")).to_csv("variant_type_concordance.csv")
```

## Evaluation signals

- Overall HGVSc agreement equals 58.52% and HGVSp agreement equals 84.04% within rounding tolerance
- Per-tool match fractions reproduce reported values: SnpEff 0.988 HGVSc, ANNOVAR 0.753 HGVSc, and VEP highest for HGVSp (0.977 in the abstract; 0.991 in the workflow card)
- Variant count after filtering equals 164,549 two-star ClinVar variants
- Stratified results show SNV as the most consistent variant-type category and MS among the least consistent, with Ins/Del/Indel near 0.995 for SnpEff and VEP
- variant_type_concordance.csv contains exactly the columns tool, variant type, annotation field, n variants, and concordance rate

## Limitations

- Some HGVS syntax in ClinVar does not adhere to HGVS recommendations (Tables S3 and S4), inflating apparent mismatches
- Discrepancies with ClinVar persisted even after restricting transcripts to ClinVar-selected ones
- Inconsistencies exist between ClinVar web pages and its VCF, so the reference strings depend on which ClinVar representation is parsed
- Multi-nucleotide variants must be phased and normalized; repeat-shifted alleles grouped inconsistently will spuriously lower concordance
