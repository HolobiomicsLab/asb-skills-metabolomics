# ASB Skills: metabolomics

Evidence-grounded skill and software-tool collections for metabolomics, generated by the
[AgenticScienceBuilder](https://github.com/HolobiomicsLab/AgenticScienceBuilder) (ASB) pipeline
and released by the Holobiomics Lab. Each skill is distilled from a peer-reviewed method paper and its
public code repository, anchored to verbatim evidence, EDAM-annotated, and gated for licensing and
PII before release.

This repository holds the metabolomics collections only. The registry of every domain, the tooling,
the governance documents and the community contribution loop live in
[asb-skill-collections](https://github.com/HolobiomicsLab/asb-skill-collections).

Per-technique packs under `packs/metabolomics/`: `ce-ms`, `direct-infusion`, `gc-ms`, `ion-mobility`, `lc-ms`, `ms-generic`, `ms-imaging`, `nmr`.

The tree shape is the one every ASB consumer resolves (`collections/<domain>/<version>/`,
`packs/<domain>/<technique>/`), so the shared tooling works unchanged on this repository.

## Install

Claude Code, from a local checkout (the route verified in the collection's `USAGE.md`):

```bash
git clone https://github.com/HolobiomicsLab/asb-skills-metabolomics.git
claude plugin marketplace add ./asb-skills-metabolomics
claude plugin install metabolomics@asb-skills-metabolomics
```
